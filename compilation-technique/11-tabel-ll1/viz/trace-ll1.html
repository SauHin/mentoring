Trace parser LL(1)

Visualisasi ini menjalankan parser LL(1) pada sebuah string: setiap baris melihat top stack dan input sekarang, lalu memilih satu aksi. Parse tree tumbuh setiap kali sebuah variabel diganti.

Coba: pilih contoh atau ketik string di kolom String, lalu klik Langkah berikutnya. Untuk string yang salah, pilih Panic mode supaya parser tidak langsung berhenti.

Perhatikan: stack ditulis dengan top di kiri. Variabel di top diganti isi sel M[top, input] yang oranye, terminal di top harus sama dengan input. String accepted hanya kalau stack dan input sama-sama tinggal $.

Ubah grammar

Satu baris per variabel: E' → +TE' | ε. Baris pertama = start symbol. Grammar harus LL(1) (tidak ada conflict). Kalau terminal lebih dari satu huruf selain id, pisahkan semua simbol dengan spasi, termasuk di string.

Trace baris yang disorot = langkah sekarang
Parsing table M oranye = sel yang dibaca
Parse tree oranye = simbol di top stack
