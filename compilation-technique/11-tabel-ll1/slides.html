Target: kamu bisa mengisi parsing table, menjalankan trace stack, menentukan apakah grammar LL(1), dan menjalankan panic-mode error recovery.

Notes 1️⃣ · Parser LL(1)

Parser LL(1) hanya butuh input, stack, dan parsing table

LL(1) parser: predictive parser tanpa rekursi. Input dibaca dari Left, menghasilkan Leftmost derivation, dengan 1 token lookahead.

  • Input diakhiri $.
  • Stack awalnya $ di dasar dan start symbol di atasnya. Stack menggantikan rekursi.
  • Sel kosong di tabel berarti error.

Notes 2️⃣ · Mengisi tabel

A → α ditulis di kolom FIRST(α), dan kalau α bisa ε, di kolom FOLLOW(A)

Proses produksi satu per satu. Contoh slide: S → aBa, B → bB | ε, dengan FOLLOW(B) = {a}.

  1. Untuk setiap a di FIRST(α): tulis di M[A, a].
  2. Kalau ε di FIRST(α): tulis di M[A, b] untuk setiap b di FOLLOW(A), termasuk $.
  3. Sel kosong = error.
Mab$
SS → aBa
BB → εB → bB

B → ε masuk kolom a karena FOLLOW(B) = {a}. Tidak ada kolom ε.

Notes 3️⃣ · Aksi parser

Top stack X dan input a menentukan aksi: pop kalau sama, ganti X dengan M[X, a] kalau variabel

Empat kemungkinan, dicek dari atas. Top stack ditulis di kiri, seperti trace di slide dosen.

KeadaanAksi

Notes 6️⃣ · Bukan LL(1)

M[E, e] berisi dua produksi, jadi grammar S → iCtSE bukan LL(1)

LL(1) grammar: tidak ada sel berisi lebih dari satu produksi (conflict). Contoh slide: S → iCtSE | a, E → eS | ε, C → b.

Mabeit$
SS → aS → iCtSE
EE → eS
E → ε		E → ε
CC → b
  • Penyebab: e ada di FIRST(eS) dan di FOLLOW(E) = {e, $}. Dengan i = if, t = then, e = else, ini dangling else: else bisa milik if mana pun (ambiguous).
  • Perbaikan: hapus left recursion, left factoring. Kalau masih conflict, grammar bukan LL(1).

Notes 7️⃣ · Syarat LL(1)

Left recursive, belum left factoring, atau ambiguous pasti bukan LL(1)

Syarat lengkap untuk setiap dua produksi A → α | β. Cukup satu yang dilanggar untuk membuat conflict.

  1. FIRST(α) dan FIRST(β) tidak beririsan.
  2. Paling banyak satu dari α dan β yang nullable.
  3. Kalau β nullable: FIRST(α) tidak beririsan dengan FOLLOW(A).
TandaSyarat yang dilanggar
A → Aα | β1: FIRST(β) ada di FIRST(Aα)
A → aβ₁ | aβ₂1: keduanya memuat a
E → eS | ε, e di FOLLOW(E)3: contoh dangling else

Template: "Grammar ini bukan LL(1), karena untuk A → α | β, terminal a ada di FIRST(α) dan di [FIRST(β) / FOLLOW(A)]."

Notes 8️⃣ · Panic mode

Panic mode membuang input sampai ketemu simbol di FOLLOW(A), lalu pop A

Panic mode: error recovery supaya parser bisa lanjut mencari error berikutnya. Contoh slide: S → AbS | e | ε, A → a | cAd, FOLLOW(A) = {b, d}.

  • Terminal tidak cocok: pop terminal itu, laporkan "missing …, inserted".

Ringkasan

Soal LL(1) biasanya berurutan: FIRST dan FOLLOW, tabel, lalu trace.

  • Tabel: A → α ke kolom FIRST(α). Kalau α nullable, juga ke kolom FOLLOW(A).
  • Trace: terminal di top dicocokkan, variabel di top diganti isi M[X, a] dengan push dibalik.
  • Hasil: accepted kalau stack dan input sama-sama $. Output = leftmost derivation.
  • LL(1)? Tidak ada sel berisi dua produksi. Panic mode memakai FOLLOW untuk melanjutkan setelah error.

Soal

Kerjakan, lalu cek di slide berikutnya atau di visualisasi.

  1. Buat parsing table untuk A → aBe | cBd | C, B → bB | ε, C → f.
  2. Apakah S → aS | a LL(1)? Kalau tidak, perbaiki.
  3. Latihan slide dosen: S → ABC, A → aA | C, B → b, C → c. Buat parsing table, lalu trace aabc.

Jawaban

Langkah lengkapnya ada di notes (nomor section di kurung).

  1. M[A, a] = A → aBe, M[A, c] = A → cBd, M[A, f] = A → C, M[B, b] = B → bB, M[B, d] = M[B, e] = B → ε, M[C, f] = C → f (2️⃣).
  2. Bukan: M[S, a] berisi dua produksi. Left factoring: S → aS', S' → S | ε (6️⃣).
  3. M[S, a] = M[S, c] = S → ABC, M[A, a] = A → aA, M[A, c] = A → C, M[B, b] = B → b, M[C, c] = C → c. Trace: setelah dua a, M[A, b] kosong, jadi rejected (4️⃣).
