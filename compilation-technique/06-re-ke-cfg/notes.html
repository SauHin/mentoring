Context-free grammar dan RE → CFG

Context-free grammar (CFG) menghasilkan string dengan mengganti variabel satu per satu. CFG lebih kuat dari RE, jadi setiap RE bisa ditulis ulang sebagai CFG dengan beberapa aturan sederhana.

Slide · Visualisasi: RE → CFG

TL;DR
  • G = (V, T, P, S): variabel, terminal, produksi A → α, start symbol.
  • RE → CFG: concatenation = ditulis berdampingan, union = alternatif |, star = variabel baru X → rX | ε.
  • Setiap star butuh variabel sendiri, supaya urutan bagian-bagian RE tetap terjaga.
  • L(G): tulis string terpendek, lalu cari produksi yang bisa diulang.

1. Definisi CFG

G = (V, T, P, S) dengan:

  • V: himpunan variabel (non-terminal), ditulis huruf besar.
  • T: himpunan terminal. V dan T tidak beririsan.
  • P: himpunan produksi A → α, dengan A ∈ V dan α ∈ (V ∪ T)*. Alternatif A → α₁, A → α₂ boleh ditulis A → α₁ | α₂.
  • S: start symbol, salah satu variabel.

Konvensi penulisan di slide: A, B, C, D, E, S = variabel. Huruf kecil dan digit = terminal. X, Y, Z = terminal atau variabel. u, v, w, x, y, z = string terminal. α, β, γ = sentential form (campuran variabel dan terminal).

CFG dipakai untuk mendefinisikan bahasa pemrograman (dalam notasi BNF), format dokumen seperti DTD di XML, dan ekspresi matematika. Mesin yang mengenali tepat semua context-free language adalah pushdown automaton (PDA).

2. Derivation dan language

αAβ ⇒ αγβ kalau ada produksi A → γ. ⇒* berarti nol langkah atau lebih. Language dari G:

L(G) = { w | w ∈ T* dan S ⇒* w }

L disebut context-free language kalau ada CFG G dengan L = L(G).

E → E+E | E*E | (E) | a | b | c | da, a+b, (a+b)*cekspresi aritmetika
Catatan slideSlide menulis P = {S → aAa, A → aAa, A → a}, tetapi derivation-nya menghasilkan aba. Supaya cocok dengan derivation itu, produksi terakhir seharusnya A → b. Dengan A → a, language-nya menjadi string a dengan panjang ganjil minimal 3.

3. Chomsky hierarchy

TypeGrammarMesinProduksi
0UnrestrictedTuring machineα → β
1Context-sensitiveLinear-bounded automatonα → β, |α| ≤ |β|
2Context-freePushdown automatonA → β, A ∈ V, β ∈ (V ∪ T)*
3RegularFinite automatonA → aB | a (right-linear) atau A → Ba | a (left-linear)

Setiap type mencakup type di bawahnya. Semua regular language juga context-free, tetapi {aⁿbⁿ} context-free dan tidak regular.

4. Aturan RE → CFG

REProduksi
∅S → S (S tidak pernah menghasilkan string terminal)
εS → ε
aS → a
a + bS → a | b
a.bS → ab
a*S → aS | ε
a⁺S → aS | a

Untuk RE yang lebih besar, pecah dari luar ke dalam:

  1. S mewakili seluruh RE.
  2. Concatenation r·s: tulis bentuk r lalu bentuk s berdampingan. String terminal ditulis langsung. Bagian berupa union atau star diganti variabel baru.
  3. Union r|s: setiap alternatif menjadi alternatif produksi.
  4. Star r*: variabel baru X dengan X → rX | ε. Kalau r = r₁|r₂, boleh langsung X → r₁X | r₂X | ε.
  5. Ulangi untuk setiap variabel baru. Terakhir, tulis V, T, P, S.

Contoh slide: (ab + ba)*(abb)*

Versi dosen:          Versi ringkas:
S → AB                S → AB
A → CA | ε            A → abA | baA | ε
C → ab | ba           B → abbB | ε
B → DB | ε
D → abb

Keduanya benar. Versi dosen membuat variabel untuk isi setiap star, versi ringkas langsung memasukkan isinya.

6. Latihan

Soal 1–3 dari slide dosen ("Construct a CFG for RE below"). Cek di visualisasi.

1. a* b* (a|c)*

Jawaban 
S → ABC
A → aA | ε
B → bB | ε
C → aC | cC | ε

G = ({S, A, B, C}, {a, b, c}, P, S). Versi dengan variabel untuk isi star: C → DC | ε, D → a | c.

2. (a|c)* ba

Jawaban 
S → Aba
A → aA | cA | ε

Bagian ba adalah string terminal biasa, jadi ditulis langsung di belakang A.

3. ((00 + 01)* 01) + (101 (0 + 10)*)

Jawaban 
S → A01 | 101B
A → 00A | 01A | ε
B → 0B | 10B | ε

Bagian terluar adalah union, jadi S punya dua alternatif. Alternatif kiri = A lalu 01, alternatif kanan = 101 lalu B.

4. Tentukan L(G) untuk S → aSbb | abb.

Jawaban

Setiap langkah menambah satu a di kiri dan dua b di kanan. L(G) = {aⁿb²ⁿ | n ≥ 1}: abb, aabbbb, …

5. Apakah S → aS | bS | ε benar untuk RE a*b*? Kalau tidak, perbaiki.

Jawaban

Tidak. Grammar itu menghasilkan ba, yang tidak ada di a*b*. Perbaikan: S → AB, A → aA | ε, B → bB | ε.
