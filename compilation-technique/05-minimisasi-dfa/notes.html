Minimisasi DFA

Satu language bisa dikenali banyak DFA dengan jumlah state berbeda. Minimisasi menggabungkan state yang tidak bisa dibedakan oleh string apa pun, sampai jumlah state paling sedikit.

Slide · Visualisasi: table-filling dan partition

TL;DR
  • p dan q distinguishable kalau ada string x yang dari p berakhir di final dan dari q tidak (atau sebaliknya).
  • Basis: (final, bukan final) pasti berbeda. Induksi: kalau δ(p,a) dan δ(q,a) berbeda, p dan q berbeda.
  • Table-filling: tandai X sampai stabil, sel kosong = ekuivalen. Partition: mulai {final}, {bukan final}, pecah berdasarkan grup tujuan sampai stabil.
  • DFA minimum: satu state per grup. Start = grup start lama, final = grup yang memuat final lama.

1. Distinguishable dan ekuivalen

DFA punya jumlah state minimum kalau semua state-nya saling distinguishable. Dua state yang tidak distinguishable disebut ekuivalen: dari keduanya, setiap string memberi hasil yang sama (diterima atau ditolak). Karena itu keduanya boleh digabung tanpa mengubah language.

  • Basis: kalau p final dan q bukan final, string ε membedakan keduanya.
  • Induksi: misalkan r = δ(p, a) dan s = δ(q, a), dan r, s sudah diketahui berbeda dengan string x. Maka string ax membedakan p dan q.

Contoh di slide: DFA "diakhiri 1" dengan 3 state (A, B, C) bisa dikecilkan menjadi 2 state, karena A dan C sama-sama bukan final dan transisinya sama.

2. Metode table-filling

  1. Buat tabel segitiga berisi semua pasangan state.
  2. Beri X pada setiap pasangan (final, bukan final).
  3. Untuk setiap pasangan (p, q) yang belum X dan setiap simbol a: kalau pasangan (δ(p,a), δ(q,a)) sudah X, beri X pada (p, q). Kalau δ(p,a) = δ(q,a), simbol a tidak membedakan apa pun.
  4. Ulangi langkah 3 sampai satu putaran penuh tidak menghasilkan X baru.
  5. Pasangan tanpa X (O) = ekuivalen. Gabungkan. Kalau (A,D) dan (D,G) ekuivalen, maka A, D, G satu grup.

3. Metode partition

  1. Round 0: P = {final, bukan final}.
  2. Untuk setiap grup G dan setiap state s di G, tulis grup tujuan δ(s, a) untuk setiap simbol a.
  3. State dalam G dengan baris grup tujuan yang sama tetap satu grup. Yang berbeda dipisah.
  4. Ulangi sampai tidak ada grup yang pecah. Start DFA minimum = grup yang memuat start lama, final = grup yang memuat final lama.

Contoh slide: 3 state

Final = 2. G1 = {2}, G2 = {1,3}. move(1,a) = 2, move(1,b) = 3, move(3,a) = 2, move(3,b) = 3: baris grup tujuan 1 dan 3 sama (G1, G2), jadi G2 tidak pecah. DFA minimum: {1,3} dan {2}.
