Thompson ε-NFA (10%)

pola Thompson (materi 02) simulasi soal 1 (7️⃣)

Merakit LEGO dari buku petunjuk: bagian kecil dirakit dulu, lalu digabung menjadi bagian besar.

LEGO boleh dirakit dari bagian mana saja. Thompson harus dari bagian terdalam, mengikuti prioritas operator.

Soal kisi ini selalu berbentuk "Construct an ε-NFA for … using Thompson's construction". Yang berbeda hanya bentuk RE-nya.

Jenis soal

JenisCiri RE di soalContoh
Aunion |, concatenation, dan starContoh 1: (a|b)*abb
Bunion ditulis +, biasanya dengan simbol 0 dan 1Contoh 2: (0+1)*1(0+1)
Cstar mengikat beberapa simbol dalam kurung, atau ada εContoh 3: (ab)*(a|ε)

Cheat sheet

Simbol a: 2 state, 1 transisi

Union a|b: +2 state, 4 ε

Concatenation ab: +0 state, 1 ε

Star a*: +2 state, 4 ε

ε masuk, ε ulangi (final dalam ke start dalam), ε lewati (nol kali), ε keluar.

Cek jumlah state

2 × (simbol + union + star)

Prioritas: kurung, lalu star, lalu concatenation, lalu union. ε dihitung sebagai simbol.

Contoh soal

Contoh 1 · Jenis A ε-NFA untuk (a|b)*abb

Construct an ε-NFA for (a|b)*abb using Thompson's construction.

  1. Pecah RE sesuai prioritas

    Cari operator yang paling akhir dikerjakan. Di sini concatenation dari empat bagian, dan di dalam star ada union.

    (a|b)* · a · b · b, dengan a|b di dalam star.

  2. Hitung target jumlah state

    Hitung simbol, union, dan star sebelum menggambar. Angka ini dipakai untuk mengecek gambar di akhir.

    5 simbol + 1 union + 1 star = 7, jadi 14 state.

  3. Rakit bagian terdalam: union a|b

    Buat fragment a dan b, lalu start baru bercabang ε ke keduanya dan kedua final bertemu di final baru. Oranye = bagian yang baru dibuat.

  4. Pasang star di luar union

    Tambah start dan final baru, lalu 4 ε: masuk, ulangi, lewati, dan keluar.

  5. Sambung a, b, b dengan concatenation

    Final bagian kiri disambung ε ke start bagian kanan, tiga kali. Final bagian dalam tidak lagi final.

  6. Cek

    Hitung state di gambar, lalu telusuri string terpendek abb: dari start, ambil ε "lewati" star, lalu baca a, b, b.

    14 state, sama dengan target. Satu start, satu final. abb sampai ke final.

ε-NFA 14 state seperti gambar langkah 5.

Cek di viz (bisa dijalankan langkah demi langkah)

Contoh 2 · Jenis B ε-NFA untuk (0+1)*1(0+1)

Construct an ε-NFA for (0+1)*1(0+1) using Thompson's construction.

  1. Baca notasi +

    Di soal seperti ini, + berarti union, sama dengan |. Bukan "satu kali atau lebih".

    (0+1)*1(0+1) = (0|1)*1(0|1): string yang simbol kedua dari kanannya 1.

  2. Pecah RE dan hitung target

    Concatenation dari tiga bagian. Ada dua union, satu di dalam star dan satu di akhir.

    (0+1)* · 1 · (0+1). 5 simbol + 2 union + 1 star = 8, jadi 16 state.

  3. Rakit (0+1)*

    Sama seperti contoh 1: union dulu, baru star.

  4. Rakit 1 dan union (0+1) kedua

    Fragment 1 berdiri sendiri. Union kedua dirakit terpisah, karena star tidak mengikatnya.

  5. Sambung ketiganya dan cek

    Dua ε concatenation menyambung star ke 1, lalu 1 ke union kedua.

    16 state, sama dengan target. String terpendek 10 dan 11 sampai ke final.

ε-NFA 16 state seperti gambar langkah 5.

Cek di viz

Contoh 3 · Jenis C ε-NFA untuk (ab)*(a|ε)

Construct an ε-NFA for (ab)*(a|ε) using Thompson's construction.

  1. Lihat apa yang diikat star

    Star mengikat seluruh isi kurung ab, jadi ab diulang bersama. Bandingkan dengan ab*, yang hanya mengulang b.

    (ab)* · (a|ε), dengan concatenation ab di dalam star.

  2. Hitung target, ε dihitung sebagai simbol

    ε juga dapat fragment: dua state dengan satu transisi ε.

    Simbol a, b, a, ε = 4. Ditambah 1 union dan 1 star = 6, jadi 12 state.

  3. Rakit ab, lalu star

    Concatenation a dan b dulu, baru star dipasang di luar fragment ab.

  4. Rakit union a|ε

    Cabang bawah union adalah fragment ε.

  5. Sambung dan cek

    Satu ε concatenation. String terpendek di sini adalah ε: lewati star, lalu ambil cabang ε.

    12 state. String ε, a, dan ab sampai ke final.

ε-NFA 12 state seperti gambar langkah 5.

Cek di viz

Yang paling sering lupa: ε "lewati" di star, dan final bagian dalam yang masih ditandai final. Daftar lengkap: materi 02 8️⃣.

Pecah, hitung target, rakit dari dalam, sambung, lalu cek dengan 2 × (simbol + union + star).

Soal latihan (sesi RE to DFA): Gambar ε-NFA untuk (a|b)*(ab|bb)a*. Berapa state-nya?

7 simbol (a, b, a, b, b, b, a), 2 union, 2 star. Jadi 2 × 11 = 22 state. Cek di viz.

RE → DFA dengan followpos (25%)

RE → DFA langsung (materi 04) kisi 3 (DFA-nya sering diminta diminimisasi), simulasi soal 2 (7️⃣)

Peta jalur angkot: untuk setiap halte, tulis halte mana saja yang bisa didatangi berikutnya. Setelah itu, rute apa pun bisa dibaca dari peta.

angkot boleh berhenti di mana saja. Di DFA, string hanya boleh berhenti di state yang memuat posisi #.

Soal kisi ini: "Convert … to a DFA directly (syntax tree, nullable, firstpos, lastpos, followpos)". Subset construction tidak diajarkan di kelas, jadi pakai metode followpos.

Contoh 1 · Jenis A DFA untuk (a|b)*abb (slide dosen)

Convert (a|b)*abb to a DFA directly.

  1. Tambah # dan beri nomor posisi

    Tulis (r)#, lalu beri nomor 1, 2, 3, … untuk setiap simbol dan # dari kiri. # menandai kapan string boleh berhenti.

    (a|b)*abb#: a = 1, b = 2, a = 3, b = 4, b = 5, # = 6.

  2. Hitung nullable, firstpos, lastpos dari bawah ke atas

    Pakai cheat sheet untuk setiap node. Yang perlu hati-hati: node · dengan anak kiri nullable, karena firstpos-nya ikut anak kanan.

    {1,2,3}: anak kiri (a|b)* nullable, jadi firstpos {1,2} digabung dengan firstpos a = {3}.

    a b →A B A B B C C B D *D B A

Contoh 2 · Jenis B DFA untuk (a|b)*(ab|bb)a* (latihan dosen)

Convert (a|b)*(ab|bb)a* to a DFA directly.

  1. Tambah # dan beri nomor posisi

    Setiap kemunculan simbol mendapat nomor sendiri, walaupun hurufnya sama.

    a = 1, b = 2 (di (a|b)*), a = 3, b = 4 (ab), b = 5, b = 6 (bb), a = 7 (a*), # = 8.

  2. Hitung nullable, firstpos, lastpos

    Perhatikan node ·a*: anak kanan a* nullable, jadi lastpos-nya ikut lastpos anak kiri.

    Nodenullablefirstposlastpos
    (a|b)*T{1,2}{1,2}
    ab|bbF{3,5}{4,6}
    (a|b)*(ab|bb)F{1,2,3,5}{4,6}

    (a|b)*(ab|bb)a*F{1,2,3,5}{4,6,7}
    root ·#F{1,2,3,5}{8}

    Karena lastpos di depan # adalah {4,6,7}, tiga posisi mendapat # (8). Itu sebabnya nanti ada lebih dari satu final.

    Posisi1 a2 b3 a4 b5 b6 b7 a8 #
    followpos{1,2,3,5}{1,2,3,5}{4}{7,8}{6}{7,8}{7,8}∅

    Contoh sel B dengan b: posisi b di B adalah 2, 4, 5, jadi {1,2,3,5} ∪ {7,8} ∪ {6}.

    DFAPosisiab
    →A{1,2,3,5}BC
    B{1,2,3,4,5}BD

    D dan E memuat posisi 8, jadi keduanya final. Ini wajar untuk RE yang diakhiri star.

    a b →A B C B B D C B D *D E D *E E D

DFA 5 state: start A, final D dan E. DFA ini belum minimum, dan minimisasinya ada di kisi 3 contoh 3.

Contoh 3 · Jenis C DFA untuk (a|ε)bc* (slide dosen)

Convert (a|ε)bc* to a DFA directly.

  1. Tambah # dan beri nomor, ε tidak bernomor

    ε tidak pernah dibaca dari input, jadi tidak diberi posisi.

    a = 1, b = 2, c = 3, # = 4.

  2. Hitung nullable, firstpos, lastpos

    Leaf ε: nullable T, firstpos dan lastpos ∅. Karena itu a|ε nullable.

    Node (a|ε)·b: lastpos kiri {1} mendapat {2}. Node ·c* dan ·#: lastpos {2,3} mendapat {3} lalu {4}. Star c*: 3 mendapat {3}.

    followpos: 1 = {2}, 2 = {3,4}, 3 = {3,4}, 4 = ∅.

  4. Bangun tabel DFA, termasuk sel ∅

    Kalau state tidak memuat posisi bersimbol itu, selnya ∅. Contoh: A = {1,2} tidak punya posisi c.

    a b c →A B C - B - C - *C - - C

DFA 3 state: start A, final C, dan sel ∅ berarti tidak ada transisi.

Minimisasi DFA (15%)

table-filling dan partition (materi 05) simulasi soal 3 (7️⃣)

Menggabung kontak HP yang ganda: dua kontak digabung kalau semua isinya menunjuk ke orang yang sama.

kontak ganda biasanya terlihat dari nama. Dua state bisa ekuivalen walaupun barisnya berbeda, jadi tetap harus dibuktikan dengan langkah di bawah.

Soal kisi ini: "Minimize the following DFA", kadang dengan metode yang disebut. Kalau tidak disebut, partition biasanya lebih cepat di kertas.

Contoh 1 · Jenis A Partition DFA 4 state (slide dosen)

Minimize the DFA: →1 (a: 2, b: 3), 2 (a: 2, b: 3), 3 (a: 4, b: 3), *4 (a: 2, b: 3).

  1. Siapkan DFA

    Cek bahwa semua state tercapai dari start dan setiap sel terisi.

    Semua tercapai (1 ke 2 dan 3, 3 ke 4). Tidak ada sel kosong, jadi tidak perlu dead state.

  2. Round 0: pisahkan final dan bukan final

    String kosong sudah membedakan final dari bukan final, jadi keduanya pasti beda grup.

    G1 = {4}, G2 = {1, 2, 3}.

  3. Round 1: tulis grup tujuan, lalu pecah

    Ganti setiap state tujuan dengan nama grupnya. State dalam satu grup yang barisnya beda harus dipisah.

    Stateab
    1G2G2
    2G2G2
    3G1G2

    3 beda baris, jadi dipisah: {4}, {1, 2}, {3}.

  4. Round 2: ulangi dengan grup baru

    Grup berubah, jadi cek sekali lagi. Berhenti kalau tidak ada yang pecah.

    1: a ke {1,2}, b ke {3}. 2: a ke {1,2}, b ke {3}. Sama, jadi stabil.

    Satu grup = satu state. Transisi diambil dari salah satu anggota.

    ab

Contoh 2 · Jenis B Table-filling DFA A–H (slide dosen)

Minimize the DFA using the table-filling algorithm: →A (0: B, 1: F), B (G, C), *C (A, C), D (C, G), E (H, F), F (C, G), G (G, E), H (G, C).

    Cari state yang tidak bisa dicapai dari A.

    Tidak ada transisi menuju D, jadi D tidak tercapai. Slide tetap mengikutkan D, jadi di sini juga. Untuk DFA yang benar-benar minimum, D dibuang.

    Satu sel untuk setiap pasangan. Beri X₀ untuk pasangan yang salah satunya final (C).

    X₀: (A,C), (B,C), (C,D), (C,E), (C,F), (C,G), (C,H).

    Untuk setiap simbol, lihat pasangan tujuannya. Kalau pasangan tujuan sudah X, beri X₁. Satu simbol pembeda sudah cukup.

Contoh 3 · Jenis C Minimisasi DFA hasil (a|b)*(ab|bb)a*

Minimize the DFA you obtained in the previous question: →A (a: B, b: C), B (B, D), C (B, D), *D (E, D), *E (E, D).

  1. Round 0

    Ada dua final (D dan E), jadi G1 berisi keduanya.

    G1 = {D, E}, G2 = {A, B, C}.

  2. Round 1: tulis grup tujuan

    Bandingkan baris di dalam grup yang sama saja.

    Stateab
    AG2G2
    BG2G1
    CG2G1
    DG1G1
    EG1G1

    Di G2, A beda dari B dan C. Hasil: {D, E}, {A}, {B, C}.

  3. Round 2: cek lagi

    B dan C sama-sama ke ({B,C}, {D,E}). D dan E sama-sama ke ({D,E}, {D,E}). Tidak ada yang pecah.

    Partisi final: {A}, {B, C}, {D, E}.

    Final = grup yang memuat state final lama, yaitu {D, E}.

    ab
    →A{B,C}{B,C}

Cek di viz

Di partition, yang dibandingkan grup tujuan, bukan state tujuan. Di table-filling, jangan berhenti setelah putaran 1. Daftar lengkap: materi 05 8️⃣.

aturan RE → CFG (materi 06) simulasi soal 4 (7️⃣)

Menerjemahkan kalimat memakai kamus: setiap kata punya padanan tetap.

satu kata di kamus bisa punya beberapa padanan. Di sini setiap operator RE punya satu pola produksi yang tetap.

Soal kisi ini: "Construct a CFG for …", kadang diminta lengkap dengan G = (V, T, P, S).

Jenis soal

JenisCiri RE di soalContoh
Aconcatenation dari beberapa starContoh 1: (ab+ba)*(abb)*
Bunion di bagian paling luarContoh 2: ((00+01)*01)+(101(0+10)*)
Cbanyak star berurutan, isi star berupa unionContoh 3: a*b*(a|c)*
Dada ⁺ (satu kali atau lebih)Contoh 4: (ab)⁺c

Cheat sheet

Pola produksi

r₁r₂
tulis berdampingan
r₁ | r₂
X → r₁ | r₂
(r)*
X → rX | ε
(r₁|r₂)*
X → r₁X | r₂X | ε
(r)⁺
X → rX | r

Urutan kerja

1
S = seluruh RE, pecah dari luar
2
bagian union atau star = variabel baru
3
tulis produksi setiap variabel baru
4
G = (V, T, P, S), lalu cek dengan string

Contoh soal

Contoh 1 · Jenis A CFG untuk (ab+ba)*(abb)* (slide dosen)

Construct a CFG for (ab + ba)*(abb)*.

  1. Lihat operator paling luar

    Bagian luar adalah concatenation dari dua star. Setiap star mendapat variabel sendiri.

    S → AB        A = (ab+ba)*,  B = (abb)*
  2. Uraikan A = (ab+ba)*

    Star dari union: setiap alternatif diikuti A, ditambah ε untuk berhenti.

    A → abA | baA | ε
  3. Uraikan B = (abb)*

    Star biasa: isi lalu B lagi, atau ε.

    B → abbB | ε
  4. Tulis G dan cek

    Turunkan string terpendek dan satu string panjang.

    G = ({S, A, B}, {a, b}, P, S). ε: S ⇒ AB ⇒ B ⇒ ε. baabb: S ⇒ AB ⇒ baAB ⇒ baB ⇒ baabbB ⇒ baabb.

S → AB, A → abA | baA | ε, B → abbB | ε. Versi dosen dengan C → ab | ba dan D → abb juga benar.

Cek di viz

Contoh 2 · Jenis B CFG untuk ((00+01)*01)+(101(0+10)*) (slide dosen)

Construct a CFG for ((00 + 01)* 01) + (101 (0 + 10)*).

  1. Lihat operator paling luar

    + paling luar = union, jadi S punya dua alternatif.

    S → A01 | 101B     kiri: (00+01)* lalu 01;  kanan: 101 lalu (0+10)*
  2. Uraikan A dan B

    Keduanya star dari union.

    A → 00A | 01A | ε
B → 0B | 10B | ε
  3. Tulis G dan cek

    Cek string terpendek di setiap cabang union.

    G = ({S, A, B}, {0, 1}, P, S). Kiri: S ⇒ A01 ⇒ 01. Kanan: S ⇒ 101B ⇒ 101.

S → A01 | 101B, A → 00A | 01A | ε, B → 0B | 10B | ε.

Cek di viz

Contoh 3 · Jenis C CFG untuk a*b*(a|c)* (latihan dosen)

Construct a CFG for a* b* (a|c)*, complete with G.

  1. Hitung star, satu variabel per star

    Ada tiga star berurutan. Kalau digabung jadi satu variabel, urutannya hilang.

    S → ABC       A = a*,  B = b*,  C = (a|c)*
  2. Uraikan setiap star

    Star biasa untuk A dan B, star dari union untuk C.

    A → aA | ε
B → bB | ε
C → aC | cC | ε
  3. Tulis G dan cek urutan

    Pastikan grammar menolak string yang urutannya salah, misalnya cb.

    G = ({S, A, B, C}, {a, b, c}, P, S). cb tidak bisa diturunkan, karena setelah C tidak ada B. Grammar S → aS | bS | cS | ε salah, karena menerima cb.

S → ABC, A → aA | ε, B → bB | ε, C → aC | cC | ε.

Cek di viz

Contoh 4 · Jenis D CFG untuk (ab)⁺c

Construct a CFG for (ab)⁺c.

  1. Pecah: plus lalu c

    ⁺ = minimal satu kali. Bagian plus mendapat variabel baru.

    S → Ac        A = (ab)⁺
  2. Uraikan A dengan pola plus

    Plus berhenti di satu isi, bukan di ε.

    A → abA | ab
  3. Cek

    String terpendek harus memuat satu ab, dan c saja harus ditolak.

    abc: S ⇒ Ac ⇒ abc. c tidak bisa diturunkan, karena A tidak punya ε.

S → Ac, A → abA | ab. G = ({S, A}, {a, b, c}, P, S).

Satu star = satu variabel, dan pola plus tidak punya ε. Daftar lengkap: materi 06 8️⃣.

S = seluruh RE. Union = |, star = rekursi + ε, plus = rekursi + satu isi.

Soal latihan: Construct a CFG for (ab|c)*b(a|b)*.

Ini soal 4 di simulasi. Jawabannya ada di 7️⃣.

Left factoring dan left recursion (10%)

left factoring (materi 08), left recursion (materi 09) kisi 6 (grammar harus bersih dulu sebelum tabel LL(1)), simulasi soal 5 (7️⃣)

Merapikan rute sebelum berangkat: gabungkan dua jalan yang awalnya sama, dan hapus putaran yang tidak pernah maju.

rute yang salah dirapikan bisa berubah tujuan. Grammar baru harus tetap menghasilkan language yang sama, jadi selalu cek dengan string pendek.

Soal kisi ini: "Perform left factoring on …" dan "Eliminate left recursion from … (with the order …)".

Jenis soal

JenisCiri soalContoh
Aleft factoring, beberapa grup awalan, satu tingkatContoh 1
Bleft factoring bertingkat, ada sisa kosong (ε)Contoh 2
Cleft recursion langsung (immediate), banyak α dan βContoh 3
Dleft recursion tidak langsung, dengan urutan variabelContoh 4

Cheat sheet

Left factoring

A → αβ₁ | αβ₂ | γ menjadi
A → αA' | γ, A' → β₁ | β₂

α = awalan bersama terpanjang. Sisa kosong ditulis ε. Ulangi di A'.

Left recursion langsung

A → Aα | β menjadi
A → βA', A' → αA' | ε

α = sisa setelah A dibuang. β = yang tidak diawali A. A' selalu punya ε.

Left recursion tidak langsung

1
proses variabel sesuai urutan soal
2
kalau Aᵢ diawali Aⱼ yang lebih awal, substitusi semua alternatif Aⱼ
3
hapus left recursion langsung di Aᵢ

Contoh soal

Contoh 1 · Jenis A Left factoring A → abB | aB | cdg | cdeB | cdfB | h (slide dosen)

Perform left factoring on A → abB | aB | cdg | cdeB | cdfB | h.

  1. Kelompokkan alternatif menurut simbol pertama

    Alternatif dengan simbol pertama sama masuk satu grup.

    Grup a: abB, aB. Grup c: cdg, cdeB, cdfB. h sendiri.

  2. Cari awalan bersama terpanjang di setiap grup

    Bandingkan simbol demi simbol sampai ada yang beda.

    Grup a: a (abB dan aB beda di simbol kedua). Grup c: cd (beda di simbol ketiga: g, e, f).

  3. Keluarkan awalan, sisanya ke variabel baru

    Setiap grup mendapat variabel baru sendiri.

    A   → aA' | cdA'' | h
A'  → bB | B
A'' → g | eB | fB
  4. Cek variabel baru

    Pastikan tidak ada lagi dua alternatif dengan awalan sama.

    A': bB dan B beda awalan. A'': g, e, f beda. Selesai.

A → aA' | cdA'' | h, A' → bB | B, A'' → g | eB | fB.

Cek di viz

Contoh 2 · Jenis B Left factoring A → ad | a | ab | abc | b (latihan dosen)

Perform left factoring on A → ad | a | ab | abc | b.

  1. Kelompokkan dan cari awalan

    Grup a berisi empat alternatif. Awalan bersama terpanjang hanya a, karena a sendiri tidak punya simbol kedua.

    Grup a: ad, a, ab, abc. Awalan: a. b sendiri.

  2. Keluarkan a, sisa kosong = ε

    Alternatif a menyisakan string kosong, jadi ditulis ε.

    A  → aA' | b
A' → d | ε | b | bc
  3. Ulangi di A'

    b dan bc masih berawalan sama, jadi difaktorkan lagi.

    A   → aA' | b
A'  → d | ε | bA''
A'' → ε | c

A → aA' | b, A' → d | ε | bA'', A'' → ε | c.

Cek di viz

Contoh 3 · Jenis C Left recursion A → Aab | Aba | aB | a, B → b | Bba (slide dosen)

Eliminate left recursion from A → Aab | Aba | aB | a, B → b | Bba.

  1. Pisahkan α dan β di setiap variabel

    α = alternatif yang diawali variabel itu sendiri, tanpa variabelnya. β = sisanya.

    A: α = ab, ba; β = aB, a. B: α = ba; β = b.

  2. Pakai rumus

    Setiap β diikuti A'. Setiap α diikuti A', ditambah ε.

    A  → aBA' | aA'
A' → abA' | baA' | ε
B  → bB'
B' → baB' | ε
  3. Cek

    String terpendek grammar lama harus masih bisa diturunkan.

    a: A ⇒ aA' ⇒ a. aab: A ⇒ aA' ⇒ aabA' ⇒ aab.

A → aBA' | aA', A' → abA' | baA' | ε, B → bB', B' → baB' | ε. Kalau grammar ini dipakai untuk LL(1), A masih perlu left factoring (aBA' dan aA' sama-sama diawali a).

Cek di viz

Contoh 4 · Jenis D Left recursion S → Aa | b, A → Ac | Sd | f, urutan S, A (slide dosen)

Eliminate left recursion from S → Aa | b, A → Ac | Sd | f with the order S, A.

  1. Proses S (variabel pertama)

    Variabel pertama tidak disubstitusi. Cek left recursion langsung.

    S → Aa | b tidak diawali S. Tidak ada yang berubah.

  2. Proses A: substitusi S

    A → Sd diawali S, yang lebih awal di urutan. Ganti S dengan semua alternatifnya.

    A → Ac | Aad | bd | f        (Sd menjadi Aad dan bd)
  3. Hapus left recursion langsung di A

    Sekarang left recursion-nya terlihat langsung.

    α = c, ad. β = bd, f.

    A  → bdA' | fA'
A' → cA' | adA' | ε
  4. Tulis hasil lengkap

    Tulis urutan yang dipakai di jawabanmu, karena urutan lain memberi jawaban lain.

    S  → Aa | b
A  → bdA' | fA'
A' → cA' | adA' | ε

Urutan S, A: S → Aa | b, A → bdA' | fA', A' → cA' | adA' | ε. Urutan A, S memberi hasil lain yang juga benar (materi 09 6️⃣).

Cek di viz

A' tanpa ε dan urutan variabel yang tidak sesuai soal adalah dua kesalahan paling sering. Daftar lengkap: materi 09 7️⃣.

Left factoring: awalan terpanjang keluar, sisanya ke A'. Left recursion: β di depan, A' → αA' | ε.

Soal latihan (latihan dosen): Eliminasi left recursion S → AA | 0, A → SS | 1, urutan S, A.

A → SS disubstitusi menjadi A → AAS | 0S | 1. Hasil: S → AA | 0, A → 0SA' | 1A', A' → ASA' | ε. Cek di viz.

Top-down parsing (30%)

    E butuh FIRST(T), dan T butuh FIRST(F). Jadi hitung dari bawah: F, T, E, lalu E' dan T'.

Contoh 6 · Jenis F Procedure recursive predictive parsing (slide dosen)

Write the recursive predictive parsing procedures for A → aBe | cBd | C, B → bB | ε, C → f.

  1. Tentukan label case dari FIRST dan FOLLOW

    Label case untuk A → α = FIRST(α). Label case untuk A → ε = FOLLOW(A).

    A: a, c, dan f (FIRST(C)). B: b, dan untuk ε: FOLLOW(B) = {e, d}. C: f.

  2. Tulis satu procedure per variabel

    Isi setiap case = ruas kanan dari kiri ke kanan: terminal jadi match, variabel jadi panggilan procedure.

    void A() {
    switch (token) {
    case 'a': match('a'); B(); match('e'); break;
    case 'c': match('c'); B(); match('d'); break;
    case 'f': C(); break;
    default:  error();
    }
}
void B() {
    switch (token) {
    case 'b': match('b'); B(); break;
    case 'e': case 'd': break;      // B → ε
    default:  error();
    }
}
void C() { match('f'); }

Tiga procedure di atas. Case e, d di B tidak melakukan apa-apa, karena B → ε.

Cek FIRST/FOLLOW di viz
