Compilation technique · 02

RE → ε-NFA (Thompson)

Thompson's construction mengubah RE apa pun menjadi ε-NFA dengan cara mekanis: buat fragment kecil untuk setiap simbol, lalu sambungkan dengan pola union, concatenation, dan star.

Slide · Visualisasi: Thompson langkah demi langkah

TL;DR
  • Setiap fragment punya satu start dan satu final, jadi bisa disambung tanpa melihat isinya.
  • Simbol: 2 state. Union: start dan final baru, cabang ε. Concatenation: final kiri → ε → start kanan. Star: start dan final baru, 4 ε (masuk, ulangi, lewati, keluar).
  • Kerjakan dari dalam ke luar: star, lalu concatenation, lalu union.
  • Cek: jumlah state = 2 × (simbol + union + star).

1. NFA dan ε-NFA

Finite automaton (FA) adalah mesin yang membaca string simbol demi simbol, lalu menjawab accepted atau rejected. Secara formal M = (Q, Σ, δ, q₀, F):

KomponenArti
Qhimpunan state yang terbatas
Σalphabet input
δfungsi transisi. Di NFA, δ(q, a) adalah himpunan state (boleh kosong, boleh lebih dari satu).
q₀start state
Fhimpunan final (accepting) state

ε-NFA adalah NFA yang juga boleh punya transisi berlabel ε: pindah state tanpa membaca input. String x diterima kalau ada minimal satu jalur dari start ke final yang label-labelnya (tanpa ε) membentuk x.

a b →0 {0,1} {0} 1 - {2} 2 - {3} *3 - -

NFA di atas menerima (a|b)*abb. Input aabb diterima lewat jalur 0 →a 0 →a 1 →b 2 →b 3. Jalur lain, misalnya 0 →a 0 →a 0 →b 0 →b 0, berakhir di state bukan final, tetapi itu tidak masalah: satu jalur yang berhasil sudah cukup.

2. Empat pola Thompson

Teorema: untuk setiap RE R ada ε-NFA M dengan L(M) = L(R). Buktinya sekaligus menjadi cara membuatnya, yaitu induksi pada struktur RE.

Simbol a (dan ε)

Dua state dan satu transisi. Untuk ε, labelnya ε. Untuk ∅, dua state tanpa transisi (tidak ada jalur ke final).

Union R | S

Start baru bercabang ε ke start R dan start S, karena string boleh mengikuti salah satunya. Final R dan final S masing-masing ε ke final baru, supaya fragment hasilnya tetap punya satu final.

Concatenation RS

Final R disambung ε ke start S. Start hasil = start R, final hasil = final S. Final R tidak lagi final.

Star R*

ε-transitionDi gambarFungsinya
masuk0 → 1mulai satu putaran R
ulangi2 → 1setelah R selesai, boleh membaca R lagi
lewati0 → 3nol kali: ε diterima
keluar2 → 3berhenti mengulang

3. Resep mengerjakan soal

  1. Pecah RE sesuai prioritas. Star mengikat paling kuat, lalu concatenation, lalu union. Contoh: (a|b)*abb = (a|b)* · a · b · b.
  2. Buat fragment simbol, satu untuk setiap kemunculan simbol.
  3. Gabungkan dari dalam ke luar. Untuk (a|b)*abb: a, b → a|b → (a|b)* → sambung a → sambung b → sambung b.
  4. Beri nomor state dari kiri ke kanan (cabang atas lebih dulu dari cabang bawah).
  5. Cek jumlah state: 2 × (simbol + union + star). Hanya ada satu start dan satu final.

Contoh: (a|b)*a

3 simbol + 1 union + 1 star → 10 state. String terpendek yang diterima: a (jalur 0 → 7 → 8 → 9 lewat ε "lewati").

Contoh slide: (0+1)*1(0+1)

5 simbol + 2 union + 1 star → 16 state.

Gaya Aho: concatenation tanpa εDi buku Aho (dan slide dosen sesi DFA & NFA), final R langsung digabung dengan start S menjadi satu state. Hasilnya satu state lebih sedikit untuk setiap concatenation. Contoh: (a|b)*a menjadi 9 state (0 sampai 8). Kedua gaya benar karena ε di antara keduanya tidak membaca apa pun. Kalau soal tidak menyebut gaya, pakai gaya slide Thompson dosen (dengan ε).

5. Latihan

Gambar ε-NFA-nya di kertas, hitung jumlah state, lalu cocokkan di visualisasi (menu "Ubah RE").

1. (a|b)*abb

Jawaban

Simbol: a dan b di dalam star, lalu a, b, b. Jadi 5 simbol + 1 union + 1 star = 7 → 14 state.

2. aa*|bb* (contoh slide NFA)

Jawaban

4 simbol + 1 union + 2 star = 7 → 14 state. Struktur: union dari (a lalu a*) dan (b lalu b*).

3. (a|b)*(ab|bb)a* (RE dari latihan sesi RE to DFA)

Jawaban

Simbol: a, b, a, b, b, b, a = 7. Union: 2 (a|b dan ab|bb). Star: 2. Total 11 → 22 state.

4. (a|ε)bc*

Jawaban

ε diperlakukan seperti simbol (2 state, transisi ε). Simbol + ε: a, ε, b, c = 4. Union 1, star 1. Total 6 → 12 state.

5. Kenapa union butuh start dan final baru, sedangkan concatenation tidak?

Jawaban

Hasil setiap pola harus punya tepat satu start dan satu final. Concatenation sudah punya satu start (milik R) dan satu final (milik S). Union punya dua start dan dua final, jadi butuh start baru yang bercabang ke keduanya dan final baru tempat keduanya bertemu.
