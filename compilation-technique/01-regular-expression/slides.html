Regular expression

Compilation technique · materi 01 · dasar untuk semua soal automata berikutnya

Target: kamu bisa membaca RE, menulis RE untuk soal "string yang …", dan mengecek jawabanmu sendiri.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · RE di compiler

Lexer memecah source code menjadi token, dan bentuk setiap token ditulis sebagai RE

Tahap pertama compiler, lexical analyzer, mengubah teks menjadi deretan token.

Source:  position = initial + rate * 60
Token:   <id,1> <=> <id,2> <+> <id,3> <*> <number,60>
IstilahArtiContoh
LexemePotongan teks asli di source coderate, 60
TokenJenis lexeme, ditambah attribute (misalnya posisi di symbol table)<id,3>
PatternAturan bentuk lexeme untuk satu token, ditulis sebagai REid → letter (letter | digit)*

Notes 2️⃣ · Istilah dasar

Language adalah himpunan string, dan RE adalah cara menulisnya

Semua istilah di bawah dipakai di setiap soal automata.

IstilahArtiContoh
Alphabet ΣHimpunan simbol yang boleh dipakaiΣ = {0, 1}
StringDeretan simbol dari Σ yang panjangnya terbatas0011
|w|Panjang string w|abcb| = 4
εString kosong, panjangnya 0|ε| = 0
LanguageHimpunan string, boleh terbatas atau tak terbatas{a, ab, abb}, semua palindrome

∅ tidak sama dengan {ε}: ∅ tidak berisi string apa pun, sedangkan {ε} berisi tepat satu string, yaitu string kosong.

Notes 3️⃣ · Operasi pada language

Tiga operasi pada language: concatenation, union, dan Kleene closure

Contoh dengan L = {0, 1, 00, 01, 10} dan M = {10, 11}. Operator RE adalah singkatan dari operasi ini.

OperasiArtiContoh
Concatenation LMSatu string dari L, lalu satu dari M{010, 011, 110, 111, 0010, …}
Union L ∪ MString dari L atau dari M{0, 1, 00, 01, 10, 11}
Kleene closure L*Gabungan nol string atau lebih dari L{1}* = {ε, 1, 11, 111, …}
Positive closure L⁺Minimal satu{1}⁺ = {1, 11, 111, …}

Karena star boleh mengambil nol string, ε selalu ada di L*.

Notes 4️⃣ · Operator dan prioritas

Prioritas operator RE: star dulu, lalu concatenation, terakhir union

Setiap regular expression dibangun dari simbol, ε, dan tiga operator ini, seperti pangkat, kali, lalu tambah.

OperatorArtiContohString yang dihasilkan
r* (star)r diulang nol kali atau lebih1*ε, 1, 11, 111, …
rs (concatenation)r lalu langsung sabab
r|s (union)r atau s. Slide dosen juga menulis r + s.0 | 10, 1
  • ab*|c dibaca (a(b*))|c. Pakai kurung kalau maksudnya lain: (ab)*.
  • r⁺ = rr*. Karena + juga dipakai untuk union, lebih aman menulis (a|b)(a|b)*.

Notes 5️⃣ · Membaca RE

Membaca RE: tulis string terpendeknya dulu, lalu cari polanya

Contoh dari slide dosen. Setelah menebak pola, uji dengan string yang lebih panjang.

REString terpendekLanguage
(0|1)*00(0|1)*00, 000, 100, 001memuat substring 00
(0|1)*011011, 0011, 1011diakhiri 011
(1|10)*ε, 1, 11, 10, 110setiap 0 didahului 1
(aa|ab|ba|bb)*ε, aa, ab, aabbpanjangnya genap
(a|b)(a|b)(a|b)(a|b)*aaa, aab, …, abbapanjangnya minimal 3

Satu language bisa ditulis dengan banyak RE. Contoh: (r*s*)* = (r|s)*.

Notes 6️⃣ · Menulis RE

Menulis RE: cocokkan kalimat soal dengan salah satu pola

Di sini Σ = {0, 1}, jadi "simbol apa saja" = (0|1). Ganti X dengan string yang diminta.

Kalimat soalPola REKenapa
diawali XX(0|1)*X wajib di depan, sisanya bebas
diakhiri X(0|1)*Xbebas di depan, X wajib di akhir
memuat substring X(0|1)*X(0|1)*bebas di kedua sisi X
simbol ke-k dari kanan adalah 1(0|1)*1(0|1)…(0|1)tepat (k − 1) simbol bebas setelah 1
panjang genap((0|1)(0|1))*setiap putaran menambah 2 simbol

(a|b)*abb berarti diakhiri abb. Untuk "diawali abb", tulis abb(a|b)*.

Notes 7️⃣ · "Atau" dan "dan"

Untuk "dan", tulis setiap urutan kemunculan lalu gabungkan dengan union

Soal dosen: string di atas {a, b, c} yang memuat minimal satu a dan satu b. Misalkan Σ* = (a|b|c)*.

  1. a lebih dulu: Σ* a Σ* b Σ*. Σ* menampung huruf apa pun di sela-selanya.
  2. b lebih dulu: ba juga harus diterima, jadi butuh Σ* b Σ* a Σ*.
  3. Gabungkan kedua urutan dengan union. Untuk "atau", union saja sudah cukup.
(a|b|c)* a (a|b|c)* b (a|b|c)*  |  (a|b|c)* b (a|b|c)* a (a|b|c)*

Notes 8️⃣ · Mengecek jawaban

RE yang salah biasanya gagal di string pendek, jadi uji dengan tiga kelompok string

Lakukan sebelum menyerahkan jawaban. Visualisasi berikutnya melakukannya otomatis.

  1. ε dan string terpendek yang seharusnya diterima. "Diakhiri 011": apakah 011 sendiri diterima?
  2. String yang hampir benar tapi harus ditolak. "Ke-3 dari kanan = 1": 100 diterima, 010 ditolak.
  3. Urutan lain yang juga memenuhi soal. Soal "dan": ab dan juga ba.

Notes 9️⃣ · Regular definition

Regular definition memberi nama pada potongan RE supaya mudah dibaca

Regular definition adalah deretan definisi nama → RE. Setiap RE boleh memakai nama sebelumnya.

letter → A | B | … | Z | a | b | … | z
digit  → 0 | 1 | … | 9
id     → letter (letter | digit)*
digits       → digit digit*
opt-fraction → ( . digits )?
opt-exponent → ( E (+|-)? digits )?
unsigned-num → digits opt-fraction opt-exponent
  • r? berarti r boleh tidak ada: r? = r | ε. 12, 12.5, dan 1.5E-3 cocok dengan unsigned-num.
  • Tanpa nama, id menjadi (A|…|z)((A|…|z)|(0|…|9))*: isinya sama, tapi sulit dibaca.

Kesalahan paling sering: arah pola tertukar dan urutan yang terlupa

Ringkasan

RE adalah rumus pendek untuk sebuah language, dan lexer memakainya untuk mengenali token.

  • Operator: star (nol kali atau lebih), concatenation, union. Prioritasnya urut seperti itu.
  • Membaca: tulis string terpendek, lalu cari polanya.
  • Menulis: pola diawali, diakhiri, memuat, posisi ke-k. "Atau" = union, "dan" = union semua urutan.
  • Mengecek: uji dengan ε, string terpendek, dan string yang hampir benar.

Soal

Soal latihan dosen. Kerjakan dulu, lalu cek jawabannya di slide berikutnya.

  1. String di atas {a, b, c} yang memuat minimal satu a dan satu b.
  2. String di atas {0, 1} yang simbol ketiganya dari kanan adalah 1.
  3. String di atas {a, b} yang diawali abb.
  4. String di atas {0, 1} yang memuat substring 011.
  5. String di atas {0, 1} yang diawali atau diakhiri (atau keduanya) dengan 01.
