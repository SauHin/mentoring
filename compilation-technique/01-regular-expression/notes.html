Regular expression

Regular expression (RE) adalah cara menulis sebuah language (himpunan string) dengan rumus pendek. Lexer memakai RE untuk mengenali token, dan semua soal automata berikutnya dimulai dari sebuah RE. Target: kamu bisa membaca RE, menulis RE untuk soal "string yang …", dan mengecek jawabanmu sendiri.

Lexer memecah source code menjadi token, dan bentuk setiap token ditulis sebagai RE

source code C yang kamu tulis sendiri RE (4️⃣) dan automata di materi 02–05

Saat membaca, matamu mengelompokkan huruf menjadi kata dulu, baru memahami artinya.

kamu bisa menebak kata yang salah ketik. Lexer tidak bisa: fi tetap dianggap nama, bukan if.

Tahap pertama compiler adalah lexical analyzer (lexer, scanner). Lexer membaca karakter demi karakter dan mengelompokkannya menjadi token, yaitu pasangan <nama token, attribute>.

Source:  position = initial + rate * 60
Token:   <id,1> <=> <id,2> <+> <id,3> <*> <number,60>

TokenJenis lexeme. Attribute menyimpan lexeme yang mana, misalnya posisi di symbol table<id,1>
PatternAturan bentuk lexeme untuk satu token, ditulis sebagai REid → letter (letter | digit)*
Kelas token dari slide, lexical error, dan input buffering

if, elsekeyword, persis karakter ituif, else

  • Lexical error: lexer hampir tidak bisa mendeteksi kesalahan program. Pada fi ( a == f(x) ), fi tetap menjadi id.
  • Input buffering: setelah <, lexer harus melihat karakter berikutnya untuk tahu apakah lexeme-nya < atau <=. Karena itu lexer memakai dua pointer (lexemeBegin dan forward) di atas buffer.
  • Get next token: parser meminta token satu per satu, jadi lexer tidak membuat daftar token sekaligus.

Lexeme = teks asli. Token = jenisnya. Pattern = aturan bentuknya, ditulis sebagai RE.

Soal latihan: Pada x = y1 + 10;, sebutkan lexeme dan token-nya.

Lexeme: x, =, y1, +, 10, ;. Token: <id,1> <=> <id,2> <+> <number,10> <;>.

Language adalah himpunan string, dan RE adalah cara menulisnya

himpunan (discrete mathematics) dan string di C operasi pada language (3️⃣)

Kamus: daftar semua kata yang ada di satu bahasa.

kamus selalu terbatas. Language boleh tak terbatas, misalnya semua string 0 dan 1.

Language adalah himpunan string dari alphabet yang sama. Istilah lain yang dipakai di setiap soal:

IstilahArtiContoh
SymbolSatu karakter, tanpa arti sendiria, 0, $
Alphabet ΣHimpunan simbol yang terbatas dan tidak kosongΣ = {0, 1}
StringDeretan simbol dari Σ yang panjangnya terbatas0011
|w|Panjang string w|abcb| = 4
εString kosong|ε| = 0

∅ tidak sama dengan {ε}. ∅ adalah language yang tidak berisi string apa pun. {ε} berisi tepat satu string, yaitu string kosong.

Symbol membentuk string, string membentuk language. ε adalah string, ∅ adalah language.

Soal latihan: Apa beda ε, {ε}, dan ∅?

ε adalah string kosong (bukan language). {ε} adalah language berisi satu string, yaitu ε. ∅ adalah language tanpa string sama sekali.

Tiga operasi pada language: concatenation, union, dan Kleene closure

language (2️⃣), union himpunan (discrete mathematics) operator RE (4️⃣), yang adalah singkatan dari operasi ini

Menu kombo: concatenation = satu makanan lalu satu minuman, union = gabung dua menu, star = ambil berapa porsi pun, termasuk nol.

urutan makan bebas. Di concatenation, urutannya tetap: string dari L dulu, baru dari M.

Kleene closure L* adalah gabungan nol string atau lebih dari L. Contoh dengan L = {0, 1, 00, 01, 10} dan M = {10, 11}:

OperasiDefinisiContoh
Concatenation LM{xy | x ∈ L, y ∈ M}LM = {010, 011, 110, 111, 0010, 0011, 0110, 0111, 1010, 1011}
Union L ∪ M{x | x ∈ L atau x ∈ M}L ∪ M = {0, 1, 00, 01, 10, 11}
Kleene closure L*L⁰ ∪ L¹ ∪ L² ∪ …{1}* = {ε, 1, 11, 111, …}
Positive closure L⁺L¹ ∪ L² ∪ …: minimal satu{1}⁺ = {1, 11, 111, …}
Contoh lain dari slide

(1100)* = {ε, 1100, 11001100, …} dan (00+11)* = {ε, 00, 11, 0000, 0011, 1100, 1111, …}.

Concatenation = sambung berurutan. Union = gabung. Star = ulang nol kali atau lebih, jadi ε selalu ikut.

Soal latihan: L = {a, b}, M = {c}. Hitung LM, L ∪ M, dan tiga string terpendek di L*.

LM = {ac, bc}. L ∪ M = {a, b, c}. L* dimulai dengan ε, a, b (lalu aa, ab, ba, bb, …).

Prioritas operator RE: star dulu, lalu concatenation, terakhir union

operasi pada language (3️⃣) membaca dan menulis RE (5️⃣, 6️⃣), Thompson (materi 02)

Seperti pangkat, lalu kali, lalu tambah di aritmetika.

aritmetika punya kurang dan bagi. RE hanya punya tiga operator, dan tanda + kadang berarti union.

Regular expression didefinisikan secara rekursif: ∅, ε, dan setiap simbol a adalah RE. Kalau r dan s RE, maka r|s (atau r+s), rs, dan r* juga RE.

Star paling kuat, union paling lemah. Kalau ragu, pakai kurung.

Soal latihan: Beri kurung lengkap untuk a|bc*, lalu tulis tiga string terpendeknya.

a|(b(c*)). String terpendek: a, b, bc.

Membaca RE: tulis string terpendeknya dulu, lalu cari polanya

operator dan prioritas (4️⃣) menulis RE (6️⃣)

Menebak aturan barisan angka dari beberapa suku pertamanya.

tebakan barisan bisa salah. Uji tebakanmu dengan string yang lebih panjang sebelum menyimpulkan.

Tulis 4–6 string terpendek yang dihasilkan, tebak polanya, lalu uji dengan string yang lebih panjang.

Satu language bisa ditulis dengan banyak RE. Contoh: (r*s*)* = (r|s)*.

String terpendek dulu, pola kemudian, lalu uji dengan string panjang.

Soal latihan: Language apa yang dihasilkan (0|1)*0(0|1)?

String yang simbol keduanya dari kanan adalah 0. String terpendek: 00, 01, 000, 001, 100, 101.

Soal latihan: Kenapa a*b* tidak sama dengan (a|b)*? Beri satu string pembeda.

ba. Di a*b*, semua a harus muncul sebelum semua b, jadi ba ditolak. (a|b)* menerimanya.

Menulis RE: cocokkan kalimat soal dengan salah satu pola

membaca RE (5️⃣) soal "atau" dan "dan" (7️⃣)

Template surat: kamu tinggal mengisi bagian yang kosong.

template tidak memeriksa isinya. RE yang diisi dari pola tetap harus diuji (8️⃣).

Soal biasanya berbentuk "string di atas Σ yang …". Tentukan alphabet dulu: "simbol apa saja" = (0|1), "string apa saja" = (0|1)*. Lalu ganti X dengan string yang diminta:

Kalimat soalPolaKenapa
diawali XX(0|1)*X wajib di depan, sisanya bebas
diakhiri X(0|1)*Xbebas di depan, X wajib di akhir
memuat substring X(0|1)*X(0|1)*bebas di kedua sisi X
simbol ke-k dari kanan adalah 1(0|1)*1 lalu (k − 1) kali (0|1)tepat (k − 1) simbol setelah 1
simbol ke-k dari kiri adalah 1(k − 1) kali (0|1), lalu 1(0|1)*tepat (k − 1) simbol sebelum 1
panjang genap((0|1)(0|1))*setiap putaran star menambah 2 simbol

(a|b)*abb berarti diakhiri abb. Untuk "diawali abb", abb ditulis di depan: abb(a|b)*.

Diawali: X di depan. Diakhiri: X di belakang. Memuat: bebas di kedua sisi.

Soal latihan: String 0 dan 1 yang simbol ketiganya dari kanan adalah 1.

(0|1)*1(0|1)(0|1). Setelah angka 1 itu ada tepat dua simbol. Uji: 100 diterima, 0100 diterima, 010 ditolak, 11 ditolak (terlalu pendek).

Soal latihan: String di atas {a, b} yang diawali abb.

abb(a|b)*

Soal latihan: String di atas {0, 1} yang memuat substring 011.

(0|1)*011(0|1)*

Untuk "atau" pakai union, untuk "dan" union semua urutan kemunculan

pola (6️⃣), union (3️⃣) mengecek jawaban (8️⃣)

"Ani dan Budi sudah datang" bisa terjadi dengan Ani datang dulu, atau Budi datang dulu.

di daftar hadir urutan tidak penting. Di RE urutan penting, jadi setiap urutan harus ditulis sendiri.

"A atau B" cukup RE_A | RE_B. RE tidak punya operator "dan", jadi untuk "memuat A dan B" kamu menulis setiap urutan kemunculan lalu menggabungkannya dengan union.

Contoh: string di atas {a, b, c} yang memuat minimal satu a dan satu b

Misalkan Σ* = (a|b|c)*.

  1. a lebih dulu: Σ* a Σ* b Σ*. Bagian Σ* menampung huruf apa pun di sela-selanya.
  2. b lebih dulu: ba juga harus diterima, jadi butuh Σ* b Σ* a Σ*.
  3. Gabungkan dengan union.
(a|b|c)* a (a|b|c)* b (a|b|c)*  |  (a|b|c)* b (a|b|c)* a (a|b|c)*

Cek cepat. Harus diterima: ab, ba, cabc. Harus ditolak: ε, aaa, cbc.

"Atau" = union. "Dan" = union dari semua urutan.

Soal latihan: String di atas {a, b, c} yang memuat minimal satu a dan satu b.

(a|b|c)*a(a|b|c)*b(a|b|c)* | (a|b|c)*b(a|b|c)*a(a|b|c)*. Butuh dua urutan, karena a boleh muncul sebelum atau sesudah b. Dengan satu urutan saja, ba ditolak.

Soal latihan: String di atas {0, 1} yang diawali atau diakhiri (atau keduanya) dengan 01.

01(0|1)* | (0|1)*01. "Atau keduanya" tidak butuh bagian tambahan, karena string seperti 0101 sudah cocok dengan bagian kiri.

Uji RE dengan ε, string terpendek, dan string yang hampir benar

RE yang kamu tulis (6️⃣, 7️⃣) ε-NFA dari RE (materi 02)

Menguji rem mobil di jalan lurus saja tidak cukup. Rem juga harus diuji di turunan.

tes mobil tidak pernah selesai. Untuk RE, visualisasi bisa mengecek semua string sampai panjang tertentu sekaligus.

RE yang salah biasanya gagal di string pendek. Uji dengan tiga kelompok ini:

  1. ε dan string terpendek yang seharusnya diterima. "Diakhiri 011": apakah 011 sendiri diterima?
  2. String yang hampir benar tapi harus ditolak. "Ke-3 dari kanan = 1": 100 diterima, 010 ditolak.
  3. Urutan lain yang juga memenuhi soal. Soal "dan": ab dan juga ba.

Buka cek RE, pilih soal, lalu tulis RE-mu. Visualisasi membandingkannya dengan kunci untuk semua string sampai panjang 6–8.

Satu string pendek yang salah sudah cukup untuk membuktikan RE-mu salah.

Soal latihan: Tulis RE untuk string 0 dan 1 yang tidak memuat 00, lalu uji.

(1|01)*(0|ε). Setiap 0 di tengah harus langsung diikuti 1, jadi bagian yang diulang adalah 1 atau 01. Di akhir boleh ada satu 0 tambahan. Uji: ε, 0, 010, 1101 diterima, 100 ditolak.

Regular definition memberi nama pada potongan RE supaya mudah dibaca

pattern untuk token (1️⃣) cara lexer mendefinisikan token di praktik

Variabel di program: hitung sekali, beri nama, lalu pakai berkali-kali.

variabel bisa diubah nilainya. Nama di regular definition tetap, dan hanya boleh memakai nama yang didefinisikan sebelumnya.

Regular definition adalah deretan definisi d₁ → r₁, d₂ → r₂, …. Hasilnya sama dengan satu RE panjang, tapi lebih mudah dibaca.

letter       → A | B | … | Z | a | b | … | z
digit        → 0 | 1 | … | 9
id           → letter (letter | digit)*

digits       → digit digit*
opt-fraction → ( . digits )?
opt-exponent → ( E (+|-)? digits )?
unsigned-num → digits opt-fraction opt-exponent

unsigned-num cocok dengan 5280, 39.37, 6.336E4, dan 1.894E-4. Tanpa nama, RE untuk id menjadi (A|…|z)((A|…|z)|(0|…|9))*.

Regular definition = RE yang dipecah dan diberi nama. Isinya tetap satu RE.

Soal latihan: Tulis regular definition untuk bilangan bulat dengan tanda opsional, misalnya -12, +7, 30. 
sign    → + | -
digit   → 0 | 1 | … | 9
integer → sign? digit digit*

Kesalahan yang sering muncul: arah pola tertukar dan urutan yang terlupa

semua section sebelumnya mengecek jawabanmu sendiri

Salah membaca petunjuk "belok kiri setelah masjid" menjadi "sebelum masjid".

salah jalan masih bisa putar balik. RE dengan arah tertukar langsung menerima string yang salah.

Setiap kesalahan di bawah membuat RE menerima string yang salah, atau menolak string yang benar.

Soal latihan: Temanmu menjawab (0|1)*01 untuk "diawali 01". String apa yang membuktikan jawabannya salah?
