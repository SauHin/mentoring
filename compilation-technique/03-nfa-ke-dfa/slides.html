Notes 1️⃣ · DFA dan NFA

DFA selalu punya tepat satu state tujuan, NFA boleh punya nol atau banyak

Keduanya mengenali language yang sama kuatnya. Bedanya ada di jumlah pilihan pada setiap langkah.

Notes 2️⃣ · Ide subset construction

Catat himpunan state yang aktif, dan himpunan itu menjadi satu state DFA

Dari satu himpunan, setiap simbol membawa ke tepat satu himpunan lain. Itulah subset construction.

a b →0 {0,1} {0} 1 - {2} 2 - {3} *3 - -
  • Mulai di {0}. Setelah a, NFA bisa di 0 atau 1: himpunan {0,1}.
  • Dari {0,1} dengan b: δ(0,b) ∪ δ(1,b) = {0} ∪ {2} = {0,2}.
  • NFA dengan n state punya paling banyak 2ⁿ himpunan, jadi prosesnya pasti selesai.

Notes 3️⃣ · ECLOSE

ECLOSE(q) adalah q ditambah semua state yang terjangkau lewat ε saja

Di ε-NFA, mesin bisa pindah lewat ε kapan saja tanpa membaca simbol. ECLOSE mengumpulkan semua state itu.

ε a b →0 {1,7} - - 1 {2,4} - - 2 - {3} - 3 {6} - - 4 - - {5} 5 {6} - - 6 {1,7} - - 7 - {8} - *8 - - -
  1. Basis: q selalu ada di ECLOSE(q).
  2. Induksi: kalau p ada di ECLOSE(q) dan ada ε dari p ke r, masukkan r.
  3. Ulangi sampai tidak ada yang bertambah. ECLOSE(0) = {0,1,7}, lalu dari 1: 2 dan 4. Hasil: {0,1,2,4,7}.

Notes 4️⃣ · Menjalankan string

Menjalankan string pada ε-NFA: pindahkan semua state aktif, lalu ambil ECLOSE

ε-NFA bilangan desimal dari slide (d = digit apa saja). Contoh: string 5.6.

ε + - . d →q0 {q1} {q1} {q1} - - q1 - - - {q2} {q1,q4} q2 - - - - {q3} q3 {q5} - - - {q3} q4 - - - {q3} - *q5 - - - - -

awal{q0}{q0,q1}

Himpunan akhir memuat final q5, jadi 5.6 accepted. -31 berakhir di {q1,q4} tanpa q5, jadi rejected.

Notes 5️⃣ · Resep

Setiap sel tabel DFA = ECLOSE(move(himpunan, simbol)), sampai tidak ada himpunan baru

move(S, a) adalah gabungan δ(p, a) untuk semua p di S. Langkahnya sama dengan menjalankan string, untuk semua simbol.

  1. Start DFA = ECLOSE(q₀), beri nama A. Tanpa ε, cukup {q₀}.
  2. Ambil baris yang belum diproses. Untuk setiap simbol, isi sel dengan ECLOSE(move).
  3. Himpunan baru = baris baru. Hasil ∅ = dead state.
  4. Ulangi sampai semua baris diproses.
  5. Final DFA = setiap himpunan yang memuat minimal satu final NFA.

Notes 6️⃣ · Contoh tanpa ε

Tanpa ε, setiap sel cukup gabungan transisi anggota himpunannya

Contoh slide: δ(q0,0) = {q0,q1}, δ(q0,1) = {q1}, δ(q1,0) = ∅, δ(q1,1) = {q0,q1}, final q1.

DFAHimpunan01
→A{q0}{q0,q1} = B{q1} = C
*B{q0,q1}{q0,q1} ∪ ∅ = B{q1} ∪ {q0,q1} = B
*C{q1}∅{q0,q1} = B

B dan C final karena keduanya memuat q1. Sel ∅ adalah dead state: boleh digambar sebagai state jebakan atau tidak digambar.

Notes 7️⃣ · Contoh ε-NFA

Di ε-NFA, start dan setiap sel harus diambil ECLOSE-nya

Contoh slide: ε-NFA (a|b)*a di slide ECLOSE (state 0 sampai 8).

→A{0,1,2,4,7}{3,8}, jadi {1,2,3,4,6,7,8} = B{5}, jadi {1,2,4,5,6,7} = C

Hanya B yang memuat 8 (final NFA), jadi hanya B yang final. Artinya string diterima kalau diakhiri a.

Notes 8️⃣ · Kesalahan umum

Kesalahan paling sering: lupa ECLOSE dan salah menentukan final

Ringkasan

Subset construction mengubah "banyak state sekaligus" menjadi "satu himpunan state".

  • State DFA = himpunan state NFA yang mungkin aktif.
  • ECLOSE(q) = q dan semua state yang terjangkau lewat ε. Start DFA = ECLOSE(q₀).
  • Sel tabel = ECLOSE(move(himpunan, simbol)). Himpunan baru = baris baru.
  • Final DFA = himpunan yang memuat minimal satu final NFA.

Soal

Latihan slide dosen. Buat tabel DFA-nya, lalu cek di slide berikutnya atau di visualisasi ("Latihan 1/2/3").

  1. p: 0 ke {p,q}, 1 ke {p}; q: 0 ke {r}, 1 ke {r}; r: 0 ke {s}, 1 ke ∅; *s: 0 ke {s}, 1 ke {s}. Start p.
  2. p: 0 ke {p,q}, 1 ke {p}; q: 0 ke {r,s}, 1 ke {t}; r: 0 ke {p,r}, 1 ke {t}; *s, *t: kosong. Start p.
  3. ε-NFA. p: ε ke ∅, a ke {p}, b ke {q}, c ke {r}; q: ε ke {p}, a ke {q}, b ke {r}; *r: ε ke {q}, a ke {r}, c ke {p}. Transisi yang tidak disebut = ∅.
