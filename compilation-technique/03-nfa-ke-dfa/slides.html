NFA → DFA (subset construction)

Compilation technique · soal "ubah NFA / NFA-ε berikut menjadi DFA" dan "apakah string ini diterima?". Kuncinya: ECLOSE dan himpunan state.

DFA dan NFA

Keduanya mengenali language yang sama kuatnya (regular language). Bedanya ada pada berapa banyak pilihan di setiap langkah.

DFANFA
Fungsi transisiδ : Q × Σ → Q, tepat satu state tujuanδ : Q × (Σ ∪ {ε}) → himpunan state: nol, satu, atau banyak
Jalur untuk satu stringTepat satuBisa banyak sekaligus

Jumlah stateSering lebih banyakSering lebih sedikit, dan mudah dibuat dari RE

Ide: state DFA = himpunan state NFA

NFA bisa berada di beberapa state sekaligus. Kalau kita mencatat himpunan state yang aktif, setiap simbol membawa himpunan itu ke tepat satu himpunan lain. Itu sudah sebuah DFA.

a b →0 {0,1} {0} 1 - {2} 2 - {3} *3 - -
  • Mulai di {0}. Setelah membaca a, NFA bisa di 0 atau 1: himpunan {0,1}.
  • Dari {0,1} dengan b: δ(0,b) ∪ δ(1,b) = {0} ∪ {2} = {0,2}.
  • Himpunan yang berbeda menjadi state DFA yang berbeda. NFA dengan n state punya paling banyak 2ⁿ himpunan, jadi prosesnya pasti selesai.

ECLOSE: semua state yang terjangkau tanpa input

Di ε-NFA, mesin bisa pindah lewat ε kapan saja tanpa membaca simbol. ECLOSE(q) adalah q ditambah semua state yang bisa dicapai dari q lewat ε saja, berapa pun langkahnya.

ε a b →0 {1,7} - - 1 {2,4} - - 2 - {3} - 3 {6} - - 4 - - {5} 5 {6} - - 6 {1,7} - - 7 - {8} - *8 - - -
  1. Basis: q selalu ada di ECLOSE(q).
  2. Induksi: kalau p ada di ECLOSE(q) dan ada ε dari p ke r, masukkan r.
  3. Ulangi sampai tidak ada yang bertambah. Contoh: ECLOSE(0) = {0, 1, 7} lalu dari 1: {2, 4} → {0,1,2,4,7}.

Menjalankan string pada ε-NFA

Soal "compute string 5.6" dikerjakan dengan mencatat himpunan state aktif. Setiap simbol: pindahkan semua state aktif, lalu ambil ECLOSE. Di ε-NFA bilangan desimal ini, d = digit apa saja.

ε + - . d →q0 {q1} {q1} {q1} - - q1 - - - {q2} {q1,q4} q2 - - - - {q3} q3 {q5} - - - {q3} q4 - - - {q3} - *q5 - - - - -
BacaPindahECLOSE
awal{q0}{q0,q1}
5{q1,q4}{q1,q4}
.{q2,q3}{q2,q3,q5}
6{q3}{q3,q5}

Input habis dan himpunan akhir memuat final state q5, jadi 5.6 accepted. Untuk -31, himpunan akhirnya {q1,q4} tanpa q5, jadi rejected.

Resep subset construction

Langkahnya sama dengan menjalankan string, tetapi untuk semua simbol dari semua himpunan yang muncul. Hasilnya ditulis sebagai tabel DFA.

  1. Start state DFA = ECLOSE(q₀). Kalau NFA tidak punya ε, cukup {q₀}. Beri nama A.
  2. Ambil state DFA yang belum diproses. Untuk setiap simbol a: gabungkan δ(p, a) untuk semua p di himpunan itu (move), lalu ambil ECLOSE-nya.
  3. Kalau himpunan hasilnya baru, tambahkan sebagai baris baru. Kalau sudah ada, tulis namanya. Kalau ∅, itu dead state.
  4. Ulangi langkah 2 sampai semua baris diproses.
  5. Final state DFA = setiap himpunan yang memuat minimal satu final state NFA.

Contoh slide: NFA tanpa ε

NFA M = ({q0,q1}, {0,1}, δ, q0, {q1}) dengan δ(q0,0) = {q0,q1}, δ(q0,1) = {q1}, δ(q1,0) = ∅, δ(q1,1) = {q0,q1}.

B dan C final karena keduanya memuat q1. Sel ∅ adalah dead state: boleh ditulis sebagai state jebakan, atau tidak digambar.

Contoh slide: ε-NFA (a|b)*a

Pakai ε-NFA di slide ECLOSE (state 0 sampai 8). Setiap sel = ECLOSE(move(himpunan, simbol)).

Hanya B yang memuat 8 (final NFA), jadi hanya B yang final. Artinya: string diterima kalau diakhiri a.

Kesalahan yang sering muncul

Hampir semua kesalahan berasal dari lupa ECLOSE atau salah menentukan final state.

KesalahanAkibatnyaPerbaikan
Start state = {q₀} di ε-NFAState yang bisa dicapai lewat ε dari q₀ hilangStart = ECLOSE(q₀)
Lupa ECLOSE setelah moveHimpunan kurang, DFA menolak string yang benarSetiap sel = ECLOSE(move(…))
Final DFA = himpunan yang sama persis dengan F{q0,q1} tidak dianggap final padahal memuat q1Final = memuat minimal satu final NFA
{q0,q1} dan {q1,q0} dianggap berbedaState ganda, tabel tidak pernah selesaiHimpunan tidak punya urutan. Tulis terurut.
Berhenti sebelum semua baris diprosesAda state tanpa transisiProses setiap himpunan baru

Ringkasan

  • State DFA adalah himpunan state NFA yang mungkin aktif.
  • ECLOSE(q) = q dan semua state yang terjangkau lewat ε. Start DFA = ECLOSE(q₀).
  • Isi tabel: untuk setiap himpunan dan simbol, move lalu ECLOSE. Himpunan baru = baris baru.
  • Final DFA = himpunan yang memuat minimal satu final NFA.
  • Menjalankan string pada ε-NFA memakai langkah yang sama, hanya untuk simbol-simbol string itu.
