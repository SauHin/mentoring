NFA → DFA (subset construction)

Setiap state DFA adalah himpunan state NFA yang mungkin aktif. Proses satu baris tabel DFA untuk setiap simbol, sampai tidak ada himpunan baru. State NFA yang disorot = himpunan hasil langkah ini.

Ubah tabel NFA

Baris pertama: simbol input (tulis ε untuk ε-transition). Setiap baris berikutnya: nama state (→ = start, * = final), lalu satu sel per simbol: {p,q}, atau - kalau kosong.
