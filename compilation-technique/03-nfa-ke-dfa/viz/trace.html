Jalankan string pada NFA

Visualisasi ini menjalankan string pada NFA. NFA bisa berada di beberapa state sekaligus: setiap simbol memindahkan semua state aktif, lalu state yang bisa dicapai lewat ε ditambahkan.

Coba: pilih contoh, ketik string di kolom String (misalnya 5.6 atau -31), lalu klik Langkah berikutnya.

Perhatikan: state oranye adalah state aktif. String accepted kalau setelah input habis ada final state yang oranye.

Ubah tabel NFA

Format sama dengan viz subset construction. Simbol d berarti digit apa saja, jadi string boleh ditulis 5.6.

NFA oranye = state aktif
