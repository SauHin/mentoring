Compilation technique · 03

NFA → DFA (subset construction)

Setiap NFA, termasuk ε-NFA, punya DFA yang menerima language yang sama. Caranya: jadikan setiap himpunan state NFA yang mungkin aktif sebagai satu state DFA.

Slide · Visualisasi: subset construction · Visualisasi: jalankan string

TL;DR
  • ECLOSE(q) = q ditambah semua state yang terjangkau lewat ε saja.
  • Start DFA = ECLOSE(q₀). Setiap sel tabel DFA = ECLOSE(move(himpunan, simbol)), dengan move = gabungan δ(p, simbol) untuk setiap p di himpunan.
  • Himpunan baru = baris baru. Ulangi sampai semua baris diproses.
  • Final DFA = himpunan yang memuat minimal satu final state NFA.

NFA lebih mudah dibuat (misalnya dari RE lewat Thompson), tetapi DFA lebih mudah dijalankan. Karena itu lexer biasanya membangun NFA dari RE, lalu mengubahnya ke DFA.

2. ECLOSE

Basis: q ∈ ECLOSE(q). Induksi: kalau p ∈ ECLOSE(q) dan ada transisi ε dari p ke r, maka r ∈ ECLOSE(q). Untuk himpunan S, ECLOSE(S) = gabungan ECLOSE(q) untuk setiap q ∈ S.

3. Menjalankan string pada ε-NFA

δ̂(q₀, w) dihitung simbol demi simbol: mulai dari ECLOSE(q₀), lalu untuk setiap simbol a, pindahkan semua state aktif dengan a, dan ambil ECLOSE hasilnya. String diterima kalau himpunan akhir memuat final state.

ε + - . d →q0 {q1} {q1} {q1} - - q1 - - - {q2} {q1,q4} q2 - - - - {q3} q3 {q5} - - - {q3} q4 - - - {q3} - *q5 - - - - -

ε-NFA dari slide untuk bilangan desimal: tanda + atau − (boleh tidak ada), digit, titik, digit. Salah satu bagian digit boleh kosong. d = digit 0 sampai 9.

4. Subset construction

  1. Start DFA = ECLOSE(q₀) (NFA tanpa ε: {q₀}). Beri nama A.
  2. Selama masih ada state DFA S yang belum diproses, untuk setiap simbol a:
    • move(S, a) = gabungan δ(p, a) untuk semua p ∈ S,
    • δD(S, a) = ECLOSE(move(S, a)).
    Kalau hasilnya himpunan baru, tambahkan sebagai state DFA baru.
  3. Final DFA = setiap S yang memuat minimal satu state di F.

Hasil ∅ berarti tidak ada jalur sama sekali (dead state). Slide dosen kadang menuliskannya sebagai state ∅. Kamu boleh menggambarnya sebagai state jebakan (semua transisi ke dirinya sendiri), atau tidak menggambarnya, asalkan konsisten.

3. ε-NFA: p: ε → ∅, a → {p}, b → {q}, c → {r}; q: ε → {p}, a → {q}, b → {r}, c → ∅; *r: ε → {q}, a → {r}, b → ∅, c → {p}. Start p.

Jawaban

ECLOSE(p) = {p}, ECLOSE(q) = {p,q}, ECLOSE(r) = {p,q,r}.
