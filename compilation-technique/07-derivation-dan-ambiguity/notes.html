Derivation, parse tree, dan ambiguity

Parser mengecek apakah urutan token bisa diturunkan dari grammar. Bukti penurunannya ditulis sebagai derivation (LMD atau RMD) atau digambar sebagai parse tree.

Slide · Visualisasi: derivation dan parse tree

TL;DR
  • LMD: selalu ganti variabel paling kiri. RMD: paling kanan. Keduanya dimulai dari S.
  • LMD dan RMD untuk string yang sama menghasilkan parse tree yang sama, hanya urutannya berbeda.
  • Ambiguous = ada string dengan dua parse tree (dua LMD). Satu contoh string sudah cukup sebagai bukti.
  • Ekspresi tanpa ambiguity: satu variabel per tingkat prioritas, E → E+T | T, T → T*F | F, F → (E) | id.

1. Parser di dalam compiler

Parser (syntax analyzer) menerima token dari lexer, mengecek apakah urutannya mengikuti grammar, membangun parse tree (atau AST), dan melaporkan syntax error. Lexer hanya mengecek kata, parser mengecek susunan kata.

if ( x > 0 )     token valid, susunan valid
if ( > x 0 )     token valid, susunan tidak valid → syntax error

Parser dibagi dua kelompok: top-down (tree dibangun dari root) dan bottom-up (dari leaf). Keduanya membaca input dari kiri ke kanan, satu token per langkah. Parser yang efisien hanya bisa dibuat untuk sebagian CFG: LL untuk top-down, LR untuk bottom-up.

2. Derivation

Satu langkah derivation ⇒ mengganti satu variabel dengan ruas kanan salah satu produksinya. Contoh grammar kalimat dari slide:

<sentence>  → <subject> <predicate>
<subject>   → <noun>
<predicate> → <verb> <object>
<object>    → <noun>
<noun>      → dog | rice | people
<verb>      → eat | hit

RMD untuk "dog eat dog":

<sentence> ⇒ <subject> <predicate>
           ⇒ <subject> <verb> <object>
           ⇒ <subject> <verb> <noun>
           ⇒ <subject> <verb> dog
           ⇒ <subject> eat dog
           ⇒ <noun> eat dog
           ⇒ dog eat dog

"hit the dog" tidak bisa diturunkan (tidak ada subject di depan, dan "the" bukan terminal), jadi kalimat itu salah menurut grammar ini.

3. Parse tree dan AST

Parse tree: root = start symbol, setiap node dalam = variabel, anak-anaknya = ruas kanan produksi yang dipakai, leaf = terminal (atau ε). Membaca leaf dari kiri ke kanan menghasilkan string-nya. Contoh (a+b)*c dengan E → E+E | E*E | (E) | a | b | c | d:

AST membuang detail grammar (variabel perantara, kurung) dan hanya menyimpan operator dan operand. Parse tree menjelaskan bagaimana program di-parse, AST menjelaskan apa arti program itu.

4. Ambiguity

Grammar ambiguous kalau ada string di L(G) yang punya lebih dari satu parse tree, atau lebih dari satu LMD (atau RMD). Kalau setiap string punya paling banyak satu parse tree, grammar itu unambiguous.

Ambiguity berbahaya karena compiler harus memberi satu arti. Grammar ekspresi di atas ditulis ulang menjadi:

E → E + T | T
T → T * F | F
F → ( E ) | id
  • Setiap tingkat prioritas punya variabel sendiri. Operator dengan prioritas lebih tinggi berada lebih dalam di tree, jadi dikerjakan lebih dulu.
  • Rekursi di kiri (E → E + T) membuat operator left associative.
  • Tidak ada algoritma umum yang bisa mengubah sembarang ambiguous grammar menjadi unambiguous. Bahkan menentukan apakah sebuah grammar ambiguous pun tidak bisa diputuskan oleh algoritma.
Inherently ambiguousSebuah context-free language disebut inherently ambiguous kalau semua grammar-nya ambiguous. Contoh dari slide: L = {aⁿbⁿcᵐdᵐ | n, m ≥ 1} ∪ {aⁿbᵐcᵐdⁿ | n, m ≥ 1}, dengan grammar S → AB | C, A → aAb | ab, B → cBd | cd, C → aCd | aDd, D → bDc | bc. String aabbccdd masuk ke kedua bagian, jadi selalu punya dua tree. Coba di visualisasi.

6. Latihan

1. (Latihan dosen) Grammar E → E + T | T, T → T * F | F, F → ( E ) | id, string id + id * id. Buat LMD, RMD, parse tree, lalu jelaskan apakah grammar ini menegakkan prioritas perkalian.

Jawaban 
LMD: E ⇒ E+T ⇒ T+T ⇒ F+T ⇒ id+T ⇒ id+T*F ⇒ id+F*F ⇒ id+id*F ⇒ id+id*id
RMD: E ⇒ E+T ⇒ E+T*F ⇒ E+T*id ⇒ E+F*id ⇒ E+id*id ⇒ T+id*id ⇒ F+id*id ⇒ id+id*id

Ya. * hanya bisa dihasilkan dari T, dan T berada di bawah E. Jadi id * id selalu menjadi satu subtree di bawah +: perkalian dikelompokkan lebih dulu. Untuk string ini hanya ada satu parse tree.

2. Dengan grammar E → E+E | E*E | (E) | a | b | c | d, buat LMD untuk (a+b)*c.

Jawaban
E ⇒ E*E ⇒ (E)*E ⇒ (E+E)*E ⇒ (a+E)*E ⇒ (a+b)*E ⇒ (a+b)*c

3. Tunjukkan bahwa S → aS | Sa | a ambiguous.

Jawaban

String aa punya dua LMD: S ⇒ aS ⇒ aa dan S ⇒ Sa ⇒ aa. Dua LMD berbeda = dua parse tree, jadi ambiguous.

4. Buat RMD untuk id * ( id + id ) dengan grammar di soal 1.

Jawaban
E ⇒ T ⇒ T*F ⇒ T*(E) ⇒ T*(E+T) ⇒ T*(E+F) ⇒ T*(E+id) ⇒ T*(T+id)
  ⇒ T*(F+id) ⇒ T*(id+id) ⇒ F*(id+id) ⇒ id*(id+id)
