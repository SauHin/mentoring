Predictive parsing, FIRST, dan FOLLOW

Compilation technique · materi 10 · prasyarat: left factoring (materi 08) dan left recursion (materi 09)

Target: kamu bisa menghitung FIRST dan FOLLOW setiap variabel tanpa melompati aturan, termasuk saat ada ε.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Backtracking

Recursive descent mencoba produksi satu per satu dan mundur kalau gagal

Recursive descent = satu fungsi rekursif per variabel. Backtracking: kembali ke pilihan terakhir dan mencoba alternatif lain. Contoh slide: S → aBc, B → bc | b, input abc.

LangkahYang dicobaHasil
1S → aBc, cocokkan acocok
2B → bc, cocokkan b, ccocok, input habis
3S masih butuh cgagal, backtrack ke B
4B → b, cocokkan bcocok
5S cocokkan ccocok, input habis: berhasil

Hasilnya benar, tapi pekerjaan diulang-ulang, jadi lambat dan jarang dipakai.

Notes 2️⃣ · Predictive parser

Predictive parser memilih produksi dari token sekarang, jadi tidak perlu backtracking

Predictive parser melihat satu token (lookahead, materi 08) untuk memilih alternatif.

stmt → if …  |  while …
     | begin …  |  for …

token sekarang if
jadi pasti alternatif pertama
  • Syarat 1: tidak left recursive (materi 09).
  • Syarat 2: sudah left factoring (materi 08).
  • Belum jaminan 100%: grammar yang pasti bisa disebut LL(1) grammar (materi 11).

Dua jenis: recursive (satu procedure per variabel) dan non-recursive (stack dan tabel, materi 11). Keduanya butuh FIRST dan FOLLOW.

Notes 3️⃣ · Satu procedure per variabel

Setiap variabel menjadi procedure, dan token sekarang memilih case-nya

Recursive predictive parsing: recursive descent tanpa backtracking. Contoh slide A → aBb | bAB, pseudo-code mirip C.

void A() {
    switch (token) {
    case 'a': match('a'); B(); match('b'); break;
    case 'b': match('b'); A(); B(); break;
    default:  error();
    }
}
  • Terminal menjadi match: cek token, lalu maju.
  • Variabel menjadi panggilan procedure-nya.
  • Label case = token yang mengawali alternatif.

Notes 4️⃣ · ε-production

B → ε dipilih kalau token sekarang bisa muncul tepat setelah B

Contoh slide: A → aBe | cBd | C, B → bB | ε, C → f. Lihat label case yang tidak terlihat langsung di produksi.

void A() { switch (token) {
    case 'a': match('a'); B(); match('e'); break;
    case 'c': match('c'); B(); match('d'); break;
    case 'f': C(); break;
    default:  error(); } }
void B() { switch (token) {
    case 'b': match('b'); B(); break;
    case 'e': case 'd': break;   // B → ε
    default:  error(); } }
  • f = terminal pertama dari C. Set ini disebut FIRST.
  • e, d = token yang bisa datang setelah B. Set ini disebut FOLLOW.
  • Token lain di B: error, bukan ε.

Notes 5️⃣ · FIRST

FIRST(α) berisi terminal yang bisa muncul paling depan di string hasil α

FIRST(α): kalau α bisa menjadi ε, ε juga masuk. Untuk variabel, gabungkan hasil semua produksinya.

Kalau produksi diawali variabel lain, hitung FIRST variabel itu dulu.

Notes 6️⃣ · FIRST dengan ε

Kalau simbol paling depan bisa menjadi ε, FIRST lanjut ke simbol berikutnya

Variabel yang bisa menjadi ε disebut nullable, seperti di materi 04.

S → ABc      A → a | ε      B → b | ε

FIRST(A) tanpa ε = {a}   A nullable, lanjut
FIRST(B) tanpa ε = {b}   B nullable, lanjut
c terminal       = {c}   berhenti

FIRST(S) = {a, b, c}
  • Berhenti di simbol pertama yang tidak nullable.
  • ε masuk FIRST(S) hanya kalau semua simbolnya nullable. Di sini tidak, karena ada c.
  • Cara sama untuk deretan: FIRST(Bc) = {b, c}.

Notes 7️⃣ · FOLLOW

FOLLOW(B) dimulai dari $ dan dari apa pun yang ada tepat di kanan B

FOLLOW(B): terminal yang bisa muncul tepat setelah B. $ = tanda akhir input. Cari B di ruas kanan.

AturanIsiContoh grammar ekspresi
1$ masuk FOLLOW(start symbol)$ masuk FOLLOW(E)
2A → αBβ: FIRST(β) tanpa ε masuk FOLLOW(B)F → (E): ) masuk FOLLOW(E)

Jadi FOLLOW(E) = {), $}. FOLLOW tidak pernah memuat ε.

Kalau B paling kanan, atau sisanya nullable, FOLLOW(A) masuk FOLLOW(B)

Aturan 3a: A → αB. Aturan 3b: A → αBβ dengan β nullable. Arahnya dari variabel kiri A ke B.

Ringkasan

FIRST dan FOLLOW menjawab satu pertanyaan: token mana yang memilih produksi mana.

  • Predictive parser: memilih produksi dari satu token, tanpa backtracking.
  • FIRST(α): terminal paling depan. Lanjut ke simbol berikutnya selama nullable.
  • FOLLOW(B): $ untuk start symbol, FIRST dari sisa di kanan B, dan FOLLOW(kiri) kalau B paling kanan atau sisanya nullable.
  • Dipakai untuk: label case di procedure, dan tabel LL(1) di materi 11.

Soal

Kerjakan, lalu cek di slide berikutnya atau di visualisasi.

  1. FIRST untuk A → aBe | cBd | C, B → bB | ε, C → f.
  2. FIRST(S) untuk S → AB, A → a | ε, B → b | ε.
  3. Latihan slide dosen: FIRST dan FOLLOW untuk S → ABC, A → aA | C, B → b, C → c.
