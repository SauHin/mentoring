Compilation technique · 04

RE → DFA langsung (followpos)

Metode ini membuat DFA langsung dari RE, tanpa ε-NFA. Setiap simbol di RE diberi nomor posisi, dan state DFA adalah himpunan posisi yang boleh dibaca berikutnya.

Slide · Visualisasi: empat tahap followpos

TL;DR
  • Kerjakan (r)#. Buat syntax tree, beri nomor posisi pada setiap leaf simbol (bukan ε).
  • Hitung nullable, firstpos, lastpos dari bawah ke atas. Aturan ·: firstpos ikut kanan kalau kiri nullable, lastpos ikut kiri kalau kanan nullable.
  • followpos: node c₁·c₂ → lastpos(c₁) disusul firstpos(c₂). Node c* → lastpos(c) disusul firstpos(c).
  • DFA: start = firstpos(root). Dari S dengan a: gabungkan followpos posisi a di S. Final = memuat posisi #.

1. Augmented RE dan syntax tree

RE r ditambah simbol khusus # di akhir: (r)#. Lalu buat syntax tree: leaf = simbol, node dalam = operator. Setiap leaf simbol (termasuk #) diberi nomor posisi dari kiri ke kanan. Leaf ε tidak diberi nomor.

3. followpos

followpos(i) = himpunan posisi j sehingga ada string di language dengan j tepat setelah i. Dua aturan, dikerjakan untuk setiap node:

  1. Node c₁ · c₂: setiap i ∈ lastpos(c₁) mendapat firstpos(c₂).
  2. Node c*: setiap i ∈ lastpos(c) mendapat firstpos(c).

Node | tidak menambah followpos, karena union hanya memilih satu cabang dan tidak menyambung dua bagian.

4. Membangun DFA

Dstates = { firstpos(root) }, belum ditandai
while ada S yang belum ditandai:
    tandai S
    for setiap simbol a:
        U = gabungan followpos(p) untuk setiap p ∈ S yang simbolnya a
        if U tidak kosong dan belum ada di Dstates: tambahkan U
        Dtran[S, a] = U
start = firstpos(root), final = setiap S yang memuat posisi #

Bandingkan dengan subset construction dari ε-NFA Thompson: hasil metode followpos biasanya punya state lebih sedikit, dan tidak perlu menghitung ECLOSE.

Contoh slide: (a|b)*a

Posisi a = 1, b = 2, a = 3, # = 4. followpos(1) = followpos(2) = {1,2,3}, followpos(3) = {4}. DFA: A = {1,2,3} dengan a → {1,2,3,4} = B, dengan b → A. B dengan a → B, dengan b → A. B final karena memuat 4.

Contoh slide: (a|ε)bc*

Posisi a = 1, b = 2, c = 3, # = 4. (a|ε) nullable, jadi firstpos(root) = {1,2}: string boleh diawali a atau b. followpos(1) = {2}, followpos(2) = {3,4}, followpos(3) = {3,4}. DFA: A = {1,2}: a → B = {2}, b → C = {3,4}; B: b → C; C (final): c → C.

5. Kesalahan yang sering muncul

6. Latihan (dari slide dosen)

Soal. RE (a|b)*(ab|bb)a*. (a) Buat syntax tree. (b) Hitung firstpos, lastpos, followpos. (c) Buat dan gambar DFA-nya.

Jawaban (a): syntax tree beranotasi

Posisi: a = 1, b = 2 (di dalam star pertama), a = 3, b = 4 (ab), b = 5, b = 6 (bb), a = 7 (a*), # = 8.

DFA ini belum minimum: B dan C punya baris yang sama, begitu juga D dan E. Hasil minimisasinya 3 state: {A}, {B,C}, {D,E}. Coba buktikan di materi 05.
