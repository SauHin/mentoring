RE ke DFA langsung (followpos)

Metode ini membuat DFA langsung dari RE, tanpa ε-NFA. Setiap simbol di RE diberi nomor posisi, dan state DFA adalah himpunan posisi yang boleh dibaca berikutnya. Target: kamu bisa membuat syntax tree, menghitung firstpos, lastpos, followpos, lalu membangun DFA-nya.

Setiap simbol di RE diberi nomor posisi, dan # di akhir menandai kapan string boleh berhenti

RE (materi 01), subset construction (materi 03) syntax tree (2️⃣) dan DFA (6️⃣)

Nomor kursi di bioskop: dua kursi sama-sama "kursi biasa", tapi nomornya berbeda.

kamu hanya duduk di satu kursi. Satu state DFA boleh memuat beberapa posisi sekaligus.

Posisi adalah nomor untuk setiap kemunculan simbol di RE, dari kiri ke kanan. RE ditambah # di akhir (augmented RE), dan # juga diberi nomor.

(a | b)* a b b #
 1   2   3 4 5 6
  • Simbol sama, posisi beda: a di posisi 1 dan 3 adalah dua posisi.
  • Arti #: kalau posisi # boleh dibaca berikutnya, string boleh berhenti. Jadi state DFA yang memuat posisi # adalah final.
  • State DFA = himpunan posisi yang boleh dibaca berikutnya. Tidak perlu ε-NFA, jadi langkahnya lebih sedikit.

Kerjakan (r)#, beri nomor setiap simbol. Memuat posisi # = final.

Soal latihan: Beri nomor posisi untuk (a|ε)bc*.

a = 1, b = 2, c = 3, # = 4. ε tidak diberi nomor, karena ε tidak membaca simbol.

Syntax tree: leaf = simbol bernomor, node dalam = operator, root = concatenation dengan #

prioritas operator RE (materi 01) nullable, firstpos, lastpos (3️⃣, 4️⃣)

Diagram kalimat di pelajaran bahasa: kalimat dipecah menjadi subjek, predikat, dan seterusnya.

kalimat kadang ambigu. Syntax tree RE selalu satu, karena prioritas operator sudah tetap.

Syntax tree adalah pohon yang menunjukkan struktur RE. Node dalam: · concatenation, | union, * star. Concatenation dibaca dari kiri, jadi pohonnya condong ke kiri.

  • Root = concatenation terakhir, yaitu dengan #.
  • Leaf ε tidak diberi nomor.

Pohon mengikuti prioritas: star paling bawah, union paling atas, # di root.

Soal latihan (slide dosen, bagian a): Buat syntax tree untuk (a|b)*(ab|bb)a*.

Posisi: a = 1, b = 2 (di dalam star pertama), a = 3, b = 4 (ab), b = 5, b = 6 (bb), a = 7 (a*), # = 8.

nullable: node itu bisa menghasilkan string kosong atau tidak

ε dan star (materi 01) aturan concatenation di firstpos dan lastpos (4️⃣)

Bagian formulir yang boleh dikosongkan.

petugas bisa tetap menolak formulir yang kosong. nullable murni ditentukan aturan tabel di bawah.

Node nullable kalau bagian RE di bawahnya bisa menghasilkan ε. Dihitung dari leaf ke root:

NodenullableKenapa

Star dan ε selalu nullable. Concatenation nullable hanya kalau kedua anaknya nullable.

Soal latihan: Mana yang nullable: a*, (a|ε), ab*, (a|b)*c?

a* T, (a|ε) T, ab* F (a tidak nullable), (a|b)*c F (c tidak nullable).

firstpos dan lastpos: posisi yang bisa menjadi simbol pertama dan terakhir

nullable (3️⃣) followpos (5️⃣) dan start state DFA (6️⃣)

Antrean: siapa saja yang mungkin berdiri paling depan, dan siapa saja yang mungkin paling belakang.

di antrean nyata satu orang pasti paling depan. firstpos bisa berisi beberapa posisi, karena RE punya pilihan.

firstpos(n) adalah posisi yang bisa menjadi simbol pertama dari bagian n, dan lastpos(n) adalah yang bisa menjadi simbol terakhir.

Kenapa aturan ·: kalau c₁ bisa kosong, simbol pertama bisa berasal dari c₂. Contoh: (a|b)*a boleh diawali posisi 3.

Hasil untuk (a|b)*abb#

Kiri node = firstpos (biru), kanan = lastpos (hijau), di atas = nullable. Node · terbawah punya firstpos {1,2,3}, bukan {1,2}, karena (a|b)* nullable.

Concatenation: cek nullable anak kiri untuk firstpos, dan nullable anak kanan untuk lastpos.

Soal latihan: Hitung firstpos root untuk (a|ε)bc*# (posisi a = 1, b = 2, c = 3, # = 4).

(a|ε) nullable, jadi firstpos ikut b: {1,2}. Artinya string boleh diawali a atau b. b tidak nullable, jadi c dan # tidak ikut.

followpos hanya ditambah oleh node concatenation dan star

firstpos dan lastpos (4️⃣) transisi DFA (6️⃣)

Aturan rangkaian kereta: setelah gerbong ini, gerbong mana saja yang boleh dipasang berikutnya.

satu kereta hanya punya satu susunan. followpos mencatat semua kemungkinan sekaligus.

followpos(i) adalah himpunan posisi yang bisa langsung menyusul posisi i di suatu string. Dua aturan, dikerjakan untuk setiap node:

  1. Node c₁ · c₂: setiap i di lastpos(c₁) mendapat firstpos(c₂). Setelah c₁ selesai, c₂ dimulai.
  2. Node c*: setiap i di lastpos(c) mendapat firstpos(c). Setelah satu putaran selesai, putaran berikutnya bisa dimulai.

Node | tidak menambah followpos, karena union hanya memilih satu cabang.

2b{1,2,3}sama dengan posisi 1
3a{4}· dengan b
4b{5}· dengan b
5b{6}· dengan #

Concatenation: lastpos kiri mendapat firstpos kanan. Star: lastpos mendapat firstpos dirinya sendiri.

Membangun DFA: dari himpunan S dengan simbol a, gabungkan followpos posisi a di S

subset construction (materi 03), followpos (5️⃣) minimisasi DFA (materi 05)

Memasak resep yang sama dengan bahan lain: isi himpunannya posisi, bukan state NFA.

bahan lain bisa mengubah rasa. Di sini hasilnya tetap DFA untuk language yang sama.

Langkahnya mirip subset construction, tanpa ECLOSE:

  1. Start = firstpos(root).
  2. Untuk setiap simbol a: ambil posisi di S yang simbolnya a, gabungkan followpos-nya. Himpunan baru = baris baru.
  3. Final = setiap himpunan yang memuat posisi #.

Dibanding subset construction dari ε-NFA Thompson, hasilnya biasanya punya state lebih sedikit, dan tidak perlu ECLOSE.

Start = firstpos(root). Sel = gabungan followpos posisi bersimbol itu. Final = memuat #.

Kesalahan yang sering muncul: aturan concatenation yang lupa mengecek nullable

semua section sebelumnya mengecek jawabanmu sendiri

Pulang tanpa kunci: kamu sampai di depan rumah, tapi tidak bisa masuk.

tanpa kunci kamu masih bisa menunggu. Tanpa #, kamu tidak bisa menentukan state final sama sekali.

Soal latihan: Temanmu menulis firstpos((a|b)*a) = {1,2}. Kenapa salah?

(a|b)* nullable, jadi firstpos ikut anak kanan: {1,2} ∪ {3} = {1,2,3}. String a (tanpa a atau b di depan) harus bisa diawali posisi 3.
