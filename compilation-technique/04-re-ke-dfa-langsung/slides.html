RE ke DFA langsung (followpos)

Compilation technique · materi 04 · prasyarat: RE (materi 01) dan subset construction (materi 03)

Target: kamu bisa membuat syntax tree, menghitung firstpos, lastpos, followpos, lalu membangun DFA tanpa ε-NFA.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Nomor posisi

Setiap simbol di RE diberi nomor posisi, dan # di akhir menandai kapan string boleh berhenti

State DFA adalah himpunan posisi yang boleh dibaca berikutnya. Tidak perlu ε-NFA.

(a | b)* a b b #
 1   2   3 4 5 6
  • Simbol sama, posisi beda: a di posisi 1 dan 3 adalah dua posisi.
  • Augmented RE: # ditambahkan di akhir. State yang memuat posisi # adalah final.
  • "Posisi mana yang boleh menyusul posisi i" dihitung lewat followpos, dari syntax tree.

Notes 2️⃣ · Syntax tree

Syntax tree: leaf = simbol bernomor, node dalam = operator, root = concatenation dengan #

Syntax tree mengikuti prioritas RE. · = concatenation, dibaca dari kiri, jadi pohonnya condong ke kiri.

  • Root = concatenation terakhir, yaitu dengan #.
  • Leaf ε tidak diberi nomor, karena ε tidak membaca simbol.
  • Nomor posisi urut dari kiri ke kanan, sesuai urutan di RE.

Notes 3️⃣ · nullable

nullable: node itu bisa menghasilkan string kosong atau tidak

Dihitung dari leaf ke root. Hasilnya menentukan aturan concatenation di slide berikutnya.

Notes 4️⃣ · firstpos dan lastpos

firstpos dan lastpos: aturan concatenation bergantung pada nullable

firstpos = posisi yang bisa menjadi simbol pertama. lastpos = posisi yang bisa menjadi simbol terakhir.

Nodefirstposlastpos
leaf ε / posisi i∅ / {i}∅ / {i}
c₁ | c₂first(c₁) ∪ first(c₂)last(c₁) ∪ last(c₂)
c₁ · c₂first(c₁), ditambah first(c₂) kalau c₁ nullablelast(c₂), ditambah last(c₁) kalau c₂ nullable

Kalau c₁ bisa kosong, simbol pertama string bisa berasal dari c₂. Contoh: (a|b)*a boleh diawali posisi 3.

Notes 4️⃣ · firstpos dan lastpos

Untuk (a|b)*abb#, firstpos node concatenation terbawah adalah {1,2,3}

Kiri node = firstpos (biru), kanan = lastpos (hijau), di atas = nullable.

Bukan {1,2}, karena (a|b)* nullable, jadi posisi 3 ikut.

Notes 5️⃣ · followpos

followpos hanya ditambah oleh node concatenation dan star

followpos(i) = posisi yang bisa langsung menyusul posisi i. Node | tidak menambah apa pun.

  1. Node c₁ · c₂: setiap i di lastpos(c₁) mendapat firstpos(c₂). Setelah c₁ selesai, c₂ dimulai.
  2. Node c*: setiap i di lastpos(c) mendapat firstpos(c). Setelah satu putaran, putaran berikutnya bisa dimulai.

Kesalahan paling sering: aturan concatenation yang lupa mengecek nullable

Ringkasan

Empat tahap, dan setiap tahap memakai hasil tahap sebelumnya.

  1. Syntax tree dari (r)#, dengan nomor posisi pada setiap simbol.
  2. nullable, firstpos, lastpos dari leaf ke root. Concatenation bergantung pada nullable.
  3. followpos hanya dari node · dan *.
  4. DFA: start = firstpos(root), sel = gabungan followpos posisi bersimbol itu, final = memuat #.

Soal

Latihan slide dosen. Kerjakan di kertas, lalu cek jawabannya di slide berikutnya.

RE: (a|b)*(ab|bb)a*

  1. Buat syntax tree dan beri nomor posisi.
  2. Hitung firstpos, lastpos, dan followpos.
  3. Buat dan gambar DFA-nya.
