Mengerjakan soal kasus

Data structure · dari soal cerita ke program C lengkap dengan linked list, stack, queue, dan priority queue.

Prasyarat: materi 01 sampai 04. Fungsi di sini diambil dari materi itu, jadi fokusnya ada di cara berpikir dan main.

Resep 6 langkah

Soal kasus jarang menyebut operasi secara langsung. Enam langkah ini mengubah cerita menjadi daftar operasi, lalu menjadi program.

  1. Baca format input dan output. Tulis sample input di kertas, lalu tandai arti setiap angka.
  2. Pilih struktur dengan bertanya: siapa yang keluar atau dilayani duluan?
  3. Petakan setiap kalimat soal ke satu operasi (satu fungsi).
  4. Tulis kerangka: struct, createNode, fungsi operasi, lalu main.
  5. Trace sample input dengan tangan, lalu cocokkan dengan sample output.
  6. Cek edge case dan aturan soal, misalnya "wajib memakai linked list" atau "list B harus kosong".

Langkah 2: pilih struktur dari kalimat soal

Cari kalimat yang menjelaskan urutan keluar atau dilayani. Kalimat itu menentukan struktur dan operasinya.

Kalimat di soalStrukturOperasi
"first come first serve", "sesuai urutan datang", antreanQueueenqueue, dequeue
"undo", "kembali ke sebelumnya", "dibalik", kurung berpasanganStackpush, pop
"prioritas", "didahulukan", "paling parah dulu"Priority queuepqPush terurut, pqPop
"maju dan mundur", "sambungkan B ke belakang A"Double linked listinsertBack, append

"membatalkan", "keluar dari antrean", "hapus id x"Struktur apa puncancel (delete berdasarkan nilai)

Contoh soal: lajur tol menyempit

Dua lajur, A (N mobil) dan B (M mobil), menyatu menjadi satu. Mobil masuk bergantian mulai dari A, sesuai urutan di lajurnya. Kalau satu lajur habis, sisa lajur lain masuk berurutan. Lalu L mobil keluar lewat exit. Cetak urutan mobil di lajur gabungan. Wajib memakai queue dengan single linked list.

Sample inputSample output
3 4
11 12 13
21 22 23 24
2
12 24
11 21 22 13 23
  • Baris 1: N dan M. Baris 2 dan 3: nomor mobil di lajur A dan B.
  • Baris 4: L. Baris 5: nomor mobil yang keluar.
  • "Bergantian", "sesuai urutan" = queue. "Keluar" = cancel.

Langkah 3: setiap kalimat menjadi satu operasi

Tulis daftar ini sebelum menulis kode. Kalau semua kalimat soal sudah punya operasi, main tinggal menyusunnya.

Kalimat soalKode
Lajur A berisi N mobil, lajur B berisi M mobilenqueue(&a, x) N kali, enqueue(&b, x) M kali
Masuk bergantian mulai dari A, sisa lajur masuk berurutanPola gabung bergantian dari materi 03
L mobil keluar lewat exitcancel(&merged, x) L kali
Cetak urutanprintQueue(&merged)
Tiga queue sekaligusKarena itu head dan tail dibungkus dalam struct Queue, lalu fungsi menerima Queue* (materi 03).

Langkah 4: kerangka program

Fungsi operasi diambil dari materi sebelumnya. Main hanya memanggil fungsi sesuai urutan soal.

#include <stdio.h>
#include <stdlib.h>
typedef struct Node {...} Node;
typedef struct {...} Queue;
Node* createNode(int x) {...}
void enqueue(Queue* q, int x) {...}
int dequeue(Queue* q) {...}
void cancel(Queue* q, int x) {...}
void printQueue(Queue* q) {...}

int main() {
    // 1. baca input, masukkan ke struktur
    // 2. jalankan operasi sesuai soal
    // 3. cetak sesuai format output
    // 4. free semua node
    return 0;
}
  • Tulis fungsi dulu, lalu uji satu per satu. Kalau enqueue dan printQueue sudah benar, bug di main lebih mudah dicari.
  • Butuh string? Tambahkan #include <string.h> untuk strcpy dan strcmp.
  • Langkah 4 (free) sering lupa. Di soal yang dicek manual, memory leak bisa mengurangi nilai.

main: urutannya sama dengan soal

Setiap blok di main adalah satu baris di daftar langkah 3.

int main() {
    Queue a = {NULL, NULL}, b = {NULL, NULL}, merged = {NULL, NULL};
    int n, m, l, x;
    scanf("%d %d", &n, &m);
    for (int i = 0; i < n; i++) { scanf("%d", &x); enqueue(&a, x); }
    for (int i = 0; i < m; i++) { scanf("%d", &x); enqueue(&b, x); }
    while (a.head != NULL || b.head != NULL) {          // gabung bergantian
        if (a.head != NULL) enqueue(&merged, dequeue(&a));
        if (b.head != NULL) enqueue(&merged, dequeue(&b));
    }
    scanf("%d", &l);
    for (int i = 0; i < l; i++) { scanf("%d", &x); cancel(&merged, x); }
    printQueue(&merged);
    while (merged.head != NULL) dequeue(&merged);       // free semua node
    return 0;
}

Mencetak sesuai format output

Output dibandingkan dengan jawaban huruf demi huruf. Cetak persis seperti sample output, tanpa teks tambahan.

void printQueue(Queue* q) {
    for (Node* cur = q->head; cur != NULL; cur = cur->next) {
        if (cur != q->head) printf(" ");
        printf("%d", cur->data);
    }
    printf("\n");
}
  • Spasi dicetak sebelum setiap angka kecuali yang pertama. Dengan begitu tidak ada spasi di akhir baris, yang di sebagian judge dianggap salah.
  • Jangan mencetak "Output:", "Hasil:", atau prompt seperti "Masukkan N:".
  • Akhiri baris dengan \n.

Langkah 6: aturan soal dan edge case

Soal kasus biasanya dicek manual. Output yang benar belum cukup kalau kode tidak memakai struktur yang diminta.

  • "Wajib memakai linked list" atau "jangan hanya mencetak": semua data harus masuk ke struktur dan diproses lewat operasinya. Program yang langsung mencetak angka dari input dianggap salah, walaupun output-nya cocok.
  • "List B harus kosong": di akhir, b.head dan b.tail harus benar-benar NULL.
  • Buat input sendiri untuk edge case, karena sample jarang mengujinya: struktur kosong (N = 0, L = 0), panjang tidak sama, hapus node pertama, terakhir, atau satu-satunya, dan prioritas seri di tengah antrean.
  • Free semua node sebelum return 0.

Contoh 2: sambung list B ke belakang A

Soal double linked list sering meminta dua list digabung. Dengan tail, cukup satu sambungan dua arah antara tail A dan head B. Tidak ada node yang dipindah satu per satu.

void append(DList* a, DList* b) {
    if (b->head == NULL) return;    // B kosong
    if (a->head == NULL) {
        a->head = b->head;          // A kosong: A = B
    } else {
        a->tail->next = b->head;    // sambungan dua arah
        b->head->prev = a->tail;
    }
    a->tail = b->tail;
    b->head = b->tail = NULL;       // B jadi kosong
}
  • Gabungan ini O(1), berapa pun panjang list-nya.
  • Setelah digabung, node B milik A. B harus dikosongkan. Kalau tidak, free B nanti melepas node yang masih dipakai A (double free).
  • Cetak hasilnya maju dan mundur. Kalau hasil mundur tidak terbalik, ada prev yang lupa disambung.

Ringkasan

  • Ikuti resep: format I/O, pilih struktur, petakan kalimat ke operasi, kerangka, trace, lalu edge case.
  • Struktur dipilih dari kalimat yang menjelaskan siapa yang keluar duluan: urutan datang (queue), yang terbaru (stack), atau prioritas (priority queue).
  • Fungsi operasi diambil dari materi 01 sampai 04. Main hanya menyusun pemanggilan fungsi sesuai urutan soal.
  • Cetak persis sesuai format, uji edge case dengan input sendiri, dan free semua node.
