Notes 1️⃣ · Resep 6 langkah

Tiga langkah pertama dikerjakan sebelum menulis satu baris kode pun

Soal kasus jarang menyebut operasi secara langsung. Enam langkah ini mengubah cerita menjadi daftar operasi, lalu menjadi program.

  1. Baca format input dan output. Tandai arti setiap angka di sample input.
  2. Pilih struktur dengan bertanya: siapa yang keluar atau dilayani duluan?
  3. Petakan setiap kalimat soal ke satu operasi (satu fungsi).
  4. Tulis kerangka: struct, createNode, fungsi operasi, lalu main.
  5. Trace sample input dengan tangan, lalu cocokkan dengan sample output.
  6. Cek edge case dan aturan soal, misalnya "wajib memakai linked list".

Notes 4️⃣ · Mencetak output

Cetak persis seperti sample output, tanpa spasi di akhir baris

Judge adalah program yang membandingkan output-mu dengan jawaban, huruf demi huruf.

void printQueue(Queue* q) {
    for (Node* cur = q->head; cur != NULL; cur = cur->next) {
        if (cur != q->head) printf(" ");
        printf("%d", cur->data);
    }
    printf("\n");
}
  • Spasi dicetak sebelum setiap angka kecuali yang pertama, jadi tidak ada spasi di akhir baris.
  • Jangan mencetak "Output:", "Hasil:", atau prompt seperti "Masukkan N:".
  • Akhiri baris dengan \n.

Notes 5️⃣ · Contoh 1: lajur tol

"Bergantian" dan "sesuai urutan" berarti queue, dan "keluar" berarti cancel

Dua lajur, A (N mobil) dan B (M mobil), menyatu bergantian mulai dari A. Lalu L mobil keluar lewat exit. Cetak urutan lajur gabungan. Wajib queue dengan single linked list.

  • Baris 4: L. Baris 5: nomor mobil yang keluar.
  • Kalau satu lajur habis, sisa lajur lain masuk berurutan.

Notes 5️⃣ · Contoh 1: lajur tol

Kerangka program: fungsi dari materi sebelumnya, lalu main yang mengikuti urutan soal

Tulis fungsi dulu dan uji satu per satu, supaya bug di main lebih mudah dicari (langkah 4).

typedef struct Node {...} Node;
typedef struct {...} Queue;
Node* createNode(int x) {...}
void enqueue(Queue* q, int x) {...}
int dequeue(Queue* q) {...}
void cancel(Queue* q, int x) {...}
void printQueue(Queue* q) {...}

int main() {
    // 1. baca input, masukkan ke struktur
    // 2. jalankan operasi sesuai soal
    // 3. cetak sesuai format output
    // 4. free semua node
    return 0;
}
  • Butuh string? Tambahkan #include <string.h> untuk strcpy dan strcmp.
  • Komentar 4 (free) sering lupa. Di soal yang dicek manual, memory leak bisa mengurangi nilai.

Notes 5️⃣ · Contoh 1: lajur tol

Setiap blok di main adalah satu baris di daftar operasi

Urutan blok sama dengan urutan kalimat soal.

int main() {
    Queue a = {NULL, NULL}, b = {NULL, NULL}, merged = {NULL, NULL};
    int n, m, l, x;
    scanf("%d %d", &n, &m);
    for (int i = 0; i < n; i++) { scanf("%d", &x); enqueue(&a, x); }
    for (int i = 0; i < m; i++) { scanf("%d", &x); enqueue(&b, x); }
    while (a.head != NULL || b.head != NULL) {          // gabung bergantian
        if (a.head != NULL) enqueue(&merged, dequeue(&a));
        if (b.head != NULL) enqueue(&merged, dequeue(&b));
    }
    scanf("%d", &l);
    for (int i = 0; i < l; i++) { scanf("%d", &x); cancel(&merged, x); }
    printQueue(&merged);
    while (merged.head != NULL) dequeue(&merged);       // free semua node
    return 0;
}

Notes 5️⃣ · Contoh 1: lajur tol

Kalau trace dengan tangan cocok dengan sample, pemetaan operasinya sudah benar

Isi tabel ini sebelum menjalankan program (langkah 5).

Tahapabmerged
Setelah input11 12 1321 22 23 24-
Setelah gabung bergantian--11 21 12 22 13 23 24
cancel 12 (di tengah)--11 21 22 13 23 24
cancel 24 (node terakhir, tail mundur)--11 21 22 13 23

Cancel 24 menghapus node terakhir, jadi tail harus mundur ke 23. Sample tidak bisa menunjukkan bug ini, karena tidak ada enqueue setelah cancel. Uji edge case sendiri.

Notes 6️⃣ · Contoh 2: sambung playlist

Menyambung list B ke belakang A cukup satu sambungan dua arah, lalu B dikosongkan

Double free adalah bug memanggil free dua kali untuk memory yang sama. Karena itu B wajib dikosongkan setelah node-nya pindah ke A.

void append(DList* a, DList* b) {
    if (b->head == NULL) return;    // B kosong
    if (a->head == NULL) {
        a->head = b->head;          // A kosong: A = B
    } else {
        a->tail->next = b->head;    // sambungan dua arah
        b->head->prev = a->tail;
    }
    a->tail = b->tail;
    b->head = b->tail = NULL;       // B jadi kosong
}
  • tail A dan head B langsung tersedia, jadi tidak ada traverse: O(1), berapa pun panjang list-nya.
  • Cetak hasilnya maju dan mundur. Kalau hasil mundur tidak terbalik, ada prev yang lupa disambung.

Notes 7️⃣ · Aturan soal

Output benar belum cukup, karena soal kasus dicek manual

Soal yang dicek manual dibaca kodenya oleh asisten, bukan hanya dibandingkan output-nya.

  • "Wajib memakai linked list" atau "jangan hanya mencetak": semua data harus masuk ke struktur dan diproses lewat operasinya.
  • "List B harus kosong": di akhir, b.head dan b.tail harus benar-benar NULL.
  • Uji edge case sendiri: struktur kosong (N = 0, L = 0), panjang tidak sama, hapus node pertama/terakhir/satu-satunya, prioritas seri di tengah. Lalu free semua node.

Ringkasan: resep yang sama untuk setiap soal kasus

  • Format I/O, pilih struktur, petakan kalimat ke operasi, kerangka, trace, edge case (1️⃣).
  • Urutan datang → queue, yang terbaru → stack, prioritas → priority queue (2️⃣).
  • Baca jumlah dulu lalu loop. Cetak persis seperti sample (3️⃣ 4️⃣).
  • Fungsi diambil dari materi 01–04. main hanya menyusun pemanggilan sesuai urutan soal (5️⃣ 6️⃣).
  • Pakai struktur yang diminta, uji edge case sendiri, dan free semua node (7️⃣ 8️⃣).
