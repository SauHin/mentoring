Priority queue

Data structure · antrean yang melayani berdasarkan prioritas, baru kemudian urutan datang.

Prasyarat: queue dan struct (materi 03), serta insertAt di single linked list (materi 01).

Kapan queue biasa tidak cukup

Di IGD, pasien kritis dilayani duluan walaupun datang belakangan. Queue biasa hanya melihat urutan datang. Priority queue melihat prioritas dulu, lalu urutan datang untuk prioritas yang sama.

Datang ke-PasienPrioritas
1Ana2
2Budi5
3Cici3
4Dodi5

Queue biasa: Ana, Budi, Cici, Dodi.

Priority queue: Budi, Dodi, Cici, Ana. Budi dan Dodi sama-sama 5, dan Budi datang duluan.

Kata kunci di soal"prioritas", "didahulukan", "paling parah dulu". Hampir selalu ada aturan tambahan: "kalau prioritasnya sama, yang datang duluan dilayani duluan".

Ide: jaga list selalu terurut

Kalau node selalu tersusun dari prioritas tertinggi, pasien berikutnya selalu ada di head. Kerja kerasnya pindah ke enqueue: node baru disisipkan di posisi yang tepat.

Cara menyimpanenqueuedequeue
List tidak terurutO(1): insert di belakangO(n): cari prioritas tertinggi dulu
List terurut (materi ini)O(n): cari posisi sisipO(1): ambil head
Heap (materi lanjutan)O(log n)O(log n)

Node menyimpan data dan prioritas

Soal priority queue hampir selalu punya nama (string) dan prioritas. Keduanya disimpan di node yang sama.

typedef struct Node {
    char name[21];
    int prio;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} PQueue;

Node* createNode(char name[], int prio) {
    Node* n = (Node*)malloc(sizeof(Node));
    strcpy(n->name, name);
    n->prio = prio;
    n->next = NULL;
    return n;
}
  • char name[21] muat 20 huruf ditambah '\0', penanda akhir string. Sesuaikan dengan batas panjang di soal.
  • Array tidak bisa di-assign dengan =. Isi string disalin dengan strcpy dari <string.h>.
  • PQueue cukup menyimpan head. Node baru bisa masuk di mana saja, jadi tail tidak membantu.

Turunkan pqPush dengan resep

Contoh: Eka (3) datang ke antrean Budi 5, Dodi 5, Cici 3, Ana 2. Eka harus masuk setelah Cici, karena Cici juga 3 dan datang lebih dulu.

  1. Panah yang berubah: Cici → Ana diganti Cici → Eka dan Eka → Ana. Pemilik panah adalah Cici, node tepat sebelum posisi sisip.
  2. Cari node itu: cur harus berhenti di node terakhir yang prioritasnya >= 3. Jadi loop terus selama node sesudah cur masih >= prioritas baru.
  3. Urutan: sambung dulu (newNode->next = cur->next), baru putus (cur->next = newNode). Sama dengan insertAt.
  4. Edge case: antrean kosong, atau prioritas baru lebih tinggi dari head. Di dua kasus ini tidak ada node sebelum posisi sisip, dan head berubah. Tangani sebelum loop.

Kode pqPush

Bagian atas menangani kasus head berubah. Bagian bawah adalah pola "cari node sebelum posisi, lalu sambung dulu, putus kemudian".

void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;   // masuk paling depan
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;
    newNode->next = cur->next;      // sambung dulu
    cur->next = newNode;            // putus kemudian
}
  • pq->head == NULL dicek lebih dulu. Kalau head NULL, || berhenti di situ, jadi pq->head->prio tidak pernah dibaca.
  • Loop membaca cur->next->prio, bukan cur->prio. Node baru masuk setelah cur, jadi yang dibandingkan adalah node sesudahnya.
  • Kalau semua node >= prio, loop berhenti di node terakhir, dan node baru masuk di belakang.

> atau >=: siapa duluan saat prioritas sama?

Satu karakter ini menentukan apakah pasien baru antre dengan benar atau menyalip pasien lain yang prioritasnya sama.

Kondisi loopcur berhenti diHasil setelah Eka (3) masuk
cur->next->prio >= prioCiciBudi, Dodi, Cici, Eka, AnaBenar
cur->next->prio > prioDodiBudi, Dodi, Eka, Cici, AnaSalah: Eka menyalip Cici
  • Aturannya: node baru melewati semua node yang prioritasnya sama atau lebih tinggi. Karena itu kondisi loop memakai >=.
  • Kondisi di head memakai kebalikannya, prio > pq->head->prio. Node baru hanya menggeser head kalau benar-benar lebih penting. Kalau ditulis >=, pasien baru dengan prioritas sama menyalip head.
Kalau angka kecil = prioritas tinggiBalik kedua perbandingan: prio < pq->head->prio dan cur->next->prio <= prio.

Coba sendiri: masukkan prioritas yang sama

pqPop: ambil head, salin namanya

Karena list selalu terurut, yang dilayani selalu head. Kodenya sama dengan dequeue, tanpa tail. Bedanya, data berupa string harus disalin sebelum node di-free.

void pqPop(PQueue* pq, char out[]) {
    Node* del = pq->head;
    strcpy(out, del->name);
    pq->head = del->next;
    free(del);
}

// pemakaian
char name[21];
if (pq.head != NULL) {
    pqPop(&pq, name);
    printf("%s\n", name);
}
  • out adalah alamat array name milik main, karena array selalu dikirim sebagai alamat. Jadi strcpy langsung mengisi array di main.
  • Jangan return del->name. Yang di-return hanya alamat array di dalam node. Setelah free, malloc berikutnya bisa memakai memory itu, jadi nama berubah menjadi nama pasien lain.
  • peek: cukup baca pq.head->name, tanpa mengeluarkan node.

Aturan berlapis: kumpulkan di higher()

Soal sering punya beberapa aturan, misalnya "prioritas tinggi dulu, kalau sama yang lebih tua dulu". Tulis semua aturan di satu fungsi, lalu pqPush cukup memanggilnya.

// 1 kalau a harus dilayani sebelum b
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;
    if (a->age != b->age)
        return a->age > b->age;
    return 0;    // sama persis
}

// di pqPush:
if (pq->head == NULL || higher(newNode, pq->head))
...
while (cur->next != NULL &&
       !higher(newNode, cur->next))
  • Setiap aturan diperiksa berurutan. Aturan berikutnya hanya dipakai kalau aturan sebelumnya seri.
  • "Yang datang duluan" tidak perlu ditulis. return 0 membuat node baru berjalan melewati node yang setara, jadi ia masuk di belakangnya.
  • Aturan alfabet: return strcmp(a->name, b->name) < 0;
  • !higher(newNode, cur->next) sama artinya dengan >= di versi satu aturan.

Ringkasan

  • Priority queue melayani berdasarkan prioritas. Untuk prioritas yang sama, yang datang duluan dilayani duluan.
  • Simpan list selalu terurut: pqPush mencari posisi (O(n)), pqPop cukup mengambil head (O(1)).
  • pqPush = kasus head + pola insertAt. Loop melewati node yang >=, kasus head memakai >.
  • Aturan berlapis ditulis di satu fungsi higher(). String disalin dengan strcpy.
