Notes 1️⃣ · Kapan butuh priority queue

Priority queue melayani berdasarkan prioritas, lalu urutan datang untuk yang seri

Priority queue adalah antrean yang mendahulukan prioritas tertinggi. Contoh di IGD, angka besar didahulukan:

Datang ke-PasienPrioritas
1Ana2
2Budi5
3Cici3
4Dodi5
  • Queue biasa: Ana, Budi, Cici, Dodi.
  • Priority queue: Budi, Dodi, Cici, Ana. Budi dan Dodi sama-sama 5, dan Budi datang duluan.
  • Kata kunci di soal: "prioritas", "didahulukan", "VIP". Cek apakah angka besar atau angka kecil yang didahulukan.

Notes 2️⃣ · List terurut

Kalau list selalu terurut, pasien berikutnya selalu ada di head

Kerja kerasnya pindah ke pqPush: node baru disisipkan di posisi yang tepat.

Notes 3️⃣ · Node

Node menyimpan nama dan prioritas, dan nama disalin dengan strcpy

Array tidak bisa di-assign dengan =, jadi isi nama disalin huruf demi huruf.

typedef struct Node {
    char name[21];
    int prio;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} PQueue;

Node* createNode(char name[], int prio) {
    Node* n = (Node*)malloc(sizeof(Node));
    strcpy(n->name, name);
    n->prio = prio;
    n->next = NULL;
    return n;
}
  • char name[21] muat 20 huruf ditambah '\0'.
  • n->name = name error. Pakai strcpy dari <string.h>.
  • PQueue cukup menyimpan head, karena node baru bisa masuk di mana saja.

Notes 4️⃣ · Menurunkan pqPush

pqPush berhenti di node terakhir yang prioritasnya sama atau lebih tinggi

Contoh: Eka (3) datang ke antrean Budi 5, Dodi 5, Cici 3, Ana 2. Eka harus masuk setelah Cici.

  1. Panah yang berubah: Cici → Ana diganti Cici → Eka dan Eka → Ana. Pemilik panah: Cici.
  2. Cari node itu: cur maju selama node sesudah cur masih >= 3.
  3. Urutan: sambung dulu (newNode->next = cur->next), baru putus (cur->next = newNode).
  4. Edge case: antrean kosong, atau prioritas baru lebih tinggi dari head. Head berubah, jadi tangani sebelum loop.

Notes 4️⃣ · Kode pqPush

pqPush = kasus head di atas, lalu pola insertAt di bawah

Bagian atas menangani head yang berubah. Bagian bawah mencari node sebelum posisi, lalu sambung dulu, putus kemudian.

void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;
    newNode->next = cur->next;      // sambung dulu
    cur->next = newNode;            // putus kemudian
}
  • pq->head == NULL dicek duluan, jadi pq->head->prio tidak dibaca saat head NULL.
  • Loop membaca cur->next->prio, karena node baru masuk setelah cur.
  • Kalau semua node >= prio, node baru masuk paling belakang.

Notes 5️⃣ · > atau >=

Loop memakai >= supaya pasien baru tidak menyalip pasien yang setara

Node baru melewati semua node yang sama atau lebih penting. Kasus head memakai >: geser head hanya kalau benar-benar lebih penting.

Notes 6️⃣ · pqPop

pqPop mengambil head, lalu menyalin nama ke array pemanggil sebelum free

List selalu terurut, jadi yang dilayani selalu head. Kodenya sama dengan dequeue, tanpa tail.

void pqPop(PQueue* pq, char out[]) {
    Node* del = pq->head;
    strcpy(out, del->name);
    pq->head = del->next;
    free(del);
}
// pemakaian
char name[21];
if (pq.head != NULL) {
    pqPop(&pq, name);
    printf("%s\n", name);
}
  • out adalah alamat array name milik main, karena array selalu dikirim sebagai alamat.
  • peek: cukup baca pq.head->name.

Jangan return del->name. Setelah free, malloc berikutnya bisa memakai memory itu, dan nama berubah jadi nama pasien lain.

Notes 7️⃣ · Aturan berlapis

Kalau aturannya lebih dari satu, kumpulkan semuanya di fungsi higher()

Fungsi pembanding memutuskan apakah a harus dilayani sebelum b, dan pqPush cukup memanggilnya.

// 1 kalau a harus dilayani sebelum b
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;
    if (a->age != b->age)
        return a->age > b->age;
    return 0;    // sama persis
}
// di pqPush:
if (pq->head == NULL || higher(newNode, pq->head))
...
while (cur->next != NULL &&
       !higher(newNode, cur->next))
  • Aturan berikutnya hanya dipakai kalau aturan sebelumnya seri.
  • "Yang datang duluan" tidak perlu ditulis: return 0 membuat node baru masuk di belakang node yang setara.
  • Aturan alfabet: return strcmp(a->name, b->name) < 0;

Ringkasan: priority queue = list terurut + pqPush yang tidak menyalip

  • Prioritas dulu, urutan datang untuk yang seri (1️⃣).
  • List selalu terurut: pqPush mencari posisi (O(n)), pqPop ambil head (O(1)) (2️⃣ 6️⃣).
  • pqPush = kasus head + pola insertAt. Loop >=, kasus head > (4️⃣ 5️⃣).
  • Nama disalin dengan strcpy, termasuk sebelum free (3️⃣ 6️⃣).
  • Aturan berlapis ditulis di satu fungsi higher() (7️⃣).

Soal latihan: kerjakan dulu, jawabannya di slide berikutnya

  1. Antrean kosong (angka besar didahulukan): A 2, B 4, C 2, D 4, E 1. Apa isi list?
  2. Kenapa loop pqPush memakai >=, sedangkan kasus head memakai >?
  3. Ubah kasus head dan kondisi loop untuk soal "prioritas 1 paling penting".
  4. Kenapa return del->name; setelah free(del) berbahaya?

Jawaban soal latihan

  1. B 4, D 4, A 2, C 2, E 1. Di prioritas yang sama, urutannya tetap urutan datang.
  2. Loop melewati yang sama atau lebih penting (pasien baru antre di belakang yang setara). Head hanya digeser kalau pasien baru benar-benar lebih penting.
  3. prio < pq->head->prio untuk head, dan cur->next->prio <= prio untuk loop.
  4. Memory node yang di-free bisa dipakai malloc berikutnya, jadi nama bisa berubah jadi nama pasien lain (use-after-free).
