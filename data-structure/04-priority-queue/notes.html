Kapan queue biasa tidak cukup: ada yang harus didahulukan

queue dan FIFO (materi 03) semua section berikutnya, dan soal antrean IGD atau VIP (materi 05)

IGD rumah sakit: pasien kritis dilayani duluan walaupun datang belakangan, tapi pasien yang sama parahnya tetap antre sesuai urutan datang.

di IGD, dokter bisa menilai ulang kondisi pasien. Di program, prioritas yang sudah masuk tidak berubah.

Priority queue adalah antrean yang melayani berdasarkan prioritas, lalu urutan datang untuk prioritas yang sama. Contoh (angka besar didahulukan):

  • Queue biasa: Ana, Budi, Cici, Dodi.
  • Priority queue: Budi, Dodi, Cici, Ana. Budi dan Dodi sama-sama 5, dan Budi datang duluan.

Kata kunci di soal: "prioritas", "didahulukan", "paling parah/tinggi/tua dulu", "VIP". Baca juga aturan seri (hampir selalu "kalau sama, yang datang duluan") dan arah angkanya: angka besar atau angka kecil yang didahulukan.

Priority queue = prioritas dulu, urutan datang kemudian.

Soal latihan: Pasien datang: Ani 1, Beni 3, Caca 3, Dedi 2 (angka besar didahulukan). Urutan dilayani?

Beni, Caca, Dedi, Ani. Beni dan Caca sama-sama 3, dan Beni datang duluan.

Ide: jaga list selalu terurut, supaya yang dilayani selalu di head

insertAt dan dequeue (materi 01 dan 03) pqPush (4️⃣) dan pqPop (6️⃣)

Rak buku yang selalu dirapikan saat buku baru datang: mencarinya nanti jadi gampang, karena yang dibutuhkan selalu di ujung.

merapikan rak bisa ditunda. Di sini setiap pqPush langsung menaruh node di posisi yang tepat.

Kalau list selalu terurut dari prioritas tertinggi, pasien berikutnya selalu ada di head, jadi pqPop cepat. Harganya, setiap pqPush harus mencari posisi yang tepat.

Soal latihan: Buat priority queue dengan list tidak terurut: pqPush memakai enqueue dari materi 03, dan pqPop mencari prioritas tertinggi. Pasien setara tetap dilayani sesuai urutan datang. 
typedef struct {
    Node* head;
    Node* tail;
} PQueue;

void pqPop(PQueue* pq, char out[]) {        // syarat: pq->head != NULL
    Node* bestPrev = NULL;
    Node* best = pq->head;
    Node* prev = pq->head;
    for (Node* cur = pq->head->next; cur != NULL; cur = cur->next) {
        if (cur->prio > best->prio) {       // >, bukan >=
            best = cur;
            bestPrev = prev;
        }
        prev = cur;
    }
    strcpy(out, best->name);
    if (bestPrev == NULL)
        pq->head = best->next;
    else
        bestPrev->next = best->next;
    if (best == pq->tail)
        pq->tail = bestPrev;
    free(best);
}

Pencarian memakai >, jadi kalau ada yang setara, pasien yang ditemukan pertama (datang duluan) tetap terpilih. Bagian delete sama dengan cancel di materi 03, termasuk memindah tail. Dengan input contoh IGD (8️⃣), outputnya sama: Budi, Eka, Cici, Dodi.

Node menyimpan nama dan prioritas, dan nama disalin dengan strcpy

string dan strcpy (algorithm and programming, materi 04) pqPush (4️⃣) dan pqPop (6️⃣)

Kartu antrean pasien: berisi nama dan tingkat keparahan.

kartu bisa difotokopi dengan sekali tekan. Nama di C harus disalin huruf demi huruf dengan strcpy.

Soal priority queue hampir selalu punya nama (string) dan prioritas. Keduanya disimpan di node yang sama, dan nama disalin dengan strcpy, karena array tidak bisa di-assign dengan =.

#include <string.h>        // strcpy, strcmp

typedef struct Node {
    char name[21];          // 20 huruf + '\0'
    int prio;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} PQueue;

Node* createNode(char name[], int prio) {
    Node* n = (Node*)malloc(sizeof(Node));
    strcpy(n->name, name);  // array tidak bisa di-assign dengan =
    n->prio = prio;
    n->next = NULL;
    return n;
}
  • char name[21]: nama 20 huruf butuh 21 byte, karena ada '\0'. Sesuaikan dengan batas di soal.
  • Hanya head, tanpa tail: node baru bisa masuk di mana saja sesuai prioritas, jadi tail jarang membantu.

Node = nama + prio + next. Isi nama dengan strcpy, bukan =.

Soal latihan: Kenapa n->name = name; error?

name adalah array, dan nama array tidak bisa diberi alamat baru. Isinya harus disalin huruf demi huruf dengan strcpy(n->name, name).

Menurunkan pqPush: kasus head berubah, lalu pola insertAt

resep 5 langkah dan pola C/D (materi 01) > atau >= (5️⃣) dan higher() (7️⃣)

Menyelip di antrean bertingkat: kamu berjalan melewati semua orang yang sama parah atau lebih parah, lalu berdiri tepat di belakang orang terakhir itu.

di antrean nyata kamu bisa melihat seluruh barisan. Di linked list, cur hanya bisa melihat node sesudahnya.

pqPush menyisipkan node di posisi yang menjaga list tetap terurut. Contoh: Eka (3) datang ke antrean Budi 5 → Dodi 5 → Cici 3 → Ana 2.

  1. Gambar: sesudah = Budi 5 → Dodi 5 → Cici 3 → Eka 3 → Ana 2.
  2. Panah yang berubah: Cici → Ana diganti Cici → Eka dan Eka → Ana.
  3. Pemilik panah: Cici, node terakhir yang prioritasnya >= 3. Jadi cur maju selama node sesudah cur masih >= prioritas baru.
  4. Urutan: newNode->next = cur->next dulu, baru cur->next = newNode (pola D).
  5. Edge case: antrean kosong, atau node baru lebih penting dari head. Head berubah, jadi tangani sebelum loop.
void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;           // masuk paling depan
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;                    // lewati yang sama atau lebih penting
    newNode->next = cur->next;              // sambung dulu
    cur->next = newNode;                    // putus kemudian
}
Kenapa ditulis begitu: tiga detail kecil
  • pq->head == NULL || ditulis lebih dulu. Kalau true, bagian kanan || tidak dijalankan, jadi pq->head->prio tidak dibaca saat head NULL.
  • Loop membandingkan cur->next->prio, bukan cur->prio. Node baru masuk setelah cur, jadi yang menentukan adalah node sesudah cur.
  • Kalau semua node >= prioritas baru, loop berhenti karena cur->next == NULL, dan node baru masuk paling belakang. Tidak perlu kasus terpisah.

pqPush = kasus head (sebelum loop) + loop "lewati yang >=" + sambung dulu, putus kemudian.

Soal latihan: Antrean: Budi 5 → Cici 3. Frida (4) datang. Di node mana cur berhenti, dan bagaimana hasilnya?

Frida tidak lebih penting dari head (4 < 5), jadi masuk loop. cur->next = Cici (3), dan 3 >= 4 false, jadi cur berhenti di Budi. Hasil: Budi 5 → Frida 4 → Cici 3.

> atau >=: satu karakter yang menentukan siapa duluan saat seri

pqPush (4️⃣) aturan berlapis (7️⃣)

Antre di loket VIP bersama tamu VIP lain: kamu tetap berdiri di belakang tamu VIP yang datang duluan, tidak menyalip.

tamu yang menyalip akan ditegur. Program yang salah memakai > diam-diam membuat pasien menyalip.

Aturannya: node baru melewati semua node yang sama atau lebih penting, jadi loop memakai >=. Kasus head memakai kebalikannya: node baru hanya menggeser head kalau benar-benar lebih penting (>).

Soal latihan: Mulai dari antrean kosong (angka besar didahulukan): A 2, B 4, C 2, D 4, E 1. Tulis isi list setelah semua masuk.

B 4, D 4, A 2, C 2, E 1. Di dalam prioritas yang sama, urutannya tetap urutan datang: B sebelum D, A sebelum C.

Soal latihan: Kondisi loop diganti menjadi cur->next->prio > prio. Ulangi soal di atas, lalu jalankan contoh IGD (8️⃣). Apa yang aneh?

Soal di atas menjadi B 4, D 4, C 2, A 2, E 1: C menyalip A. Tapi contoh IGD tetap mencetak Budi, Eka, Cici, Dodi, sama dengan versi benar. Di contoh itu, pasien setara selalu bertemu di head, dan kasus head memakai > yang benar, jadi loop tidak pernah diuji.

Soal latihan: Ubah pqPush untuk soal "prioritas 1 paling penting, lalu 2, lalu 3", dengan aturan seri tetap urutan datang.

Kedua perbandingan dibalik. Loop tetap memakai versi "sama atau lebih penting" (<=), dan kasus head tetap versi "benar-benar lebih penting" (<).

pqPop: ambil head, dan salin namanya ke array pemanggil sebelum free

dequeue (materi 03) dan array sebagai alamat (algorithm and programming, materi 04) program IGD (8️⃣)

Memanggil pasien: catat namanya di buku dulu, baru kartu antreannya dibuang.

kartu yang dibuang masih bisa dipungut dari tempat sampah. Memory yang di-free bisa langsung dipakai pasien baru.

Karena list selalu terurut, yang dilayani selalu head, jadi pqPop sama dengan dequeue di materi 03, tanpa tail. Bedanya, data berupa string harus disalin dengan strcpy ke array milik pemanggil sebelum node di-free.

void pqPop(PQueue* pq, char out[]) {    // syarat: pq->head != NULL
    Node* del = pq->head;
    strcpy(out, del->name);              // salin sebelum free
    pq->head = del->next;
    free(del);
}

// pemakaian
char name[21];
if (pq.head != NULL) {
    pqPop(&pq, name);
    printf("%s\n", name);
}
  • out: alamat array name milik main, karena array selalu dikirim sebagai alamat. Jadi strcpy mengisi array di main, sama seperti scanf("%s", name) yang tidak butuh &.
  • peek: baca pq.head->name dan pq.head->prio tanpa mengeluarkan node.

Jangan return del->name. Yang di-return hanya alamat array di dalam node. Setelah free, malloc berikutnya bisa memakai memory itu. Diuji di MinGW: nama masih benar tepat setelah free, tapi berubah jadi nama pasien baru setelah pqPush berikutnya.

Kenapa dequeue di materi 03 boleh return langsung?

Bandingkan dengan dequeue di materi 03: int x = del->data; return x; aman, karena int disalin nilainya. Array tidak bisa disalin dengan = atau di-return, jadi isinya disalin dengan strcpy ke array yang tetap hidup.

pqPop = ambil head. Nama disalin ke array pemanggil dengan strcpy sebelum free.

Soal latihan: Kenapa fungsi ini kadang mencetak nama yang aneh? 
char* pqPop(PQueue* pq) {
    Node* del = pq->head;
    pq->head = del->next;
    free(del);
    return del->name;
}

del->name dibaca setelah free(del) (use-after-free). Memory itu bisa dipakai ulang oleh malloc berikutnya, jadi nama yang di-return bisa berubah menjadi nama pasien baru. Salin nama ke array milik pemanggil dengan strcpy sebelum free.

Aturan berlapis: kumpulkan semua aturan di satu fungsi higher()

pqPush dan >= (4️⃣, 5️⃣) soal dengan aturan prioritas, umur, VIP, atau alfabet (materi 05)

Aturan juara lomba: nilai tertinggi menang. Kalau seri, yang lebih cepat. Kalau masih seri, yang daftar duluan.

juri bisa memutuskan hal baru di tempat. Fungsi higher hanya menjalankan aturan yang sudah kamu tulis.

Fungsi pembanding adalah fungsi yang memutuskan apakah a harus dilayani sebelum b. Semua aturan dikumpulkan di sana, jadi pqPush cukup memanggilnya.

// return 1 kalau a harus dilayani sebelum b
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;    // aturan 1
    if (a->age != b->age)
        return a->age > b->age;      // aturan 2, hanya kalau aturan 1 seri
    return 0;                        // seri total: urutan datang
}

void pqPush(PQueue* pq, Node* newNode) {
    if (pq->head == NULL || higher(newNode, pq->head)) {
        newNode->next = pq->head;
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && !higher(newNode, cur->next))
        cur = cur->next;
    newNode->next = cur->next;
    cur->next = newNode;
}
  • "Datang duluan" tidak perlu ditulis: return 0 membuat node baru berjalan melewati node yang setara, jadi ia masuk di belakangnya.
  • !higher(newNode, cur->next) artinya "node sesudah cur sama atau lebih penting". Ini versi umum dari >=.

pqPush versi ini menerima node yang sudah dibuat, jadi struct boleh punya field apa saja tanpa mengubah pqPush.

Aturan diperiksa berurutan, dan aturan berikutnya hanya dipakai kalau aturan sebelumnya seri.

Soal latihan: Tulis higher() untuk aturan "prioritas tinggi dulu; kalau sama, nama urut alfabet". 
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;
    return strcmp(a->name, b->name) < 0;
}

strcmp mengembalikan angka negatif kalau string pertama lebih dulu di urutan alfabet.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Node {
    char name[21];
    int prio;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} PQueue;

Node* createNode(char name[], int prio) {
    Node* n = (Node*)malloc(sizeof(Node));
    strcpy(n->name, name);
    n->prio = prio;
    n->next = NULL;
    return n;
}

void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;
    newNode->next = cur->next;
    cur->next = newNode;
}

void pqPop(PQueue* pq, char out[]) {     // syarat: pq->head != NULL
    Node* del = pq->head;
    strcpy(out, del->name);
    pq->head = del->next;
    free(del);
}

int main() {
    PQueue igd = {NULL};
    int q, prio;
    char cmd[10], name[21];

    scanf("%d", &q);
    for (int i = 0; i < q; i++) {
        scanf("%s", cmd);
        if (strcmp(cmd, "DATANG") == 0) {
            scanf("%s %d", name, &prio);
            pqPush(&igd, name, prio);
        } else if (igd.head == NULL) {          // PANGGIL saat kosong
            printf("Tidak ada pasien\n");
        } else {
            pqPop(&igd, name);
            printf("%s\n", name);
        }
    }

    while (igd.head != NULL)                    // free pasien yang tersisa
        pqPop(&igd, name);
    return 0;
}

Sudah diuji dengan MinGW gcc (C) dan g++ (C++98).
