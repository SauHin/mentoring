Priority queue

Antrean yang melayani berdasarkan prioritas. Untuk prioritas yang sama, yang datang duluan dilayani duluan.

Slide · Visualisasi priority queue · Lanjut: Mengerjakan soal kasus

PrasyaratQueue dan struct dari materi 03, serta insertAt (pola C dan D) dari single linked list.
TL;DR
  • Simpan list selalu terurut dari prioritas tertinggi. pqPop cukup mengambil head: O(1). pqPush mencari posisi sisip: O(n).
  • pqPush = kasus head berubah + pola insertAt (cari node sebelum posisi, sambung dulu, putus kemudian).
  • Supaya pasien dengan prioritas sama tidak saling menyalip: loop memakai >=, kasus head memakai >.
  • Aturan berlapis ditulis di satu fungsi higher(a, b). String disalin dengan strcpy, termasuk sebelum free.

1. Kapan queue biasa tidak cukup

Queue biasa hanya melihat urutan datang. Di banyak situasi, ada yang harus didahulukan: pasien kritis di IGD, penumpang first class, atau tugas sistem yang mendesak.

Datang ke-PasienPrioritas

  • Queue biasa: Ana, Budi, Cici, Dodi.
  • Priority queue (angka besar didahulukan): Budi, Dodi, Cici, Ana. Budi dan Dodi sama-sama 5, dan Budi datang duluan.
Kata kunci di soal"prioritas", "didahulukan", "paling parah/tinggi/tua dulu", "VIP". Baca juga aturan seri: hampir selalu "kalau sama, yang datang duluan dilayani duluan". Cek juga arah angkanya: apakah angka besar atau angka kecil yang didahulukan.

2. Ide: jaga list selalu terurut

head → [Budi 5] → [Dodi 5] → [Cici 3] → [Ana 2] → NULL

Kalau list selalu terurut, pasien berikutnya selalu ada di head, jadi pqPop O(1). Harganya, setiap pqPush harus mencari posisi yang tepat.

    struct Node* next;
} Node;

Node* createNode(char name[], int prio) {

4. Menurunkan pqPush

Contoh: Eka (3) datang ke antrean Budi 5 → Dodi 5 → Cici 3 → Ana 2. Eka harus masuk setelah Cici, karena Cici juga 3 dan datang lebih dulu.

  1. Gambar sebelum dan sesudah. Sesudah: Budi 5 → Dodi 5 → Cici 3 → Eka 3 → Ana 2.
  2. Panah yang berubah: Cici → Ana diganti Cici → Eka dan Eka → Ana.
  3. Pemilik panah: Cici, yaitu node terakhir yang prioritasnya >= 3. Jadi cur maju selama node sesudah cur masih >= prioritas baru.
  4. Urutan: newNode->next = cur->next dulu, baru cur->next = newNode (pola D).
  5. Edge case: antrean kosong, atau node baru lebih penting dari head. Di dua kasus ini tidak ada node sebelum posisi sisip, dan head berubah. Tangani sebelum loop, seperti pos == 0 di insertAt.
void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;           // masuk paling depan
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;                    // lewati yang sama atau lebih penting
    newNode->next = cur->next;              // sambung dulu
    cur->next = newNode;                    // putus kemudian
}
  • pq->head == NULL || ditulis lebih dulu. Kalau bernilai true, bagian kanan || tidak dijalankan, jadi pq->head->prio tidak dibaca saat head NULL.
  • Loop membandingkan cur->next->prio, bukan cur->prio. Node baru masuk setelah cur, jadi yang menentukan adalah node sesudah cur.
  • Kalau semua node >= prioritas baru, loop berhenti karena cur->next == NULL, dan node baru masuk paling belakang. Tidak perlu kasus terpisah.

5. > atau >=: menentukan siapa duluan saat seri

Kondisi loopcur berhenti diHasil
cur->next->prio >= prioCiciBudi, Dodi, Cici, Eka, Ana (benar)
cur->next->prio > prioDodiBudi, Dodi, Eka, Cici, Ana (Eka menyalip Cici)

Aturannya: node baru melewati semua node yang sama atau lebih penting. Karena itu loop memakai >=.

Kasus head memakai kebalikannya: prio > pq->head->prio. Node baru hanya menggeser head kalau benar-benar lebih penting. Kalau ditulis >=, pasien baru yang setara dengan head langsung menyalip.

Aturan di soalKasus headKondisi loop
Angka besar didahulukanprio > pq->head->priocur->next->prio >= prio
Angka kecil didahulukanprio < pq->head->priocur->next->prio <= prio
Cara cek cepatMasukkan dua pasien dengan prioritas sama, lalu panggil pqPop. Yang keluar harus pasien pertama. Coba di visualisasi: masukkan prioritas 3 dua kali.

6. pqPop dan peek

void pqPop(PQueue* pq, char out[]) {    // syarat: pq->head != NULL
    Node* del = pq->head;
    strcpy(out, del->name);              // salin sebelum free
    pq->head = del->next;
    free(del);
}

// pemakaian
char name[21];
if (pq.head != NULL) {
    pqPop(&pq, name);
    printf("%s\n", name);
}
  • Sama dengan dequeue di materi 03, tanpa tail.
  • out adalah alamat array name milik main. Array selalu dikirim ke fungsi sebagai alamat elemen pertamanya (parameter char out[] sama dengan char* out). Jadi strcpy mengisi array di main, sama seperti scanf("%s", name) yang tidak butuh &.
  • Kenapa tidak char* name = del->name; return name;? Baris itu hanya menyalin alamat array di dalam node, bukan huruf-hurufnya. Setelah free(del), memory node boleh dipakai ulang oleh malloc berikutnya. Diuji di MinGW: nama masih terbaca benar tepat setelah free, tapi berubah menjadi nama pasien baru setelah pqPush berikutnya. Bug seperti ini lolos tes sederhana.
  • Bandingkan dengan dequeue di materi 03: int x = del->data; return x; aman, karena int disalin nilainya. Array tidak bisa disalin dengan = atau di-return, jadi isinya harus disalin dengan strcpy ke array yang tetap hidup setelah fungsi selesai, yaitu milik pemanggil.
  • peek: baca pq.head->name dan pq.head->prio tanpa mengeluarkan node.

7. Aturan berlapis: fungsi higher()

Soal sering punya lebih dari satu aturan, misalnya: "prioritas tertinggi dulu; kalau sama, yang lebih tua dulu; kalau masih sama, yang datang duluan". Kumpulkan semua aturan di satu fungsi.

// return 1 kalau a harus dilayani sebelum b
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;    // aturan 1
    if (a->age != b->age)
        return a->age > b->age;      // aturan 2, hanya kalau aturan 1 seri
    return 0;                        // seri total: urutan datang
}

void pqPush(PQueue* pq, Node* newNode) {
    if (pq->head == NULL || higher(newNode, pq->head)) {
        newNode->next = pq->head;
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && !higher(newNode, cur->next))
        cur = cur->next;
    newNode->next = cur->next;
    cur->next = newNode;
}
  • Aturan "datang duluan" tidak perlu ditulis. return 0 membuat node baru berjalan melewati node yang setara, jadi ia masuk di belakangnya.
  • !higher(newNode, cur->next) artinya "node sesudah cur sama atau lebih penting". Ini versi umum dari >=.
  • pqPush versi ini menerima node yang sudah dibuat, jadi struct boleh punya field apa saja tanpa mengubah pqPush.
Aturan di soalBaris di higher
Nama urut alfabetreturn strcmp(a->name, b->name) < 0;
Member VIP duluan (vip = 1 atau 0)if (a->vip != b->vip) return a->vip;
Waktu tunggu terlama duluanreturn a->arrive < b->arrive;

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Node {
    char name[21];
    int prio;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
} PQueue;

Node* createNode(char name[], int prio) {
    Node* n = (Node*)malloc(sizeof(Node));
    strcpy(n->name, name);
    n->prio = prio;
    n->next = NULL;
    return n;
}

void pqPush(PQueue* pq, char name[], int prio) {
    Node* newNode = createNode(name, prio);
    if (pq->head == NULL || prio > pq->head->prio) {
        newNode->next = pq->head;
        pq->head = newNode;
        return;
    }
    Node* cur = pq->head;
    while (cur->next != NULL && cur->next->prio >= prio)
        cur = cur->next;
    newNode->next = cur->next;
    cur->next = newNode;
}

void pqPop(PQueue* pq, char out[]) {     // syarat: pq->head != NULL
    Node* del = pq->head;
    strcpy(out, del->name);
    pq->head = del->next;
    free(del);
}

int main() {
    PQueue igd = {NULL};
    int q, prio;
    char cmd[10], name[21];

    scanf("%d", &q);
    for (int i = 0; i < q; i++) {
        scanf("%s", cmd);
        if (strcmp(cmd, "DATANG") == 0) {
            scanf("%s %d", name, &prio);
            pqPush(&igd, name, prio);
        } else if (igd.head == NULL) {          // PANGGIL saat kosong
            printf("Tidak ada pasien\n");
        } else {
            pqPop(&igd, name);
            printf("%s\n", name);
        }
    }

    while (igd.head != NULL)                    // free pasien yang tersisa
        pqPop(&igd, name);
    return 0;
}
  • scanf("%s", name) tanpa &, karena nama array sudah berupa alamat.
  • Perintah dibandingkan dengan strcmp(cmd, "DATANG") == 0. Operator == pada dua string membandingkan alamat, bukan isi.
  • Sudah diuji dengan MinGW gcc (C) dan g++ (C++98).

10. Latihan

1. Mulai dari antrean kosong (angka besar didahulukan): A 2, B 4, C 2, D 4, E 1. Tulis isi list setelah semua masuk.

Jawaban

B 4, D 4, A 2, C 2, E 1. Di dalam prioritas yang sama, urutannya tetap urutan datang: B sebelum D, A sebelum C.

2. Temukan bug. Kondisi loop pqPush diganti menjadi cur->next->prio > prio. Ulangi latihan 1. Lalu jalankan contoh IGD di bagian 8. Apa yang aneh?

Jawaban

Latihan 1 menjadi B 4, D 4, C 2, A 2, E 1: C menyalip A. Tapi contoh IGD tetap mencetak Budi, Eka, Cici, Dodi, sama dengan versi benar. Di contoh itu, pasien setara selalu bertemu di head, dan kasus head memakai > yang benar, jadi loop tidak pernah diuji.

Pelajarannya: lolos sample output belum berarti benar. Buat sendiri input dengan prioritas seri di tengah antrean.

3. Turunkan sendiri. Ubah pqPush untuk soal "prioritas 1 paling penting, lalu 2, lalu 3", dengan aturan seri tetap urutan datang.

Jawaban 
if (pq->head == NULL || prio < pq->head->prio) { ... }
while (cur->next != NULL && cur->next->prio <= prio)
    cur = cur->next;

Kedua perbandingan dibalik. Loop tetap memakai versi "sama atau lebih penting" (<=), dan kasus head tetap versi "benar-benar lebih penting" (<).

4. Turunkan sendiri. Buat priority queue dengan list tidak terurut: pqPush memakai enqueue dari materi 03 (O(1)), dan pqPop mencari prioritas tertinggi (O(n)). Pasien setara tetap dilayani sesuai urutan datang.

Jawaban 
typedef struct {
    Node* head;
    Node* tail;
} PQueue;

void pqPop(PQueue* pq, char out[]) {        // syarat: pq->head != NULL
    Node* bestPrev = NULL;
    Node* best = pq->head;
    Node* prev = pq->head;
    for (Node* cur = pq->head->next; cur != NULL; cur = cur->next) {
        if (cur->prio > best->prio) {       // >, bukan >=
            best = cur;
            bestPrev = prev;
        }
        prev = cur;
    }
    strcpy(out, best->name);
    if (bestPrev == NULL)
        pq->head = best->next;
    else
        bestPrev->next = best->next;
    if (best == pq->tail)
        pq->tail = bestPrev;
    free(best);
}

Pencarian memakai >, jadi kalau ada yang setara, pasien yang ditemukan pertama (datang duluan) tetap terpilih. Bagian delete sama dengan cancel di materi 03, termasuk memindah tail. Dengan input contoh IGD, outputnya sama: Budi, Eka, Cici, Dodi.

5. Turunkan sendiri. Tulis higher() untuk aturan: "prioritas tinggi dulu; kalau sama, nama urut alfabet".

Jawaban 
int higher(Node* a, Node* b) {
    if (a->prio != b->prio)
        return a->prio > b->prio;
    return strcmp(a->name, b->name) < 0;
}

strcmp mengembalikan angka negatif kalau string pertama lebih dulu di urutan alfabet.

6. Temukan bug. Kenapa fungsi ini kadang mencetak nama yang aneh?

char* pqPop(PQueue* pq) {
    Node* del = pq->head;
    pq->head = del->next;
    free(del);
    return del->name;
}
Jawaban

del->name dibaca setelah free(del) (use-after-free). Memory itu sudah dilepas, jadi bisa dipakai ulang oleh malloc berikutnya. Kalau pqPush berikutnya mendapat memory yang sama, nama yang di-return berubah menjadi nama pasien baru. Salin nama ke array milik pemanggil dengan strcpy sebelum free.
