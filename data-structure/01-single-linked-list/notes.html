Data structure · 01

Single linked list

Kumpulan node yang saling menyambung lewat pointer next. Tujuan materi ini: kamu bisa menurunkan kode linked list sendiri, bukan menghafalnya.

Slide · Visualisasi operasi · Lanjut: Double linked list

TL;DR
  • Node = data + next (alamat node berikutnya). List cukup diwakili head.
  • Semua operasi = mengubah panah. Gambar dulu, baru tulis kode.
  • Aturan utama: sambung dulu, putus kemudian. Jangan sampai kehilangan alamat node.
  • Node hanya bisa mengubah next miliknya sendiri, jadi untuk insert/delete di posisi pos kamu butuh node di pos - 1.

1. Kenapa linked list?

Bayangkan array [10, 20, 30, 40] dan kamu mau menyisipkan 25 setelah 20:

  • Array: geser 30 dan 40 ke kanan dulu → O(n), dan ukuran array terbatas.
  • Linked list: tiap elemen menyimpan alamat elemen berikutnya. Menyisipkan cukup mengubah 2 panah, tidak ada yang digeser.
head → [10] → [20] → [30] → [40] → NULL

Harganya: tidak bisa langsung loncat ke elemen ke-i. Harus jalan dari head satu per satu.

2. Struktur node

typedef struct Node {
    int data;
    struct Node* next;    // alamat node berikutnya, NULL kalau node terakhir
} Node;

Node* head = NULL;        // alamat node pertama, NULL kalau list kosong
int size = 0;

Node* createNode(int x) {
    Node* n = malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}

Pahami kenapa tiap bagian ditulis begitu:

KodeKenapa
struct Node* nextDi dalam struct, nama Node (hasil typedef) belum selesai dibuat. Jadi pakai nama lengkapnya: struct Node.
Node* headList tidak disimpan "utuh". Cukup simpan alamat node pertama, sisanya bisa dicapai lewat next.
mallocNode harus tetap hidup setelah fungsi selesai. Variabel lokal hilang saat fungsi return, jadi node dibuat di heap.
n->next = NULLmalloc tidak mengosongkan memory. Tanpa baris ini, next berisi alamat acak.
Bedakan node dan pointerhead, cur, del bukan node. Mereka variabel yang menyimpan alamat node. Mengubah cur tidak mengubah list. Mengubah cur->next mengubah list.

3. Resep: cara menulis operasi apa pun

Kamu tidak perlu menghafal kode insert atau delete. Pakai 5 langkah ini setiap kali:

  1. Gambar sebelum dan sesudah. Pakai list kecil, misalnya 3 node.
  2. Tandai panah yang berubah. Panah mana yang hilang, panah mana yang baru? Tiap panah baru = satu baris assignment.
  3. Cari node yang kamu butuhkan. Untuk mengubah sebuah panah, kamu butuh alamat node pemilik panah itu. Kalau belum punya, traverse dulu.
  4. Tentukan urutan. Sebelum menimpa sebuah pointer, pastikan alamat yang disimpannya tidak dibutuhkan lagi, atau sudah disimpan di tempat lain.
  5. Cek edge case. List kosong? Posisi 0 (head berubah)? Node terakhir? List 1 node?

4. Empat pola yang selalu muncul

PolaKodecur berhenti di
A. Kunjungi semua nodewhile (cur != NULL)NULL (sudah lewat node terakhir)
B. Cari node terakhirwhile (cur->next != NULL)Node terakhir
C. Satu sebelum posisi posfor (i = 0; i < pos - 1; i++)Node di pos - 1
D. Sambung dulu, putus kemudiannew->next = X; lalu A->next = new;(urutan assignment)
Cara memilih polaTanya: "Saat loop berhenti, cur harus menunjuk ke mana?" Kalau kamu butuh node terakhir untuk disambung, pakai B, bukan A. Dengan A, cur sudah NULL dan tidak bisa dipakai.

5. Menurunkan kode tiap operasi

Buka visualisasi operasi dan nyalakan mode tebak. Coba tebak tiap langkah sebelum ditampilkan.

insertFront(x): O(1)

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [5] → [10] → [20] → NULL
  • Panah baru: [5] → [10] dan head → [5].
  • Urutan: head menyimpan satu-satunya alamat [10]. Kalau head ditimpa duluan, alamat itu hilang. Jadi sambungkan [5] → [10] dulu.
  • Edge case list kosong: newNode->next = head jadi NULL, memang benar. Tidak perlu if.
void insertFront(int x) {
    Node* newNode = createNode(x);
    newNode->next = head;   // sambung dulu
    head = newNode;         // baru pindahkan head
    size++;
}
Cek pemahaman: apa yang terjadi kalau dua baris tengah ditukar?

head = newNode lalu newNode->next = head → newNode->next = newNode. Node menunjuk dirinya sendiri, dan seluruh list lama hilang (memory leak). Print akan looping selamanya.

insertBack(x): O(n)

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [10] → [20] → [50] → NULL
  • Panah baru: [20] → [50]. Pemiliknya node terakhir.
  • Node yang dibutuhkan: node terakhir. Tidak ada pointer yang langsung ke sana, jadi pakai pola B.
  • Edge case list kosong: tidak ada node terakhir. Node baru langsung jadi head.
void insertBack(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = newNode;
    } else {
        Node* cur = head;
        while (cur->next != NULL)   // pola B
            cur = cur->next;
        cur->next = newNode;
    }
    size++;
}
Cek pemahaman: kenapa kondisinya cur->next != NULL, bukan cur != NULL?

Dengan cur != NULL, loop berhenti saat cur sudah NULL. Baris berikutnya cur->next = newNode akan crash (NULL dereference). Kita butuh cur berhenti di node terakhir, bukan sesudahnya.

Mau O(1)? Simpan pointer tail ke node terakhir. Ini yang dilakukan double linked list.

insertAt(pos, x): O(n)

Sebelum:  head → [10] → [20] → [30] → NULL          insertAt(2, 25)
Sesudah:  head → [10] → [20] → [25] → [30] → NULL
  • Panah baru: [25] → [30] dan [20] → [25]. Panah lama [20] → [30] hilang.
  • Node yang dibutuhkan: [20], pemilik panah yang berubah. Itu node di pos - 1 → pola C.
  • Urutan: alamat [30] hanya ada di cur->next. Pakai dulu untuk newNode->next, baru timpa cur->next (pola D).
  • Edge case pos == 0: tidak ada node di posisi -1. Yang berubah head, jadi pakai insertFront.
  • Edge case pos == size: cur = node terakhir, cur->next = NULL. Kode yang sama sudah benar.
void insertAt(int pos, int x) {          // syarat: 0 <= pos <= size
    if (pos == 0) { insertFront(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)    // pola C
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur->next;           // sambung dulu
    cur->next = newNode;                 // baru putus
    size++;
}
Cek pemahaman: kenapa loop-nya pos - 1 kali?

cur mulai di posisi 0. Tiap iterasi maju 1. Setelah k iterasi, cur ada di posisi k. Kita mau berhenti di posisi pos - 1, jadi loop pos - 1 kali. Cek dengan contoh: pos = 2 → loop 1 kali → cur di posisi 1 ([20]). Cocok.

deleteAt(pos): O(n)

Sebelum:  head → [10] → [20] → [30] → NULL          deleteAt(1)
Sesudah:  head → [10] → [30] → NULL                 [20] di-free
  • Panah baru: [10] → [30]. Pemiliknya node di pos - 1 → pola C lagi.
  • Urutan: setelah cur->next ditimpa, alamat [20] hilang dan tidak bisa di-free. Jadi simpan di del dulu.
  • Kapan free? Paling akhir. Setelah free(del), del->next tidak boleh dibaca lagi.
  • Edge case pos == 0: tidak ada node sebelumnya. Yang berubah head.
void deleteAt(int pos) {                 // syarat: 0 <= pos < size
    Node* del;
    if (pos == 0) {
        del = head;
        head = head->next;
    } else {
        Node* cur = head;
        for (int i = 0; i < pos - 1; i++)
            cur = cur->next;
        del = cur->next;                 // simpan alamat dulu
        cur->next = del->next;           // lompati del
    }
    free(del);                           // terakhir
    size--;
}
Cek pemahaman: apa salahnya free(del); cur->next = del->next;?

Setelah free, memory del sudah dikembalikan. Membaca del->next adalah use-after-free: kadang terlihat jalan, kadang crash, kadang membaca data sampah. Selalu putus sambungan dulu, baru free.

search(x) dan printList(): O(n)

Dua-duanya pola A: kunjungi semua node sampai NULL.

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;          // ketemu: berhenti lebih awal
        cur = cur->next;
    }
    return NULL;                 // tidak ketemu
}

void printList() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

freeList(): hapus semua node

Di C, setiap malloc harus punya free. Coba turunkan sendiri dulu: kalau cur di-free, bagaimana cara pindah ke node berikutnya?

Lihat jawaban 
void freeList() {
    Node* cur = head;
    while (cur != NULL) {
        Node* nextNode = cur->next;   // simpan dulu, sebelum cur di-free
        free(cur);
        cur = nextNode;
    }
    head = NULL;
    size = 0;
}

Polanya sama dengan deleteAt: alamat yang masih dibutuhkan disimpan dulu, baru free.

8. Full code

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

Node* head = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}

void insertFront(int x) {
    Node* newNode = createNode(x);
    newNode->next = head;
    head = newNode;
    size++;
}

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = newNode;
    } else {
        Node* cur = head;
        while (cur->next != NULL)
            cur = cur->next;
        cur->next = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur->next;
    cur->next = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del;
    if (pos == 0) {
        del = head;
        head = head->next;
    } else {
        Node* cur = head;
        for (int i = 0; i < pos - 1; i++)
            cur = cur->next;
        del = cur->next;
        cur->next = del->next;
    }
    free(del);
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;
}

void printList() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

void freeList() {
    Node* cur = head;
    while (cur != NULL) {
        Node* nextNode = cur->next;
        free(cur);
        cur = nextNode;
    }
    head = NULL;
    size = 0;
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printList();          // 10 20 25 30

    deleteAt(0);          // hapus 10
    deleteAt(1);          // hapus 25
    printList();          // 20 30

    printf("%s\n", search(30) != NULL ? "30 ketemu" : "30 tidak ada");

    freeList();
    return 0;
}

9. Latihan

Latihan ini melatih cara berpikir, bukan hafalan. Kerjakan dengan menggambar dulu.

1. Trace. Mulai dari list kosong: insertBack(4), insertFront(2), insertAt(1, 3), insertAt(3, 5), deleteAt(0). Gambar list setelah tiap langkah.

Jawaban

[4] → [2, 4] → [2, 3, 4] → [2, 3, 4, 5] → [3, 4, 5].

2. Temukan bug. Fungsi ini seharusnya menghapus node terakhir. Untuk list mana dia crash, dan kenapa?

void deleteBack() {
    Node* cur = head;
    while (cur->next->next != NULL)
        cur = cur->next;
    free(cur->next);
    cur->next = NULL;
}
Jawaban

Crash untuk list kosong (cur->next saat cur NULL) dan list 1 node (cur->next->next saat cur->next NULL). Untuk list 1 node, yang harus berubah adalah head, karena tidak ada node sebelum node terakhir. Perbaikan:

void deleteBack() {
    if (head == NULL) return;
    if (head->next == NULL) {       // 1 node: head berubah
        free(head);
        head = NULL;
    } else {
        Node* cur = head;
        while (cur->next->next != NULL)   // berhenti di node kedua dari belakang
            cur = cur->next;
        free(cur->next);
        cur->next = NULL;
    }
    size--;
}

3. Lengkapi. Fungsi ini menghitung jumlah semua data. Isi bagian kosong, dan sebutkan polanya.

int sum() {
    int total = 0;
    for (Node* cur = head; ________; ________)
        total += cur->data;
    return total;
}
Jawaban

cur != NULL dan cur = cur->next. Ini pola A, karena semua node harus dikunjungi, termasuk node terakhir.

4. Turunkan sendiri. Pakai resep 5 langkah untuk menulis void insertAfter(int target, int x): sisipkan x tepat setelah node pertama yang bernilai target. Kalau target tidak ada, jangan lakukan apa-apa.

Jawaban 
void insertAfter(int target, int x) {
    Node* cur = search(target);          // node pemilik panah yang berubah
    if (cur == NULL) return;             // edge case: target tidak ada
    Node* newNode = createNode(x);
    newNode->next = cur->next;           // sambung dulu
    cur->next = newNode;                 // baru putus
    size++;
}

Perhatikan: ini sama persis dengan bagian akhir insertAt. Yang beda hanya cara menemukan cur.

5. Tantangan. Tulis void reverse() yang membalik arah semua panah, tanpa membuat node baru. Petunjuk: gambar 3 node, lalu pikirkan apa yang harus kamu simpan sebelum membalik satu panah.

Jawaban 
void reverse() {
    Node* before = NULL;
    Node* cur = head;
    while (cur != NULL) {
        Node* after = cur->next;   // simpan dulu, karena panah cur akan dibalik
        cur->next = before;        // balik panah
        before = cur;              // geser kedua pointer
        cur = after;
    }
    head = before;                 // node terakhir jadi node pertama
}

Sebelum cur->next ditimpa, alamat node berikutnya disimpan di after. Aturannya tetap sama: jangan sampai kehilangan alamat.
