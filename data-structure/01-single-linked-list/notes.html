Kenapa linked list: menyisipkan cukup mengubah panah

array dan pointer (algorithm and programming, materi 04) semua section berikutnya, double linked list, stack, dan queue

Rangkaian gerbong kereta: setiap gerbong hanya terkait ke gerbong di belakangnya. Menyisipkan gerbong cukup melepas satu sambungan, lalu memasang dua sambungan baru.

semua gerbong kereta bisa kamu lihat dari peron. Node di linked list hanya bisa dicapai dengan berjalan dari node pertama.

Linked list adalah kumpulan elemen yang setiap elemennya menyimpan alamat elemen berikutnya. Contoh: menyisipkan 25 setelah 20 di [10, 20, 30, 40].

ArrayLinked list
Insert di tengah30 dan 40 harus digeser satu per satuCukup ubah 2 panah, tidak ada yang digeser
UkuranTetap sejak deklarasiNode bisa ditambah kapan saja
Akses elemen ke-iLangsung lewat indexHarus berjalan dari node pertama

Linked list menukar akses cepat ke elemen ke-i dengan insert dan delete yang cukup mengubah panah.

Soal latihan: Kamu sering menyisipkan data di depan, tapi jarang mencari data ke-i. Pilih array atau linked list?

Linked list. Menyisipkan di depan cukup mengubah panah, sedangkan di array semua elemen harus digeser. Kelemahan linked list (akses ke-i) jarang dipakai di kasus ini.

Node: data ditambah alamat node berikutnya

pointer sebagai kotak berisi alamat (algorithm and programming, materi 04) createNode (3️⃣) dan semua operasi

Kartu berantai di permainan harta karun: setiap kartu berisi satu petunjuk dan lokasi kartu berikutnya.

kartu yang hilang bisa dicari lagi. Node yang alamatnya hilang tidak bisa dicapai lagi sama sekali.

Node adalah satu elemen linked list, berisi data dan next (alamat node berikutnya). Seluruh list cukup diwakili head, yaitu alamat node pertama.

typedef struct Node {
    int data;
    struct Node* next;    // alamat node berikutnya, NULL kalau node terakhir
} Node;

Node* head = NULL;        // alamat node pertama, NULL kalau list kosong
int size = 0;
Baru melihat struct, typedef, dan ->?
  • struct menggabungkan beberapa variabel jadi satu tipe baru. Di sini satu node berisi data dan next.
  • typedef ... Node; memberi nama pendek, jadi cukup menulis Node, bukan struct Node.
  • struct Node* next di dalam struct memakai nama lengkap, karena nama Node dari typedef belum selesai dibuat di baris itu.
  • p->data artinya "data milik node yang alamatnya disimpan p". Sama dengan (*p).data.

head, cur, del bukan node. Mereka variabel yang menyimpan alamat node. Mengubah cur tidak mengubah list. Mengubah cur->next mengubah list.

Node = data + next. List cukup diwakili head. Node terakhir: next = NULL.

Soal latihan: Dengan list di gambar, apa isi head->next->data?

head = alamat node 10. head->next = alamat node 20. Jadi head->next->data = 20.

createNode: node dibuat dengan malloc supaya tetap hidup setelah fungsi selesai

struct Node (2️⃣) dan stdlib.h (algorithm and programming, materi 01) semua operasi insert (6️⃣ sampai 8️⃣)

Menyewa loker jangka panjang: lokernya tetap ada walaupun kamu pulang, sampai kamu sendiri yang mengembalikannya.

penyewaan loker punya batas waktu. Memory dari malloc tidak dikembalikan otomatis, jadi kamu wajib mengembalikannya dengan free.

malloc adalah fungsi untuk meminta memory di heap, yaitu area memory yang tetap ada sampai di-free. Variabel lokal biasa hilang saat fungsi selesai, jadi node tidak bisa dibuat sebagai variabel lokal.

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}
KodeKenapa
malloc(sizeof(Node))Minta memory sebesar satu node, dan dapat alamatnya.
(Node*) di depan mallocmalloc mengembalikan void* (alamat tanpa tipe). C mengubahnya otomatis, tapi compiler C++ (Dev-C++ dengan file .cpp) tidak. Cast ini membuat kode jalan di keduanya.
n->next = NULLmalloc tidak mengosongkan memory. Tanpa baris ini, next berisi alamat acak.

Node dibuat dengan malloc. Setiap malloc nanti butuh tepat satu free.

Soal latihan: Apa yang salah kalau createNode ditulis dengan variabel lokal, misalnya Node n; ... return &n;?

n hilang saat createNode selesai, jadi alamat yang dikembalikan menunjuk memory yang sudah tidak dimiliki siapa pun. Node harus dibuat dengan malloc supaya tetap hidup.

Resep 5 langkah: cara menulis operasi apa pun tanpa menghafal

node dan panah next (2️⃣) semua operasi (6️⃣ sampai 11), double linked list, stack, queue

Memindahkan kabel di stopkontak: lihat dulu kabel mana yang mau dipindah, siapkan colokan baru, baru cabut yang lama.

kabel yang tercabut masih bisa kamu pungut. Alamat node yang tertimpa hilang selamanya.

Semua operasi linked list adalah soal mengubah panah. Yang sering bikin crash adalah situasi khusus, yang disebut edge case: list kosong, posisi 0, node terakhir, atau list 1 node.

  1. Gambar sebelum dan sesudah. Pakai list kecil, misalnya 3 node.
  2. Tandai panah yang berubah. Setiap panah baru = satu baris assignment.
  3. Cari pemilik panah. Untuk mengubah panah, kamu butuh alamat node pemiliknya. Kalau belum punya, traverse dulu (5️⃣).
  4. Tentukan urutan. Sebelum menimpa pointer, pastikan alamatnya tidak dibutuhkan lagi atau sudah disimpan di tempat lain.
  5. Cek edge case. Ulangi langkah 1 dengan list kosong, posisi 0, dan list 1 node.

Kenapa urutannya begini: panah baru bisa ditandai setelah ada gambar, dan urutan kode baru bisa ditentukan setelah tahu panah milik siapa. Edge case dicek terakhir, dengan membandingkan kode kasus normal.

Gambar → tandai panah → cari pemiliknya → urutkan → cek edge case.

Soal latihan: Kenapa langkah 3 (cari pemilik panah) sering butuh traverse?

Program hanya langsung memegang head. Pemilik panah yang berubah biasanya node di tengah atau di akhir, jadi alamatnya harus dicari dengan berjalan dari head.

Empat pola traverse: tentukan di mana cur harus berhenti

langkah 3 dan 4 resep (4️⃣), loop (algorithm and programming, materi 03) insertBack, insertAt, deleteAt, search (7️⃣ sampai 10)

Naik lift: kamu harus tahu mau berhenti di lantai berapa. Berhenti satu lantai terlalu jauh sama salahnya dengan satu lantai terlalu dekat.

di lift kamu bisa turun lagi. Di single linked list, cur tidak bisa mundur, karena tidak ada panah ke belakang.

Traverse adalah berjalan dari node ke node lewat cur = cur->next. Bedanya hanya di mana cur berhenti:

PolaKodecur berhenti di
A. Kunjungi semua nodewhile (cur != NULL)NULL (sudah lewat node terakhir)
B. Cari node terakhirwhile (cur->next != NULL)Node terakhir
C. Satu sebelum posisi posfor (i = 0; i < pos - 1; i++)Node di pos - 1
D. Sambung dulu, putus kemudiannew->next = X; lalu A->next = new;(aturan urutan, bukan loop)

Cara memilih: tanya "saat loop berhenti, cur harus menunjuk ke mana?" Kalau kamu butuh node terakhir untuk disambung, pakai B, bukan A.

A = sampai NULL, B = berhenti di node terakhir, C = berhenti di pos − 1, D = sambung dulu baru putus.

Soal latihan: Untuk menghitung banyaknya node, pola mana yang dipakai?

Pola A, karena semua node harus dikunjungi, termasuk node terakhir. Loop berhenti saat cur sudah NULL.

insertFront: sambung node baru dulu, baru pindahkan head

resep dan pola D (4️⃣, 5️⃣) insertAt di posisi 0 (8️⃣) dan push di stack

Menyisipkan diri di depan antrean sambil memegang bahu orang pertama, lalu petugas menunjukmu sebagai orang pertama.

di antrean, orang lain tetap terlihat walau petugas salah tunjuk. Di linked list, kalau head pindah duluan, list lama tidak bisa dicapai lagi.

insertFront menambah node baru di depan list. Ikuti resepnya:

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [5] → [10] → [20] → NULL
  1. Panah baru: [5] → [10] dan head → [5].
  2. Urutan: alamat [10] hanya tersimpan di head. Kalau head ditimpa duluan, alamat itu hilang. Jadi sambung [5] → [10] dulu.
  3. Edge case list kosong: newNode->next = head berisi NULL, dan itu memang benar. Tidak perlu if.
void insertFront(int x) {
    Node* newNode = createNode(x);
    newNode->next = head;   // sambung dulu
    head = newNode;         // baru pindahkan head
    size++;
}

Buka visualisasi operasi, centang Mode tebak, lalu klik insertFront. Tebak panah mana yang berubah sebelum setiap langkah tampil.

Sambung dulu (newNode->next = head), baru pindahkan head.

Soal latihan: Apa yang terjadi kalau dua baris tengah ditukar?

head = newNode lalu newNode->next = head membuat newNode->next = newNode. Node menunjuk dirinya sendiri, dan seluruh list lama hilang (memory leak). printList akan berputar selamanya.

insertBack: cari node terakhir dengan pola B

pola B (5️⃣) tail di double linked list, enqueue di queue

Ikut antrean dari belakang: kamu harus berjalan sampai orang terakhir dulu, baru berdiri di belakangnya.

di antrean, orang terakhir terlihat dari jauh. Di single linked list, node terakhir hanya bisa ditemukan dengan berjalan dari head.

insertBack menambah node di akhir list. Panah baru dimiliki node terakhir, jadi node itu harus dicari dulu.

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [10] → [20] → [50] → NULL
  1. Panah baru: [20] → [50]. Pemiliknya node terakhir.
  2. Cari pemilik: tidak ada pointer yang langsung ke node terakhir, jadi pakai pola B.
  3. Edge case list kosong: tidak ada node terakhir. Node baru langsung jadi head.
void insertBack(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = newNode;
    } else {
        Node* cur = head;
        while (cur->next != NULL)   // pola B
            cur = cur->next;
        cur->next = newNode;
    }
    size++;
}

Mau lebih cepat? Simpan pointer tail ke node terakhir, jadi tidak perlu traverse. Ini yang dilakukan double linked list.

Node terakhir dicari dengan while (cur->next != NULL), bukan cur != NULL.

Soal latihan: Kenapa kondisinya cur->next != NULL, bukan cur != NULL?

Dengan cur != NULL, loop berhenti saat cur sudah NULL. Baris cur->next = newNode lalu mengakses NULL, dan program crash. Kita butuh cur berhenti di node terakhir, bukan sesudahnya.

insertAt: berhenti di node satu sebelum posisi

pola C dan D (5️⃣), insertFront (6️⃣) deleteAt (9️⃣), yang memakai pola yang sama

Menyisipkan buku di rak berantai: kamu harus memegang buku sebelum tempat itu, karena hanya buku itu yang memegang sambungan ke buku berikutnya.

di rak, kamu bisa memegang dua buku sekaligus dengan dua tangan. Di single linked list, setiap node hanya memegang panah ke depan.

insertAt(pos, x) menyisipkan node baru di posisi pos. Panah yang berubah dimiliki node di pos - 1.

Sebelum:  head → [10] → [20] → [30] → NULL          insertAt(2, 25)
Sesudah:  head → [10] → [20] → [25] → [30] → NULL
  1. Panah baru: [25] → [30] dan [20] → [25]. Panah lama [20] → [30] hilang.
  2. Cari pemilik: [20], node di pos - 1. Pakai pola C.
  3. Urutan: alamat [30] hanya ada di cur->next. Pakai dulu untuk newNode->next, baru timpa (pola D).
  4. Edge case: pos == 0 tidak punya node di posisi −1, jadi pakai insertFront. pos == size sudah benar dengan kode yang sama.
void insertAt(int pos, int x) {          // syarat: 0 <= pos <= size
    if (pos == 0) { insertFront(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)    // pola C
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur->next;           // sambung dulu
    cur->next = newNode;                 // baru putus
    size++;
}

Butuh node pos − 1 (pola C), sambung dulu baru putus (pola D), dan pos == 0 ditangani insertFront.

Soal latihan: Kenapa loop-nya jalan pos - 1 kali?

cur mulai di posisi 0, dan setiap putaran maju 1. Setelah k putaran, cur ada di posisi k. Kita mau berhenti di posisi pos − 1, jadi loop pos − 1 kali. Cek: pos = 2 → loop 1 kali → cur di posisi 1 ([20]). Cocok.

deleteAt: simpan alamat node dulu, free paling akhir

pola C (5️⃣) dan insertAt (8️⃣) pop di stack dan dequeue di queue

Melepas gerbong di tengah: catat dulu nomor gerbongnya, sambungkan gerbong depan ke gerbong belakang, baru gerbong itu dibawa ke gudang.

gerbong di gudang masih bisa dilihat. Node yang sudah di-free tidak boleh dibaca sama sekali.

Use-after-free adalah bug membaca memory yang sudah di-free. Hasilnya tidak bisa ditebak: kadang terlihat jalan, kadang crash. deleteAt harus diurutkan supaya bug ini tidak terjadi.

Sebelum:  head → [10] → [20] → [30] → NULL          deleteAt(1)
Sesudah:  head → [10] → [30] → NULL                 [20] di-free
  1. Panah baru: [10] → [30]. Pemiliknya node di pos - 1 (pola C).
  2. Urutan: setelah cur->next ditimpa, alamat [20] hilang dan tidak bisa di-free. Jadi simpan di del dulu.
  3. free paling akhir: setelah free(del), del->next tidak boleh dibaca lagi.
  4. Edge case pos == 0: tidak ada node sebelumnya. Yang berubah head.
void deleteAt(int pos) {                 // syarat: 0 <= pos < size
    Node* del;
    if (pos == 0) {
        del = head;
        head = head->next;
    } else {
        Node* cur = head;
        for (int i = 0; i < pos - 1; i++)
            cur = cur->next;
        del = cur->next;                 // simpan alamat dulu
        cur->next = del->next;           // lompati del
    }
    free(del);                           // terakhir
    size--;
}

Simpan alamat node di del, lompati node itu, baru free(del).

Soal latihan: Apa salahnya free(del); cur->next = del->next;?

Setelah free, memory del sudah dikembalikan. Membaca del->next adalah use-after-free. Selalu putus sambungan dulu, baru free.

Soal latihan: Mulai dari list kosong: insertBack(4), insertFront(2), insertAt(1, 3), insertAt(3, 5), deleteAt(0). Gambar list setelah setiap langkah.

[4] → [2, 4] → [2, 3, 4] → [2, 3, 4, 5] → [3, 4, 5].

search dan printList: kunjungi semua node dengan pola A

pola A (5️⃣) insertAfter (soal di bawah) dan operasi cari di struktur data lain

Mencari nama di daftar absen yang tidak urut: baca dari atas, satu per satu, sampai ketemu atau daftar habis.

daftar absen bisa kamu lompati dengan mata. cur hanya bisa maju satu node setiap langkah.

search dan printList sama-sama berjalan sampai NULL (pola A). Bedanya, search bisa berhenti lebih awal saat data ketemu.

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;          // ketemu: berhenti lebih awal
        cur = cur->next;
    }
    return NULL;                 // tidak ketemu
}

void printList() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

Mengunjungi semua node = while (cur != NULL). search mengembalikan alamat node, atau NULL kalau tidak ketemu.

Soal latihan: Lengkapi fungsi ini dan sebutkan polanya: int sum() { int total = 0; for (Node* cur = head; ____; ____) total += cur->data; return total; }

cur != NULL dan cur = cur->next. Ini pola A, karena semua node harus dikunjungi, termasuk node terakhir.

Soal latihan: Pakai resep 5 langkah untuk menulis void insertAfter(int target, int x): sisipkan x tepat setelah node pertama yang bernilai target. Kalau target tidak ada, jangan lakukan apa-apa. 
void insertAfter(int target, int x) {
    Node* cur = search(target);          // node pemilik panah yang berubah
    if (cur == NULL) return;             // edge case: target tidak ada
    Node* newNode = createNode(x);
    newNode->next = cur->next;           // sambung dulu
    cur->next = newNode;                 // baru putus
    size++;
}

Ini sama persis dengan bagian akhir insertAt. Yang beda hanya cara menemukan cur.

freeList: simpan alamat node berikutnya sebelum free

deleteAt dan aturan "simpan dulu" (9️⃣) akhir setiap program yang memakai malloc

Membongkar rantai kertas sambil membaca petunjuknya: baca dulu lokasi kartu berikutnya, baru buang kartu yang sedang dipegang.

kartu yang dibuang masih bisa dipungut. Node yang di-free tidak boleh dibaca lagi.

Di C, setiap malloc harus punya free. Node yang tidak di-free tetap memakan memory sampai program selesai, dan kondisi ini disebut memory leak. Turunkan sendiri dulu: kalau cur di-free, bagaimana cara pindah ke node berikutnya?

Lihat jawaban 
void freeList() {
    Node* cur = head;
    while (cur != NULL) {
        Node* nextNode = cur->next;   // simpan dulu, sebelum cur di-free
        free(cur);
        cur = nextNode;
    }
    head = NULL;
    size = 0;
}

Polanya sama dengan deleteAt: alamat yang masih dibutuhkan disimpan dulu, baru free.

Sebelum free(cur), simpan cur->next. Lupa free = memory leak.

Soal latihan (tantangan): Tulis void reverse() yang membalik arah semua panah, tanpa membuat node baru. 
void reverse() {
    Node* before = NULL;
    Node* cur = head;
    while (cur != NULL) {
        Node* after = cur->next;   // simpan dulu, karena panah cur akan dibalik
        cur->next = before;        // balik panah
        before = cur;              // geser kedua pointer
        cur = after;
    }
    head = before;                 // node terakhir jadi node pertama
}

Sebelum cur->next ditimpa, alamat node berikutnya disimpan di after. Aturannya tetap sama: jangan sampai kehilangan alamat.

Waktu tempuh antrean: dilayani di depan selalu cepat, tapi mencari orang ke-100 butuh waktu sebanding dengan panjang antrean.

antrean nyata punya waktu dalam menit. Big-O tidak menghitung detik, hanya cara waktunya tumbuh saat data bertambah.

Big-O adalah notasi untuk cara waktu operasi tumbuh saat jumlah data (n) bertambah. O(1) = tetap, berapa pun n. O(n) = makin banyak node → makin lama, sebanding dengan n.

O(n). printList mengunjungi setiap node sekali, jadi waktunya sebanding dengan banyaknya node.

Checklist pilot sebelum terbang: setiap kecelakaan kecil biasanya karena satu langkah checklist terlewat.

pilot punya kopilot yang mengecek ulang. Compiler tidak mengecek urutan pointer-mu, jadi kamu sendiri yang harus mengecek.

Semua bug di bawah lolos compile. Cari dengan menggambar ulang list sebelum dan sesudah operasi.

Soal latihan: Fungsi ini seharusnya menghapus node terakhir. Untuk list mana dia crash, dan kenapa? 
void deleteBack() {
    Node* cur = head;
    while (cur->next->next != NULL)
        cur = cur->next;
    free(cur->next);
    cur->next = NULL;
}

Crash untuk list kosong (cur->next saat cur NULL) dan list 1 node (cur->next->next saat cur->next NULL). Untuk list 1 node, yang harus berubah adalah head, karena tidak ada node sebelum node terakhir. Perbaikan:

void deleteBack() {
    if (head == NULL) return;
    if (head->next == NULL) {       // 1 node: head berubah
        free(head);
        head = NULL;
    } else {
        Node* cur = head;
        while (cur->next->next != NULL)   // berhenti di node kedua dari belakang
            cur = cur->next;
        free(cur->next);
        cur->next = NULL;
    }
    size--;
}

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

Node* head = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}

void insertFront(int x) {
    Node* newNode = createNode(x);
    newNode->next = head;
    head = newNode;
    size++;
}

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = newNode;
    } else {
        Node* cur = head;
        while (cur->next != NULL)
            cur = cur->next;
        cur->next = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur->next;
    cur->next = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del;
    if (pos == 0) {
        del = head;
        head = head->next;
    } else {
        Node* cur = head;
        for (int i = 0; i < pos - 1; i++)
            cur = cur->next;
        del = cur->next;
        cur->next = del->next;
    }
    free(del);
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;
}

void printList() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

void freeList() {
    Node* cur = head;
    while (cur != NULL) {
        Node* nextNode = cur->next;
        free(cur);
        cur = nextNode;
    }
    head = NULL;
    size = 0;
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printList();          // 10 20 25 30

    deleteAt(0);          // hapus 10
    deleteAt(1);          // hapus 25
    printList();          // 20 30

    printf("%s\n", search(30) != NULL ? "30 ketemu" : "30 tidak ada");

    freeList();
    return 0;
}

Program lengkap = struct + createNode + operasi + main. Setiap malloc punya free di freeList.

Soal latihan: Apa output main di atas?

Baris pertama 10 20 25 30. Setelah deleteAt(0) dan deleteAt(1), baris kedua 20 30. Baris ketiga 30 ketemu.
