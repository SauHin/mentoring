Notes 1️⃣ · Kenapa linked list

Di linked list, menyisipkan cukup mengubah panah, tanpa menggeser elemen

Linked list adalah kumpulan elemen yang setiap elemennya menyimpan alamat elemen berikutnya. Contoh: sisipkan 25 setelah 20.

ArrayLinked list
Insert di tengahSemua elemen sesudahnya digeser satu per satuCukup ubah 2 panah
UkuranTetap sejak deklarasiNode bisa ditambah kapan saja
Akses elemen ke-iLangsung lewat indexHarus berjalan dari node pertama

Panah = pointer. Mengubah panah artinya mengubah alamat yang disimpan sebuah pointer.

Notes 2️⃣ · Node

Setiap node menyimpan data dan alamat node berikutnya

Node adalah satu elemen linked list: data + next. Seluruh list cukup diwakili head.

typedef struct Node {
    int data;
    struct Node* next;
} Node;
Node* head = NULL;
  • p->data = data milik node yang alamatnya disimpan p.
  • head, cur, del adalah variabel berisi alamat, bukan node.

Notes 3️⃣ · createNode

Node dibuat dengan malloc supaya tetap hidup setelah fungsi selesai

malloc meminta memory di heap, yang tetap ada sampai di-free.

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}
  • (Node*): malloc mengembalikan void*. Compiler C++ mewajibkan cast ini, jadi tulis supaya jalan di keduanya.
  • n->next = NULL: malloc tidak mengosongkan memory. Tanpa baris ini, next berisi alamat acak.
  • Setiap malloc nanti butuh tepat satu free.

Notes 4️⃣ · Resep 5 langkah

Operasi apa pun bisa diturunkan dengan lima langkah yang sama

Edge case adalah situasi khusus yang sering bikin crash: list kosong, posisi 0, node terakhir, list 1 node.

  1. Gambar list sebelum dan sesudah operasi. 3 node sudah cukup.
  2. Tandai panah yang hilang dan yang baru. Setiap panah baru = satu baris kode.
  3. Cari pemilik panah, karena untuk mengubah panah kamu butuh alamat node pemiliknya.
  4. Urutkan kodenya. Jangan menimpa pointer yang alamatnya masih dibutuhkan.
  5. Cek edge case dengan menggambar ulang untuk list kosong, posisi 0, dan list 1 node.

Notes 6️⃣ · insertFront

insertFront menyambung node baru dulu, baru memindahkan head

Ada dua panah baru: dari node baru ke node pertama lama, dan dari head ke node baru.

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [5] → [10] → [20] → NULL
Node* newNode = createNode(x);
newNode->next = head;   // 1. sambung
head = newNode;         // 2. pindah
  • Alamat [10] hanya ada di head, jadi head dipakai dulu di langkah 1, baru ditimpa.
  • List kosong: newNode->next berisi NULL, dan itu benar. Tidak perlu if.

Kalau urutannya ditukar, newNode->next = newNode. List lama hilang, dan print berputar selamanya.

Notes 7️⃣ · insertBack

insertBack harus mencari node terakhir dulu dengan pola B

Panah baru dimiliki node terakhir, dan tidak ada pointer yang langsung ke node itu.

if (head == NULL) {
    head = newNode;
} else {
    Node* cur = head;
    while (cur->next != NULL)   // pola B
        cur = cur->next;
    cur->next = newNode;
}
  • List kosong: tidak ada node terakhir, jadi yang berubah head.
  • Mau tanpa traverse? Simpan pointer tail, seperti di double linked list.

while (cur != NULL) berhenti saat cur sudah NULL, lalu cur->next = newNode crash.

Notes 8️⃣ · insertAt

insertAt butuh node di pos - 1, karena node itulah pemilik panahnya

Pola C membawa cur ke pos - 1, lalu pola D menyambung node baru sebelum panah lama diputus.

insertAt(2, 25)
Sebelum:  [10] → [20] → [30] → NULL
Sesudah:  [10] → [20] → [25] → [30] → NULL
if (pos == 0) { insertFront(x); return; }
Node* cur = head;
for (int i = 0; i < pos - 1; i++)   // pola C
    cur = cur->next;
newNode->next = cur->next;   // sambung
cur->next = newNode;         // putus
  • Loop pos - 1 kali, jadi cur berhenti di [20].
  • Alamat [30] hanya ada di cur->next, jadi dipakai dulu sebelum ditimpa.
  • pos == 0 tidak punya node di posisi −1, jadi panggil insertFront.

Notes 9️⃣ · deleteAt

deleteAt menyimpan alamat node dulu, dan memanggil free paling akhir

Use-after-free adalah bug membaca memory yang sudah di-free, dan hasilnya tidak bisa ditebak.

Node* del;
if (pos == 0) {
    del = head;
    head = head->next;
} else {
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)
        cur = cur->next;
    del = cur->next;        // simpan alamat
    cur->next = del->next;  // lompati
}
free(del);                  // terakhir
  • Setelah cur->next ditimpa, alamat node yang dihapus tidak tersimpan di mana pun. Karena itu disimpan dulu di del.
  • Setelah free(del), del->next tidak boleh dibaca lagi.

Notes 10 dan 11 · search, printList, freeList

Mengunjungi semua node memakai pola A, dan freeList menyimpan next sebelum free

search berhenti lebih awal kalau data ketemu. freeList membebaskan setiap node supaya tidak terjadi memory leak.

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {      // pola A
        if (cur->data == x) return cur;
        cur = cur->next;
    }
    return NULL;
}
void freeList() {
    Node* cur = head;
    while (cur != NULL) {
        Node* nextNode = cur->next;  // simpan
        free(cur);
        cur = nextNode;
    }
    head = NULL;
}

Memory leak = node yang tidak di-free tetap memakan memory sampai program selesai.

Notes 12 · Time complexity

Linked list cepat di bagian depan, tapi butuh traverse untuk posisi lain

Big-O menunjukkan cara waktu tumbuh saat jumlah node (n) bertambah. O(1) = tetap, O(n) = sebanding dengan n.

Ringkasan: semua operasi linked list adalah soal mengubah panah

  • Node = data + next. List cukup diwakili head. Node dibuat dengan malloc (2️⃣ 3️⃣).
  • Gambar dulu, tandai panah, cari pemiliknya, urutkan, lalu cek edge case (4️⃣).
  • Insert dan delete di posisi pos butuh node pos − 1, karena node hanya bisa mengubah next miliknya sendiri (5️⃣ 8️⃣ 9️⃣).
  • Sambung dulu, putus kemudian. Simpan alamat sebelum ditimpa atau di-free (6️⃣ 9️⃣ 11).
  • Ada traverse → O(n). Hanya memakai head → O(1) (12).
