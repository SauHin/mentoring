Single linked list

Data structure · cara menurunkan kode linked list sendiri, bukan menghafalnya.

Kenapa linked list?

Array menyimpan elemen berderet, jadi insert di tengah memaksa elemen lain bergeser. Linked list tidak punya masalah ini. Contoh: sisipkan 25 setelah 20.

ArrayLinked list
Insert di tengahSemua elemen sesudahnya digeser satu per satu: O(n)Cukup ubah 2 panah, tidak ada yang digeser
UkuranTetap sejak deklarasi (atau harus realokasi)Node bisa ditambah kapan saja
Akses elemen ke-iLangsung lewat index: O(1)Harus berjalan dari head: O(n)

Panah = pointer. Mengubah panah artinya mengubah alamat yang disimpan sebuah pointer.

Node = data + alamat node berikutnya

Setiap node menyimpan data dan alamat node sesudahnya (next). Node-node itu tersebar di memory, tapi tersambung lewat next.

typedef struct Node {
    int data;
    struct Node* next;
} Node;

Node* head = NULL;
  • Seluruh list cukup diwakili head, yaitu alamat node pertama. List kosong berarti head = NULL.
  • Node terakhir ditandai dengan next = NULL.
  • head, cur, dan del adalah variabel berisi alamat, bukan node itu sendiri.

createNode: kenapa ditulis begini?

Semua operasi insert diawali membuat node baru. Setiap baris fungsi ini punya alasan.

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}
  • malloc: node harus tetap ada setelah fungsi selesai. Variabel lokal hilang saat fungsi selesai, jadi node disimpan di heap.
  • (Node*): malloc mengembalikan void*. Compiler C++ mewajibkan cast ini, compiler C tidak. Tulis cast supaya kode jalan di keduanya.
  • n->next = NULL: malloc tidak mengosongkan memory. Tanpa baris ini, next berisi alamat acak.
  • Setiap malloc nanti butuh tepat satu free.

Resep: tulis operasi apa pun tanpa menghafal

Semua operasi linked list adalah soal mengubah panah. Lima langkah ini berlaku untuk insert, delete, dan operasi lain yang belum pernah kamu lihat.

  1. Gambar list sebelum dan sesudah operasi. 3 node sudah cukup.
  2. Tandai panah yang hilang dan yang baru. Setiap panah baru = satu baris kode.
  3. Cari pemilik panah. Untuk mengubah sebuah panah, kamu butuh alamat node yang memiliki panah itu.
  4. Urutkan baris kodenya. Jangan menimpa pointer yang alamatnya masih dibutuhkan baris berikutnya.
  5. Cek edge case: list kosong, posisi 0, node terakhir, dan list berisi 1 node.

4 pola yang selalu muncul

Langkah 3 dan 4 dari resep hampir selalu berakhir di salah satu pola ini. Bedanya ada pada di mana cur harus berhenti.

PolaKodecur berhenti di

Cara memilih polaTanyakan: "Saat loop berhenti, cur harus berada di node mana?"

insertFront: sambung dulu

Node baru masuk di depan. Ada dua panah baru: dari node baru ke node pertama lama, dan dari head ke node baru.

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [5] → [10] → [20] → NULL
Node* newNode = createNode(x);
newNode->next = head;   // 1. sambung
head = newNode;         // 2. pindah
  • Alamat [10] hanya tersimpan di head. Karena itu head dipakai dulu di langkah 1, baru ditimpa di langkah 2.
  • Kalau list kosong, newNode->next = head berisi NULL. Hasilnya sudah benar, jadi tidak perlu if.
Kalau urutannya ditukarhead sudah menunjuk newNode, jadi newNode->next = newNode. List lama hilang, dan print berputar selamanya.

insertBack: cari node terakhir

Panah baru dimiliki node terakhir, jadi node terakhir harus dicari dulu dengan pola B.

if (head == NULL) {
    head = newNode;
} else {
    Node* cur = head;
    while (cur->next != NULL)   // pola B
        cur = cur->next;
    cur->next = newNode;
}
  • Kalau list kosong, tidak ada node terakhir. Yang berubah adalah head.
  • Node terakhir harus dicari dengan traverse, jadi operasi ini O(n).
Kenapa bukan while (cur != NULL)?Loop itu berhenti saat cur sudah NULL. Baris cur->next = newNode lalu mengakses NULL, dan program crash.

insertAt: berhenti satu sebelum

Panah yang berubah adalah next milik node di posisi pos - 1. Jadi cur harus berhenti di sana (pola C).

insertAt(2, 25)
Sebelum:  [10] → [20] → [30] → NULL
Sesudah:  [10] → [20] → [25] → [30] → NULL
if (pos == 0) { insertFront(x); return; }
Node* cur = head;
for (int i = 0; i < pos - 1; i++)   // pola C
    cur = cur->next;
newNode->next = cur->next;   // sambung
cur->next = newNode;         // putus
  • Loop jalan pos - 1 kali, jadi cur berhenti di [20].
  • Alamat [30] hanya ada di cur->next. Pakai dulu untuk menyambung node baru, baru timpa (pola D).
  • Kalau pos == 0, tidak ada node di posisi −1. Yang berubah adalah head, jadi panggil insertFront.

deleteAt: simpan dulu, free terakhir

Panah baru melompati node yang dihapus: dari node pos - 1 langsung ke node pos + 1. Jadi kita butuh node pos - 1 lagi (pola C).

Node* del;
if (pos == 0) {
    del = head;
    head = head->next;
} else {
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)
        cur = cur->next;
    del = cur->next;        // simpan alamat
    cur->next = del->next;  // lompati
}
free(del);                  // terakhir
  • Setelah cur->next ditimpa, alamat node yang dihapus tidak tersimpan di mana pun. Karena itu alamatnya disimpan dulu di del.
  • free dipanggil paling akhir. Setelah free, del->next tidak boleh dibaca lagi (use-after-free).

Time complexity

Linked list cepat di bagian depan, tapi lambat untuk posisi lain, karena node hanya bisa dicapai dengan berjalan dari head.

OperasiSingle LLAlasan
insertFront, delete node pertamaO(1)head langsung tersedia
insertBackO(n)Harus mencari node terakhir. Bisa O(1) kalau menyimpan tail.
insertAt, deleteAtO(n)Harus berjalan sampai node pos - 1
search, akses elemen ke-iO(n)Tidak ada index

Ringkasan

  • Operasi linked list = mengubah panah. Gambar dulu, tulis kode belakangan.
  • Sebuah node hanya bisa mengubah next miliknya sendiri. Karena itu insert dan delete di posisi pos butuh node pos - 1.
  • Sambung dulu, putus kemudian, supaya tidak ada alamat yang hilang.
  • Selalu cek edge case: list kosong, pos == 0, dan node terakhir.
