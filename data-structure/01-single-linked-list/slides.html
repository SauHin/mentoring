Node = data + alamat node berikutnya

typedef struct Node {
    int data;
    struct Node* next;
} Node;

Node* head = NULL;
  • List cukup diwakili head: alamat node pertama.
  • Node terakhir: next = NULL.
  • head, cur, del = variabel berisi alamat, bukan node.

createNode: kenapa begini?

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}
  • malloc: node harus tetap hidup setelah fungsi selesai → simpan di heap, bukan variabel lokal.
  • (Node*): malloc mengembalikan void*. Compiler C++ wajib cast ini, C tidak. Pakai cast supaya jalan di keduanya.
  • n->next = NULL: malloc tidak mengosongkan memory. Tanpa ini, next berisi alamat acak.
  • Setiap malloc nanti butuh satu free.

Resep: tulis operasi apa pun tanpa menghafal

  1. Gambar list sebelum dan sesudah (3 node cukup).
  2. Tandai panah yang hilang dan yang baru. 1 panah baru = 1 baris kode.
  3. Cari pemilik panah. Untuk mengubah sebuah panah, kamu butuh alamat node pemiliknya.
  4. Urutkan: jangan timpa pointer yang alamatnya masih dibutuhkan.
  5. Cek edge case: list kosong, posisi 0, node terakhir, 1 node.

Cara memilihTanya: "Saat loop berhenti, cur harus di mana?"

insertFront: sambung dulu

Sebelum:  head → [10] → [20] → NULL
Sesudah:  head → [5] → [10] → [20] → NULL
Node* newNode = createNode(x);
newNode->next = head;   // 1. sambung
head = newNode;         // 2. pindah
  • Panah baru: [5] → [10] dan head → [5].
  • head = satu-satunya alamat [10] → pakai dulu, baru timpa.
  • List kosong? next = head = NULL. Sudah benar, tanpa if.
Kalau ditukarnewNode->next = newNode: list lama hilang, print looping selamanya.

insertBack: cari node terakhir

if (head == NULL) {
    head = newNode;
} else {
    Node* cur = head;
    while (cur->next != NULL)   // pola B
        cur = cur->next;
    cur->next = newNode;
}
  • Panah baru: [terakhir] → [new]. Pemiliknya node terakhir → pola B.
  • List kosong: tidak ada node terakhir → head yang berubah.
  • Harus traverse → O(n).
Kenapa bukan cur != NULL?Loop berhenti saat cur sudah NULL, lalu cur->next crash.

insertAt: berhenti satu sebelum

insertAt(2, 25)
Sebelum:  [10] → [20] → [30] → NULL
Sesudah:  [10] → [20] → [25] → [30] → NULL
if (pos == 0) { insertFront(x); return; }
Node* cur = head;
for (int i = 0; i < pos - 1; i++)   // pola C
    cur = cur->next;
newNode->next = cur->next;   // sambung
cur->next = newNode;         // putus
  • Yang berubah: next milik [20] = node di pos - 1.
  • Loop pos - 1 kali → cur di posisi pos - 1.
  • Alamat [30] hanya ada di cur->next → pakai dulu (pola D).
  • pos == 0: tidak ada node di -1 → head berubah.

deleteAt: simpan dulu, free terakhir

Node* del;
if (pos == 0) {
    del = head;
    head = head->next;
} else {
    Node* cur = head;
    for (int i = 0; i < pos - 1; i++)
        cur = cur->next;
    del = cur->next;        // simpan alamat
    cur->next = del->next;  // lompati
}
free(del);                  // terakhir
  • Panah baru: [pos-1] → [pos+1] → butuh node pos - 1 lagi (pola C).
  • Setelah cur->next ditimpa, alamat del hilang → simpan dulu.
  • free paling akhir. Setelah free, del->next tidak boleh dibaca (use-after-free).

Ringkasan

  • Operasi linked list = mengubah panah. Gambar dulu, kode belakangan.
  • Node hanya bisa mengubah next miliknya → butuh node pos - 1.
  • Sambung dulu, putus kemudian. Jangan pernah kehilangan alamat.
  • Selalu cek: list kosong, pos == 0, node terakhir.
