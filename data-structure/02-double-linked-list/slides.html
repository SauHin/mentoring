Double linked list

Data structure · materi 02 · prasyarat: single linked list

Target: kamu bisa menulis setiap operasi dengan resep dari single linked list, ditambah satu aturan: setiap panah punya pasangan.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Kenapa double linked list

Single linked list tidak bisa mundur, jadi delete pun harus mencari node sebelumnya

Double linked list adalah linked list yang setiap node-nya menyimpan alamat node sebelum dan sesudahnya.

  • Mundur satu langkah = traverse lagi dari head.
  • Delete butuh node sebelumnya, dan node itu harus dicari dari head.

Notes 2️⃣ · Node

Setiap node menyimpan prev dan next, dan list menyimpan head dan tail

Tail adalah alamat node terakhir, jadi ujung belakang bisa diakses tanpa traverse.

  • List kosong: head dan tail NULL. List 1 node: head dan tail menunjuk node yang sama.
  • Aturan emas: A->next == B kalau dan hanya kalau B->prev == A.

Notes 3️⃣ · Panah berpasangan

Resepnya sama, tapi setiap sambungan butuh dua baris kode

Resep 5 langkah dari single linked list tetap berlaku. Bedanya, setiap sambungan punya dua arah.

Notes 4️⃣ · insertFront

insertFront menyambung kedua arah dulu, baru memindahkan head

Sambungan baru [5] ⇄ [10] butuh dua baris, lalu head dipindah ke node baru.

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = tail = newNode;
    } else {
        newNode->next = head;   // 1
        head->prev = newNode;   // 2
        head = newNode;         // 3
    }
    size++;
}
  • List kosong: node baru menjadi head dan tail sekaligus.
  • Langkah 2 masih memakai head lama, jadi head baru dipindah di langkah 3.

Kalau langkah 3 jalan duluan, langkah 2 menjadi newNode->prev = newNode.

Notes 5️⃣ · insertBack

insertBack adalah cermin insertFront, tanpa traverse karena ada tail

Tukar head ↔ tail dan next ↔ prev dari kode insertFront.

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}
  • Node terakhir sudah ada di tail, jadi tidak perlu dicari.
  • Tanpa tail, kita harus traverse sampai node terakhir, seperti di single linked list.

Notes 6️⃣ · insertAt

insertAt mengubah empat pointer, dan cur->prev ditimpa paling akhir

Node baru masuk tepat sebelum cur (node di posisi pos). Ada dua sambungan baru, jadi 4 baris.

Node* cur = head;
for (int i = 0; i < pos; i++)
    cur = cur->next;
Node* newNode = createNode(x);
newNode->next = cur;          // 1
newNode->prev = cur->prev;    // 2
cur->prev->next = newNode;    // 3
cur->prev = newNode;          // 4
  • Langkah 1–2 hanya mengisi newNode, jadi list belum berubah.
  • Langkah 2 dan 3 masih membaca cur->prev yang lama, jadi langkah 4 harus terakhir.
  • Posisi 0 dan posisi size memakai insertFront dan insertBack.

Notes 7️⃣ · deleteAt

deleteAt melompati node dari dua arah, dan memindahkan head atau tail di ujung

Bypass artinya tetangga kiri dan kanan disambung langsung, melompati node yang dihapus.

if (del->prev != NULL)
    del->prev->next = del->next;
else
    head = del->next;
if (del->next != NULL)
    del->next->prev = del->prev;
else
    tail = del->prev;
free(del);

Notes 8️⃣ · search dan traverse

Print maju dan print mundur harus saling terbalik

search sama dengan single linked list. Yang baru: traverse mundur dari tail lewat prev.

void printForward() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
}
void printBackward() {
    for (Node* cur = tail; cur != NULL; cur = cur->prev)
        printf("%d ", cur->data);
}
  • Trik debugging: kalau hasil print mundur bukan kebalikan print maju, ada pointer prev yang salah.
  • Untuk mengambil node ke-i, mulai dari tail kalau i lebih dekat ke belakang.

Notes 9️⃣ · Time complexity

Double linked list unggul di kedua ujung, dibayar dengan satu pointer per node

Amortized artinya sesekali lambat (array pindah ke memory lebih besar), tapi rata-ratanya tetap O(1).

Notes 10 · Bug

Sebagian besar bug double linked list terjadi di ujung list atau karena prev lupa diubah

Dangling pointer adalah pointer yang masih menunjuk memory yang sudah di-free.

Notes 11 · Dipakai di mana

Double linked list dipakai saat program perlu bergerak maju dan mundur

Contohnya ada di aplikasi sehari-hari.

  • Browser: back = cur = cur->prev, forward = cur = cur->next.
  • Editor: undo dan redo. Playlist: lagu sebelumnya dan berikutnya.
  • LRU cache: memindahkan dan menghapus item di tengah dengan cepat.
  • Linux kernel: struct list_head adalah double linked list yang melingkar.

Notes 11 · Browser history

Coba sendiri: membuka halaman baru dari tengah history membuang semua halaman forward

Ringkasan: double linked list = single linked list + prev + tail

  • Setiap node menyimpan prev dan next, dan list menyimpan head dan tail (2️⃣).
  • Setiap sambungan punya dua sisi: ubah next dan prev berpasangan (3️⃣).
  • Pointer yang masih dibutuhkan (head lama, cur->prev) ditimpa paling akhir (4️⃣ 6️⃣).
  • Delete melompati node dari dua arah. Di ujung, yang berubah head atau tail (7️⃣).
  • O(1) di kedua ujung dan untuk delete node yang sudah dipegang (9️⃣).
