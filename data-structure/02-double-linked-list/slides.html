Double linked list

Data structure · linked list yang bisa traverse maju dan mundur

Prasyarat: single linked list (resep 5 langkah dan pola "sambung dulu").

Ingat lagi: single linked list

  • Tiap node cuma punya next, jadi hanya bisa maju.
  • Mundur 1 langkah? Ulang dari head: O(n).
  • Delete node? Butuh node sebelumnya, jadi harus dicari dulu.

Solusinya: tambah pointer prev

  • prev → node sebelumnya, next → node sesudahnya.
  • Di ujung list: head->prev dan tail->next = NULL (garis miring).
  • Simpan head dan tail: dua ujung bisa diakses langsung.

Struktur node

typedef struct Node {
    int data;
    struct Node* prev;
    struct Node* next;
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}
  • 1 node = data + 2 pointer
  • List kosong: head == tail == NULL
  • List 1 node: head == tail
  • createNode: malloc + isi prev/next dengan NULL
  • Trade-off: butuh memory 1 pointer ekstra per node

Cara berpikir: resep yang sama + 1 aturan

  1. Gambar sebelum & sesudah, tandai panah yang berubah.
  2. Cari pemilik panah, lalu urutkan: sambung dulu, putus kemudian.
  3. Cek edge case: list kosong, head, tail, 1 node.
Aturan tambahan DLL: setiap panah punya pasanganSambungan baru A ⇄ B = 2 baris: A->next = B dan B->prev = A. Jumlah baris ganjil? Hampir pasti ada yang lupa.

Bonus: node sebelum cur = cur->prev, jadi tidak perlu berhenti di pos - 1 seperti di single linked list.

insertFront

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}
  1. newNode->next → head lama
  2. head->prev → newNode
  3. Baru pindahkan head
Urutan pentingKalau head = newNode jalan sebelum langkah 2, newNode jadi menunjuk dirinya sendiri.

insertBack

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}
  • Cermin dari insertFront: tukar head ↔ tail dan next ↔ prev.
  • Ada tail → O(1).
  • Tanpa tail → harus traverse sampai ujung: O(n).

insertAt: 4 pointer berubah

Node* cur = head;
for (int i = 0; i < pos; i++)
    cur = cur->next;
Node* newNode = createNode(x);
newNode->next = cur;
newNode->prev = cur->prev;
cur->prev->next = newNode;
cur->prev = newNode;
  1. Traverse sampai cur (node di posisi pos)
  2. Isi pointer newNode dulu: list belum berubah, aman
  3. cur->prev->next = newNode
  4. cur->prev = newNode: paling akhir
Kenapa langkah 4 terakhir?Langkah 2 dan 3 masih butuh nilai cur->prev yang lama.

deleteAt: bypass dari dua arah

if (del->prev != NULL)
    del->prev->next = del->next;
else
    head = del->next;
if (del->next != NULL)
    del->next->prev = del->prev;
else
    tail = del->prev;
free(del);
  • Node sebelum del: next melompati del
  • Node sesudah del: prev melompati del
  • del di ujung → yang pindah head / tail
Keunggulan utama DLLSudah pegang pointer ke del? Delete cukup O(1), tidak perlu cari node sebelumnya.

Dipakai di mana?

  • Browser: tombol back / forward
  • Editor: undo / redo
  • Playlist: lagu prev / next
  • LRU cache: pindah & delete node di tengah dalam O(1)
  • Linux kernel: struct list_head adalah (circular) double linked list

Ringkasan

  • DLL = SLL + prev + tail
  • Traverse 2 arah, delete node yang sudah ditunjuk O(1)
  • Tiap link punya 2 sisi: ubah next & prev berpasangan
  • Selalu cek edge case: list kosong, 1 node, head, tail
