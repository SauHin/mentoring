Double linked list

Data structure · linked list yang bisa di-traverse maju dan mundur.

Prasyarat: single linked list (resep 5 langkah dan pola "sambung dulu, putus kemudian").

Ingat lagi: single linked list

Di single linked list, setiap node hanya tahu node sesudahnya. Ini menimbulkan dua masalah.

  • Node hanya punya next, jadi traverse hanya bisa maju. Untuk mundur satu langkah, kita harus mulai lagi dari head: O(n).
  • Untuk delete sebuah node, kita butuh node sebelumnya. Node itu harus dicari dulu dari head.

Solusinya: tambah pointer prev

Setiap node menyimpan dua alamat: node sebelumnya (prev) dan node sesudahnya (next). List juga menyimpan dua ujung: head dan tail.

  • Di kedua ujung list, head->prev dan tail->next bernilai NULL. Di gambar, NULL ditandai garis miring.
  • Dengan tail, ujung belakang bisa diakses langsung tanpa traverse.

Struktur node

Dibanding single linked list, ada tambahan satu pointer di setiap node dan satu pointer tail untuk list.

typedef struct Node {
    int data;
    struct Node* prev;
    struct Node* next;
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}
  • Satu node = data + 2 pointer.
  • List kosong: head dan tail sama-sama NULL.
  • List berisi 1 node: head dan tail menunjuk node yang sama.
  • createNode mengisi prev dan next dengan NULL, karena malloc tidak mengosongkan memory.
  • Trade-off: setiap node butuh memory untuk 1 pointer tambahan.

Cara berpikir: resep yang sama + 1 aturan

Resep dari single linked list tetap berlaku. Bedanya, setiap sambungan sekarang punya dua arah.

  1. Gambar list sebelum dan sesudah, lalu tandai panah yang berubah.
  2. Cari pemilik panah, lalu urutkan kodenya: sambung dulu, putus kemudian.
  3. Cek edge case: list kosong, perubahan di head atau tail, dan list berisi 1 node.
Aturan tambahan: setiap panah punya pasanganMenyambung A ⇄ B butuh 2 baris: A->next = B dan B->prev = A. Kalau jumlah baris pengubah pointer ganjil, hampir pasti ada pasangan yang lupa.

Bonus: node sebelum cur bisa diambil dari cur->prev. Jadi loop tidak perlu berhenti di pos - 1 seperti di single linked list.

insertFront

Node baru menjadi node pertama. Ada satu sambungan baru dua arah antara node baru dan head lama, lalu head dipindahkan.

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}
  1. newNode->next menunjuk head lama.
  2. head->prev menunjuk newNode.
  3. Baru setelah itu head dipindahkan ke newNode.

Kalau list kosong, node baru menjadi head dan tail sekaligus.

Urutan pentingKalau head = newNode jalan sebelum langkah 2, baris head->prev = newNode membuat newNode menunjuk dirinya sendiri.

insertBack

Kebalikan dari insertFront: node baru masuk di belakang, setelah tail.

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}
  • Kodenya adalah cermin dari insertFront: tukar head ↔ tail dan next ↔ prev.
  • Karena tail langsung tersedia, operasi ini O(1).
  • Tanpa tail, kita harus traverse sampai node terakhir: O(n).

insertAt: 4 pointer berubah

Node baru masuk di antara cur->prev dan cur. Ada dua sambungan dua arah, jadi 4 pointer berubah. Posisi 0 dan posisi terakhir memakai insertFront dan insertBack.

Node* cur = head;
for (int i = 0; i < pos; i++)
    cur = cur->next;
Node* newNode = createNode(x);
newNode->next = cur;
newNode->prev = cur->prev;
cur->prev->next = newNode;
cur->prev = newNode;
  1. Traverse sampai cur (node di posisi pos).
  2. Isi pointer newNode dulu. List lama belum berubah, jadi aman.
  3. Node sebelum cur menunjuk node baru.
  4. cur->prev = newNode ditulis paling akhir, karena langkah 2 dan 3 masih membaca cur->prev yang lama. Kalau ditimpa duluan, alamat node sebelumnya hilang.

deleteAt: bypass dari dua arah

Node yang dihapus (del) dilompati dari kiri dan dari kanan. Kalau del ada di ujung, yang berubah adalah head atau tail.

if (del->prev != NULL)
    del->prev->next = del->next;
else
    head = del->next;
if (del->next != NULL)
    del->next->prev = del->prev;
else
    tail = del->prev;
free(del);
  • Node sebelum del: next-nya melompati del.
  • Node sesudah del: prev-nya melompati del.
  • Kalau del node pertama, head pindah. Kalau node terakhir, tail pindah.
Keunggulan utama double linked listKalau sudah memegang pointer ke del, delete cukup O(1). Node sebelumnya tidak perlu dicari, karena sudah ada di del->prev.

Time complexity

Dipakai di mana?

Double linked list dipakai saat program perlu bergerak maju dan mundur, atau menghapus elemen di tengah dengan cepat.

  • Browser: tombol back dan forward.
  • Editor: undo dan redo.
  • Playlist: lagu sebelumnya dan berikutnya.
  • LRU cache: memindahkan dan menghapus node di tengah dalam O(1).
  • Linux kernel: struct list_head adalah circular double linked list.

Ringkasan

  • Double linked list = single linked list + prev di setiap node + tail.
  • Bisa traverse dua arah, dan delete node yang sudah ditunjuk cukup O(1).
  • Setiap sambungan punya dua sisi: ubah next dan prev berpasangan.
  • Selalu cek edge case: list kosong, 1 node, perubahan di head dan tail.
