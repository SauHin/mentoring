Double linked list

Linked list yang tiap node-nya tahu node sebelum dan sesudahnya.

Slide · Visualisasi operasi · Browser history

TL;DR
  • Node punya prev + next. List menyimpan head + tail.
  • Bisa traverse 2 arah. Delete node yang sudah ditunjuk cukup O(1).
  • Setiap ubah next, cek apakah prev pasangannya juga harus diubah.
  • Edge case wajib: list kosong, 1 node, node pertama, node terakhir.

1. Kenapa butuh double linked list?

Di single linked list, node cuma punya next. Akibatnya:

  • Mundur 1 langkah → ulang traverse dari head: O(n).
  • Delete node X → harus ubah next milik node sebelum X, padahal node itu tidak diketahui. Harus dicari dulu.

Solusinya: tambah pointer prev di tiap node.

2. Struktur node

struct Node {
    int data;
    Node* prev;   // node sebelumnya (nullptr kalau node pertama)
    Node* next;   // node sesudahnya (nullptr kalau node terakhir)
};

Node* head = nullptr;
Node* tail = nullptr;
int size = 0;
Aturan emasUntuk dua node A dan B yang bersebelahan: A->next == B ⇔ B->prev == A. Pakai aturan ini untuk mengecek setiap operasi.

Di sini head, tail, dan size dibuat global supaya kode pendek. Di project nyata biasanya jadi member sebuah class.

3. Operasi

Buka visualisasi operasi sambil membaca. Kodenya sama persis.

insertFront(x): O(1)

void insertFront(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (head == nullptr) {            // list kosong
        head = tail = newNode;
    } else {
        newNode->next = head;         // 1. sambung ke head lama
        head->prev = newNode;         // 2. head lama menunjuk balik
        head = newNode;               // 3. baru pindahkan head
    }
    size++;
}
Awas urutanKalau langkah 3 jalan duluan, langkah 2 jadi newNode->prev = newNode: node menunjuk dirinya sendiri.

insertBack(x): O(1)

void insertBack(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (tail == nullptr) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

Cermin dari insertFront: tukar head ↔ tail dan next ↔ prev.

insertAt(pos, x): O(n)

void insertAt(int pos, int x) {          // syarat: 0 <= pos <= size
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;                 // cur = node di posisi pos
    Node* newNode = new Node{x, nullptr, nullptr};
    newNode->next = cur;                 // 1
    newNode->prev = cur->prev;           // 2
    cur->prev->next = newNode;           // 3
    cur->prev = newNode;                 // 4: paling akhir!
    size++;
}
  • Index mulai dari 0. Node baru masuk tepat sebelum cur.
  • Langkah 1–2 cuma mengisi pointer newNode → list belum berubah, aman.
  • Langkah 3–4 mengubah list. Langkah 4 harus terakhir karena langkah 2–3 masih butuh cur->prev yang lama.

deleteAt(pos): O(n), atau O(1) kalau node sudah ditunjuk

void deleteAt(int pos) {                 // syarat: 0 <= pos < size
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != nullptr)
        del->prev->next = del->next;     // bypass dari depan
    else
        head = del->next;                // del = node pertama
    if (del->next != nullptr)
        del->next->prev = del->prev;     // bypass dari belakang
    else
        tail = del->prev;                // del = node terakhir
    delete del;
    size--;
}

Dua if itu sudah menangani semua edge case:

Posisi delprevnextHasil
Di tengahadaadaKedua tetangga saling menunjuk

Satu-satunya nodenullnullhead & tail → nullptr
Keunggulan utama DLLKalau sudah pegang pointer ke node yang mau dihapus, loop pencarian tidak perlu. Delete jadi O(1). Di single linked list ini tetap O(n).

search(x): O(n)

Node* search(int x) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return nullptr;                      // tidak ketemu
}

Traverse maju & mundur: O(n)

void printForward() {
    for (Node* cur = head; cur != nullptr; cur = cur->next)
        std::cout << cur->data << " ";
}

void printBackward() {
    for (Node* cur = tail; cur != nullptr; cur = cur->prev)
        std::cout << cur->data << " ";
}
Trik debuggingPrint maju lalu print mundur. Kalau hasilnya tidak saling terbalik, ada pointer prev yang salah.

Kenapa delete node terakhir di single LL tetap O(n) walau ada tail? Karena tail baru = node sebelum tail lama, dan node itu harus dicari dari head.

6. Dipakai di mana?

  • Browser back / forward: coba di visualisasi browser history
  • Undo / redo di editor
  • Playlist: lagu prev / next
  • LRU cache: pindah & delete item di tengah dalam O(1)
  • std::list di C++ adalah double linked list

#include <iostream>

struct Node {
    int data;
    Node* prev;
    Node* next;
};

Node* head = nullptr;
Node* tail = nullptr;
int size = 0;

void insertFront(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (head == nullptr) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}

void insertBack(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (tail == nullptr) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;
    Node* newNode = new Node{x, nullptr, nullptr};
    newNode->next = cur;
    newNode->prev = cur->prev;
    cur->prev->next = newNode;
    cur->prev = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != nullptr)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != nullptr)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    delete del;
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return nullptr;
}

void printForward() {
    for (Node* cur = head; cur != nullptr; cur = cur->next)
        std::cout << cur->data << " ";
    std::cout << "\n";
}

void printBackward() {
    for (Node* cur = tail; cur != nullptr; cur = cur->prev)
        std::cout << cur->data << " ";
    std::cout << "\n";
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printForward();       // 10 20 25 30
    printBackward();      // 30 25 20 10

    deleteAt(0);          // hapus 10
    deleteAt(size - 1);   // hapus 30
    printForward();       // 20 25

    std::cout << (search(25) != nullptr ? "25 ketemu" : "25 tidak ada") << "\n";

    while (head != nullptr)   // kosongkan list → tidak ada memory leak
        deleteAt(0);
    return 0;
}

8. Latihan

1. Mulai dari list kosong, jalankan insertBack(5), insertFront(3), insertAt(1, 4), deleteAt(0). Tulis isi list, head, dan tail tiap langkah.

Jawaban

[5] → [3, 5] → [3, 4, 5] → [4, 5]. Akhirnya head = 4, tail = 5.

2. Di insertFront, apa yang terjadi kalau head->prev = newNode dan head = newNode ditukar urutannya?

Jawaban

head->prev = newNode jadi newNode->prev = newNode (menunjuk diri sendiri). Head lama tetap prev == nullptr, jadi print maju benar tapi print mundur berhenti di head lama.

3. Tulis reverse() yang membalik list tanpa membuat node baru.

Jawaban 
void reverse() {
    Node* cur = head;
    while (cur != nullptr) {
        Node* tmp = cur->next;
        cur->next = cur->prev;    // tukar prev & next
        cur->prev = tmp;
        cur = tmp;
    }
    Node* tmp = head;             // tukar head & tail
    head = tail;
    tail = tmp;
}

O(n). Cukup tukar prev ↔ next di tiap node, lalu tukar head ↔ tail.

4. Tulis bool deleteValue(int x): hapus node pertama bernilai x, return false kalau tidak ada.

Jawaban 
bool deleteValue(int x) {
    Node* del = search(x);
    if (del == nullptr) return false;
    if (del->prev != nullptr)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != nullptr)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    delete del;
    size--;
    return true;
}

Bagian delete-nya sama dengan deleteAt. Bedanya hanya cara menemukan del.

5. Tulis Node* getNode(int i). Kalau i lebih dekat ke belakang, mulai dari tail.

Jawaban 
Node* getNode(int i) {
    if (i < size / 2) {
        Node* cur = head;
        for (int k = 0; k < i; k++)
            cur = cur->next;
        return cur;
    }
    Node* cur = tail;
    for (int k = size - 1; k > i; k--)
        cur = cur->prev;
    return cur;
}

Tetap O(n), tapi maksimal ~n/2 langkah.
