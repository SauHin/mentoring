Kenapa double linked list: single linked list tidak bisa mundur

single linked list (data structure, materi 01) semua section berikutnya, dan queue (materi 03)

Jalan satu arah vs dua arah: di jalan satu arah, kalau kelewatan satu rumah, kamu harus memutar dari awal.

di jalan, memutar hanya butuh waktu. Di program, memutar berarti traverse lagi dari head, dan waktunya bertambah sebanding dengan panjang list.

Di single linked list, node hanya punya next. Akibatnya ada dua masalah:

  • Mundur satu langkah: harus traverse lagi dari head.
  • Delete node X: butuh node sebelum X, padahal node itu tidak diketahui, jadi harus dicari dulu.

Double linked list adalah linked list yang setiap node-nya menyimpan alamat node sebelum dan sesudahnya. Kedua masalah di atas hilang.

Double linked list = single linked list yang bisa mundur, karena setiap node juga tahu node sebelumnya.

Soal latihan: Di single linked list, kenapa delete node yang sudah kamu pegang alamatnya tetap butuh traverse?

Yang harus diubah adalah next milik node sebelum node itu. Node sebelumnya tidak tersimpan di mana pun, jadi harus dicari dari head.

Node menyimpan prev dan next, dan list menyimpan head dan tail

struct Node dan createNode (materi 01) semua operasi (4️⃣ sampai 8️⃣)

Barisan orang yang saling bergandengan dengan kedua tangan: tangan kiri memegang orang di depan, tangan kanan memegang orang di belakang.

orang yang melepas satu tangan langsung terasa. Pointer prev yang lupa diubah tidak terasa sampai list ditelusuri mundur.

Setiap node punya prev (node sebelumnya) dan next (node sesudahnya). List menyimpan dua ujung: head dan tail, yaitu alamat node terakhir.

typedef struct Node {
    int data;
    struct Node* prev;   // node sebelumnya (NULL kalau node pertama)
    struct Node* next;   // node sesudahnya (NULL kalau node terakhir)
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}

head, tail, dan size dibuat global supaya kode pendek. Di project nyata biasanya dibungkus dalam satu struct (misalnya DList) yang dikirim ke setiap fungsi.

Aturan emas: untuk dua node bersebelahan A dan B, A->next == B kalau dan hanya kalau B->prev == A.

Soal latihan: List berisi 1 node bernilai 7. Apa isi head, tail, prev, dan next?

head dan tail sama-sama menunjuk node 7. prev dan next node itu sama-sama NULL.

Resepnya sama dengan single linked list, tapi setiap panah punya pasangan

resep 5 langkah dan pola D (materi 01) semua operasi (4️⃣ sampai 7️⃣)

Jabat tangan: kalau A menjabat tangan B, B juga menjabat tangan A. Satu jabat tangan selalu melibatkan dua tangan.

jabat tangan terjadi bersamaan. Di C, kedua arah panah ditulis dalam dua baris terpisah, jadi satu baris bisa terlupa.

Pakai resep 5 langkah yang sama: gambar, tandai panah, cari pemilik panah, urutkan, cek edge case. Bedanya:

Single LLDouble LL
Panah antar dua node1 (next)2 (next + prev)
Baris kode per sambungan12, satu untuk setiap arah
Node sebelum curHarus dicari (pola C: berhenti di pos - 1)Langsung: cur->prev. Jadi cur boleh berhenti di pos
Ujung listheadhead dan tail, dua-duanya bisa berubah

Cara cek kodemu: setiap sambungan baru antara A dan B menghasilkan dua baris, A->next = B dan B->prev = A. Kalau jumlah baris pengubah pointer ganjil, hampir pasti ada pasangan yang lupa.

Satu sambungan = dua baris. Ubah next → ubah juga prev pasangannya.

Soal latihan: Menyisipkan node di tengah list membuat berapa sambungan baru, dan berapa baris pengubah pointer?

Dua sambungan baru (ke node sebelum dan ke node sesudah), jadi 4 baris.

insertFront: sambung kedua arah dulu, baru pindahkan head

insertFront di single linked list (materi 01) dan panah berpasangan (3️⃣) insertAt di posisi 0 (6️⃣)

Orang baru masuk di depan barisan bergandengan: ia memegang orang pertama, orang pertama balas memegangnya, baru petugas menunjuknya sebagai yang terdepan.

petugas bisa menunjuk dua kali. Kalau head dipindah duluan, head lama tidak bisa dicapai lagi untuk diberi prev.

insertFront menambah node di depan. Sambungan baru [5] ⇄ [10] butuh 2 baris, lalu head dipindah.

Sebelum:  head → [10] ⇄ [20] ← tail
Sesudah:  head → [5] ⇄ [10] ⇄ [20] ← tail
void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {               // list kosong
        head = tail = newNode;
    } else {
        newNode->next = head;         // 1. sambung ke head lama
        head->prev = newNode;         // 2. head lama menunjuk balik
        head = newNode;               // 3. baru pindahkan head
    }
    size++;
}
  • Edge case list kosong: node baru jadi head dan tail.

Kalau langkah 3 jalan duluan, langkah 2 menjadi newNode->prev = newNode: node menunjuk dirinya sendiri.

Sambung kedua arah ke head lama, baru pindahkan head. List kosong → head = tail = node baru.

Soal latihan: Apa yang terjadi kalau head->prev = newNode dan head = newNode ditukar urutannya?

head->prev = newNode menjadi newNode->prev = newNode (menunjuk diri sendiri). Head lama tetap prev == NULL, jadi print maju benar, tapi print mundur berhenti di head lama.

insertBack: cermin insertFront, dan tidak perlu traverse karena ada tail

insertFront (4️⃣) dan tail (2️⃣) enqueue di queue (materi 03)

Bayangan di cermin: kiri jadi kanan, tapi gerakannya sama.

bayangan cermin terjadi otomatis. Di kode, kamu sendiri yang harus menukar head ↔ tail dan next ↔ prev dengan teliti.

insertBack menambah node di belakang. Node terakhir sudah ada di tail, jadi tidak perlu dicari seperti di single linked list.

Sebelum:  head → [10] ⇄ [20] ← tail
Sesudah:  head → [10] ⇄ [20] ⇄ [50] ← tail
void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

Ini cermin dari insertFront: tukar head ↔ tail dan next ↔ prev.

insertBack = insertFront yang dicerminkan. Karena ada tail, tidak ada traverse.

Soal latihan: Tulis urutan baris insertBack dengan menukar head/tail dan next/prev dari insertFront.

Dari newNode->next = head; head->prev = newNode; head = newNode; menjadi newNode->prev = tail; tail->next = newNode; tail = newNode;.

insertAt: empat pointer berubah, dan cur->prev ditimpa paling akhir

insertAt di single linked list (materi 01), insertFront dan insertBack (4️⃣, 5️⃣) sisipan di tengah antrean, misalnya priority queue (materi 04)

Menyelip di tengah barisan bergandengan: kamu memegang dua orang di kiri dan kanan, lalu keduanya melepas pegangan satu sama lain dan memegangmu.

di barisan nyata semua tangan berpindah hampir bersamaan. Di C, satu baris yang ditulis terlalu awal bisa menghapus alamat yang masih dibutuhkan.

insertAt(pos, x) menyisipkan node baru tepat sebelum node di posisi pos (index mulai 0). Ada dua sambungan baru, jadi 4 baris.

insertAt(2, 25)
Sebelum:  [10] ⇄ [20] ⇄ [30]
Sesudah:  [10] ⇄ [20] ⇄ [25] ⇄ [30]
void insertAt(int pos, int x) {          // syarat: 0 <= pos <= size
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;                 // cur = node di posisi pos
    Node* newNode = createNode(x);
    newNode->next = cur;                 // 1
    newNode->prev = cur->prev;           // 2
    cur->prev->next = newNode;           // 3
    cur->prev = newNode;                 // 4: paling akhir!
    size++;
}
  • Langkah 1–2: hanya mengisi pointer newNode, jadi list belum berubah dan aman.
  • Langkah 3–4: mengubah list. Langkah 4 harus terakhir, karena langkah 2 dan 3 masih membaca cur->prev yang lama.
  • Pemilik panah: [20] dan [30]. Cukup cari [30], karena [20] = cur->prev.

Isi pointer node baru dulu, ubah tetangga kemudian, dan cur->prev ditimpa terakhir.

Soal latihan: Apa yang rusak kalau langkah 4 (cur->prev = newNode) dijalankan pertama kali?

Alamat [20] hilang, karena hanya tersimpan di cur->prev. Langkah 2 lalu mengisi newNode->prev = newNode, dan langkah 3 mengubah newNode->next, bukan [20]->next. Node 20 tidak tersambung ke node baru.

deleteAt: lompati node dari dua arah, dan pindahkan head atau tail di ujung

deleteAt di single linked list (materi 01) dequeue dan cancel di queue (materi 03)

Orang di tengah barisan bergandengan keluar: orang di kiri dan kanannya saling bergandengan langsung.

orang yang keluar bisa kembali. Node yang sudah di-free tidak boleh dibaca lagi.

Node yang dihapus (del) di-bypass: tetangga kiri dan kanannya disambung langsung, melompati del. Kedua tetangga bisa ditemukan dari del sendiri, jadi tidak perlu node pos - 1.

void deleteAt(int pos) {                 // syarat: 0 <= pos < size
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != NULL)
        del->prev->next = del->next;     // bypass dari depan
    else
        head = del->next;                // del = node pertama
    if (del->next != NULL)
        del->next->prev = del->prev;     // bypass dari belakang
    else
        tail = del->prev;                // del = node terakhir
    free(del);
    size--;
}

Dua if sudah menangani semua edge case. Kalau alamat del sudah dipegang, delete tidak perlu traverse sama sekali.

Soal latihan: Mulai dari list kosong: insertBack(5), insertFront(3), insertAt(1, 4), deleteAt(0). Tulis isi list, head, dan tail di setiap langkah.

[5] → [3, 5] → [3, 4, 5] → [4, 5]. Di akhir, head = 4 dan tail = 5.

Soal latihan: Tulis int deleteValue(int x): hapus node pertama bernilai x. Return 1 kalau berhasil, 0 kalau tidak ada. 
int deleteValue(int x) {
    Node* del = search(x);
    if (del == NULL) return 0;
    if (del->prev != NULL)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != NULL)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    free(del);
    size--;
    return 1;
}

Bagian delete-nya sama dengan deleteAt. Bedanya hanya cara menemukan del (search, di 8️⃣).

search dan traverse: bisa maju dari head atau mundur dari tail

pola A di single linked list (materi 01) deleteValue (7️⃣) dan debugging pointer prev

Membaca daftar dari atas ke bawah, lalu dari bawah ke atas: kalau isinya sama, daftarnya utuh.

daftar kertas tidak bisa rusak di satu arah saja. Linked list bisa: next benar tapi prev salah.

search sama dengan single linked list. Yang baru: printBackward berjalan dari tail lewat prev.

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;                      // tidak ketemu
}

void printForward() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
}

void printBackward() {
    for (Node* cur = tail; cur != NULL; cur = cur->prev)
        printf("%d ", cur->data);
}

Trik debugging: print maju, lalu print mundur. Kalau hasilnya tidak saling terbalik, ada pointer prev yang salah.

Maju dari head lewat next, mundur dari tail lewat prev. Hasil keduanya harus saling terbalik.

Soal latihan: Tulis Node* getNode(int i). Kalau i lebih dekat ke belakang, mulai dari tail. 
Node* getNode(int i) {
    if (i < size / 2) {
        Node* cur = head;
        for (int k = 0; k < i; k++)
            cur = cur->next;
        return cur;
    }
    Node* cur = tail;
    for (int k = size - 1; k > i; k--)
        cur = cur->prev;
    return cur;
}

Tetap O(n), tapi paling banyak sekitar n/2 langkah.

Soal latihan: Tulis reverse() yang membalik list tanpa membuat node baru. 
void reverse() {
    Node* cur = head;
    while (cur != NULL) {
        Node* tmp = cur->next;
        cur->next = cur->prev;    // tukar prev & next
        cur->prev = tmp;
        cur = tmp;
    }
    Node* tmp = head;             // tukar head & tail
    head = tail;
    tail = tmp;
}

Cukup tukar prev ↔ next di setiap node, lalu tukar head ↔ tail.

Time complexity: unggul di kedua ujung, dibayar dengan memory tambahan

Big-O di single linked list (materi 01) memilih struktur data untuk stack, queue, dan priority queue

Rumah dengan dua pintu: keluar masuk lewat depan atau belakang sama cepat, tapi biaya bangunnya lebih mahal.

pintu kedua dibangun sekali. Pointer prev menambah memory di setiap node.

Dynamic array adalah array yang otomatis pindah ke memory lebih besar saat penuh. Pindahnya jarang, jadi rata-rata waktunya tetap O(1), dan ini disebut amortized.

Double linked list: O(1) di kedua ujung dan untuk delete node yang sudah dipegang. Harganya satu pointer tambahan per node.

Soal latihan: Kenapa delete node terakhir di single linked list tetap O(n), walaupun ada tail?

Setelah node terakhir dihapus, tail baru = node sebelum tail lama. Node itu tidak tersimpan di mana pun, jadi harus dicari dari head.

Bug yang sering muncul: kebanyakan karena prev lupa diubah

panah berpasangan dan edge case (3️⃣, 7️⃣) membaca kodemu sendiri saat print mundur salah atau crash

Peta jalan dua arah yang baru diperbarui satu arahnya: perjalanan pergi lancar, pulangnya tersesat.

peta yang salah masih bisa ditanyakan ke orang. Pointer yang salah tidak memberi tanda apa pun sampai dipakai.

Pointer yang masih menunjuk memory yang sudah di-free disebut dangling pointer. Bug ini dan bug lain di bawah lolos compile.

Crash untuk node pertama (del->prev = NULL) dan node terakhir (del->next = NULL). Langkah 5 resep (edge case) terlewat: di ujung list, yang berubah adalah head atau tail, bukan node tetangga. Perbaikannya dua if/else seperti di deleteAt.

Dipakai di mana: semua yang butuh maju dan mundur, misalnya browser history

traverse dua arah (8️⃣) undo/redo dan stack (materi 03)

Tombol back dan forward di browser: setiap halaman tahu halaman sebelum dan sesudahnya.

browser asli menyimpan lebih banyak data (posisi scroll, cache). Di sini setiap halaman hanya sebuah node berisi URL.

Double linked list dipakai saat program perlu bergerak maju dan mundur, atau menghapus elemen di tengah dengan cepat:

  • Browser: back dan forward.
  • Editor: undo dan redo.
  • Playlist: lagu sebelumnya dan berikutnya.
  • LRU cache: memindahkan dan menghapus item di tengah dengan cepat.
  • Linux kernel: struct list_head adalah double linked list yang melingkar.

Buka browser history. Buka beberapa halaman, tekan back, lalu buka halaman baru. Node sesudah cur dibuang, jadi tombol forward mati.

Back = cur = cur->prev, forward = cur = cur->next. Membuka halaman baru dari tengah membuang semua node sesudah cur.

Soal latihan: History: A ⇄ B ⇄ C, dan cur = C. Kamu menekan back dua kali, lalu membuka D. Apa isi history sekarang?

Back dua kali: cur = A. Membuka D membuang B dan C (node sesudah cur), lalu menyambung D. History menjadi A ⇄ D, dengan cur = D.

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* prev;
    struct Node* next;
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur;
    newNode->prev = cur->prev;
    cur->prev->next = newNode;
    cur->prev = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != NULL)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != NULL)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    free(del);
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;
}

void printForward() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

void printBackward() {
    for (Node* cur = tail; cur != NULL; cur = cur->prev)
        printf("%d ", cur->data);
    printf("\n");
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printForward();       // 10 20 25 30
    printBackward();      // 30 25 20 10

    deleteAt(0);          // hapus 10
    deleteAt(size - 1);   // hapus 30
    printForward();       // 20 25

    printf("%s\n", search(25) != NULL ? "25 ketemu" : "25 tidak ada");

    while (head != NULL)   // kosongkan list, supaya tidak ada memory leak
        deleteAt(0);
    return 0;
}

Program lengkap = struct + createNode + operasi + main. List dikosongkan di akhir supaya tidak ada memory leak.
