Double linked list

Linked list yang tiap node-nya tahu node sebelum dan sesudahnya.

Slide · Visualisasi operasi · Browser history

PrasyaratPahami dulu single linked list, terutama resep 5 langkah dan pola D (sambung dulu, putus kemudian). Materi ini memakai resep yang sama.
TL;DR
  • Node punya prev + next. List menyimpan head + tail.
  • Bisa traverse 2 arah. Delete node yang sudah ditunjuk cukup O(1).
  • Resepnya sama dengan single linked list, plus satu aturan: setiap panah punya pasangan. Ubah next → ubah juga prev pasangannya.
  • Edge case wajib: list kosong, 1 node, node pertama, node terakhir.

1. Kenapa butuh double linked list?

Di single linked list, node cuma punya next. Akibatnya:

  • Mundur 1 langkah → ulang traverse dari head: O(n).
  • Delete node X → harus ubah next milik node sebelum X, padahal node itu tidak diketahui. Harus dicari dulu.

Solusinya: tambah pointer prev di tiap node.

2. Struktur node

typedef struct Node {
    int data;
    struct Node* prev;   // node sebelumnya (NULL kalau node pertama)
    struct Node* next;   // node sesudahnya (NULL kalau node terakhir)
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

// alokasi node baru di heap, prev & next kosong.
// (Node*) wajib kalau di-compile dengan compiler C++ (g++, Dev-C++).
Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}
Aturan emasUntuk dua node A dan B yang bersebelahan: A->next == B ⇔ B->prev == A. Pakai aturan ini untuk mengecek setiap operasi.

Di sini head, tail, dan size dibuat global supaya kode pendek. Di project nyata biasanya dibungkus dalam satu struct (misalnya DList) yang dikirim sebagai pointer ke setiap fungsi.

3. Cara berpikir

Pakai resep 5 langkah dari single linked list: gambar sebelum/sesudah, tandai panah, cari pemilik panah, urutkan, cek edge case. Di double linked list ada dua perubahan:

Single LLDouble LL
Panah antar dua node1 (next)2 (next + prev)
Baris kode per sambungan12, satu untuk tiap arah
Node sebelum curHarus dicari (pola C: berhenti di pos - 1)Langsung: cur->prev. Jadi cur boleh berhenti di pos
Ujung listheadhead dan tail, dua-duanya bisa berubah
Cara cek kode sendiriHitung panah yang berubah di gambarmu. Setiap sambungan baru antara A dan B harus menghasilkan dua baris: A->next = B dan B->prev = A. Kalau jumlah baris ganjil, hampir pasti ada yang lupa.

4. Operasi

Buka visualisasi operasi sambil membaca. Kodenya sama persis.

insertFront(x): O(1)

Sebelum:  head → [10] ⇄ [20] ← tail
Sesudah:  head → [5] ⇄ [10] ⇄ [20] ← tail

Sambungan baru: [5] ⇄ [10] (2 baris) + head pindah. Edge case: list kosong → node baru jadi head dan tail.

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {            // list kosong
        head = tail = newNode;
    } else {
        newNode->next = head;         // 1. sambung ke head lama
        head->prev = newNode;         // 2. head lama menunjuk balik
        head = newNode;               // 3. baru pindahkan head
    }
    size++;
}
Awas urutanKalau langkah 3 jalan duluan, langkah 2 jadi newNode->prev = newNode: node menunjuk dirinya sendiri.

insertBack(x): O(1)

Sebelum:  head → [10] ⇄ [20] ← tail
Sesudah:  head → [10] ⇄ [20] ⇄ [50] ← tail

Beda dengan single linked list: node terakhir tidak perlu dicari, karena sudah ada di tail.

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

Cermin dari insertFront: tukar head ↔ tail dan next ↔ prev.

insertAt(pos, x): O(n)

insertAt(2, 25)
Sebelum:  [10] ⇄ [20] ⇄ [30]
Sesudah:  [10] ⇄ [20] ⇄ [25] ⇄ [30]

Sambungan baru: [20] ⇄ [25] dan [25] ⇄ [30] → 4 baris. Pemilik panah: [20] dan [30]. Cukup cari [30] (node di pos), karena [20] = cur->prev.

void insertAt(int pos, int x) {          // syarat: 0 <= pos <= size
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;                 // cur = node di posisi pos
    Node* newNode = createNode(x);
    newNode->next = cur;                 // 1
    newNode->prev = cur->prev;           // 2
    cur->prev->next = newNode;           // 3
    cur->prev = newNode;                 // 4: paling akhir!
    size++;
}
  • Index mulai dari 0. Node baru masuk tepat sebelum cur.
  • Langkah 1–2 cuma mengisi pointer newNode → list belum berubah, aman.
  • Langkah 3–4 mengubah list. Langkah 4 harus terakhir karena langkah 2–3 masih butuh cur->prev yang lama.

deleteAt(pos): O(n), atau O(1) kalau node sudah ditunjuk

deleteAt(1)
Sebelum:  [10] ⇄ [20] ⇄ [30]
Sesudah:  [10] ⇄ [30]          [20] di-free

Sambungan baru: [10] ⇄ [30] → 2 baris. Keduanya bisa ditemukan dari del sendiri (del->prev dan del->next), jadi tidak perlu node pos - 1 seperti di single linked list.

void deleteAt(int pos) {                 // syarat: 0 <= pos < size
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != NULL)
        del->prev->next = del->next;     // bypass dari depan
    else
        head = del->next;                // del = node pertama
    if (del->next != NULL)
        del->next->prev = del->prev;     // bypass dari belakang
    else
        tail = del->prev;                // del = node terakhir
    free(del);
    size--;
}

Dua if itu sudah menangani semua edge case:

Posisi delprevnextHasil
Di tengahadaadaKedua tetangga saling menunjuk
Node pertamanulladahead pindah ke node ke-2
Node terakhiradanulltail pindah mundur
Satu-satunya nodenullnullhead & tail → NULL
Keunggulan utama DLLKalau sudah pegang pointer ke node yang mau dihapus, loop pencarian tidak perlu. Delete jadi O(1). Di single linked list ini tetap O(n).

search(x): O(n)

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;                      // tidak ketemu
}

Traverse maju & mundur: O(n)

void printForward() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
}

void printBackward() {
    for (Node* cur = tail; cur != NULL; cur = cur->prev)
        printf("%d ", cur->data);
}
Trik debuggingPrint maju lalu print mundur. Kalau hasilnya tidak saling terbalik, ada pointer prev yang salah.

Kenapa delete node terakhir di single LL tetap O(n) walau ada tail? Karena tail baru = node sebelum tail lama, dan node itu harus dicari dari head.

7. Dipakai di mana?

  • Browser back / forward: coba di visualisasi browser history
  • Undo / redo di editor
  • Playlist: lagu prev / next
  • LRU cache: pindah & delete item di tengah dalam O(1)
  • Linux kernel: struct list_head adalah (circular) double linked list

Lihat full code 
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* prev;
    struct Node* next;
} Node;

Node* head = NULL;
Node* tail = NULL;
int size = 0;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->prev = n->next = NULL;
    return n;
}

void insertFront(int x) {
    Node* newNode = createNode(x);
    if (head == NULL) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}

void insertBack(int x) {
    Node* newNode = createNode(x);
    if (tail == NULL) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;
    Node* newNode = createNode(x);
    newNode->next = cur;
    newNode->prev = cur->prev;
    cur->prev->next = newNode;
    cur->prev = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != NULL)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != NULL)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    free(del);
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != NULL) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return NULL;
}

void printForward() {
    for (Node* cur = head; cur != NULL; cur = cur->next)
        printf("%d ", cur->data);
    printf("\n");
}

void printBackward() {
    for (Node* cur = tail; cur != NULL; cur = cur->prev)
        printf("%d ", cur->data);
    printf("\n");
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printForward();       // 10 20 25 30
    printBackward();      // 30 25 20 10

    deleteAt(0);          // hapus 10
    deleteAt(size - 1);   // hapus 30
    printForward();       // 20 25

    printf("%s\n", search(25) != NULL ? "25 ketemu" : "25 tidak ada");

    while (head != NULL)   // kosongkan list → tidak ada memory leak
        deleteAt(0);
    return 0;
}

9. Latihan

1. Mulai dari list kosong, jalankan insertBack(5), insertFront(3), insertAt(1, 4), deleteAt(0). Tulis isi list, head, dan tail tiap langkah.

Jawaban

[5] → [3, 5] → [3, 4, 5] → [4, 5]. Akhirnya head = 4, tail = 5.

2. Di insertFront, apa yang terjadi kalau head->prev = newNode dan head = newNode ditukar urutannya?

Jawaban

head->prev = newNode jadi newNode->prev = newNode (menunjuk diri sendiri). Head lama tetap prev == NULL, jadi print maju benar tapi print mundur berhenti di head lama.

3. Tulis reverse() yang membalik list tanpa membuat node baru.

Jawaban 
void reverse() {
    Node* cur = head;
    while (cur != NULL) {
        Node* tmp = cur->next;
        cur->next = cur->prev;    // tukar prev & next
        cur->prev = tmp;
        cur = tmp;
    }
    Node* tmp = head;             // tukar head & tail
    head = tail;
    tail = tmp;
}

O(n). Cukup tukar prev ↔ next di tiap node, lalu tukar head ↔ tail.

4. Tulis int deleteValue(int x): hapus node pertama bernilai x. Return 1 kalau berhasil, 0 kalau tidak ada.

Jawaban 
int deleteValue(int x) {
    Node* del = search(x);
    if (del == NULL) return 0;
    if (del->prev != NULL)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != NULL)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    free(del);
    size--;
    return 1;
}

Bagian delete-nya sama dengan deleteAt. Bedanya hanya cara menemukan del.

5. Tulis Node* getNode(int i). Kalau i lebih dekat ke belakang, mulai dari tail.

Jawaban 
Node* getNode(int i) {
    if (i < size / 2) {
        Node* cur = head;
        for (int k = 0; k < i; k++)
            cur = cur->next;
        return cur;
    }
    Node* cur = tail;
    for (int k = size - 1; k > i; k--)
        cur = cur->prev;
    return cur;
}

Tetap O(n), tapi maksimal ~n/2 langkah.

6. Temukan bug. Fungsi ini lolos tes untuk node di tengah. Di posisi mana dia crash, dan baris mana yang hilang?

void deleteNode(Node* del) {
    del->prev->next = del->next;
    del->next->prev = del->prev;
    free(del);
}
Jawaban

Crash untuk node pertama (del->prev = NULL) dan node terakhir (del->next = NULL). Langkah 5 resep (edge case) terlewat: di ujung list, yang berubah adalah head atau tail, bukan node tetangga. Perbaikannya adalah dua if/else seperti di deleteAt.
