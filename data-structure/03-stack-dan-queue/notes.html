Data structure · 03

Stack dan queue

Linked list yang hanya boleh diakses di ujung tertentu. Dua struktur ini muncul di hampir setiap soal kasus.

Slide · Visualisasi stack · Visualisasi queue · Lanjut: Priority queue

PrasyaratPahami dulu single linked list (insertFront, delete node pertama, pola "sambung dulu, putus kemudian") dan pointer tail dari double linked list.
TL;DR
  • Stack = LIFO: push dan pop di top (head). Queue = FIFO: enqueue di tail, dequeue di head. Semuanya O(1).
  • Bungkus pointer ujung dalam struct (Stack, Queue) dan kirim alamatnya ke fungsi. Dengan begitu satu program bisa punya banyak antrean.
  • Edge case wajib: mengambil dari struktur kosong, dequeue node terakhir (tail = NULL), cancel node pertama atau terakhir.
  • Cancel (keluar dari tengah antrean) memakai dua pointer yang berjalan beriringan: prev dan cur.

1. Stack dan queue: list dengan aturan

Stack dan queue tidak menyimpan data dengan cara baru. Isinya tetap linked list. Yang baru adalah aturannya: data hanya boleh masuk dan keluar di ujung tertentu.

StackQueue
AturanLIFO (last in, first out)FIFO (first in, first out)
Contoh nyataTumpukan piring, tombol back, undoAntrean kasir, printer, "first come first serve"

Kenapa aksesnya dibatasi? Banyak soal hanya butuh "data yang paling baru" atau "data yang paling lama menunggu". Kalau hanya ujung list yang dipakai, semua operasi menjadi O(1), dan tidak ada loop traverse yang bisa salah.

2. Satu struct = satu stack atau queue

Materi 01 dan 02 memakai head global, jadi program hanya bisa punya satu list. Soal kasus sering butuh dua atau tiga antrean sekaligus. Solusinya: bungkus pointer ujung dalam struct, lalu buat satu variabel untuk setiap antrean.

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;              // node paling atas, NULL kalau kosong
} Stack;

typedef struct {
    Node* head;             // depan antrean: tempat keluar
    Node* tail;             // belakang antrean: tempat masuk
} Queue;

int main() {
    Stack s = {NULL};
    Queue a = {NULL, NULL}, b = {NULL, NULL};
    enqueue(&a, 10);        // kirim alamat a
    ...
}

Program tetap bisa di-compile, tapi a.head di main tetap NULL. Node baru juga bocor (memory leak), karena alamatnya hanya tersimpan di salinan.

3. Stack

Kenapa top diletakkan di head

top → [30] → [20] → [10] → NULL

Di single linked list, insert dan delete di depan sama-sama O(1). Kalau top diletakkan di node terakhir, push masih bisa O(1) (dengan tail), tapi pop harus mengubah next milik node sebelum node terakhir. Node itu harus dicari dari head: O(n).

Jadi push = insertFront dan pop = delete node pertama. Kodenya sama dengan materi 01, hanya head diganti s->top.

push(s, x) dan pop(s): O(1)

void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;   // 1. sambung ke top lama
    s->top = newNode;         // 2. baru pindahkan top
}

int pop(Stack* s) {           // syarat: s->top != NULL
    Node* del = s->top;       // simpan alamat
    int x = del->data;        // simpan data sebelum free
    s->top = del->next;
    free(del);
    return x;
}
  • Push ke stack kosong: newNode->next = s->top berisi NULL. Hasilnya sudah benar, jadi tidak perlu if.
  • Pop node terakhir: s->top = del->next berisi NULL. Stack otomatis kosong, juga tanpa if.
  • Pop stack kosong (stack underflow): del NULL, jadi del->data crash. Fungsi pop tidak mengecek ini. Yang memanggil pop harus mengecek dulu: while (s.top != NULL) ...
  • pop mengembalikan data, karena soal hampir selalu butuh nilai yang keluar: dicetak, dibandingkan, atau dipindah ke struktur lain.

4. Queue

Kenapa masuk di tail, keluar di head

keluar ← head → [10] → [20] → [30] ← tail ← masuk
Pilihan arahenqueuedequeue
Masuk di tail, keluar di headO(1): tail->next = newNodeO(1): head = head->next
Masuk di head, keluar di tailO(1)O(n): tail baru = node sebelum tail, harus dicari dari head

enqueue(q, x) dan dequeue(q): O(1)

void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {          // queue kosong
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;    // 1. node terakhir menunjuk node baru
        q->tail = newNode;          // 2. tail pindah
    }
}

int dequeue(Queue* q) {             // syarat: q->head != NULL
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)            // node terakhir baru saja keluar
        q->tail = NULL;
    free(del);
    return x;
}
KasusYang harus terjadi
Enqueue ke queue kosongTidak ada node terakhir untuk disambung. Node baru menjadi head dan tail.
Dequeue node terakhirhead menjadi NULL, dan tail juga harus diubah ke NULL.
Dequeue queue kosongCrash. Cek q.head != NULL sebelum memanggil dequeue.
Kenapa tail = NULL wajib?Tanpa baris itu, tail masih menunjuk node yang sudah di-free (dangling pointer). Enqueue berikutnya melihat tail != NULL, lalu menulis tail->next ke memory yang sudah di-free. head tetap NULL, jadi node baru tidak pernah tercetak.

5. Cancel: keluar dari tengah antrean

Soal antrean sering punya pelanggan yang membatalkan. Ini delete berdasarkan nilai, bukan berdasarkan posisi. Turunkan dengan resep dari materi 01:

  1. Gambar. [10] → [20] → [30], cancel 20, hasilnya [10] → [30].
  2. Panah yang berubah: next milik [10]. Pemilik panah adalah node sebelum node yang dihapus.
  3. Cari node yang dibutuhkan. Single linked list tidak bisa mundur. Jadi saat cur mencari x, simpan juga node sebelumnya di prev.
  4. Urutan: prev->next = cur->next dulu, baru free(cur).
  5. Edge case: x di node pertama (tidak ada prev), x di node terakhir (tail berubah), x satu-satunya node, dan x tidak ada.
void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {   // NULL dicek duluan
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;          // x tidak ada
    if (prev == NULL)
        q->head = cur->next;          // cur node pertama
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;               // cur node terakhir
    free(cur);
}
Posisi xprevYang berubah
Di tengahadaprev->next melompati cur
Node pertamaNULLhead pindah ke node ke-2
Node terakhiradaprev->next menjadi NULL dan tail mundur ke prev
Satu-satunya nodeNULLhead dan tail menjadi NULL
Tidak ada-Tidak ada (cur NULL, langsung return)

Kenapa tidak memakai pola C (berhenti di pos - 1)? Karena yang dicari nilai, bukan posisi. Kita baru tahu posisi x setelah membandingkan cur->data, jadi node sebelumnya harus diingat sepanjang jalan.

6. Pola yang sering muncul di soal

Gabung dua antrean bergantian

// a = 4 7,  b = 2 6 8 9
while (a.head != NULL || b.head != NULL) {
    if (a.head != NULL) enqueue(&c, dequeue(&a));
    if (b.head != NULL) enqueue(&c, dequeue(&b));
}
// c = 4 2 7 6 8 9,  a dan b kosong

  • Kondisi loop memakai ||: loop jalan selama salah satu antrean masih berisi.
  • Kalau a habis duluan, if pertama bernilai false di setiap putaran berikutnya, jadi sisa b masuk berurutan. Tidak perlu loop tambahan untuk sisa.
  • Data benar-benar berpindah lewat dequeue dan enqueue. Ini penting kalau soal mengecek bahwa kode memakai queue, bukan hanya mencetak angka.

Balik urutan dengan stack

for (int i = 0; i < n; i++) {
    scanf("%d", &x);
    push(&s, x);
}
while (s.top != NULL)
    printf("%d ", pop(&s));      // input 1 2 3, output 3 2 1

Undo, back, dan tanda kurung

  • Undo: setiap aksi di-push. Undo = pop aksi terakhir.
  • Tombol back: setiap halaman yang ditinggalkan di-push. Back = pop.
  • Tanda kurung: kurung yang terakhir dibuka harus ditutup duluan. Soal lengkapnya ada di materi 05.

7. Versi array (singkat)

Stack dan queue juga bisa dibuat dengan array. Ini sering ditanyakan di teori, tapi soal coding biasanya mewajibkan linked list.

#define MAX 100

int stack[MAX];
int top = -1;                    // -1 = stack kosong

void push(int x) { stack[++top] = x; }     // syarat: top < MAX - 1
int pop() { return stack[top--]; }         // syarat: top >= 0

int queue[MAX];
int front = 0, count = 0;

void enqueue(int x) {                      // syarat: count < MAX
    queue[(front + count) % MAX] = x;
    count++;
}

int dequeue() {                            // syarat: count > 0
    int x = queue[front];
    front = (front + 1) % MAX;
    count--;
    return x;
}
  • Queue array memakai circular index (% MAX). Tanpa itu, front terus bergeser ke kanan, dan slot di awal array yang sudah kosong tidak pernah dipakai lagi.
  • Array punya batas MAX. Push ke stack penuh (stack overflow) menulis di luar array.

10. Full code

Bisa di-compile sebagai C atau C++Sudah diuji dengan MinGW gcc (C) dan g++ (C++98). Simpan sebagai .c atau .cpp di Dev-C++.
Lihat full code 
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;
} Stack;

typedef struct {
    Node* head;
    Node* tail;
} Queue;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}

/* ---------- Stack: masuk dan keluar di top ---------- */
void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;
    s->top = newNode;
}

int pop(Stack* s) {                  // syarat: s->top != NULL
    Node* del = s->top;
    int x = del->data;
    s->top = del->next;
    free(del);
    return x;
}

/* ---------- Queue: masuk di tail, keluar di head ---------- */
void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;
        q->tail = newNode;
    }
}

int dequeue(Queue* q) {              // syarat: q->head != NULL
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)
        q->tail = NULL;
    free(del);
    return x;
}

void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;
    if (prev == NULL)
        q->head = cur->next;
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;
    free(cur);
}

void printQueue(Queue* q) {
    for (Node* cur = q->head; cur != NULL; cur = cur->next) {
        if (cur != q->head) printf(" ");
        printf("%d", cur->data);
    }
    printf("\n");
}

int main() {
    // Stack: yang terakhir masuk keluar duluan
    Stack s = {NULL};
    push(&s, 10);
    push(&s, 20);
    push(&s, 30);
    printf("top: %d\n", s.top->data);        // 30 (peek)
    while (s.top != NULL)
        printf("%d ", pop(&s));               // 30 20 10
    printf("\n");

    // Queue: gabung dua queue bergantian, lalu cancel
    Queue a = {NULL, NULL}, b = {NULL, NULL}, c = {NULL, NULL};
    enqueue(&a, 4);
    enqueue(&a, 7);
    enqueue(&b, 2);
    enqueue(&b, 6);
    enqueue(&b, 8);
    enqueue(&b, 9);
    while (a.head != NULL || b.head != NULL) {
        if (a.head != NULL) enqueue(&c, dequeue(&a));
        if (b.head != NULL) enqueue(&c, dequeue(&b));
    }
    printQueue(&c);                           // 4 2 7 6 8 9
    cancel(&c, 9);                            // node terakhir: tail pindah
    cancel(&c, 4);                            // node pertama: head pindah
    enqueue(&c, 5);
    printQueue(&c);                           // 2 7 6 8 5

    while (c.head != NULL)                    // kosongkan queue: tidak ada memory leak
        dequeue(&c);
    return 0;
}

11. Latihan

1. Mulai dari stack kosong: push(1), push(2), pop(), push(3), pop(), pop(). Apa saja return value dari setiap pop?

Jawaban

2, 3, 1. Setelah push 1 dan 2, top = 2, jadi pop pertama mengembalikan 2. Lalu 3 di-push di atas 1, jadi pop berikutnya 3, lalu 1.

2. Urutan yang sama, tapi dengan queue: enqueue(1), enqueue(2), dequeue(), enqueue(3), dequeue(), dequeue().

Jawaban

1, 2, 3. Queue selalu mengeluarkan data sesuai urutan masuk, apa pun selingan operasinya.

3. Temukan bug. Kode ini di-compile tanpa error, tapi tidak mencetak apa pun. Kenapa?

void push(Stack s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s.top;
    s.top = newNode;
}
...
Stack st = {NULL};
push(st, 5);
while (st.top != NULL) printf("%d ", pop(&st));
Jawaban

push menerima salinan st. Yang berubah adalah s.top milik salinan, lalu salinan hilang saat fungsi selesai. st.top di main tetap NULL, jadi loop tidak jalan. Node 5 juga bocor. Perbaikan: void push(Stack* s, int x), pakai s->top, dan panggil push(&st, 5).

4. Temukan bug. Baris if (q->head == NULL) q->tail = NULL; dihapus dari dequeue. Apa yang terjadi pada urutan enqueue(5), dequeue(), enqueue(7), lalu printQueue?

Jawaban

Setelah dequeue, head = NULL, tapi tail masih menunjuk node 5 yang sudah di-free. enqueue(7) melihat tail != NULL, jadi menulis tail->next ke memory yang sudah di-free, lalu tail pindah ke node 7. head tetap NULL, jadi printQueue mencetak baris kosong, dan node 7 bocor.

5. Turunkan sendiri. Tambahkan int size ke struct Queue, supaya jumlah isi antrean bisa dibaca dalam O(1). Baris apa saja yang berubah?

Jawaban 
typedef struct {
    Node* head;
    Node* tail;
    int size;
} Queue;

Queue a = {NULL, NULL, 0};
// enqueue: q->size++;  di akhir fungsi
// dequeue: q->size--;  sebelum return
// cancel:  q->size--;  tepat sebelum free(cur), bukan sebelum return pertama

Di cancel, size hanya berkurang kalau x ketemu. Kalau ditulis di awal fungsi, size berkurang walaupun x tidak ada.

6. Turunkan sendiri. Gabungkan dua antrean dengan pola 2 dari a, lalu 1 dari b. Contoh: a = 1 2 3 4 5, b = 6 7, hasilnya 1 2 6 3 4 7 5.

Jawaban 
while (a.head != NULL || b.head != NULL) {
    for (int k = 0; k < 2 && a.head != NULL; k++)
        enqueue(&c, dequeue(&a));
    if (b.head != NULL)
        enqueue(&c, dequeue(&b));
}

Kondisi a.head != NULL ikut di dalam for, supaya loop berhenti kalau a habis di tengah giliran.

7. Cetak isi stack dari top ke bawah tanpa mengubah stack.

Jawaban 
for (Node* cur = s.top; cur != NULL; cur = cur->next)
    printf("%d ", cur->data);

Mencetak cukup dengan traverse. Kalau memakai pop, stack menjadi kosong setelah dicetak.
