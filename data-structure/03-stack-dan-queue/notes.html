Stack: yang terakhir masuk keluar duluan

insertFront dan delete node pertama di single linked list (materi 01) kode stack (4️⃣), undo, tombol back, dan cek tanda kurung (materi 05)

Tumpukan piring: piring baru ditaruh di atas, dan yang diambil selalu piring paling atas.

piring di tengah masih bisa kamu tarik paksa. Stack benar-benar hanya mengizinkan akses ke elemen paling atas.

Stack adalah struktur data yang hanya bisa diisi dan diambil dari satu ujung, yang disebut top. Aturannya LIFO (last in, first out): yang terakhir masuk keluar duluan.

  • Masuk: push, menaruh data di top.
  • Keluar: pop, mengambil data dari top.
  • Lihat tanpa mengambil: peek, yaitu s.top->data.

Kenapa aksesnya dibatasi? Banyak soal hanya butuh "data yang paling baru". Kalau hanya ujung list yang dipakai, semua operasi cepat dan tidak ada loop traverse yang bisa salah.

Stack = LIFO. Push dan pop sama-sama di top.

Soal latihan: Push 1, 2, 3 ke stack kosong, lalu pop dua kali. Data apa yang keluar, dan apa yang tersisa?

Keluar 3, lalu 2. Yang tersisa hanya 1.

stack (1️⃣) dan tail di double linked list (materi 02) kode queue (5️⃣), antrean layanan, dan priority queue (materi 04)

Antrean kasir: yang datang duluan dilayani duluan, dan orang baru berdiri di belakang.

di antrean nyata ada yang menyerobot. Di queue murni tidak ada, kecuali lewat operasi khusus seperti cancel (6️⃣).

Queue adalah struktur data yang diisi dari belakang dan diambil dari depan. Aturannya FIFO (first in, first out): yang pertama masuk keluar duluan.

Satu struct = satu stack atau queue, dan fungsi menerima alamatnya

head global di materi 01–02, dan pointer ke struct (->) semua kode di materi ini, dan soal kasus dengan beberapa antrean (materi 05)

Buku antrean per loket: satu buku untuk loket A, satu untuk loket B. Petugas yang mencatat butuh buku aslinya, bukan fotokopinya.

fotokopi masih bisa kamu tempel balik. Salinan struct di fungsi hilang begitu fungsi selesai.

Materi 01 dan 02 memakai head global, jadi program hanya bisa punya satu list. Soal kasus sering butuh dua atau tiga antrean, jadi pointer ujungnya dibungkus dalam struct. Fungsi menerima pointer ke struct (Queue* q), supaya perubahan head dan tail terlihat di main.

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;              // node paling atas, NULL kalau kosong
} Stack;

typedef struct {
    Node* head;             // depan antrean: tempat keluar
    Node* tail;             // belakang antrean: tempat masuk
} Queue;

int main() {
    Stack s = {NULL};
    Queue a = {NULL, NULL}, b = {NULL, NULL};
    enqueue(&a, 10);        // kirim alamat a
    ...
}

Kode stack: top diletakkan di node pertama, jadi push dan pop tidak perlu traverse

insertFront dan deleteAt(0) di single linked list (materi 01) pola stack (8️⃣) dan soal kasus (materi 05)

Menaruh dan mengambil piring selalu di atas tumpukan, bukan di bawah.

piring paling bawah masih bisa kamu lihat. Di single linked list, node terakhir hanya bisa dicapai dengan traverse dari head.

Top diletakkan di head, karena di single linked list insert dan delete di depan sama-sama cepat. Kalau top di node terakhir, pop harus mengubah next milik node sebelumnya, yang harus dicari dari head. Jadi push = insertFront dan pop = delete node pertama.

top → [30] → [20] → [10] → NULL
void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;   // 1. sambung ke top lama
    s->top = newNode;         // 2. baru pindahkan top
}

int pop(Stack* s) {           // syarat: s->top != NULL
    Node* del = s->top;       // simpan alamat
    int x = del->data;        // simpan data sebelum free
    s->top = del->next;
    free(del);
    return x;
}
  • Push ke stack kosong / pop node terakhir: otomatis benar tanpa if, karena s->top berisi NULL.
  • pop mengembalikan data: soal hampir selalu butuh nilai yang keluar, misalnya untuk dicetak.

Pop dari stack kosong disebut stack underflow: del bernilai NULL, jadi del->data crash. Cek dulu sebelum memanggil pop: while (s.top != NULL) ...

Buka visualisasi stack, push beberapa nilai, lalu pop. Node yang terakhir di-push selalu yang pertama di-pop.

push = insertFront, pop = delete node pertama. Cek s.top != NULL sebelum pop.

Soal latihan: Mulai dari stack kosong: push(1), push(2), pop(), push(3), pop(), pop(). Apa return value dari setiap pop?

2, 3, 1. Setelah push 1 dan 2, top = 2, jadi pop pertama mengembalikan 2. Lalu 3 di-push di atas 1, jadi pop berikutnya 3, lalu 1.

Kode queue: masuk di tail, keluar di head, dan tail ikut NULL saat antrean kosong

insertBack dengan tail (materi 02) dan pop (4️⃣) cancel (6️⃣) dan gabung antrean (7️⃣)

Antrean dengan dua petugas: satu di belakang mencatat orang baru, satu di depan memanggil orang berikutnya.

kalau antrean kosong, petugas belakang sadar sendiri. Di kode, tail harus diubah ke NULL secara manual.

Arahnya dipilih supaya keduanya cepat di single linked list. Masuk di head dan keluar di tail tidak bisa, karena tail baru (node sebelum tail) harus dicari dari head.

keluar ← head → [10] → [20] → [30] ← tail ← masuk
void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {          // queue kosong
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;    // 1. node terakhir menunjuk node baru
        q->tail = newNode;          // 2. tail pindah
    }
}

int dequeue(Queue* q) {             // syarat: q->head != NULL
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)            // node terakhir baru saja keluar
        q->tail = NULL;
    free(del);
    return x;
}

Enqueue ke queue kosongTidak ada node terakhir untuk disambung. Node baru menjadi head dan tail.
Dequeue node terakhirhead menjadi NULL, dan tail juga harus NULL.
Dequeue queue kosongCrash. Cek q.head != NULL dulu.

Tanpa tail = NULL, tail menunjuk node yang sudah di-free (dangling pointer, materi 02). Enqueue berikutnya menulis ke memory itu, dan data baru tidak pernah tercetak.

Buka visualisasi queue. Dequeue sampai antrean kosong, lalu perhatikan tail ikut berubah jadi NULL.

enqueue di tail, dequeue di head. Kalau antrean jadi kosong, tail juga harus NULL.

Cancel: dua pointer berjalan beriringan untuk menghapus berdasarkan nilai

resep 5 langkah dan deleteAt (materi 01) soal antrean dengan pembatalan (materi 05)

Mencari teman di barisan sambil memegang bahu orang di depanmu: begitu temanmu ketemu, orang yang kamu pegang langsung digandengkan ke orang setelah temanmu.

di barisan nyata kamu bisa menoleh ke belakang. Di single linked list tidak bisa, jadi node sebelumnya harus diingat sepanjang jalan.

Cancel adalah delete berdasarkan nilai. Pemilik panah yang berubah adalah node sebelum node yang dihapus, jadi saat cur mencari x, node sebelumnya disimpan di prev. Pola ini disebut dua pointer beriringan.

void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {   // NULL dicek duluan
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;          // x tidak ada
    if (prev == NULL)
        q->head = cur->next;          // cur node pertama
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;               // cur node terakhir
    free(cur);
}

Karena yang dicari nilai, bukan posisi. Posisi x baru diketahui setelah cur->data dibandingkan, jadi node sebelumnya harus diingat sepanjang jalan.

Buka visualisasi queue dan klik cancel dengan nilai di tengah, lalu di ujung. Perhatikan prev yang mengikuti cur.

prev mengikuti cur. Saat x ketemu, prev->next = cur->next, dan head/tail dipindah kalau x di ujung.

Pola queue: gabung dua antrean bergantian dengan dequeue dan enqueue

enqueue dan dequeue (5️⃣) soal kasus dua loket atau dua jalur (materi 05)

Dua jalur mobil yang menyatu jadi satu lajur: satu mobil dari kiri, satu dari kanan, bergantian.

di jalan, jalur yang kosong tetap ada. Di kode, kalau satu antrean habis, sisa antrean lain langsung masuk berurutan.

Soal sering meminta dua antrean dilayani bergantian. Data benar-benar dipindah lewat dequeue dan enqueue, jadi a dan b kosong di akhir.

// a = 4 7,  b = 2 6 8 9
while (a.head != NULL || b.head != NULL) {
    if (a.head != NULL) enqueue(&c, dequeue(&a));
    if (b.head != NULL) enqueue(&c, dequeue(&b));
}
// c = 4 2 7 6 8 9,  a dan b kosong
  • Kondisi loop memakai || (atau): loop jalan selama salah satu antrean masih berisi.
  • Sisa antrean: kalau a habis duluan, if pertama selalu false, jadi sisa b masuk berurutan tanpa loop tambahan.

Pola stack: kalau yang terbaru diproses duluan, pakai stack

push dan pop (4️⃣) cek tanda kurung (materi 05)

Tombol undo di editor: yang dibatalkan selalu aksi terakhir, lalu aksi sebelumnya, dan seterusnya.

editor asli menyimpan detail aksi yang rumit. Di soal, setiap aksi cukup disimpan sebagai satu node.

Kalau soal meminta sesuatu dibalik atau dibatalkan, yang diproses duluan adalah yang terakhir masuk. Itu LIFO, jadi pakai stack.

for (int i = 0; i < n; i++) {
    scanf("%d", &x);
    push(&s, x);
}
while (s.top != NULL)
    printf("%d ", pop(&s));      // input 1 2 3, output 3 2 1
  • Undo: setiap aksi di-push. Undo = pop aksi terakhir.
  • Tombol back: setiap halaman yang ditinggalkan di-push. Back = pop.
  • Tanda kurung: kurung yang terakhir dibuka harus ditutup duluan. Soal lengkapnya ada di materi 05.

"Balik", "batalkan", atau "yang terakhir duluan" → stack.

Soal latihan: Cetak isi stack dari top ke bawah tanpa mengubah stack. 
for (Node* cur = s.top; cur != NULL; cur = cur->next)
    printf("%d ", cur->data);

Mencetak cukup dengan traverse. Kalau memakai pop, stack menjadi kosong setelah dicetak.

Versi array: ukurannya tetap, dan queue butuh index melingkar

array dan operator % (algorithm and programming) soal teori tentang stack dan queue berbasis array

Meja putar di restoran: setelah piring paling ujung, putarannya kembali ke awal.

meja putar benar-benar melingkar. Array tetap lurus di memory, dan "melingkar" hanya didapat dari perhitungan % MAX.

Stack dan queue juga bisa dibuat dengan array. Ini sering ditanyakan di teori, tapi soal coding biasanya mewajibkan linked list. Queue array memakai circular index: index yang kembali ke 0 setelah sampai ujung array, dihitung dengan % MAX.

#define MAX 100

int stack[MAX];
int top = -1;                    // -1 = stack kosong

void push(int x) { stack[++top] = x; }     // syarat: top < MAX - 1
int pop() { return stack[top--]; }         // syarat: top >= 0

int queue[MAX];
int front = 0, count = 0;

void enqueue(int x) {                      // syarat: count < MAX
    queue[(front + count) % MAX] = x;
    count++;
}

int dequeue() {                            // syarat: count > 0
    int x = queue[front];
    front = (front + 1) % MAX;
    count--;
    return x;
}

UkuranTetap (MAX)Bertambah sesuai kebutuhan

Tanpa % MAX, front terus bergeser ke kanan, dan slot di awal array yang sudah kosong tidak pernah dipakai lagi.

Soal latihan: MAX = 4, front = 3, count = 2. Di index berapa enqueue berikutnya menulis?

(front + count) % MAX = (3 + 2) % 4 = 1. Index kembali ke awal array.

Time complexity: semua operasi utama O(1), karena hanya menyentuh ujung

Big-O (materi 01) memilih struktur data di soal kasus

Mengambil piring paling atas selalu secepat apa pun tinggi tumpukannya.

tumpukan piring yang terlalu tinggi bisa roboh. Linked list tidak punya batas tinggi, selama memory masih ada.

Stack dan queue cepat karena operasi utamanya hanya menyentuh ujung list, yang langsung tersedia lewat top, head, dan tail.

OperasiKompleksitasAlasan
push, pop, peekO(1)Hanya menyentuh top
enqueue, dequeueO(1)Head dan tail langsung tersedia

Hanya ujung → O(1). Mencari nilai di tengah → O(n).

Soal latihan: Kenapa gabung dua antrean berukuran n dan m butuh O(n + m)?

Setiap node di a dan b dipindah tepat satu kali, dan setiap pemindahan (dequeue + enqueue) butuh waktu tetap. Totalnya n + m pemindahan.

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;
} Stack;

typedef struct {
    Node* head;
    Node* tail;
} Queue;

Node* createNode(int x) {
    Node* n = (Node*)malloc(sizeof(Node));
    n->data = x;
    n->next = NULL;
    return n;
}

/* ---------- Stack: masuk dan keluar di top ---------- */
void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;
    s->top = newNode;
}

int pop(Stack* s) {                  // syarat: s->top != NULL
    Node* del = s->top;
    int x = del->data;
    s->top = del->next;
    free(del);
    return x;
}

/* ---------- Queue: masuk di tail, keluar di head ---------- */
void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;
        q->tail = newNode;
    }
}

int dequeue(Queue* q) {              // syarat: q->head != NULL
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)
        q->tail = NULL;
    free(del);
    return x;
}

void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;
    if (prev == NULL)
        q->head = cur->next;
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;
    free(cur);
}

void printQueue(Queue* q) {
    for (Node* cur = q->head; cur != NULL; cur = cur->next) {
        if (cur != q->head) printf(" ");
        printf("%d", cur->data);
    }
    printf("\n");
}

int main() {
    // Stack: yang terakhir masuk keluar duluan
    Stack s = {NULL};
    push(&s, 10);
    push(&s, 20);
    push(&s, 30);
    printf("top: %d\n", s.top->data);        // 30 (peek)
    while (s.top != NULL)
        printf("%d ", pop(&s));               // 30 20 10
    printf("\n");

    // Queue: gabung dua queue bergantian, lalu cancel
    Queue a = {NULL, NULL}, b = {NULL, NULL}, c = {NULL, NULL};
    enqueue(&a, 4);
    enqueue(&a, 7);
    enqueue(&b, 2);
    enqueue(&b, 6);
    enqueue(&b, 8);
    enqueue(&b, 9);
    while (a.head != NULL || b.head != NULL) {
        if (a.head != NULL) enqueue(&c, dequeue(&a));
        if (b.head != NULL) enqueue(&c, dequeue(&b));
    }
    printQueue(&c);                           // 4 2 7 6 8 9
    cancel(&c, 9);                            // node terakhir: tail pindah
    cancel(&c, 4);                            // node pertama: head pindah
    enqueue(&c, 5);
    printQueue(&c);                           // 2 7 6 8 5

    while (c.head != NULL)                    // kosongkan queue: tidak ada memory leak
        dequeue(&c);
    return 0;
}

Program lengkap = struct Node, Stack, Queue + operasi + main. Antrean dikosongkan di akhir supaya tidak ada memory leak.

Soal latihan: Kenapa baris terakhir output adalah 2 7 6 8 5?

Setelah gabung, c = 4 2 7 6 8 9. cancel 9 menghapus node terakhir (tail mundur ke 8). cancel 4 menghapus node pertama (head pindah ke 2). enqueue 5 menyambung 5 di belakang 8.
