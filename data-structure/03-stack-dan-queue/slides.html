Stack dan queue

Data structure · materi 03 · prasyarat: single linked list dan tail dari double linked list

Target: kamu bisa menulis push, pop, enqueue, dequeue, dan cancel sendiri, lalu memilih stack atau queue untuk sebuah soal kasus.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Stack

Di stack, data yang terakhir masuk adalah yang pertama keluar

Stack adalah struktur data yang hanya diisi dan diambil dari satu ujung, yaitu top. Aturannya LIFO (last in, first out).

  • push: taruh data di top. pop: ambil data dari top.
  • peek: lihat data top tanpa mengambilnya (s.top->data).
  • Contoh nyata: tumpukan piring, tombol back, undo.

Notes 2️⃣ · Queue

Di queue, data yang pertama masuk adalah yang pertama keluar

Queue adalah struktur data yang diisi dari belakang dan diambil dari depan. Aturannya FIFO (first in, first out).

StackQueue
AturanLIFO: yang terakhir masuk keluar duluanFIFO: yang pertama masuk keluar duluan
ContohTumpukan piring, tombol back, undoAntrean kasir, printer, "first come first serve"

Kalau soal hanya butuh "yang terbaru" atau "yang paling lama menunggu", cukup ujung list yang dipakai, jadi tidak perlu traverse.

Notes 3️⃣ · Struct pembungkus

Satu struct untuk satu antrean, dan fungsi menerima alamatnya

Fungsi menerima pointer ke struct (Queue* q), supaya perubahan head dan tail terlihat di main.

typedef struct {
    Node* top;
} Stack;

typedef struct {
    Node* head;
    Node* tail;
} Queue;

Queue a = {NULL, NULL}, b = {NULL, NULL};
enqueue(&a, 10);   // kirim alamat a
  • Butuh tiga antrean? Buat tiga variabel Queue. = {NULL, NULL} wajib, karena variabel lokal berisi garbage value.
  • Di fungsi tulis q->head, karena q berisi alamat struct.

Kalau parameternya Queue q, fungsi mengubah salinan, dan a.head di main tetap NULL.

Notes 4️⃣ · Kode stack

Top stack diletakkan di node pertama, karena insert dan delete di sana tidak perlu traverse

Jadi push = insertFront dan pop = delete node pertama, yang sudah kamu turunkan di materi 01.

Kalau top di node terakhir, pop harus mengubah next milik node sebelumnya, dan node itu harus dicari dari head.

Notes 4️⃣ · Kode stack

pop menyimpan alamat dan data node dulu, baru memindahkan top dan free

Stack underflow adalah pop dari stack kosong, yang membuat NULL->data dibaca dan program crash.

void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;   // sambung dulu
    s->top = newNode;         // baru pindah
}

int pop(Stack* s) {           // syarat: s->top != NULL
    Node* del = s->top;
    int x = del->data;
    s->top = del->next;
    free(del);
    return x;
}
  • Data disalin ke x sebelum free. Setelah free, del->data berisi garbage value.
  • pop mengembalikan data, karena soal hampir selalu butuh nilai yang keluar.
  • Cek dulu sebelum pop: while (s.top != NULL).

Notes 5️⃣ · Kode queue

Queue masuk di tail dan keluar di head, supaya keduanya tidak perlu traverse

Arah sebaliknya membuat dequeue lambat, karena tail baru harus dicari dari head.

Notes 5️⃣ · Kode queue

Kalau node terakhir keluar, tail juga harus diubah ke NULL

Enqueue = insertBack dengan tail. Dequeue = pop, ditambah satu edge case untuk tail.

void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;
        q->tail = newNode;
    }
}
int dequeue(Queue* q) {
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)
        q->tail = NULL;
    free(del);
    return x;
}
  • Antrean kosong: node baru langsung menjadi head dan tail.
  • Tanpa tail = NULL, tail menunjuk node yang sudah di-free. Enqueue berikutnya menulis ke memory itu, dan data baru hilang.

Notes 6️⃣ · Cancel

Cancel memakai prev yang selalu satu langkah di belakang cur

Dua pointer beriringan: saat nilai x ketemu, prev adalah node yang next-nya harus diubah.

void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;        // x tidak ada
    if (prev == NULL)
        q->head = cur->next;        // cur node pertama
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;             // cur node terakhir
    free(cur);
}
  • cur != NULL dicek duluan, supaya cur->data tidak dibaca saat cur NULL.
  • x di node pertama: head pindah. x di node terakhir: tail mundur ke prev.
  • Pola C (berhenti di pos − 1) tidak bisa dipakai, karena yang dicari nilai, bukan posisi.

Notes 7️⃣ · Pola queue

Gabung dua antrean bergantian: satu dequeue dari tiap antrean per putaran

Loop jalan selama salah satu antrean masih berisi (||), jadi sisa antrean yang lebih panjang masuk berurutan.

// a = 4 7,  b = 2 6 8 9
while (a.head != NULL || b.head != NULL) {
    if (a.head != NULL) enqueue(&c, dequeue(&a));
    if (b.head != NULL) enqueue(&c, dequeue(&b));
}
// c = 4 2 7 6 8 9

Notes 8️⃣ · Pola stack

Kalau soal minta dibalik atau dibatalkan, yang terbaru diproses duluan, jadi pakai stack

"Yang terakhir masuk diproses duluan" adalah LIFO.

// Balik urutan: push semua, lalu pop semua
for (int i = 0; i < n; i++) {
    scanf("%d", &x);
    push(&s, x);
}
while (s.top != NULL)
    printf("%d ", pop(&s));    // input 1 2 3, output 3 2 1
  • Undo: setiap aksi di-push. Undo = pop aksi terakhir.
  • Tombol back: setiap halaman yang ditinggalkan di-push. Back = pop.
  • Tanda kurung: yang terakhir dibuka ditutup duluan (materi 05).

Notes 9️⃣ · Versi array

Versi array punya ukuran tetap, dan queue-nya butuh index melingkar

Circular index adalah index yang kembali ke 0 setelah sampai ujung array, dihitung dengan % MAX.

int stack[MAX], top = -1;
void push(int x) { stack[++top] = x; }
int pop() { return stack[top--]; }

int queue[MAX], front = 0, count = 0;
void enqueue(int x) {
    queue[(front + count) % MAX] = x;
    count++;
}
  • Tanpa % MAX, slot di awal array yang sudah kosong tidak pernah dipakai lagi.
  • Push ke stack penuh (stack overflow) menulis di luar array, jadi cek penuh wajib.
  • Soal yang mewajibkan linked list tidak boleh dijawab dengan versi array.

Notes 10 · Time complexity

Operasi utama stack dan queue O(1), karena hanya menyentuh ujung list

top, head, dan tail langsung tersedia, jadi tidak ada traverse.

Ringkasan: stack dan queue adalah linked list dengan aturan masuk-keluar

  • Stack = LIFO, push dan pop di top. Queue = FIFO, enqueue di tail, dequeue di head (1️⃣ 2️⃣).
  • Satu struct = satu antrean. Fungsi menerima Queue* q dan dipanggil dengan &a (3️⃣).
  • Edge case: ambil dari struktur kosong, dequeue node terakhir (tail = NULL), cancel di ujung (4️⃣ 5️⃣ 6️⃣).
  • Gabung bergantian = loop dengan ||. Balik atau batalkan = stack (7️⃣ 8️⃣).
  • Operasi utama O(1). Versi array butuh cek penuh dan circular index (9️⃣ 10).
