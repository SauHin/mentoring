Stack dan queue

Data structure · linked list dengan aturan: data hanya boleh masuk dan keluar di ujung tertentu.

Prasyarat: single linked list (insertFront, delete node pertama) dan pointer tail dari double linked list.

Dua aturan antre: LIFO dan FIFO

Stack dan queue menyimpan data seperti linked list biasa. Bedanya, keduanya membatasi di mana data boleh masuk dan keluar.

StackQueue
AturanLIFO (last in, first out): yang terakhir masuk keluar duluanFIFO (first in, first out): yang pertama masuk keluar duluan
ContohTumpukan piring, tombol back, undoAntrean kasir, printer, "first come first serve"

Keluarpop: ambil dari topdequeue: ambil dari depan
Kenapa aksesnya dibatasi?Kalau soal hanya butuh "yang terbaru" atau "yang paling lama menunggu", cukup ujung list yang dipakai. Semua operasinya jadi O(1), tanpa traverse.

Satu struct = satu stack atau queue

Dengan head global (materi 01 dan 02), program hanya punya satu list. Soal kasus sering butuh beberapa antrean sekaligus, jadi pointer ujungnya dibungkus dalam struct.

typedef struct {
    Node* top;
} Stack;

typedef struct {
    Node* head;
    Node* tail;
} Queue;

Queue a = {NULL, NULL}, b = {NULL, NULL};
enqueue(&a, 10);   // kirim alamat a
  • Satu variabel = satu antrean. Butuh tiga antrean? Buat tiga variabel Queue.
  • Fungsi menerima Queue* q dan dipanggil dengan &a. Kalau parameternya Queue q, fungsi mengubah salinan, dan a.head di main tetap NULL.
  • Di dalam fungsi, tulis q->head, karena q berisi alamat struct.
  • Kosong berarti a.head == NULL (queue) atau s.top == NULL (stack).

Stack: top diletakkan di head

Di single linked list, insert dan delete di depan sama-sama O(1). Karena itu top stack adalah node pertama.

  • push = insertFront dan pop = delete node pertama. Kodenya sudah kamu turunkan di materi 01.
  • Top tidak diletakkan di node terakhir. Pop di sana harus mengubah next milik node sebelumnya, dan node itu harus dicari dari head: O(n).

Kode stack: push dan pop

Push memakai pola "sambung dulu, putus kemudian". Pop menyimpan alamat dan data node dulu, baru memindahkan top dan free.

void push(Stack* s, int x) {
    Node* newNode = createNode(x);
    newNode->next = s->top;   // sambung dulu
    s->top = newNode;         // baru pindah
}

int pop(Stack* s) {           // syarat: s->top != NULL
    Node* del = s->top;
    int x = del->data;
    s->top = del->next;
    free(del);
    return x;
}
  • pop mengembalikan data, karena soal hampir selalu butuh nilai yang keluar: dicetak atau dipindah ke struktur lain.
  • Data disalin ke x sebelum free. Setelah free, del->data berisi garbage value.
  • Pop dari stack kosong membaca NULL->data dan crash (stack underflow). Cek dulu: while (s.top != NULL).
  • peek cukup s.top->data, tanpa mengeluarkan node.

Queue: masuk di tail, keluar di head

Queue memakai dua ujung, satu untuk masuk dan satu untuk keluar. Arahnya dipilih supaya keduanya O(1) di single linked list.

Pilihan arahenqueuedequeue
Masuk di tail, keluar di headO(1): tail->next = node baruO(1): head pindah ke head->next
Masuk di head, keluar di tailO(1)O(n): tail baru = node sebelum tail, harus dicari dari head

Kode queue: enqueue dan dequeue

Enqueue = insertBack dengan tail (materi 02, tanpa prev). Dequeue = pop, ditambah satu edge case: kalau antrean menjadi kosong, tail juga harus NULL.

void enqueue(Queue* q, int x) {
    Node* newNode = createNode(x);
    if (q->tail == NULL) {
        q->head = q->tail = newNode;
    } else {
        q->tail->next = newNode;
        q->tail = newNode;
    }
}
int dequeue(Queue* q) {
    Node* del = q->head;
    int x = del->data;
    q->head = del->next;
    if (q->head == NULL)
        q->tail = NULL;
    free(del);
    return x;
}
  • Kalau antrean kosong, tidak ada node terakhir untuk disambung. Node baru langsung menjadi head dan tail.
  • Kalau node terakhir keluar tanpa tail = NULL, tail menunjuk node yang sudah di-free. Enqueue berikutnya menulis ke memory itu, dan data baru hilang.

Cancel: keluar dari tengah antrean

Soal antrean sering punya pelanggan yang membatalkan. Ini delete berdasarkan nilai, dan butuh dua pointer yang berjalan beriringan: prev dan cur.

void cancel(Queue* q, int x) {
    Node* prev = NULL;
    Node* cur = q->head;
    while (cur != NULL && cur->data != x) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return;        // x tidak ada
    if (prev == NULL)
        q->head = cur->next;        // cur node pertama
    else
        prev->next = cur->next;
    if (cur == q->tail)
        q->tail = prev;             // cur node terakhir
    free(cur);
}
  • prev selalu satu langkah di belakang cur. Saat x ketemu, prev adalah node yang next-nya harus diubah (pemilik panah).
  • cur != NULL dicek lebih dulu, supaya cur->data tidak dibaca saat cur NULL.
  • Kalau cur node terakhir, tail mundur ke prev. Kalau satu-satunya node, prev NULL, jadi head dan tail sama-sama NULL.

Pola queue: gabung dua antrean bergantian

Soal sering meminta dua antrean dilayani bergantian. Ambil satu dari tiap antrean secara bergiliran, lalu masukkan ke antrean baru.

// a = 4 7,  b = 2 6 8 9
while (a.head != NULL || b.head != NULL) {
    if (a.head != NULL) enqueue(&c, dequeue(&a));
    if (b.head != NULL) enqueue(&c, dequeue(&b));
}
// c = 4 2 7 6 8 9
  • Loop jalan selama salah satu antrean masih berisi. Kalau a habis duluan, if pertama bernilai false, jadi sisa b masuk berurutan.
  • Setelah loop, a dan b kosong.

Pola stack: proses yang paling baru dulu

Kalau soal meminta sesuatu dibalik atau dibatalkan, yang diproses duluan adalah yang paling baru masuk. Itu LIFO, jadi pakai stack.

// Balik urutan: push semua, lalu pop semua
for (int i = 0; i < n; i++) {
    scanf("%d", &x);
    push(&s, x);
}
while (s.top != NULL)
    printf("%d ", pop(&s));    // input 1 2 3, output 3 2 1
  • Undo: setiap aksi di-push. Undo = pop aksi terakhir.
  • Tombol back: setiap halaman yang ditinggalkan di-push. Back = pop.
  • Tanda kurung: kurung yang terakhir dibuka harus ditutup duluan. Latihannya ada di materi 05.

Bug yang sering muncul

Hampir semua bug stack dan queue terjadi saat struktur kosong, saat node terakhir keluar, atau saat struct dikirim tanpa alamat.

Time complexity

Stack dan queue cepat karena setiap operasi utamanya hanya menyentuh ujung list.

OperasiKompleksitasAlasan
push, pop, peekO(1)Hanya menyentuh top
enqueue, dequeueO(1)Head dan tail langsung tersedia
cancel(x)O(n)x harus dicari dari head
Gabung bergantianO(n + m)Setiap node dipindah tepat satu kali

Ringkasan

  • Stack (LIFO) dan queue (FIFO) adalah linked list yang hanya boleh diakses di ujung tertentu.
  • Stack: push dan pop di top (head). Queue: enqueue di tail, dequeue di head. Semuanya O(1).
  • Bungkus pointer ujung dalam struct, lalu kirim alamatnya (&a) ke fungsi. Dengan begitu satu program bisa punya banyak stack dan queue.
  • Edge case: mengambil dari struktur kosong, dequeue node terakhir (tail = NULL), dan cancel node pertama atau terakhir.
