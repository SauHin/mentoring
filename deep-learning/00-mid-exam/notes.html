Limitasi linear model

Bobotnya cuma 5%.

Cukup pahami dua hal: kenapa garis lurus tidak cukup, dan kenapa deep learning bisa.

Masalahnya: lampu tangga

Bayangkan lampu tangga dengan dua saklar, satu di bawah dan satu di atas.

Lampu menyala kalau tepat satu saklar naik, dan mati kalau posisi kedua saklar sama.

Saklar bawah (x₁)Saklar atas (x₂)Lampu
00mati (0)
01nyala (1)
10nyala (1)
11mati (0)

Pola ini disebut XOR (exclusive OR).

Kelihatannya sederhana, tapi model linear tidak bisa mempelajarinya.

Model linear hanya bisa menggambar garis lurus

Model linear adalah model yang menghitung output dari jumlah berbobot input ditambah bias.

z = w₁x₁ + w₂x₂ + b

  • x₁, x₂: input, di sini posisi kedua saklar.
  • w₁, w₂: weight, seberapa penting setiap input.
  • b: bias, menggeser posisi garis batas.

Perceptron (S1 slide 10) memakai rumus ini, lalu memutuskan: kelas 1 kalau z > 0, kelas 0 kalau tidak.

Titik-titik dengan z = 0 menjadi batas antar kelas, yang disebut decision boundary.

Untuk 2 input, batas ini selalu garis lurus, apa pun nilai w dan b.

Titik "nyala" ada di dua pojok yang bersilangan.

Jadi garis lurus mana pun selalu salah di minimal satu titik.

Data seperti ini disebut tidak linearly separable, yaitu tidak bisa dipisah oleh satu garis lurus.

Bukti dengan pertidaksamaan (di luar slide)

Langkah 1. Tulis syarat setiap baris: (0,0) mati berarti b ≤ 0, (1,0) nyala berarti w₁ + b > 0, (0,1) nyala berarti w₂ + b > 0, dan (1,1) mati berarti w₁ + w₂ + b ≤ 0.

Langkah 2. Jumlahkan syarat (1,0) dan (0,1): w₁ + w₂ + 2b > 0, jadi w₁ + w₂ + b > −b.

Langkah 3. Karena b ≤ 0, nilai −b ≥ 0, jadi w₁ + w₂ + b > 0.

Langkah 4. Ini bertentangan dengan syarat (1,1), jadi tidak ada w dan b yang cocok.

Menambah layer linear tidak membantu

Ide pertama biasanya: "tambah layer saja".

Tanpa activation function, berapa pun layer linear tetap setara satu layer linear.

Layer 1 menghitung h = 2x + 1, lalu layer 2 menghitung y = 3h − 4.

Gabungannya y = 3(2x + 1) − 4 = 6x − 1, tetap garis lurus.

Bentuk umumnya: W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂), yaitu satu layer dengan weight dan bias baru.

Kenapa deep learning bisa

Aturan utama: linear model atau deep learning?

PilihPakai kalauAlasan
Model linearData bisa dipisah garis lurus, data sedikit, atau keputusan harus mudah dijelaskanSederhana, cepat, tidak mudah overfit
Deep learningPolanya tidak lurus (seperti XOR), atau datanya mentah seperti gambar, suara, dan teksHidden layer dan activation bisa membentuk batas yang melengkung dan mempelajari fitur sendiri

Deep learning memakai MLP (Multilayer Perceptron), yaitu jaringan dengan hidden layer di tengah dan activation function non-linear di setiap layer (S1 slide 11).

  1. Hidden layer memindahkan titik ke ruang baru.

    Contoh MLP 2-2-1 untuk lampu tangga, dengan activation step (1 kalau z > 0, 0 kalau tidak).

    Neuron h₁ = step(x₁ + x₂ − 0,5) berperan sebagai OR, dan h₂ = step(x₁ + x₂ − 1,5) berperan sebagai AND.

    Output y = step(h₁ − h₂ − 0,5), artinya "OR tapi bukan AND".

    x₁x₂h₁ (OR)h₂ (AND)h₁ − h₂ − 0,5y
    0000−0,50
    01100,51
    10100,51
    1111−0,50

    Di ruang (h₁, h₂), titik (0,1) dan (1,0) menyatu di (1,0), jadi satu garis cukup, seperti gambar kanan di atas.

    Weight ini disusun manual untuk menunjukkan idenya.

    Saat training, weight dicari otomatis oleh backpropagation.

  2. Activation membuat layer tidak bisa diringkas.

    Kalau step dibuang dari hidden layer, h₁ − h₂ = (x₁ + x₂ − 0,5) − (x₁ + x₂ − 1,5) = 1 untuk semua input.

    Akibatnya output sama untuk keempat input, dan hanya 2 dari 4 yang benar.

  3. Fiturnya dipelajari sendiri, bukan ditebak manusia.

    Model linear sebenarnya bisa menyelesaikan XOR kalau kita menambah fitur buatan x₁x₂, misalnya step(x₁ + x₂ − 2x₁x₂ − 0,5).

    Masalahnya, fitur seperti ini harus ditebak manusia (feature engineering manual).

    Deep learning mempelajari fiturnya sendiri dari data mentah (S1 slide 7).

    Universal Approximation Theorem (S1 slide 12): MLP dengan satu hidden layer bisa mendekati fungsi kontinu apa pun, asal neuronnya cukup.

Template jawaban

Model linear menghitung output dari jumlah berbobot input, z = wᵀx + b, sehingga decision boundary-nya selalu garis lurus. Akibatnya model linear gagal untuk data yang tidak linearly separable, misalnya XOR, karena garis lurus mana pun salah di minimal satu titik. Menambah layer linear juga tidak membantu, karena gabungannya tetap linear. Deep learning mengatasinya dengan hidden layer dan activation function non-linear (misalnya ReLU): hidden layer memindahkan data ke ruang fitur baru yang bisa dipisah, dan fiturnya dipelajari sendiri dari data.

Model training dan evaluation

Topiknya luas, tapi pola soalnya biasanya sama: diberi gejala (grafik loss atau angka), lalu diminta penyebab dan solusinya.

Contoh yang dipakai di seluruh bagian ini: model pendeteksi transaksi fraud, dengan 60 fraud di antara 1.000 transaksi.

Training itu turun gunung dalam kabut

Kamu turun gunung dalam kabut tebal.

Kamu tidak bisa melihat lembah, jadi kamu meraba kemiringan tanah di kaki, lalu melangkah ke arah yang paling menurun.

gunung asli tiga dimensi, sedangkan "gunung" loss punya jutaan dimensi (satu per weight) dan penuh titik datar yang bukan lembah.

Training adalah proses mengubah weight sedikit demi sedikit supaya loss, yaitu ukuran kesalahan model, makin kecil.

Setiap langkah terdiri dari 4 tahap, dan urutannya tidak bisa ditukar.

  1. Forward: model menebak.

    Data mengalir dari layer pertama ke terakhir dengan weight saat ini, dan keluar sebagai prediksi.

    Contoh: model memberi peluang fraud 0,3 untuk sebuah transaksi.

  2. Loss: ukur seberapa salah tebakannya.

    Kalau transaksi itu ternyata fraud, tebakan 0,3 cukup salah, jadi loss-nya besar.

    Tahap ini harus setelah forward, karena loss butuh prediksi.

  3. Backward (backpropagation): cari arah perbaikan.

    Chain rule menghitung gradient, yaitu seberapa besar setiap weight ikut menyebabkan loss (S1 slide 16).

    Tahap ini harus setelah loss, karena gradient adalah turunan dari loss.

  4. Update: geser weight ke arah yang mengecilkan loss.

    Optimizer memakai gradient dari tahap 3.

    Kalau update dilakukan sebelum backward, weight bergerak dengan gradient lama atau kosong.

Kode training loop dari slide 
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for x, y in dataloader:
    pred = model(x)            # 1. forward
    loss = loss_fn(pred, y)    # 2. loss
    loss.backward()            # 3. backward
    optimizer.step()           # 4. update
    optimizer.zero_grad()      # kosongkan gradient untuk batch berikutnya

Tanpa zero_grad(), PyTorch menjumlahkan gradient dari batch sebelumnya, jadi arah update tercampur (perilaku PyTorch ini di luar slide).

Gradient descent: rumus satu langkah

θ ← θ − η ∇L

  • θ: semua weight dan bias.
  • η (learning rate): besar langkah.
  • ∇L (gradient): arah yang membuat loss naik paling cepat.
  • Tanda minus: melangkah berlawanan arah, supaya loss turun.

Contoh: w = 2,0, gradient 0,5, dan η = 0,1, jadi w baru = 2,0 − 0,1 × 0,5 = 1,95.

Learning rate terlalu besar membuat loss melompat-lompat dan makin besar (divergen).

Learning rate terlalu kecil membuat training sangat lambat.

Contoh hitungan: tiga learning rate

Loss L(w) = (w − 3)², jadi minimum ada di w = 3 dan gradient-nya 2(w − 3).

Mulai dari w = 0.

η = 0,1, langkah 1: gradient 2(0 − 3) = −6, jadi w = 0 − 0,1 × (−6) = 0,6.

    Backpropagation mengalikan turunan setiap layer.

Overfitting: bagus di latihan, jelek di ujian

Overfitting adalah kondisi saat model menghafal data training, termasuk noise-nya, sehingga gagal di data baru.

Kayak murid yang hafal kunci jawaban latihan, tapi bingung saat soalnya diganti angka.

Tandanya: training loss terus turun, tapi validation loss naik.

Dropout dan augmentation hanya aktif saat training, karena saat evaluasi model harus melihat data apa adanya.

L = 0,40, λ = 0,01, dan weight w = (2, −1, 3).

Langkah 1. Σ w² = 4 + 1 + 9 = 14.

Langkah 2. Lnew = 0,40 + 0,01 × 14 = 0,54.

Weight 3 menyumbang 9 dari 14, jadi weight terbesar paling "dihukum".

CNN: komponen dan hitungan arsitektur

Kata kisi-kisi: hitungannya di arsitektur, bukan di isi konvolusi.

Jadi kamu tidak perlu mengalikan kernel dengan piksel.

Yang dihitung adalah ukuran output dan jumlah parameter setiap layer.

Contoh yang dipakai: foto angka tulisan tangan MNIST, ukuran 28 × 28 piksel, hitam putih.

Masalahnya: MLP boros dan buta posisi

MLP harus meratakan gambar menjadi satu baris angka (flatten) sebelum diproses (S4 slide 6).

Akibatnya, piksel yang tadinya bertetangga tidak lagi dianggap berdekatan, padahal garis dan sudut terbentuk dari piksel yang bertetangga.

Selain itu, parameternya meledak: foto 224 × 224 RGB punya 150.528 angka, jadi layer pertama dengan 1.000 neuron saja butuh 150.529.000 parameter.

CNN (Convolutional Neural Network) menyelesaikan keduanya dengan kernel kecil yang digeser ke seluruh gambar.

Kernel conv 3 × 3 dengan 64 filter pada foto RGB hanya butuh 1.792 parameter, berapa pun ukuran fotonya.

  1. Convolution: kernel adalah detektor pola yang dipelajari.

    Kernel adalah matriks weight kecil, misalnya 3 × 3, yang digeser di atas gambar.

    Di setiap posisi, kernel menghitung satu angka: seberapa cocok potongan gambar itu dengan pola kernel.

    Output satu kernel disebut feature map, jadi 16 kernel menghasilkan 16 feature map (16 channel).

    Satu kernel selalu menembus semua channel input.

    Kernel 3 × 3 pada input 16 channel sebenarnya berukuran 3 × 3 × 16.

    Layer awal menangkap pola sederhana seperti tepi, layer akhir menangkap bentuk yang lebih kompleks (S4 slide 22).

  2. ReLU: tanpa activation, tumpukan conv tetap linear.

    Sama seperti soal 1, activation membuat tumpukan layer tidak bisa diringkas menjadi satu operasi linear.

  3. Pooling: mengecilkan gambar tanpa belajar apa pun.

    Max pooling 2 × 2 mengambil angka terbesar dari setiap jendela 2 × 2, jadi 28 × 28 menjadi 14 × 14.

    Karena hanya mengambil yang terbesar, geseran kecil pada gambar tidak banyak mengubah hasilnya (translation invariance).

  4. Flatten dan fully connected: dari fitur ke keputusan.

    Setelah beberapa blok, feature map diratakan menjadi C · H · W angka (S4 slide 20), lalu fully connected memutuskan kelasnya.

Rumus ukuran output

Rumus ini dan rumus parameter di bawah tidak ada di slide, tapi semua angka di slide (LeNet-5, VGG, kode 32*7*7) cocok dengan rumus ini.

O = ⌊(I − K + 2P) / S⌋ + 1

  • I: ukuran input (tinggi atau lebar).
  • K: ukuran kernel.
  • P: padding di setiap sisi, jadi total tambahannya 2P.
  • S: stride, besar langkah kernel.
  • ⌊ ⌋: bulatkan ke bawah, karena kernel tidak boleh keluar dari gambar.

Cara membacanya: setelah padding, panjang input menjadi I + 2P, lalu kita menghitung berapa kali kernel bisa melangkah, seperti menghitung tiang pagar.

  • Pooling memakai rumus yang sama. MaxPool2d(2) artinya K = 2, S = 2, P = 0, jadi (28 − 2) / 2 + 1 = 14.
  • Channel output conv = jumlah kernel. Pooling tidak mengubah jumlah channel.
  • Flatten: C × H × W menjadi C · H · W. Contoh: 32 × 7 × 7 menjadi 1.568 angka.

Generative model dan training GAN

Kisi-kisi menekankan prinsip kerja dan training GAN "secara fundamental".

Jadi pahami idenya dulu.

Rumus loss cukup bisa dibaca dan dihitung.

Masalahnya: membuat data yang belum pernah ada

Classifier menjawab pertanyaan "foto ini kucing atau anjing?".

Generative model menjawab tugas yang berbeda: "buatkan foto kucing baru yang belum pernah ada".

Generative model adalah model yang mempelajari sebaran data P(x), sehingga bisa membuat sampel baru yang mirip data training (S7 slide 6).

Kebalikannya, discriminative model hanya mempelajari P(y | x), yaitu label dari sebuah input.

"Mempelajari sebaran" artinya model tahu seperti apa data yang wajar.

Contoh: model yang paham sebaran wajah tahu bahwa mata ada di atas hidung, jadi ia tidak membuat wajah dengan mata di dagu.

  1. GAN: dua network saling melawan.

    Generator membuat data palsu dari noise, discriminator menilai asli atau palsu, dan keduanya makin pintar karena saling mengalahkan.

    Dibahas lengkap di bawah.

  2. VAE: meringkas data menjadi sebaran, lalu membangun ulang.

    Encoder mengubah data menjadi sebaran latent, lalu decoder membangun data dari titik acak di sebaran itu.

    Dibahas di soal 6.

  3. Diffusion: belajar menghapus noise sedikit demi sedikit.

    Forward process: gambar asli diberi noise Gaussian sedikit demi sedikit, sampai menjadi noise murni (S7 slide 21).

    Reverse process: model belajar membalik proses itu, satu langkah demi satu langkah, dari noise kembali ke gambar (S7 slide 22).

    Training: model hanya disuruh menebak noise yang ditambahkan di setiap langkah, dengan loss |ε − εθ|² (S7 slide 23).

    Karena setiap langkahnya kecil dan jelas targetnya, training diffusion stabil dan tahan mode collapse.

GAN: pemalsu uang melawan polisi

Pemalsu uang terus memperbaiki uang palsunya, dan polisi terus belajar membedakan uang asli dari yang palsu.

Keduanya makin hebat karena saling melawan.

polisi sungguhan tidak memberi tahu pemalsu di mana kesalahannya.

Di GAN, discriminator justru mengirim gradient ke generator, yang isinya "ubah bagian ini supaya lebih mirip asli".

GAN (Generative Adversarial Network) adalah dua neural network yang dilatih bergantian dalam permainan dua pemain (Goodfellow, 2014).

  • Generator (G): menerima noise acak z dan membuat sampel palsu G(z), si pemalsu.
  • Discriminator (D): menerima sampel asli atau palsu dan mengeluarkan peluang sampel itu asli (0 sampai 1), si polisi.

Discriminator sebenarnya binary classifier (asli = 1, palsu = 0), tapi berbeda dari classifier biasa:

  • Datanya bergerak. Kelas "palsu" terus berubah karena G terus belajar, sedangkan classifier biasa belajar dari data yang tetap.
  • Perannya pelatih. D biasanya dibuang setelah training, karena yang dipakai adalah G.

Loss D dan loss G

Kedua loss di S7 slide 10 adalah binary cross entropy dengan label yang berbeda.

LD = −E[log D(x)] − E[log(1 − D(G(z)))]

LG = −E[log D(G(z))]

  • D(x): nilai D untuk data asli. D ingin nilainya mendekati 1.
  • D(G(z)): nilai D untuk data palsu. D ingin mendekati 0, G ingin mendekati 1.
  • E[·]: rata-rata satu batch. log artinya ln (logaritma natural, tombol ln di kalkulator).

Karena tujuan D dan G bertolak belakang, slide menyebut objektifnya minimax game.

Proses training: satu iterasi

  1. Ambil satu batch data asli dan satu batch noise.

    G mengubah noise menjadi sampel palsu G(z).

  2. Latih D dulu: asli diberi label 1, palsu diberi label 0.

    Sampel palsu di-detach(), supaya langkah ini hanya mengubah D.

    D dilatih dulu supaya penilaiannya masuk akal sebelum dipakai untuk mengajari G.

    Kalau detach lupa, loss D ikut mengirim gradient ke G, dan arahnya membuat palsu makin mudah dikenali, kebalikan tujuan G.

  3. Latih G: sampel palsu dinilai D, tapi labelnya 1.

    G ingin D menganggap palsunya asli, jadi labelnya 1.

    Gradient mengalir melewati D ke G, tapi hanya weight G yang di-update.

  4. Ulangi, sambil memantau loss, contoh hasil, dan FID.

    Loss saja tidak cukup untuk menilai kualitas gambar (lihat evaluasi di bawah).

Kode training loop (S7 slide 11, dilengkapi) 
for real in dataloader:
    fake = G(torch.randn(batch_size, 100))   # noise ke sampel palsu

    # Langkah 2: train discriminator
    loss_D = loss_fn(D(real), 1) + loss_fn(D(fake.detach()), 0)
    opt_D.zero_grad(); loss_D.backward(); opt_D.step()

    # Langkah 3: train generator
    loss_G = loss_fn(D(fake), 1)              # G ingin D(fake) = 1
    opt_G.zero_grad(); loss_G.backward(); opt_G.step()

Label ditulis 1 dan 0 seperti di slide.

Di kode asli, label berupa tensor, misalnya torch.ones_like(...).

Training yang tepat adalah training yang seimbang

Kalau G sempurna, sampel palsu tidak bisa dibedakan dari yang asli.

Saat itu D hanya bisa menebak seperti lempar koin: D(x) ≈ D(G(z)) ≈ 0,5.

Titik seimbang ini disebut Nash equilibrium, yaitu kondisi saat tidak ada pemain yang bisa menang dengan mengubah strateginya sendirian.

Rumus lengkapnya, D*(x) = pdata(x) / (pdata(x) + pg(x)), dari paper Goodfellow (2014), tidak ada di slide.

Cukup ingat angka 0,5-nya.

Kalau D terlalu kuat, G tidak mendapat sinyal yang berguna.

Kalau D terlalu lemah, G tidak mendapat kritik yang tajam.

  • LeakyReLU, bukan ReLU.

    Gradient tetap mengalir untuk input negatif, jadi sinyal dari D ke G tidak terputus (S7 slide 13).

  • Batch normalization.

    Menjaga sebaran aktivasi setiap layer tetap stabil, jadi training tidak mudah meledak.

  • Tanpa sigmoid di layer terakhir D, pakai BCEWithLogitsLoss.

    Sigmoid dan log dihitung bersama secara stabil, jadi tidak muncul log(0) saat D sangat yakin.

  • Label smoothing dan noise injection.

    Label asli ditulis 0,9, bukan 1, dan input D diberi noise kecil, supaya D tidak terlalu yakin dan tidak terlalu kuat.

  • Varian yang lebih stabil.

    DCGAN: fully connected diganti Conv di D dan ConvTranspose (kebalikan conv, memperbesar ukuran) di G (S7 slide 15).

    Conditional GAN: label kelas ikut menjadi input G dan D, jadi kita bisa meminta "buat digit 3" (S7 slide 17).

    StyleGAN: arsitektur berbasis style dari NVIDIA, untuk wajah fotorealistik (S7 slide 16).

Mengukur hasil: FID dan Inception Score

Loss GAN tidak menunjukkan kualitas gambar, jadi hasilnya dinilai dengan metrik lain (S7 slide 18).

  • FID (Fréchet Inception Distance): makin kecil makin baik. Jarak antara sebaran fitur gambar asli dan gambar palsu.
  • IS (Inception Score): makin besar makin baik. Mengukur realisme dan keragaman.
  • Inspeksi visual tetap perlu, misalnya untuk melihat mode collapse.

Keduanya memakai classifier yang sudah dilatih (Inception) untuk mengubah gambar menjadi fitur.

Loss: kenapa MSE berbeda dari MAE

  • MSE = (1/n) Σ (y − ŷ)²: error besar dihukum jauh lebih berat.
  • MAE = (1/n) Σ |y − ŷ|: lebih tahan outlier.
  • BCE = −[y ln ŷ + (1 − y) ln(1 − ŷ)]: tebakan yakin tapi salah dihukum sangat berat.
  • Cross entropy = −ln(peluang kelas yang benar).

  1. Untuk gambar, MLP buta posisi dan boros.

    Gambar harus di-flatten, jadi piksel bertetangga tidak lagi dianggap berdekatan (S4 slide 6).

  2. Parameter banyak dan data sedikit membuat MLP menghafal.

    Tandanya training loss turun tapi validation loss naik, solusinya ada di soal 2.

  3. Data tidak seimbang membuat MLP condong ke kelas mayoritas.

    Di kasus bank, model yang selalu menebak "lancar" sudah mendapat accuracy 95% (S3 slide 24).

    Class weight: kesalahan di kelas minoritas diberi bobot lebih besar, misalnya sekitar 19 untuk gagal bayar (perbandingan 95 : 5).

  4. Fitur dengan skala besar mendominasi.

    Penghasilan (jutaan rupiah) jauh lebih besar dari umur (puluhan), jadi tanpa normalisasi gradient didominasi penghasilan.

  5. MLP tidak punya "ingatan" urutan.

    Untuk data seperti harga saham, MLP hanya melihat satu vektor tanpa urutan, jadi data masa lalu harus dimasukkan manual sebagai fitur.

  6. Keputusan MLP sulit dijelaskan.

    Bank biasanya wajib menjelaskan alasan penolakan kredit, padahal keputusan MLP tersebar di ribuan weight.

Studi kasus autoencoder

Catatan dosen: justifikasi bentuk arsitektur yang dipilih.

Bentuknya tidak harus simetris, dan latent boleh lebih besar dari input asal memakai sparse autoencoder, bukan vanilla.

Masalahnya: meringkas tanpa label

Bayangkan kamu meringkas satu bab buku menjadi catatan satu halaman, lalu menulis ulang bab itu hanya dari catatanmu.

Kalau tulisan ulangnya mirip aslinya, berarti catatanmu memuat hal yang paling penting.

Batas analogi: autoencoder tidak "mengerti" isinya.

Ia hanya menyimpan informasi yang paling mengurangi error rekonstruksi, dan hanya bekerja baik untuk data yang mirip data training.

Autoencoder adalah neural network unsupervised yang belajar merekonstruksi input-nya sendiri (S6 slide 6).

  • Encoder: meringkas input x menjadi vektor latent z, si catatan.
  • Latent (bottleneck): representasi ringkas di tengah.
  • Decoder: membangun ulang x̂ dari z.

Loss-nya adalah reconstruction error, misalnya MSE: L = (1/n) Σ (x − x̂)².

Targetnya input itu sendiri, jadi autoencoder tidak butuh label.

Contoh S6 slide 12 untuk MNIST: 784-128-32-128-784, yaitu 784 piksel diringkas menjadi 32 angka, kompresi 784 / 32 = 24,5 kali.

Layer terakhir memakai Sigmoid, karena piksel sudah dinormalisasi ke rentang 0 sampai 1 (S6 slide 30–31).

Jumlah parameternya (784 + 1) · 128 + (128 + 1) · 32 + (32 + 1) · 128 + (128 + 1) · 784 = 209.968.

Memilih tipe autoencoder

Aturan utama: kasus apa, tipe apa?

KasusTipeAlasan
Deteksi anomali (mesin rusak, fraud), data normal banyakVanilla undercompleteDilatih hanya dengan data normal, jadi data aneh direkonstruksi buruk dan error-nya tinggi
Kompresi, visualisasi (latent 2), pencarian gambar miripVanilla undercompleteLatent kecil memaksa model menyimpan pola penting saja
Membersihkan noise di foto, scan, atau X-rayDenoisingInput diberi noise, target tetap bersih, jadi model belajar membuang noise
Membuat data baru, interpolasi halusVAELatent berupa sebaran yang rapat, jadi titik acak menghasilkan data yang masuk akal
Fitur yang mudah ditafsirkan, latent lebih besar dari inputSparsePenalti membuat hanya sedikit neuron aktif, jadi setiap neuron menjadi detektor pola tertentu
  1. Vanilla (undercomplete): latent lebih kecil dari input.

    Bentuknya jam pasir: makin ke tengah makin kecil, lalu membesar lagi (S6 slide 11).

    Karena latent-nya sempit, model terpaksa membuang detail yang tidak penting.

  2. Denoising: input kotor, target bersih.

    Saat training, input diberi noise buatan, tapi target tetap gambar yang bersih (S6 slide 15–16).

    Hasilnya model yang bisa membersihkan noise, dan fiturnya lebih tahan gangguan.

  3. Sparse: hanya sedikit neuron latent yang boleh aktif.

    Loss ditambah penalti: Ltotal = Lreconstruction + λ |z|₁ (S6 slide 19).

    Setiap neuron yang aktif "mahal", jadi model hanya menyalakan neuron yang benar-benar perlu.

  4. VAE: latent berupa sebaran, bukan satu titik.

    Encoder mengeluarkan rata-rata μ dan simpangan σ, lalu z diambil acak: z = μ + σ · ε, dengan ε dari N(0, 1) (S6 slide 22).

    Loss = reconstruction + KL divergence, dan KL memaksa sebaran latent mendekati N(0, 1), jadi latent space rapat tanpa lubang (S6 slide 23).

    Setelah training, z acak dari N(0, 1) dimasukkan ke decoder untuk membuat data baru.

Menentukan bentuk arsitektur

Ini inti catatan dosen: setiap keputusan bentuk harus punya alasan.

Aturan utama: empat keputusan bentuk

KeputusanPilihanAlasan
Ukuran latentLebih kecil dari input (undercomplete), atau lebih besar (overcomplete) hanya dengan sparseLatent kecil memaksa kompresi. Latent besar tanpa batasan membuat model cukup menyalin input
Simetris atau tidakSimetris umum dipakai, tapi tidak wajibLihat contoh bentuk asimetris di bawah
Fully connected atau convData tabular atau sensor: Linear. Gambar: Conv di encoder, ConvTranspose di decoderConv menjaga struktur spasial dan jauh lebih hemat parameter (soal 3)
Output dan lossData 0 sampai 1: Sigmoid + MSE atau BCE. Data standardisasi (bisa negatif): tanpa activation + MSERange output harus sama dengan range input, karena targetnya input itu sendiri
  • Vanilla overcomplete gagal: model cukup menyalin input.

    Dengan 256 neuron untuk 64 angka input, jaringan bisa meneruskan input apa adanya, dan loss-nya hampir nol tanpa belajar pola apa pun (S6 slide 31).

    Untuk deteksi anomali, model seperti ini ikut merekonstruksi anomali dengan baik, jadi anomalinya tidak terdeteksi.

  • Sparse overcomplete berhasil: menyalin input jadi mahal.

    Menyalin input butuh banyak neuron aktif, padahal setiap neuron aktif menambah penalti λ |z|₁.

    Contoh dengan λ = 0,001 dan reconstruction loss yang sama, 0,020: latent sparse dengan |z|₁ = 2,5 memberi loss 0,0225, sedangkan latent padat dengan |z|₁ = 40 memberi 0,060.

    Jadi training mendorong model ke latent yang sparse.

  • Bentuk asimetris boleh, asal ada alasannya.

    Decoder ringan: kalau yang dipakai nanti hanya encoder (misalnya sebagai fitur untuk model lain), decoder sederhana memaksa encoder membuat latent yang kaya.

    Decoder lebih berat: kalau output-nya rumit, misalnya gambar resolusi tinggi, decoder butuh kapasitas lebih.

    VAE: encoder berakhir di dua kepala (μ dan σ), sedangkan decoder hanya menerima satu z.

    Contoh alasan asimetris ini dirangkum dari luar slide, karena slide hanya menyebut "typically symmetric".

  • Kecilkan ukuran bertahap.

    Misalnya 784, 256, 64, lalu 16, bukan langsung 784 ke 2, supaya informasi tidak hilang di satu layer.

Deteksi anomali: memilih threshold

Slide hanya menyebut "anomali = reconstruction error tinggi" (S6 slide 9).

Cara memilih batasnya (di luar slide):

  1. Latih autoencoder hanya dengan data normal.
  2. Hitung reconstruction error di data validasi yang juga normal.
  3. Tentukan threshold, misalnya rata-rata + 3 × simpangan baku.
  4. Tandai data baru dengan error di atas threshold sebagai anomali.
