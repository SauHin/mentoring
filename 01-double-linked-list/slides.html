Double linked list

Struktur data · list yang bisa ditelusuri maju dan mundur

Ingat lagi: single linked list

  • Setiap node hanya tahu node sesudahnya.
  • Mundur satu langkah berarti mulai lagi dari head: O(n).
  • Untuk menghapus node, kita butuh node sebelumnya, padahal node itu tidak tersimpan.

Idenya: tambah satu pointer

  • Setiap node menyimpan prev (node sebelumnya) dan next (node sesudahnya).
  • prev milik node pertama dan next milik node terakhir bernilai null (garis miring).
  • Kita menyimpan head dan tail, jadi kedua ujung bisa diakses langsung.

Struktur node

struct Node {
    int data;
    Node* prev;
    Node* next;
};

Node* head = nullptr;
Node* tail = nullptr;
int size = 0;
  • Satu node = data + dua pointer.
  • List kosong: head dan tail sama-sama nullptr.
  • List satu node: head dan tail menunjuk node yang sama.
  • Harga yang dibayar: satu pointer tambahan per node.

Tambah di depan

void insertFront(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (head == nullptr) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}
  1. Node baru menunjuk head lama lewat next.
  2. Head lama menunjuk balik lewat prev.
  3. Baru setelah itu, pindahkan head.
  4. Kalau head dipindah lebih dulu, kita kehilangan alamat node lama.

Tambah di belakang

void insertBack(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (tail == nullptr) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}
  • Kebalikan dari tambah di depan: tukar next dengan prev, dan head dengan tail.
  • Karena ada tail, operasi ini O(1). Tanpa tail, kita harus berjalan sampai ujung dulu.

Sisip di tengah: empat pointer

Node* cur = head;
for (int i = 0; i < pos; i++)
    cur = cur->next;
Node* newNode = new Node{x, nullptr, nullptr};
newNode->next = cur;
newNode->prev = cur->prev;
cur->prev->next = newNode;
cur->prev = newNode;
  1. Jalan sampai cur, yaitu node di posisi pos.
  2. Sambungkan node baru dulu: next ke cur, prev ke node sebelum cur.
  3. Lalu node sebelum cur menunjuk node baru.
  4. cur->prev diubah paling akhir, karena langkah 2 dan 3 masih memakai nilai lamanya.

Hapus node: lewati dari dua arah

if (del->prev != nullptr)
    del->prev->next = del->next;
else
    head = del->next;
if (del->next != nullptr)
    del->next->prev = del->prev;
else
    tail = del->prev;
delete del;
  • Node sebelum del melompati del lewat next.
  • Node sesudah del melompati del lewat prev.
  • Kalau del ada di ujung, yang berpindah adalah head atau tail.
  • Kalau kita sudah punya pointer ke del, hapus cukup O(1). Kita tidak perlu mencari node sebelumnya.

Dipakai di mana?

  • Tombol kembali dan maju di browser.
  • Undo dan redo di editor teks.
  • Playlist musik: lagu sebelumnya dan lagu berikutnya.
  • LRU cache: memindahkan dan menghapus item di tengah list dalam O(1).
  • std::list di C++ adalah double linked list.

Ringkasan

  • Double linked list = single linked list + pointer prev + pointer tail.
  • Bisa ditelusuri maju dan mundur, dan menghapus node yang sudah ditunjuk cukup O(1).
  • Setiap sambungan punya dua sisi. Ubah next dan prev berpasangan.
  • Selalu cek kasus tepi: list kosong, satu node, head, dan tail.
