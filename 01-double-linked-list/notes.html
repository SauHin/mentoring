Double linked list

Linked list yang setiap node-nya tahu node sebelum dan sesudahnya, jadi list bisa ditelusuri maju dan mundur.

Buka slide · Visualisasi operasi · Visualisasi riwayat browser

Tujuan

Setelah sesi ini, kamu bisa:

  • menjelaskan perbedaan single linked list dan double linked list,
  • menulis operasi tambah, sisip, hapus, cari, dan telusuri dalam C++,
  • menangani kasus tepi: list kosong, satu node, node pertama, dan node terakhir,
  • membandingkan kompleksitas double linked list dengan array dan single linked list.

1. Masalah pada single linked list

Di single linked list, setiap node hanya menyimpan pointer next. Akibatnya ada dua hal yang lambat:

  • Mundur. Untuk pindah ke node sebelumnya, kita harus mulai lagi dari head. Itu O(n).
  • Menghapus node. Untuk menghapus node X, kita harus mengubah next milik node sebelum X. Node itu tidak kita ketahui, jadi kita harus mencarinya dari head.

2. Apa itu double linked list

Double linked list (disebut juga doubly linked list) adalah linked list yang setiap node-nya punya dua pointer:

  • prev: menunjuk node sebelumnya. Untuk node pertama, nilainya nullptr.
  • next: menunjuk node sesudahnya. Untuk node terakhir, nilainya nullptr.

Kita juga menyimpan dua pointer ke ujung list: head (node pertama) dan tail (node terakhir).

Aturan yang selalu benar: untuk dua node A dan B yang bersebelahan, A->next == B jika dan hanya jika B->prev == A.

Aturan di atas adalah alat cek utama. Setiap kali kamu mengubah satu sisi sambungan, sisi lainnya juga harus diubah.

3. Struktur node

struct Node {
    int data;
    Node* prev;
    Node* next;
};

Node* head = nullptr;
Node* tail = nullptr;
int size = 0;

Di catatan ini, head, tail, dan size dibuat global supaya kodenya pendek. Di proyek nyata, ketiganya biasanya menjadi anggota sebuah class.

4. Operasi

Coba setiap operasi di visualisasi operasi sambil membaca bagian ini. Visualisasi itu memakai kode yang sama persis.

4.1 Tambah di depan

void insertFront(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (head == nullptr) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}

Kalau list kosong, node baru menjadi head dan tail sekaligus. Kalau tidak kosong, sambungkan node baru ke head lama dari dua arah, lalu pindahkan head.

Urutan penting. Kalau head = newNode dijalankan lebih dulu, baris head->prev = newNode akan membuat node baru menunjuk dirinya sendiri, dan head lama tidak pernah mendapat prev.

4.2 Tambah di belakang

void insertBack(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (tail == nullptr) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

Operasi ini adalah cermin dari tambah di depan: head ditukar dengan tail, dan next ditukar dengan prev. Karena kita menyimpan tail, operasi ini O(1).

4.3 Sisip di posisi tertentu

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;
    Node* newNode = new Node{x, nullptr, nullptr};
    newNode->next = cur;
    newNode->prev = cur->prev;
    cur->prev->next = newNode;
    cur->prev = newNode;
    size++;
}

Posisi dihitung dari 0. Node baru masuk tepat sebelum cur, jadi setelah disisipkan, node baru berada di posisi pos. Fungsi ini mengandaikan bahwa 0 <= pos <= size.

Ada empat pointer yang berubah. Dua yang pertama hanya mengisi pointer milik node baru, jadi aman. Dua yang terakhir mengubah list. cur->prev harus diubah paling akhir, karena baris sebelumnya masih membutuhkan nilai lamanya untuk menemukan node sebelum cur.

Di tengah list, cur->prev tidak pernah null, karena kasus pos == 0 sudah ditangani di awal.

4.4 Hapus di posisi tertentu

void deleteAt(int pos) {
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != nullptr)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != nullptr)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    delete del;
    size--;
}

Fungsi ini mengandaikan bahwa 0 <= pos < size. Ide utamanya: node sebelum del dan node sesudah del saling menunjuk, sehingga del terlewati dari dua arah.

Dua if di atas menangani semua kasus tepi sekaligus:

Kalau kita sudah memegang pointer ke node yang mau dihapus, kita tidak perlu loop pencarian. Hapus menjadi O(1). Ini keunggulan utama double linked list dibandingkan single linked list.

4.5 Cari nilai

Node* search(int x) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return nullptr;
}

Sama seperti single linked list: cek node satu per satu dari head. Kompleksitasnya O(n).

4.6 Telusuri maju dan mundur

void printForward() {
    Node* cur = head;
    while (cur != nullptr) {
        std::cout << cur->data << " ";
        cur = cur->next;
    }
}

void printBackward() {
    Node* cur = tail;
    while (cur != nullptr) {
        std::cout << cur->data << " ";
        cur = cur->prev;
    }
}

Telusuri mundur hanya bisa dilakukan dengan cepat karena ada tail dan prev. Cetak maju lalu cetak mundur juga cara mudah untuk mengecek apakah pointer prev sudah benar. Hasil keduanya harus saling terbalik.

Di single linked list, menghapus node terakhir tetap O(n) walaupun ada tail. Alasannya, tail baru harus menjadi node sebelum tail lama, dan node itu harus dicari dari head.

6. Kesalahan yang sering terjadi

  • Hanya mengubah satu arah. next diubah, tetapi prev pasangannya lupa diubah. Cetak maju terlihat benar, tetapi cetak mundur salah.
  • Urutan salah. Pointer diubah sebelum nilai lamanya selesai dipakai. Contoh: cur->prev = newNode dijalankan sebelum cur->prev->next = newNode.
  • Lupa kasus tepi. Menulis del->prev->next tanpa mengecek apakah del->prev null. Program crash saat menghapus node pertama.
  • Lupa memindahkan head atau tail. Setelah menghapus node terakhir, tail masih menunjuk memori yang sudah di-delete (dangling pointer).
  • Lupa delete. Node dilepas dari list tetapi tidak dihapus dari memori (memory leak).

7. Penerapan

  • Tombol kembali dan maju di browser. Coba di visualisasi riwayat browser.
  • Undo dan redo di editor.
  • Playlist musik dengan tombol lagu sebelumnya dan berikutnya.
  • LRU cache (cache yang membuang item yang paling lama tidak dipakai). Item dipindah ke depan atau dihapus dari tengah dalam O(1).
  • std::list di C++ adalah double linked list.

8. Program lengkap

Lihat program lengkap 
#include <iostream>

struct Node {
    int data;
    Node* prev;
    Node* next;
};

Node* head = nullptr;
Node* tail = nullptr;
int size = 0;

void insertFront(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (head == nullptr) {
        head = tail = newNode;
    } else {
        newNode->next = head;
        head->prev = newNode;
        head = newNode;
    }
    size++;
}

void insertBack(int x) {
    Node* newNode = new Node{x, nullptr, nullptr};
    if (tail == nullptr) {
        head = tail = newNode;
    } else {
        newNode->prev = tail;
        tail->next = newNode;
        tail = newNode;
    }
    size++;
}

void insertAt(int pos, int x) {
    if (pos == 0) { insertFront(x); return; }
    if (pos == size) { insertBack(x); return; }
    Node* cur = head;
    for (int i = 0; i < pos; i++)
        cur = cur->next;
    Node* newNode = new Node{x, nullptr, nullptr};
    newNode->next = cur;
    newNode->prev = cur->prev;
    cur->prev->next = newNode;
    cur->prev = newNode;
    size++;
}

void deleteAt(int pos) {
    Node* del = head;
    for (int i = 0; i < pos; i++)
        del = del->next;
    if (del->prev != nullptr)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != nullptr)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    delete del;
    size--;
}

Node* search(int x) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == x)
            return cur;
        cur = cur->next;
    }
    return nullptr;
}

void printForward() {
    Node* cur = head;
    while (cur != nullptr) {
        std::cout << cur->data << " ";
        cur = cur->next;
    }
    std::cout << "\n";
}

void printBackward() {
    Node* cur = tail;
    while (cur != nullptr) {
        std::cout << cur->data << " ";
        cur = cur->prev;
    }
    std::cout << "\n";
}

int main() {
    insertBack(20);
    insertBack(30);
    insertFront(10);
    insertAt(2, 25);
    printForward();       // 10 20 25 30
    printBackward();      // 30 25 20 10

    deleteAt(0);          // hapus 10
    deleteAt(size - 1);   // hapus 30
    printForward();       // 20 25

    std::cout << (search(25) != nullptr ? "25 ketemu" : "25 tidak ada") << "\n";

    while (head != nullptr)   // kosongkan list supaya tidak ada memory leak
        deleteAt(0);
    return 0;
}

9. Latihan

  1. Mulai dari list kosong, jalankan insertBack(5), insertFront(3), insertAt(1, 4), lalu deleteAt(0). Tulis isi list, head, dan tail setelah setiap langkah.
Lihat jawaban 1

[5] → [3, 5] → [3, 4, 5] → [4, 5]. Di akhir, head menunjuk 4 dan tail menunjuk 5.

  1. Di insertFront, apa yang terjadi kalau urutan head->prev = newNode dan head = newNode ditukar?
Lihat jawaban 2

Setelah head = newNode, baris head->prev = newNode sama dengan newNode->prev = newNode. Node baru menunjuk dirinya sendiri sebagai prev, dan head lama tetap punya prev == nullptr. Cetak maju masih benar, tetapi cetak mundur berhenti di head lama.

  1. Tulis fungsi reverse() yang membalik urutan list tanpa membuat node baru.
Lihat jawaban 3 
void reverse() {
    Node* cur = head;
    while (cur != nullptr) {
        Node* tmp = cur->next;
        cur->next = cur->prev;
        cur->prev = tmp;
        cur = tmp;
    }
    Node* tmp = head;
    head = tail;
    tail = tmp;
}

Setiap node cukup menukar prev dan next. Setelah itu, tukar head dan tail. Kompleksitasnya O(n).

  1. Tulis fungsi bool deleteValue(int x) yang menghapus node pertama bernilai x. Kembalikan false kalau x tidak ada.
Lihat jawaban 4 
bool deleteValue(int x) {
    Node* del = search(x);
    if (del == nullptr) return false;
    if (del->prev != nullptr)
        del->prev->next = del->next;
    else
        head = del->next;
    if (del->next != nullptr)
        del->next->prev = del->prev;
    else
        tail = del->prev;
    delete del;
    size--;
    return true;
}

Bagian hapusnya sama dengan deleteAt. Yang berbeda hanya cara menemukan del.

  1. Tulis fungsi Node* getNode(int i) yang mengambil node di posisi i. Kalau i lebih dekat ke ujung belakang, mulai dari tail.
Lihat jawaban 5 
Node* getNode(int i) {
    if (i < size / 2) {
        Node* cur = head;
        for (int k = 0; k < i; k++)
            cur = cur->next;
        return cur;
    }
    Node* cur = tail;
    for (int k = size - 1; k > i; k--)
        cur = cur->prev;
    return cur;
}

Kompleksitasnya tetap O(n), tetapi jumlah langkahnya paling banyak sekitar n/2. std::list tidak punya akses indeks langsung karena alasan yang sama.
