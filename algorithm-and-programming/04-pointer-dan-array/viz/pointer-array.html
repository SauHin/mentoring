Pointer dan array di memory

Visualisasi ini menggambar pointer sebagai panah biru ke kotak yang alamatnya ia simpan, dan array sebagai kotak berderet dengan alamat berurutan. Ukuran mengikuti Dev-C++: int 4 byte, pointer 8 byte.

Coba: pilih program di menu Program, lalu klik Langkah berikutnya.

Perhatikan: alamat di bawah setiap kotak, dan ke mana panah pointer menunjuk.
