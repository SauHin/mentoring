Pointer dan array

Algorithm and programming · kotak yang isinya alamat kotak lain

Pointer = kotak berisi alamat

int i = 7;
int *ptr;
ptr = &i;
*ptr = 5;     // i jadi 5

   ptr              i
┌────────┐      ┌─────┐
│ 0x1000 │ ───▶ │  5  │
└────────┘      └─────┘
  0x1008         0x1000
  • &i = ambil alamat i
  • *ptr = ikuti alamat di ptr
  • Belum diisi = menunjuk sampah. Pakai NULL.

Array = kotak berderet

int A[5] = {10, 20, 30, 40, 50};

 index:   [0]    [1]    [2]    [3]    [4]
        │  10  │  20  │  30  │  40  │  50  │
 alamat: 0x1000 0x1004 0x1008 0x100c 0x1010
  • Index mulai 0, terakhir = ukuran − 1.
  • int B[8] = {1, 2}; → sisanya otomatis 0.
  • A = {…} setelah deklarasi → error. Isi dengan loop.

A[i] = *(A + i): turunkan sendiri

  1. A = alamat elemen pertama (&A[0]).
  2. A + i = maju i elemen (otomatis × 4 byte untuk int).
  3. *(A + i) = isi elemen ke-i = A[i].
Catatan slide kuliah"ptr is a pointer constant": yang tepat, ptr adalah pointer variable. Yang konstan adalah nama array.

Index di luar batas: lolos compile!

int A[3] = {1, 2, 3};
int x = 99;
A[3] = 7;      // index valid: 0, 1, 2
printf("%d", x);
  • C tidak memeriksa batas array.
  • Tidak ada error. Nilai 7 menimpa memory lain, misalnya x.
  • Disebut undefined behavior: lebih berbahaya dari error.

Coba sendiri: pointer & array di memory

Array 2D: tetap satu deret

int B[3][3] = {{1, 2},
               {3, 4, 5},
               {7}};

B: {1, 2, 0}
   {3, 4, 5}
   {7, 0, 0}
  • Setiap { } = satu baris, sisanya 0.
  • Di memory: baris 0, lalu baris 1, … (row-major).
  • Posisi a[i][j] = i × kolom + j.
  • Proses dengan nested loop: luar = baris, dalam = kolom.

String = array char + '\0'

char s[] = "BiNus";
// = {'B','i','N','u','s','\0'}  → 6 kotak

int n = 0;
while (s[n] != '\0')
    n++;            // n = 5 = strlen
  • 'A' = 1 karakter. "A" = 2 byte ('A' + '\0').
  • Fungsi string bekerja sampai '\0'.
  • name = "Amir"; → error. Pakai strcpy.
  • Bandingkan string: strcmp(a, b) == 0, bukan ==.

Ringkasan

  • & = ambil alamat, * = ikuti alamat.
  • Array = kotak berderet. A[i] = *(A + i).
  • C tidak memeriksa batas array. Kamu yang harus menjaga index.
  • String = array char + '\0'.
