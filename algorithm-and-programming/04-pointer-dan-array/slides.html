Pointer dan array

Algorithm and programming · pointer adalah kotak yang isinya alamat kotak lain.

Pointer = kotak berisi alamat

Variabel biasa menyimpan nilai. Pointer menyimpan alamat variabel lain, sehingga pointer bisa membaca dan mengubah variabel itu.

int i = 7;
int *ptr;
ptr = &i;
*ptr = 5;     // i menjadi 5

   ptr              i
┌────────┐      ┌─────┐
│ 0x1000 │ ───▶ │  5  │
└────────┘      └─────┘
  0x1008         0x1000
  • &i artinya ambil alamat i. Di sini hasilnya 0x1000.
  • *ptr artinya ikuti alamat yang disimpan ptr, lalu pakai kotak di sana. Jadi *ptr = 5 mengubah i.
  • Pointer yang belum diisi menunjuk ke alamat acak. Isi dengan NULL kalau belum ada alamat yang dituju.

Tiga arti tanda *

Tanda * punya arti berbeda tergantung tempatnya. Lihat posisinya untuk menentukan artinya.

Pointer ke pointer: int **pp menyimpan alamat sebuah pointer. **pp berarti ikuti 2 panah. Jumlah * sama dengan jumlah panah yang diikuti.

Array = kotak berderet

Array adalah sekumpulan kotak bertipe sama yang disimpan berurutan di memory. Setiap kotak diakses lewat index.

int A[5] = {10, 20, 30, 40, 50};

 index:   [0]    [1]    [2]    [3]    [4]
        │  10  │  20  │  30  │  40  │  50  │
 alamat: 0x1000 0x1004 0x1008 0x100c 0x1010
  • Index mulai dari 0, jadi index terakhir = ukuran − 1. Alamatnya naik 4 byte karena setiap int berukuran 4 byte.
  • int B[8] = {1, 2}; mengisi dua elemen pertama. Sisanya otomatis 0.
  • A = {…} setelah deklarasi menghasilkan error. Isi elemen satu per satu, biasanya dengan loop.

A[i] = *(A + i): turunkan sendiri

Notasi index sebenarnya adalah operasi pointer. Tiga langkah ini menjelaskan alasannya.

  1. Nama array A berisi alamat elemen pertama, yaitu &A[0].
  2. A + i maju sebanyak i elemen, bukan i byte. Untuk int, alamatnya otomatis bertambah i × 4 byte.
  3. *(A + i) mengikuti alamat itu, jadi hasilnya isi elemen ke-i, sama dengan A[i].
Catatan untuk slide kuliahSlide menyebut "ptr is a pointer constant". Yang tepat, ptr adalah pointer variable: isinya boleh diganti. Yang konstan adalah nama array, karena alamatnya tidak bisa diubah.

Index out of bounds: lolos compile!

C tidak memeriksa apakah index masih di dalam batas array. Kesalahan index tidak memunculkan error.

int A[3] = {1, 2, 3};
int x = 99;
A[3] = 7;      // index valid hanya 0, 1, 2
printf("%d", x);
  • A[3] berada tepat setelah array. Nilai 7 ditulis ke memory milik variabel lain, misalnya x.
  • Program tetap jalan, tapi hasilnya bisa salah atau crash. Ini disebut undefined behavior, dan lebih berbahaya dari error karena tidak terlihat.

Slide kuliah menandai arr1[10] = 12 sebagai "error". Kenyataannya kode itu lolos compile di Dev-C++.

Coba sendiri: pointer dan array di memory

Array 2D: tetap satu deret di memory

Array 2D terlihat seperti tabel, tapi di memory tetap disimpan berderet, baris demi baris.

int B[3][3] = {{1, 2},
               {3, 4, 5},
               {7}};

B: {1, 2, 0}
   {3, 4, 5}
   {7, 0, 0}
  • Setiap { } mengisi satu baris. Elemen yang tidak diisi menjadi 0.
  • Di memory, baris 0 disimpan dulu, lalu baris 1, dan seterusnya (row-major).
  • Karena itu a[i][j] berada di urutan ke i × jumlah kolom + j.
  • Proses array 2D dengan nested loop: loop luar untuk baris, loop dalam untuk kolom.

String = array char + '\0'

C tidak punya tipe string. String adalah array char yang diakhiri karakter '\0' sebagai penanda akhir.

char s[] = "BiNus";
// = {'B','i','N','u','s','\0'}  → 6 kotak

int n = 0;
while (s[n] != '\0')
    n++;            // n = 5, sama dengan strlen
  • 'A' adalah satu karakter. "A" adalah string 2 byte: 'A' dan '\0'.
  • Semua fungsi string bekerja sampai bertemu '\0'. Tanpa '\0', fungsi itu terus membaca memory di luar array.
  • name = "Amir"; menghasilkan error, karena nama array tidak bisa diisi ulang. Pakai strcpy(name, "Amir").
  • Bandingkan string dengan strcmp(a, b) == 0. a == b hanya membandingkan alamat.

Ringkasan

  • & artinya ambil alamat, * artinya ikuti alamat.
  • Array adalah kotak berderet, dan A[i] sama dengan *(A + i).
  • C tidak memeriksa batas array. Kamu sendiri yang harus menjaga index tetap valid.
  • String adalah array char yang diakhiri '\0'. Salin dengan strcpy, bandingkan dengan strcmp.
