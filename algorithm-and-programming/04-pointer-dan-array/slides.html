Pointer dan array

Algorithm and programming · materi 04

Target: kamu bisa menggambar isi memory untuk kode pointer, array, dan string, lalu menebak output-nya. Pointer hanyalah kotak yang isinya alamat kotak lain.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Pointer

Pointer menyimpan alamat, jadi bisa mengubah variabel lain lewat alamat itu

Pointer adalah variabel yang isinya alamat variabel lain. Alamatnya diambil dengan &, seperti di scanf.

int i = 7;
int *ptr;
ptr = &i;     // ptr menunjuk i
*ptr = 5;     // i menjadi 5

Pointer yang belum diisi menunjuk ke alamat acak. Isi dengan NULL kalau belum ada alamat yang dituju.

Notes 2️⃣ · Tanda *

Arti tanda * ditentukan oleh posisinya

Dereference adalah mengikuti alamat di pointer untuk memakai kotak di sana, ditulis *ptr.

TempatContohArti

Ringkasnya: & = ambil alamat, * di depan pointer = ikuti alamat.

Notes 3️⃣ · Pointer ke pointer

Jumlah * sama dengan jumlah panah yang diikuti

Pointer ke pointer menyimpan alamat pointer lain. Pointer juga kotak, jadi punya alamat sendiri.

int i, *ptr, **ptr_ptr;
ptr = &i;          // ptr menunjuk i
ptr_ptr = &ptr;    // ptr_ptr menunjuk ptr
**ptr_ptr = 9;     // ikuti 2 panah: ptr_ptr → ptr → i, jadi i = 9
  • *ptr_ptr (satu bintang) = kotak ptr, yang isinya alamat i.
  • Pola ini dipakai fungsi yang perlu mengubah pointer, misalnya head di linked list.

Notes 4️⃣ · Array

Array adalah kotak bertipe sama yang berderet, dengan index mulai dari 0

Array adalah sekumpulan kotak bertipe sama yang disimpan berurutan dan diakses lewat index.

  • Index terakhir = ukuran − 1. int B[8] = {1, 2}; mengisi dua elemen pertama, sisanya otomatis 0.
  • A = {…} setelah deklarasi menghasilkan error. Isi elemen satu per satu dengan loop.

Notes 5️⃣ · A[i] = *(A + i)

Notasi A[i] hanyalah singkatan dari *(A + i)

Aritmetika pointer menambah pointer dengan bilangan bulat, dan satuannya elemen, bukan byte.

  1. Nama array A adalah alamat elemen pertama, yaitu &A[0].
  2. A + i maju i elemen. Untuk int, alamatnya otomatis bertambah i × 4 byte.
  3. *(A + i) mengikuti alamat itu, jadi hasilnya isi elemen ke-i, sama dengan A[i].

Contoh dengan array di slide sebelumnya: *(A + 2) = isi alamat 0x1000 + 2 × 4 = 0x1008 = 30.

Notes 7️⃣ · Index di luar batas

Index di luar batas lolos compile, lalu diam-diam merusak memory

Undefined behavior adalah perilaku yang tidak diatur standar C, jadi hasilnya bisa berbeda di setiap komputer.

int A[3] = {1, 2, 3};
int x = 99;
A[3] = 7;      // index valid hanya 0, 1, 2
printf("%d", x);
  • A[3] berada tepat setelah array. Nilai 7 bisa menimpa variabel lain, misalnya x.
  • C tidak memeriksa batas array, jadi kamu sendiri yang harus menjaga index tetap 0 sampai ukuran − 1.

Slide kuliah menandai arr1[10] = 12 sebagai error. Kenyataannya kode itu lolos compile di Dev-C++.

Notes 8️⃣ · Array 2D

Array 2D tetap satu deret di memory, disimpan baris demi baris

Row-major artinya baris 0 disimpan seluruhnya dulu, lalu baris 1, dan seterusnya.

int B[3][3] = {{1, 2},
               {3, 4, 5},
               {7}};

B: {1, 2, 0}
   {3, 4, 5}
   {7, 0, 0}
  • Setiap { } mengisi satu baris. Elemen yang tidak diisi menjadi 0.
  • a[i][j] ada di posisi i × jumlah_kolom + j dari awal.
  • Proses dengan nested loop: loop luar untuk baris, loop dalam untuk kolom.

Notes 9️⃣ · Array of pointer

Array of pointer menyimpan deretan alamat, bukan deretan nilai

Array of pointer adalah array yang setiap elemennya pointer.

int x = 1, y = 2, z = 3;
int *ptr[3] = {&x, &y, &z};
for (int i = 0; i < 3; i++) printf("%d ", *ptr[i]);   // 1 2 3
  • *ptr[i]: ambil elemen ke-i (sebuah alamat), lalu ikuti alamat itu.
  • *ptr[1] = 20; mengubah y menjadi 20.

Notes 10 · String

String adalah array char yang diakhiri '\0', jadi butuh satu kotak tambahan

Null character '\0' adalah karakter bernilai 0 yang menandai akhir string.

char s[] = "BiNus";
// = {'B','i','N','u','s','\0'}: 6 kotak

int n = 0;
while (s[n] != '\0')
    n++;            // n = 5, sama dengan strlen
  • 'A' adalah satu karakter. "A" adalah string 2 byte: 'A' dan '\0'.
  • name = "Amir"; error, karena nama array tidak bisa diisi ulang. Pakai strcpy(name, "Amir").
  • scanf string tanpa &, karena nama array sudah alamat.

Ringkasan: pointer dan array sama-sama soal alamat

  • & = ambil alamat, * = ikuti alamat. Jumlah * = jumlah panah (1️⃣ 2️⃣ 3️⃣).
  • Array = kotak berderet, dan A[i] sama dengan *(A + i). Nama array tidak bisa dipindah (4️⃣ 5️⃣ 6️⃣).
  • C tidak memeriksa batas array. Index valid hanya 0 sampai ukuran − 1 (7️⃣).
  • Array 2D disimpan row-major. Array of pointer = deretan alamat (8️⃣ 9️⃣).
  • String = array char + '\0'. Salin dengan strcpy, bandingkan dengan strcmp (10 11).

Soal latihan: kerjakan dulu, jawabannya di slide berikutnya

  1. int a = 3, *p = &a; *p = *p + 4; Berapa nilai a?
  2. int A[5] = {10, 20, 30, 40, 50}; int *p = A + 3; Berapa *(p - 1)?
  3. int B[3][3] = {{1, 2}, {3, 4, 5}, {7}}; Berapa B[2][1]?
  4. Berapa kotak yang dibutuhkan char s[] = "KASUR";, dan kenapa?

Soal lain (max/min, matriks, validasi password, balik string) ada di akhir setiap section notes.

Jawaban soal latihan

  1. a = 7. *p adalah kotak a, jadi barisnya sama dengan a = a + 4.
  2. p menunjuk A[3], jadi *(p - 1) = A[2] = 30.
  3. Baris 2 hanya diisi {7}, jadi B[2][1] = 0.
  4. 6 kotak: 5 huruf ditambah '\0' sebagai penanda akhir string.
