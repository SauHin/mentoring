Pointer dan array

Pointer terasa sulit kalau dihafal sebagai aturan simbol. Dengan gambar kotak dan alamat dari materi 02, pointer hanyalah kotak yang isinya alamat kotak lain.

Slide · Visualisasi pointer & array

TL;DR
  • &x = alamat x. *p = isi kotak yang alamatnya disimpan di p.
  • Array = kotak berderet tanpa celah. A[i] sama dengan *(A + i).
  • C tidak memeriksa batas array: A[10] pada array 10 elemen lolos compile, tapi merusak memory.
  • String = array char yang diakhiri '\0'. Semua fungsi string berhenti di '\0'.

1. Ingat lagi: setiap kotak punya alamat

int i = 7;
printf("%d\n", i);    // 7         ← isi kotak
printf("%p\n", &i);   // 000000000061FE1C  ← alamat kotak (angkanya bisa berbeda)

Kamu sudah memakai alamat sejak materi 02: scanf("%d", &i) memberi tahu scanf di mana kotak i berada, supaya scanf bisa menulis ke sana.

2. Pointer: kotak berisi alamat

int i = 7;
int *ptr;      // ptr: kotak yang akan menyimpan alamat sebuah int
ptr = &i;      // simpan alamat i ke ptr  → ptr "menunjuk" i
*ptr = 5;      // ikuti alamat di ptr, ubah isinya → i jadi 5

     ptr                 i
  ┌────────┐         ┌──────┐
  │ 0x1000 │ ──────▶ │  5   │
  └────────┘         └──────┘
    0x1008             0x1000

Tanda * punya tiga arti, tergantung tempatnya:

TempatContohArti
Di deklarasiint *ptr;"ptr adalah pointer ke int"
Di depan pointer, dalam ekspresi*ptr = 5;"kotak yang ditunjuk ptr" (dereference)
Di antara dua nilaia * bPerkalian
Pointer kosongPointer yang belum diisi menunjuk ke alamat acak. *ptr = 5; sebelum ptr = &i; bisa merusak memory atau crash. Kalau belum punya alamat, isi dengan NULL supaya jelas "belum menunjuk apa-apa".

Jalankan langkah ini di visualisasi (program "Pointer dasar"). Panahnya terlihat.

Pointer ke pointer

int i, *ptr, **ptr_ptr;
ptr = &i;          // ptr menunjuk i
ptr_ptr = &ptr;    // ptr_ptr menunjuk ptr (pointer juga kotak, punya alamat)
**ptr_ptr = 9;     // ikuti 2 panah: ptr_ptr → ptr → i. i = 9

Jumlah * = jumlah panah yang diikuti.

3. Array: kotak berderet

int A[5] = {10, 20, 30, 40, 50};

 index:   [0]    [1]    [2]    [3]    [4]
        ┌────┬──────┬──────┬──────┬──────┐

  • Homogen: semua elemen bertipe sama. Index mulai 0, jadi index terakhir = ukuran − 1.
  • Random access: elemen mana pun bisa langsung diakses, karena alamatnya bisa dihitung.

int A[5]; lalu A = {0,0,0,0,0};Error: kurung kurawal hanya boleh saat deklarasi. Isi dengan loop.

4. Array dan pointer: A[i] = *(A + i)

Nama array A adalah alamat elemen pertama (&A[0]). Dari situ, A[i] bisa diturunkan sendiri:

  1. Elemen ke-i ada di alamat A + i × 4 (int = 4 byte).
  2. Di C, A + i otomatis dikali ukuran elemen. A + 2 berarti maju 2 elemen, bukan 2 byte.
  3. Jadi *(A + i) = isi elemen ke-i = A[i]. Tanda [ ] hanyalah singkatan.
int arr[4] = {1, 2, 3, 4};
int *ptr = arr;           // ptr menunjuk arr[0]
printf("%d\n", *(ptr + 1));   // 2
printf("%d\n", *(arr + 1));   // 2
printf("%d\n", ptr[1]);       // 2: pointer juga boleh pakai [ ]

Pointer variable vs nama array

int *ptr (pointer variable)int arr[4] (nama array)
IsinyaAlamat, bisa diganti kapan sajaAlamat elemen pertama, tetap
ptr = &x; / arr = &x;BolehError: nama array tidak bisa diberi alamat baru
ptr++ / arr++Boleh: pindah ke elemen berikutnyaError
Catatan: slide "Accessing array using a pointer"Di slide tertulis "ptr is a pointer constant pointing to the first element". Yang tepat: ptr adalah pointer variable, sesuai komentar di kodenya sendiri (// ptr is a pointer variable). Yang konstan adalah nama array arr.

5. Index di luar batas

int A[3] = {1, 2, 3};
A[3] = 7;    // index valid hanya 0, 1, 2

A[3] = alamat A + 3 elemen = kotak setelah array berakhir. C tidak memeriksa batas array, jadi baris ini lolos compile tanpa error. Saat jalan, nilai 7 ditulis ke memory milik variabel lain, atau program crash. Ini disebut undefined behavior, dan jauh lebih berbahaya daripada error, karena tidak ada yang memberi tahu.

Catatan: slide "Pointer constant (array)"Di slide, arr1[10] = 12; // error max 9 ditandai error. Index 10 memang salah, tapi compiler (termasuk Dev-C++) tidak menolaknya. Kesalahannya baru terasa saat program jalan. Lihat program "Index di luar batas" di visualisasi.

6. Array 2D dan 3D

int a[3][4];   // 3 baris, 4 kolom. a[baris][kolom]

Di memory, array 2D tetap satu deret: baris 0 seluruhnya, lalu baris 1, dan seterusnya (row-major). Posisi a[i][j] dari awal = i × jumlah_kolom + j.

InisialisasiIsi
int a[2][4] = {3,5,6,10,4,7,8,2};Diisi berurutan per baris: {3,5,6,10}, {4,7,8,2}
int a[2][4] = {{3,5,6,10},{4,7,8,2}};Sama, tapi lebih jelas
int b[2][4] = {{3},{4,7,8,2}};Baris 0 = {3,0,0,0}: setiap { } mengisi satu baris, sisanya 0

Pola memproses array 2D = nested loop (materi 03): loop luar untuk baris, loop dalam untuk kolom.

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++)
        printf("%4d", a[i][j]);
    printf("\n");
}

3D sama saja, ditambah satu dimensi: x[blok][baris][kolom].

Array of pointer

int x = 1, y = 2, z = 3;
int *ptr[3] = {&x, &y, &z};   // array berisi 3 alamat
for (int i = 0; i < 3; i++) printf("%d ", *ptr[i]);   // 1 2 3

7. String = array char + '\0'

char s[] = "BiNus";
// sama dengan:
char s[] = {'B', 'i', 'N', 'u', 's', '\0'};   // 6 kotak, bukan 5!
  • 'A' (kutip tunggal) = satu karakter, 1 byte. "A" (kutip ganda) = string, 2 byte: 'A' dan '\0'.
  • '\0' (nilai 0) menandai akhir string. printf %s, strlen, dan strcpy semuanya membaca sampai ketemu '\0'.
  • char name[40] = "Amir"; boleh (saat deklarasi). name = "Amir"; error, karena nama array tidak bisa diberi alamat baru. Pakai strcpy(name, "Amir");.
  • scanf string tanpa &: scanf("%s", name);, karena name sudah alamat.

Turunkan sendiri: strlen

Daripada menghafal cara kerja strlen, tulis sendiri dengan pola loop dari materi 03:

int n = 0;
while (s[n] != '\0')   // selama belum ketemu akhir string
    n++;
// n = panjang string

Jalankan di visualisasi (program "String & \0").

10. Latihan

1. Baca 10 bilangan bulat ke array, lalu cetak max, min, dan rata-ratanya.

Jawaban 
#include <stdio.h>

int main() {
    int a[10], max, min, total = 0;
    for (int i = 0; i < 10; i++) scanf("%d", &a[i]);
    max = min = a[0];                       // juara sementara = data pertama
    for (int i = 0; i < 10; i++) {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
        total += a[i];
    }
    printf("Max = %d, Min = %d, Avg = %.2f\n", max, min, (float)total / 10);
    return 0;
}

Gabungan tiga pola: akumulasi, cari max, dan cari min. max dan min dimulai dari data pertama, bukan 0, supaya tetap benar kalau semua data negatif.

3. Perkalian matriks A (2 × 3) dengan B (3 × 2).

Jawaban

Turunkan dari definisinya: C[i][j] = baris i dari A "dikali" kolom j dari B, yaitu jumlah dari A[i][k] × B[k][j] untuk semua k. "Jumlah dari" = pola akumulasi, jadi butuh loop ketiga.

#include <stdio.h>

int main() {
    int A[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int B[3][2] = {{7, 8}, {9, 10}, {11, 12}};
    int C[2][2];
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            C[i][j] = 0;                       // akumulator
            for (int k = 0; k < 3; k++)
                C[i][j] += A[i][k] * B[k][j];
        }
    }
    for (int i = 0; i < 2; i++)
        printf("%d %d\n", C[i][0], C[i][1]);   // 58 64 / 139 154
    return 0;
}

4. Berapa nilainya? int A[3][4] = {1, 3, 2, 4, 5, 7, 6, 8, 9, 11, 12}; dan int B[3][3] = {{1, 2}, {3, 4, 5}, {7}}; → A[1][1], B[2][2], A[2][3], B[0][1], A[0][2].

Jawaban

Tulis dulu isi setiap baris. A: {1,3,2,4}, {5,7,6,8}, {9,11,12,0}. B: {1,2,0}, {3,4,5}, {7,0,0}.

A[1][1] = 7, B[2][2] = 0, A[2][3] = 0, B[0][1] = 2, A[0][2] = 2.

5. Cetak input pengguna, tapi spasi berlebih (dua spasi atau lebih berturut-turut) dijadikan satu spasi.

Jawaban

Idenya: cetak spasi hanya kalau karakter sebelumnya bukan spasi.

#include <stdio.h>

int main() {
    char s[200];
    scanf("%[^\n]", s);
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == ' ' && i > 0 && s[i - 1] == ' ')
            continue;                 // spasi kedua dan seterusnya dilewati
        putchar(s[i]);
    }
    putchar('\n');
    return 0;
}

6. Validasi password: harus ada huruf besar, huruf kecil, angka, karakter spesial (_/@-!?*#), tanpa spasi, dan maksimal 12 karakter.

Jawaban

Pola "hitung yang memenuhi syarat": siapkan satu penanda per syarat, lalu periksa setiap karakter dengan ctype.h.

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char p[100];
    int upper = 0, lower = 0, digit = 0, special = 0, space = 0;
    scanf("%[^\n]", p);
    for (int i = 0; p[i] != '\0'; i++) {
        if (isupper(p[i])) upper = 1;
        else if (islower(p[i])) lower = 1;
        else if (isdigit(p[i])) digit = 1;
        else if (strchr("_/@-!?*#", p[i])) special = 1;
        else if (isspace(p[i])) space = 1;
    }
    if (upper && lower && digit && special && !space && strlen(p) <= 12)
        printf("Valid\n");
    else
        printf("Tidak valid\n");
    return 0;
}

strchr(daftar, c) mengecek apakah karakter c ada di dalam daftar.

7. Balik string: KASUR → RUSAK.

Jawaban

Tukar huruf paling kiri dengan paling kanan, lalu bergerak ke tengah. Simpan satu huruf di variabel sementara sebelum ditimpa.

#include <stdio.h>
#include <string.h>

int main() {
    char s[100];
    scanf("%s", s);
    for (int i = 0, j = strlen(s) - 1; i < j; i++, j--) {
        char c = s[i];     // simpan dulu
        s[i] = s[j];
        s[j] = c;
    }
    printf("%s\n", s);
    return 0;
}
