Pointer: kotak yang isinya alamat kotak lain

alamat kotak dan &x di scanf (materi 02) array (4️⃣), string (10), dan linked list (data structure)

Kertas berisi alamat rumah temanmu. Kertasnya bukan rumah, tapi dengan kertas itu kamu bisa datang dan mengubah isi rumahnya.

kertas alamat bisa kamu tulis sembarangan dan tidak terjadi apa-apa. Pointer yang berisi alamat sembarang bisa merusak memory saat dipakai.

Kamu sudah memakai alamat sejak materi 02: scanf("%d", &i) memberi tahu scanf di mana kotak i berada. Pointer adalah variabel yang isinya alamat variabel lain.

int i = 7;
int *ptr;      // ptr: kotak yang akan menyimpan alamat sebuah int
ptr = &i;      // simpan alamat i ke ptr: ptr "menunjuk" i
*ptr = 5;      // ikuti alamat di ptr, ubah isinya: i jadi 5

Pointer yang belum diisi menunjuk ke alamat acak. *ptr = 5; sebelum ptr = &i; bisa merusak memory atau crash. Kalau belum punya alamat, isi dengan NULL (alamat 0, artinya "belum menunjuk apa-apa").

Buka visualisasi, program "Pointer dasar". Panah biru muncul setelah ptr = &i.

& = ambil alamat. Pointer = kotak yang menyimpan alamat itu.

Soal latihan: int a = 3, *p = &a; *p = *p + 4; Berapa nilai a?

a = 7. *p adalah kotak a, jadi barisnya sama dengan a = a + 4.

Tanda * punya tiga arti, tergantung tempatnya

pointer (1️⃣) membaca semua kode pointer, termasuk linked list

Kata "bisa" dalam bahasa Indonesia: "aku bisa berenang" dan "bisa ular". Artinya ditentukan oleh posisinya di kalimat.

di bahasa sehari-hari kadang tetap ambigu. Di C, posisi * selalu menentukan artinya dengan pasti.

Dereference adalah mengikuti alamat yang disimpan pointer untuk memakai kotak di sana, ditulis *ptr. Tanda * yang sama juga dipakai untuk hal lain:

TempatContohArti
Di deklarasiint *ptr;"ptr adalah pointer ke int"
Di depan pointer, dalam ekspresi*ptr = 5;Dereference: "kotak yang ditunjuk ptr"
Di antara dua nilaia * bPerkalian

& = ambil alamat, * di depan pointer = ikuti alamat.

Soal latihan: Di baris int *q = &x; y = *q * 2;, apa arti setiap *?

int *q: deklarasi pointer. *q: dereference (isi x). * 2: perkalian. Jadi y = isi x dikali 2.

Pointer ke pointer: jumlah * = jumlah panah yang diikuti

pointer dan dereference (1️⃣, 2️⃣) fungsi yang mengubah pointer, misalnya insert(Node **head) di linked list

Kertas yang berisi lokasi kertas lain, yang berisi alamat rumah. Kamu harus mengikuti dua petunjuk untuk sampai ke rumah.

di dunia nyata kamu bisa berhenti di tengah. Di C, jumlah * menentukan persis berapa petunjuk yang diikuti.

Pointer ke pointer adalah pointer yang menyimpan alamat pointer lain. Pointer juga kotak, jadi ia punya alamat sendiri.

int i, *ptr, **ptr_ptr;
ptr = &i;          // ptr menunjuk i
ptr_ptr = &ptr;    // ptr_ptr menunjuk ptr
**ptr_ptr = 9;     // ikuti 2 panah: ptr_ptr → ptr → i. Jadi i = 9

Buka visualisasi, program "Pointer ke pointer". Ada dua panah berantai.

Satu * = ikuti satu panah. **pp = ikuti dua panah.

Soal latihan: Dengan kode di atas, apa yang ditunjuk oleh *ptr_ptr (satu bintang)?

*ptr_ptr adalah kotak ptr itu sendiri (ikuti satu panah), yang isinya alamat i. Baru **ptr_ptr sampai ke i.

Array: kotak bertipe sama yang berderet tanpa celah

variabel sebagai kotak (materi 02) dan loop (materi 03) A[i] = *(A + i) (5️⃣), string (10), stack dan queue berbasis array (data structure)

Deretan kursi bernomor di bioskop: semua kursinya sama, dan kursi nomor 5 bisa langsung didatangi tanpa melewati kursi 1 sampai 4.

nomor kursi bioskop mulai dari 1. Index array mulai dari 0.

Array adalah sekumpulan kotak bertipe sama yang disimpan berurutan di memory, dan diakses lewat index. Index mulai dari 0, jadi index terakhir = ukuran − 1.

Aturan inisialisasi array
InisialisasiHasil
int B[] = {1, 2, -4, 8};Ukuran dihitung otomatis: 4 elemen
int B[8] = {1, 2, -4, 8};8 elemen. Sisa 4 elemen otomatis 0
int B[4] = {1, 2, -4, 8, 9};Error: isi lebih banyak dari ukuran
int A[5]; lalu A = {0,0,0,0,0};Error: kurung kurawal hanya boleh saat deklarasi. Isi dengan loop.

Array = kotak berderet, semuanya bertipe sama. Index mulai 0, terakhir = ukuran − 1.

Soal latihan: Baca 10 bilangan bulat ke array, lalu cetak max, min, dan rata-ratanya. 
#include <stdio.h>

int main() {
    int a[10], max, min, total = 0;
    for (int i = 0; i < 10; i++) scanf("%d", &a[i]);
    max = min = a[0];                       // juara sementara = data pertama
    for (int i = 0; i < 10; i++) {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
        total += a[i];
    }
    printf("Max = %d, Min = %d, Avg = %.2f\n", max, min, (float)total / 10);
    return 0;
}

Gabungan tiga pola dari materi 03: akumulasi, cari max, dan cari min. max dan min dimulai dari data pertama, bukan 0, supaya tetap benar kalau semua data negatif.

A[i] sama dengan *(A + i): turunkan sendiri

array berderet (4️⃣) dan dereference (2️⃣) pointer variable vs nama array (6️⃣) dan index di luar batas (7️⃣)

Rumah di satu gang: kalau tahu alamat rumah pertama dan semua rumah sama lebarnya, kamu bisa menghitung letak rumah ke-5.

di gang, kamu menghitung lebar rumah sendiri. Di C, perkalian dengan ukuran elemen dilakukan otomatis.

Aritmetika pointer adalah menambah atau mengurangi pointer dengan bilangan bulat, yang satuannya elemen, bukan byte. Dari situ, A[i] bisa diturunkan:

  1. Nama array A adalah alamat elemen pertama (&A[0]).
  2. A + i maju i elemen. Untuk int, alamatnya bertambah i × 4 byte secara otomatis.
  3. *(A + i) mengikuti alamat itu, jadi hasilnya isi elemen ke-i, yaitu A[i]. Tanda [ ] hanyalah singkatan.
int arr[4] = {1, 2, 3, 4};
int *ptr = arr;               // ptr menunjuk arr[0]
printf("%d\n", *(ptr + 1));   // 2
printf("%d\n", *(arr + 1));   // 2
printf("%d\n", ptr[1]);       // 2: pointer juga boleh pakai [ ]

Buka visualisasi, program "Array & *(A+i)". Saat p = p + 1, panah p pindah satu kotak (4 byte), bukan 1 byte.

A + i = alamat elemen ke-i. *(A + i) = isinya = A[i].

Soal latihan: int A[5] = {10, 20, 30, 40, 50}; int *p = A + 3; Berapa *p, *(p - 1), dan p[1]?

p menunjuk A[3]. *p = 40. *(p - 1) = A[2] = 30. p[1] = *(p + 1) = A[4] = 50.

Pointer variable bisa dipindah, nama array tidak

A[i] = *(A + i) (5️⃣) kenapa name = "Amir"; error di string (10)

Papan nama gedung vs penunjuk jalan. Papan nama menempel di gedungnya. Penunjuk jalan bisa dicabut dan dipasang mengarah ke tempat lain.

papan nama gedung masih bisa dibongkar. Nama array benar-benar tidak bisa diberi alamat baru.

Slide dosen menyebut nama array sebagai pointer constant: alamat yang tetap dan tidak bisa diganti. Pointer biasa disebut pointer variable, karena isinya bisa diganti kapan saja.

int *ptr (pointer variable)int arr[4] (nama array)
IsinyaAlamat, bisa diganti kapan sajaAlamat elemen pertama, tetap
ptr = &x; / arr = &x;BolehError
ptr++ / arr++Boleh: pindah ke elemen berikutnyaError

Catatan untuk slide "Accessing array using a pointer": di slide tertulis "ptr is a pointer constant". Yang tepat, ptr adalah pointer variable, sesuai komentar di kodenya sendiri (// ptr is a pointer variable). Yang konstan adalah nama array arr.

Pointer variable bisa diisi ulang dan digeser. Nama array selalu menempel di elemen pertamanya.

Soal latihan: int arr[3], *p = arr; Mana yang error: p++; atau arr++;?

arr++; error, karena nama array adalah pointer constant. p++; boleh, dan membuat p menunjuk arr[1].

Index di luar batas lolos compile, tapi merusak memory

A[i] = *(A + i) (5️⃣) dan off-by-one (materi 03) semua loop yang memproses array

Menaruh barang di loker nomor 11, padahal lokermu hanya sampai 10: barangnya masuk ke loker orang lain.

petugas loker akan menegurmu. C tidak menegur sama sekali, jadi kesalahannya tidak terlihat.

C tidak memeriksa batas array. A[3] pada array 3 elemen menunjuk kotak setelah array berakhir, dan kodenya lolos compile tanpa error.

int A[3] = {1, 2, 3};
int x = 99;
A[3] = 7;      // index valid hanya 0, 1, 2
printf("%d", x);   // bisa tercetak 7!

Hasil seperti ini disebut undefined behavior: perilaku yang tidak diatur standar C, jadi bisa berbeda di setiap komputer. Nilai 7 bisa menimpa variabel lain, atau program crash.

Catatan untuk slide "Pointer constant (array)": di slide, arr1[10] = 12; // error max 9 ditandai error. Index 10 memang salah, tapi compiler (termasuk Dev-C++) tidak menolaknya. Kesalahannya baru terasa saat program jalan.

Buka visualisasi, program "Index di luar batas". x berubah jadi 7 padahal tidak pernah disentuh.

Index valid hanya 0 sampai ukuran − 1. C tidak memeriksanya, jadi kamu sendiri yang harus menjaga.

Soal latihan: int A[5]; for (int i = 0; i <= 5; i++) A[i] = 0; Apa yang salah?

Loop jalan untuk i = 0 sampai 5, padahal index terakhir 4. A[5] = 0 menulis di luar array (off-by-one). Pakai i < 5.

Array 2D tetap disimpan satu deret, baris demi baris

array (4️⃣) dan nested loop (materi 03) matriks, tabel nilai, dan papan permainan

Kursi bioskop yang punya baris dan nomor kursi, tapi dicetak di tiket berurutan: semua kursi baris A dulu, lalu baris B.

bioskop memang punya baris fisik. Memory tidak punya baris, jadi "baris" hanya cara kita membagi satu deret panjang.

Array 2D ditulis int a[3][4]; (3 baris, 4 kolom), dan diakses a[baris][kolom]. Di memory, isinya row-major: baris 0 seluruhnya, lalu baris 1, dan seterusnya. Karena itu posisi a[i][j] dari awal = i × jumlah_kolom + j.

InisialisasiIsi
int a[2][4] = {3,5,6,10,4,7,8,2};Diisi berurutan per baris: {3,5,6,10}, {4,7,8,2}
int a[2][4] = {{3,5,6,10},{4,7,8,2}};Sama, tapi lebih jelas
int b[2][4] = {{3},{4,7,8,2}};Baris 0 = {3,0,0,0}: setiap { } mengisi satu baris, sisanya 0

Pola memproses array 2D = nested loop: loop luar untuk baris, loop dalam untuk kolom. 3D sama saja, ditambah satu dimensi: x[blok][baris][kolom].

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++)
        printf("%4d", a[i][j]);
    printf("\n");
}

Buka visualisasi, program "Array 2D (row-major)". Alamat baris 1 dimulai tepat setelah baris 0 berakhir.

Array 2D = deret panjang yang dibagi per baris. a[i][j] ada di posisi i × kolom + j.

Soal latihan: int A[3][4] = {1, 3, 2, 4, 5, 7, 6, 8, 9, 11, 12}; dan int B[3][3] = {{1, 2}, {3, 4, 5}, {7}};. Berapa A[1][1], B[2][2], A[2][3], B[0][1], A[0][2]?

Tulis dulu isi setiap baris. A: {1,3,2,4}, {5,7,6,8}, {9,11,12,0}. B: {1,2,0}, {3,4,5}, {7,0,0}.

A[1][1] = 7, B[2][2] = 0, A[2][3] = 0, B[0][1] = 2, A[0][2] = 2.

Soal latihan: Jumlahkan dua matriks 2 × 3.

Elemen hasil di posisi (i, j) = jumlah elemen kedua matriks di posisi yang sama.

for (int i = 0; i < 2; i++)
    for (int j = 0; j < 3; j++)
        c[i][j] = a[i][j] + b[i][j];
Soal latihan: Kalikan matriks A (2 × 3) dengan B (3 × 2).

Turunkan dari definisinya: C[i][j] = jumlah dari A[i][k] × B[k][j] untuk semua k. "Jumlah dari" = pola akumulasi, jadi butuh loop ketiga.

#include <stdio.h>

int main() {
    int A[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int B[3][2] = {{7, 8}, {9, 10}, {11, 12}};
    int C[2][2];
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            C[i][j] = 0;                       // akumulator
            for (int k = 0; k < 3; k++)
                C[i][j] += A[i][k] * B[k][j];
        }
    }
    for (int i = 0; i < 2; i++)
        printf("%d %d\n", C[i][0], C[i][1]);   // 58 64 / 139 154
    return 0;
}

Array of pointer: array yang isinya alamat

pointer (1️⃣) dan array (4️⃣) array berisi string, misalnya nama hari di materi 03

Buku alamat: setiap baris berisi alamat satu rumah, bukan rumahnya sendiri.

buku alamat boleh berisi alamat rumah yang sudah dibongkar. Pointer ke variabel yang sudah hilang membuat program salah atau crash.

Array of pointer adalah array yang setiap elemennya pointer. int *ptr[3] dibaca "ptr adalah array 3 elemen, dan setiap elemennya pointer ke int".

int x = 1, y = 2, z = 3;
int *ptr[3] = {&x, &y, &z};   // array berisi 3 alamat
for (int i = 0; i < 3; i++) printf("%d ", *ptr[i]);   // 1 2 3

*ptr[i] berarti: ambil elemen ke-i (sebuah alamat), lalu ikuti alamat itu.

Array of pointer = deretan alamat. *ptr[i] = isi kotak yang ditunjuk elemen ke-i.

Soal latihan: Dengan kode di atas, apa yang terjadi setelah *ptr[1] = 20;?

ptr[1] berisi alamat y, jadi y menjadi 20.

String adalah array char yang diakhiri '\0'

array (4️⃣), %s dan buffer (materi 02) fungsi string (11)

Kalimat yang diakhiri titik: pembaca tahu kalimatnya selesai di titik itu, walaupun kertasnya masih panjang.

tanpa titik, manusia masih bisa menebak akhir kalimat. Fungsi string tanpa '\0' terus membaca memory di luar array.

C tidak punya tipe string. String adalah array char yang diakhiri null character '\0', yaitu karakter bernilai 0 yang menandai akhir string.

char s[] = "BiNus";
// sama dengan:
char s[] = {'B', 'i', 'N', 'u', 's', '\0'};   // 6 kotak, bukan 5!
  • 'A' (kutip tunggal) = satu karakter, 1 byte. "A" (kutip ganda) = string, 2 byte: 'A' dan '\0'.
  • char name[40] = "Amir"; boleh (saat deklarasi). name = "Amir"; error, karena nama array tidak bisa diberi alamat baru (6️⃣). Pakai strcpy(name, "Amir");.
  • scanf string tanpa &: scanf("%s", name);, karena name sudah alamat.
Turunkan sendiri: cara kerja strlen

Buka visualisasi, program "String & \0", lalu program "Balik string".

String = array char + '\0'. Sediakan selalu satu kotak tambahan untuk '\0'.

Soal latihan: Balik string: KASUR → RUSAK.

Tukar huruf paling kiri dengan paling kanan, lalu bergerak ke tengah. Simpan satu huruf di variabel sementara sebelum ditimpa.

#include <stdio.h>
#include <string.h>

int main() {
    char s[100];
    scanf("%s", s);
    for (int i = 0, j = strlen(s) - 1; i < j; i++, j--) {
        char c = s[i];     // simpan dulu
        s[i] = s[j];
        s[j] = c;
    }
    printf("%s\n", s);
    return 0;
}

Lihat setiap pertukaran di visualisasi, program "Balik string".

Soal latihan: Cetak input pengguna, tapi spasi berlebih (dua spasi atau lebih berturut-turut) dijadikan satu spasi.

Idenya: cetak spasi hanya kalau karakter sebelumnya bukan spasi.

#include <stdio.h>

int main() {
    char s[200];
    scanf("%[^\n]", s);
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == ' ' && i > 0 && s[i - 1] == ' ')
            continue;                 // spasi kedua dan seterusnya dilewati
        putchar(s[i]);
    }
    putchar('\n');
    return 0;
}

&& artinya "dan": ketiga syarat harus benar.

Fungsi string dan karakter: cukup tahu, semuanya bekerja sampai '\0'

string dan '\0' (10), header file (materi 01) validasi input dan olah teks

Kotak perkakas: kamu tidak perlu membuat obeng sendiri, cukup tahu obeng ada di laci mana.

obeng bisa dipakai untuk benda apa pun. Fungsi string hanya benar untuk array yang punya '\0'.

Header string.h dan ctype.h berisi fungsi siap pakai. Tidak perlu dihafal, pakai tabel ini sebagai referensi.

Konversi string ke angka (stdlib.h): strtol (ke long), strtoul (ke unsigned long), strtod (ke double). Ketiganya juga memberi tahu sisa string yang bukan angka, lewat parameter char **endPtr.

Jangan bandingkan string dengan ==. if (s1 == s2) membandingkan alamat kedua array (pasti berbeda), bukan isinya. Pakai if (strcmp(s1, s2) == 0).

Salin dengan strcpy, bandingkan dengan strcmp(...) == 0, ukur dengan strlen.

Soal latihan: Validasi password: harus ada huruf besar, huruf kecil, angka, karakter spesial (_/@-!?*#), tanpa spasi, dan maksimal 12 karakter.

Pola "hitung yang memenuhi syarat": siapkan satu penanda per syarat, lalu periksa setiap karakter dengan ctype.h.

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char p[100];
    int upper = 0, lower = 0, digit = 0, special = 0, space = 0;
    scanf("%[^\n]", p);
    for (int i = 0; p[i] != '\0'; i++) {
        if (isupper(p[i])) upper = 1;
        else if (islower(p[i])) lower = 1;
        else if (isdigit(p[i])) digit = 1;
        else if (strchr("_/@-!?*#", p[i])) special = 1;
        else if (isspace(p[i])) space = 1;
    }
    if (upper && lower && digit && special && !space && strlen(p) <= 12)
        printf("Valid\n");
    else
        printf("Tidak valid\n");
    return 0;
}

strchr(daftar, c) mengecek apakah karakter c ada di dalam daftar. !space artinya "space bernilai 0".

semua section sebelumnya membaca kodemu sendiri saat program crash atau output aneh

Montir yang mengenali kerusakan dari bunyi mesin: bunyi tertentu mengarah ke bagian tertentu.

montir bisa salah tebak. Di program, kamu bisa memastikan penyebabnya dengan menggambar isi memory.
