Notes 1️⃣ · Resep 6 langkah

Pahami soal dulu, baru susun logika, baru tulis kode

Soal kasus adalah soal cerita yang meminta program lengkap: baca input, proses, cetak output.

  1. Tandai input, proses, output, dan batasnya.
  2. Kerjakan sample dengan tangan.
  3. Tulis langkah dalam bahasa biasa.
  4. Pilih alat C dari kalimat soal.
  5. Tulis kode bertahap: input, proses, output.
  6. Uji: sample, edge case, format.
  • Langkah 1–3 di kertas, langkah 4–6 di Dev-C++.
  • Kalau langsung menulis kode, kamu memikirkan arti soal, logika, dan sintaks sekaligus, jadi kesalahan sulit dilacak.

Notes 4️⃣ · Bahasa biasa

Langkah 3: tulis langkahnya dalam bahasa biasa sebelum menulis sintaks C

Isinya sama dengan yang kamu lakukan saat trace, ditulis berurutan seperti pseudocode (materi 01).

1. Baca N.
2. Siapkan total = 0, tertinggi = -1, lulus = 0.
3. Ulangi N kali: baca satu nilai, tambahkan ke total,
   ganti tertinggi kalau nilai lebih besar, tambah lulus kalau nilai ≥ 75.
4. Cetak total / N dengan 2 desimal, tertinggi, dan lulus.

Setiap kata kerja (baca, ulangi, ganti, cetak) nanti menjadi satu bagian kode. Kalau langkahnya tidak bisa ditulis begini, kodenya juga belum bisa ditulis.

Notes 6️⃣ · Membaca input

Input hampir selalu memakai salah satu dari tiga pola

Yang membedakan adalah cara program tahu kapan berhenti membaca.

/* 1. N lalu N data */
scanf("%d", &n);
for (i = 0; i < n; i++) scanf("%d", &x);

/* 2. Sentinel: berhenti saat bertemu 0 */
scanf("%d", &x);
while (x != 0) { /* proses x */ scanf("%d", &x); }

/* 3. Satu kata tanpa spasi */
scanf("%s", kata);

%d melewati spasi dan Enter, jadi data boleh satu baris atau beberapa baris.

Notes 8️⃣ · Contoh 1

Contoh 1: setiap nilai cukup diproses sekali, jadi satu loop tanpa array

Isi main() untuk soal nilai kuis. Output: "Rata-rata: 72.40", "Tertinggi: 90", "Lulus: 3".

int n, i, nilai;
int total = 0, tertinggi = -1, lulus = 0;

scanf("%d", &n);
for (i = 0; i < n; i++) {
    scanf("%d", &nilai);
    total += nilai;
    if (nilai > tertinggi) {
        tertinggi = nilai;
    }
    if (nilai >= 75) {
        lulus++;
    }
}
printf("Rata-rata: %.2f\n", (double)total / n);
printf("Tertinggi: %d\n", tertinggi);
printf("Lulus: %d\n", lulus);
  • tertinggi = -1: lebih kecil dari nilai terkecil (0), jadi nilai pertama pasti menggantikannya.
  • Akumulator total dan lulus mulai dari 0.
  • Casting: (double)total / n, karena total / n membuang desimal.

Coba sendiri: trace contoh 1, contoh 2, dan program bug

Notes 9️⃣ · Contoh 2

Contoh 2: data yang dipakai lagi setelah semua dibaca harus disimpan di array

Soal: baca N suhu (1 ≤ N ≤ 100), cetak rata-rata 1 desimal dan nomor hari (mulai 1) yang suhunya di atas rata-rata.

Sample input 6 lalu 30 28 33 29 35 31. Sample output "Rata-rata: 31.0" dan "Hari: 3 5". Kalau tidak ada, cetak "Hari: tidak ada".

  • Hari pertama (30) baru bisa dinilai setelah rata-rata (31.0) diketahui.
  • Rata-rata baru diketahui setelah semua suhu dibaca, dan input tidak bisa dibaca dua kali.
  • Jadi: loop 1 menyimpan ke array dan menjumlah, loop 2 membandingkan.

Notes 9️⃣ · Contoh 2

Loop pertama menyimpan, loop kedua membandingkan

Isi main() untuk soal suhu. Nomor hari dicetak sebagai i + 1, karena index mulai dari 0.

int n, i, ada = 0, total = 0, suhu[100];
double rata;
scanf("%d", &n);
for (i = 0; i < n; i++) {
    scanf("%d", &suhu[i]);
    total += suhu[i];
}
rata = (double)total / n;
printf("Rata-rata: %.1f\n", rata);
printf("Hari:");
for (i = 0; i < n; i++) {
    if (suhu[i] > rata) {
        printf(" %d", i + 1);
        ada++;
    }
}
if (ada == 0) printf(" tidak ada");
printf("\n");
  • suhu[100]: ukuran mengikuti constraint N ≤ 100.
  • printf(" %d"): spasi sebelum setiap angka, jadi tidak ada spasi di akhir.
  • ada: menghitung hari yang dicetak, supaya bisa mencetak "tidak ada".

Ringkasan

Setiap soal kasus dikerjakan dengan resep yang sama.

  • Di kertas: tandai input, proses, output, dan constraint, lalu trace sample dan tulis langkahnya.
  • Pilih alat: "sebanyak N" = for, "sampai 0" = while, "jika" = if, data dipakai lagi = array.
  • Kode: input, lalu proses, lalu output dengan format persis.
  • Uji: sample, edge case, dan daftar bug sebelum mengumpulkan.

Soal

Tiga dari tujuh soal format quiz di notes 11. Tentukan output untuk sample input-nya, lalu cek di slide berikutnya.

  1. Kembalian: pecahan 50000, 20000, 10000, 5000, 2000, 1000. Cetak kembalian, lalu jumlah lembar tiap pecahan dari yang terbesar (lembar sesedikit mungkin). Input 37000 100000 (harga, uang).
  2. Nilai huruf: akhir = 20% tugas + 30% kuis + 50% ujian. A ≥ 85, B ≥ 70, C ≥ 55, D ≥ 40, sisanya E. Cetak "Mahasiswa k: akhir huruf" (2 desimal). Input 2, 85 85 85, 55 55 54.
  3. Bilangan prima: untuk setiap N, cetak "N adalah prima" atau "N bukan prima". Input 3, 1, 12, 97.

Jawaban

Format soal lengkap, petunjuk, dan full code ada di notes 11, dan sudah diuji di compiler C dan C++.

  1. "Kembalian: 63000", lalu 50000: 1, 20000: 0, 10000: 1, 5000: 0, 2000: 1, 1000: 1. Kuncinya: kembali / pecahan untuk jumlah lembar, kembali % pecahan untuk sisanya.
  2. "Mahasiswa 1: 85.00 A" dan "Mahasiswa 2: 54.50 D". Kuncinya: (20 * tugas + 30 * kuis + 50 * ujian) / 100.0, dan if diurutkan dari batas tertinggi.
  3. "1 bukan prima", "12 bukan prima", "97 adalah prima". Kuncinya: cek pembagi selama i * i <= n, break saat ketemu, dan N < 2 bukan prima.
