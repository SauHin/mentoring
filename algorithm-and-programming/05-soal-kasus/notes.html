Resep 6 langkah: pahami soal dulu, baru logika, baru kode

tujuh langkah dari masalah ke program (materi 01) semua section di halaman ini

Memasak pesanan tamu: pahami pesanannya, coba bayangkan hasilnya, tulis langkahnya, siapkan alat, masak, lalu cicipi.

masakan yang sedikit beda masih bisa dimakan. Output yang beda satu spasi saja sudah dianggap salah.

Soal kasus adalah soal cerita yang meminta program lengkap: membaca input, memprosesnya, lalu mencetak output dengan format tertentu. Kerjakan selalu dengan resep yang sama:

  1. Tandai input, proses, output, dan batas nilainya.
  2. Kerjakan sample input dengan tangan sampai hasilnya sama dengan sample output.
  3. Tulis langkah dalam bahasa biasa, 3–6 baris.
  4. Pilih alat C dari kalimat soal.
  5. Tulis kode bertahap: input, lalu proses, lalu output.
  6. Uji dengan sample, edge case, dan format output.

Kenapa urutannya begini: langkah 1–3 dikerjakan tanpa kode. Kalau kamu langsung menulis kode, kamu memikirkan arti soal, logika, dan sintaks sekaligus, jadi kesalahan sulit dilacak.

Langkah 1–3 di kertas, langkah 4–6 di Dev-C++.

Soal latihan: Kenapa sample input dikerjakan dengan tangan (langkah 2) sebelum menulis kode?

Kalau hasil hitunganmu sudah sama dengan sample output, berarti kamu sudah paham soalnya. Kalau nanti output program salah, kesalahannya pasti di kode, bukan di cara memahami soal.

Langkah 1: tandai input, proses, output, dan batas nilainya dengan tiga warna

input, proses, output (materi 01) pilih tipe data (5️⃣) dan pola input (6️⃣)

Membaca resep sambil menandai bahan, cara masak, dan cara penyajian dengan stabilo berbeda.

resep bisa dibaca sekilas. Soal kasus harus dibaca kalimat per kalimat, karena satu kata ("di atas", "minimal") bisa mengubah jawaban.

Di kertas, tandai ketiga bagian soal dengan tiga warna stabilo berbeda. Contoh soal (dipakai lagi di 8️⃣):

Pak Budi punya N mahasiswa (1 ≤ N ≤ 100). Baris pertama berisi N, baris kedua berisi N nilai bulat 0–100. Hitung rata-rata, nilai tertinggi, dan jumlah yang lulus (nilai ≥ 75). Cetak tiga baris: "Rata-rata: " dengan 2 desimal, "Tertinggi: ", dan "Lulus: ".

BagianIsi di soal
InputN (1 ≤ N ≤ 100), lalu N nilai bulat 0–100
Prosesrata-rata, nilai tertinggi, banyak nilai ≥ 75
Outputtiga baris dengan label persis, rata-rata 2 desimal

Constraint (batas nilai, misalnya 1 ≤ N ≤ 100) menentukan ukuran array dan tipe data, jadi jangan dilewati.

Tiga warna: input, proses, output. Constraint selalu dicatat.

Soal latihan: Constraint soal: "harga tiap barang 1 sampai 1.000.000, paling banyak 10.000 barang". Tipe apa untuk total harga?

Total bisa mencapai 1.000.000 × 10.000 = 1010, lebih besar dari batas int (sekitar 2,1 × 109). Pakai long long dan %lld (materi 02).

contoh di buku sudah ada pembahasannya. Di soal kasus, kamu yang harus menemukan kenapa sample output-nya begitu.

Langkah 3: tulis langkahnya dalam bahasa biasa, 3–6 baris

pseudocode (materi 01) pilih alat C (5️⃣)

Menulis daftar belanja sebelum ke pasar, supaya tidak bingung di tengah jalan.

daftar belanja boleh berantakan. Langkah di sini harus berurutan, karena program menjalankannya dari atas ke bawah.

Tulis apa yang kamu lakukan saat trace di 3️⃣, tanpa sintaks C:

1. Baca N.
2. Siapkan total = 0, tertinggi = -1, lulus = 0.
3. Ulangi N kali: baca satu nilai, tambahkan ke total,
   ganti tertinggi kalau nilai lebih besar, tambah lulus kalau nilai ≥ 75.
4. Cetak total / N dengan 2 desimal, tertinggi, dan lulus.
  • Gunanya: logika diperiksa sendiri, terpisah dari sintaks.
  • Cek: setiap kata kerja (baca, ulangi, ganti, cetak) nanti menjadi satu bagian kode.

Kalau langkahnya tidak bisa ditulis dalam bahasa biasa, kodenya juga belum bisa ditulis.

Soal latihan: Tulis langkah bahasa biasa untuk "baca N bilangan, cetak berapa yang genap".

1. Baca N. 2. Siapkan genap = 0. 3. Ulangi N kali: baca satu bilangan, kalau sisa baginya dengan 2 adalah 0, tambah genap. 4. Cetak genap.

Langkah 4: pilih alat C dari kata kunci di kalimat soal

tipe data, if, loop, array (materi 01–04) kedua contoh (8️⃣, 9️⃣)

Memilih alat dari jenis pekerjaan: sekrup pakai obeng, paku pakai palu.

alat yang kurang tepat kadang masih bisa dipakai. Di C, alat yang salah (misalnya int untuk desimal) langsung memberi output yang salah.

Setiap kata kunci di soal menunjuk ke satu alat:

Kata kunci soal menentukan alat. Butuh data lagi setelah dibaca berarti butuh array.

Soal latihan: "Baca bilangan sampai bertemu -1, cetak bilangan terkecil." Alat apa saja?

while dengan sentinel -1, dan variabel pembanding terkecil. Nilai awalnya bisa bilangan pertama yang dibaca, atau angka yang lebih besar dari batas soal.

Pola membaca input: N lalu N data, sentinel, atau kata

scanf dan buffer keyboard (materi 02), sentinel (materi 03) kedua contoh (8️⃣, 9️⃣)

Petugas loket yang tahu dari awal berapa tamu yang datang, dibanding petugas yang menunggu sampai ada tanda "tutup".

petugas bisa menebak antrean. Program harus tahu persis kapan berhenti membaca, dari N atau dari sentinel.

Hampir semua soal quiz memakai salah satu dari tiga pola ini:

/* 1. N lalu N data */
scanf("%d", &n);
for (i = 0; i < n; i++) scanf("%d", &x);

/* 2. Sentinel: berhenti saat bertemu 0 */
scanf("%d", &x);
while (x != 0) { /* proses x */ scanf("%d", &x); }

/* 3. Satu kata tanpa spasi */
scanf("%s", kata);

%d melewati spasi dan Enter, jadi data boleh satu baris atau beberapa baris. Kata tanpa &, karena nama array sudah berupa alamat (materi 04).

Tahu dulu kapan berhenti membaca: dari N, dari sentinel, atau satu kata.

Soal latihan: Di pola sentinel, kenapa scanf ditulis dua kali (sebelum loop dan di akhir body)?

scanf pertama mengisi x sebelum kondisi pertama dicek. scanf di akhir body membaca data berikutnya sebelum kondisi dicek lagi. Tanpa yang kedua, x tidak pernah berubah dan loop tidak berhenti.

Output harus sama persis dengan sample output, sampai spasi dan newline

printf dan format specifier (materi 02) uji format (10)

Mengisi formulir resmi: tulisan di luar kotak atau format tanggal yang beda membuat formulir ditolak.

petugas kadang memaklumi. Penilaian otomatis membandingkan output karakter per karakter, tanpa memaklumi.

Quiz biasanya dinilai dengan membandingkan output-mu dan output kunci karakter per karakter. Bandingkan bagian ini:

Jangan mencetak teks yang tidak diminta, seperti "Masukkan N:". Teks itu ikut terbaca sebagai output dan membuat jawaban salah.

Cetak hanya yang diminta, dengan format yang persis sama.

Soal latihan: Bagaimana mencetak bilangan dipisah spasi tanpa spasi di akhir?

Cetak spasi sebelum setiap bilangan kecuali yang pertama: if (i > 0) printf(" "); printf("%d", x);. Atau cetak label dulu, lalu printf(" %d", x) untuk setiap bilangan, seperti di 9️⃣.

Contoh 1 nilai kuis: loop, if, akumulator, dan casting dalam satu program

langkah 1–4 (2️⃣ sampai 5️⃣) contoh dengan array (9️⃣)

Menyalin rekap nilai satu per satu ke buku: sambil membaca, kamu menjumlah, mencatat yang tertinggi, dan menghitung yang lulus.

di buku kamu bisa membaca ulang. Di program ini setiap nilai hanya dibaca sekali, jadi semua dihitung dalam satu loop.

Soalnya ada di 2️⃣. Sample input 5 lalu 80 65 90 75 52, sample output "Rata-rata: 72.40", "Tertinggi: 90", "Lulus: 3". Tiga keputusan penting:

  • Nilai awal tertinggi: -1, lebih kecil dari nilai terkecil (0), jadi nilai pertama pasti menggantikannya.
  • Satu loop cukup: setiap nilai langsung diproses, tidak perlu disimpan.
  • Casting: (double)total / n, karena total / n membuang desimal.
Full code contoh 1 
#include <stdio.h>

int main() {
    int n, i, nilai;
    int total = 0, tertinggi = -1, lulus = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &nilai);
        total += nilai;
        if (nilai > tertinggi) {
            tertinggi = nilai;
        }
        if (nilai >= 75) {
            lulus++;
        }
    }

    printf("Rata-rata: %.2f\n", (double)total / n);
    printf("Tertinggi: %d\n", tertinggi);
    printf("Lulus: %d\n", lulus);
    return 0;
}

Jalankan di visualisasi, lalu bandingkan trace table-nya dengan trace tanganmu di 3️⃣.

Data yang cukup diproses sekali: satu loop, tanpa array.

Soal latihan: Ubah program supaya juga mencetak "Terendah: " (nilai terendah).

Tambahkan int terendah = 101; (lebih besar dari nilai terbesar), lalu di dalam loop if (nilai < terendah) terendah = nilai;, dan setelah loop printf("Terendah: %d\n", terendah);. Dengan sample input, hasilnya 52.

Contoh 2 suhu: data harus disimpan di array kalau dipakai lagi setelah semua dibaca

array (materi 04), contoh 1 (8️⃣) latihan (11)

Memilih siswa yang nilainya di atas rata-rata kelas: kamu harus mencatat semua nilai dulu, baru bisa memilih.

di kelas kamu bisa bertanya ulang ke siswa. Program tidak bisa membaca input yang sama dua kali, jadi semua data disimpan di array.

Baris pertama berisi N hari (1 ≤ N ≤ 100), baris kedua N suhu bulat. Cetak "Rata-rata: " dengan 1 desimal, lalu "Hari:" diikuti nomor hari (mulai 1) yang suhunya di atas rata-rata. Kalau tidak ada, cetak "Hari: tidak ada".

Sample input 6 lalu 30 28 33 29 35 31, sample output "Rata-rata: 31.0" dan "Hari: 3 5". Kenapa butuh array: hari pertama (30) baru bisa dinilai setelah rata-rata (31.0) diketahui, dan rata-rata baru diketahui setelah semua suhu dibaca.

  • Loop 1: simpan ke suhu[i] dan jumlahkan.
  • Loop 2: bandingkan setiap suhu[i] dengan rata-rata, cetak i + 1.
Full code contoh 2 
#include <stdio.h>

int main() {
    int n, i, ada = 0, total = 0;
    int suhu[100];
    double rata;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &suhu[i]);
        total += suhu[i];
    }
    rata = (double)total / n;

    printf("Rata-rata: %.1f\n", rata);
    printf("Hari:");
    for (i = 0; i < n; i++) {
        if (suhu[i] > rata) {
            printf(" %d", i + 1);
            ada++;
        }
    }
    if (ada == 0) {
        printf(" tidak ada");
    }
    printf("\n");
    return 0;
}

Jalankan di visualisasi. Lewat "Ubah input", coba 3 lalu 30 30 30 untuk melihat "tidak ada".

Butuh data lagi setelah semuanya dibaca berarti simpan di array, lalu pakai dua loop.

Soal latihan: Kenapa yang dicetak i + 1, bukan i?

Index array dimulai dari 0, tapi soal menghitung hari mulai dari 1. Suhu 33 ada di suhu[2], dan itu hari ke-3.

Latihan 1: kembalian (pembagian integer dan modulo)

Mesin kasir hanya punya uang pecahan 50000, 20000, 10000, 5000, 2000, dan 1000. Diberikan harga barang dan uang yang dibayar pembeli. Hitung kembalian, lalu tentukan berapa lembar setiap pecahan yang diberikan, mulai dari pecahan terbesar, supaya jumlah lembarnya sesedikit mungkin.

  • Format input: satu baris berisi dua bilangan bulat: harga dan uang.
  • Format output: baris pertama "Kembalian: " diikuti besar kembalian. Lalu enam baris, satu untuk setiap pecahan dari yang terbesar, dengan format "pecahan: jumlah lembar".
  • Batasan: 1000 ≤ harga ≤ uang ≤ 1.000.000, keduanya kelipatan 1000.

Petunjuk

Jumlah lembar = kembali / pecahan (pembagian integer), dan sisa yang belum dibayar = kembali % pecahan. Simpan keenam pecahan di array, supaya cukup satu loop. Sample kedua menguji kembalian 0.

Full code 
#include <stdio.h>

int main() {
    int pecahan[6] = {50000, 20000, 10000, 5000, 2000, 1000};
    int harga, uang, kembali, i;

    scanf("%d %d", &harga, &uang);
    kembali = uang - harga;
    printf("Kembalian: %d\n", kembali);
    for (i = 0; i < 6; i++) {
        printf("%d: %d\n", pecahan[i], kembali / pecahan[i]);
        kembali = kembali % pecahan[i];
    }
    return 0;
}
Latihan 2: nilai huruf (if dan else if)

Nilai akhir mahasiswa dihitung dari 20% nilai tugas, 30% nilai kuis, dan 50% nilai ujian. Nilai huruf: A kalau nilai akhir ≥ 85, B kalau ≥ 70, C kalau ≥ 55, D kalau ≥ 40, dan E untuk sisanya. Cetak nilai akhir dan nilai huruf setiap mahasiswa.

  • Format input: baris pertama berisi T, banyaknya mahasiswa. T baris berikutnya masing-masing berisi tiga bilangan bulat: nilai tugas, kuis, dan ujian.
  • Format output: untuk mahasiswa ke-k, cetak "Mahasiswa k: " diikuti nilai akhir dengan 2 desimal, satu spasi, lalu nilai huruf.
  • Batasan: 1 ≤ T ≤ 100, setiap nilai 0–100.
Sample inputSample output

Mahasiswa 2: 64.50 C

Petunjuk

Hitung (20 * tugas + 30 * kuis + 50 * ujian) / 100.0. Pembilangnya bulat, jadi nilai seperti 85.00 tidak bergeser menjadi 84.999… karena pembulatan double. Urutkan if dari batas tertinggi, supaya nilai 90 tidak berhenti di syarat ≥ 40. Sample kedua menguji batas tepat 85 dan nilai 54.50.

Full code 
#include <stdio.h>

int main() {
    int t, k, tugas, kuis, ujian;
    double akhir;
    char huruf;

    scanf("%d", &t);
    for (k = 1; k <= t; k++) {
        scanf("%d %d %d", &tugas, &kuis, &ujian);
        akhir = (20 * tugas + 30 * kuis + 50 * ujian) / 100.0;
        if (akhir >= 85) {
            huruf = 'A';
        } else if (akhir >= 70) {
            huruf = 'B';
        } else if (akhir >= 55) {
            huruf = 'C';
        } else if (akhir >= 40) {
            huruf = 'D';
        } else {
            huruf = 'E';
        }
        printf("Mahasiswa %d: %.2f %c\n", k, akhir, huruf);
    }
    return 0;
}
Latihan 3: kasir diskon (sentinel dan long long)

Kasir membaca harga barang satu per satu sampai bertemu angka 0. Kalau total belanja lebih dari 100000, pembeli mendapat diskon 10% (dibulatkan ke bawah). Cetak jumlah barang, total belanja, dan uang yang harus dibayar.

  • Format input: beberapa bilangan bulat, satu per baris. Bilangan terakhir selalu 0 dan bukan harga barang.
  • Format output: tiga baris: "Jumlah barang: ", "Total: ", dan "Bayar: ", masing-masing diikuti angkanya.
  • Batasan: setiap harga 1–1.000.000, paling banyak 10.000 barang.

Petunjuk

Pakai pola sentinel (6️⃣). Total bisa mencapai 1010, lebih dari batas int, jadi pakai long long dan %lld. total / 10 adalah pembagian integer, jadi diskonnya otomatis dibulatkan ke bawah. Sample kedua menguji input yang langsung 0.

Full code 
#include <stdio.h>

int main() {
    long long harga, total = 0, bayar;
    int jumlah = 0;

    scanf("%lld", &harga);
    while (harga != 0) {
        total += harga;
        jumlah++;
        scanf("%lld", &harga);
    }

    bayar = total;
    if (total > 100000) {
        bayar = total - total / 10;
    }

    printf("Jumlah barang: %d\n", jumlah);
    printf("Total: %lld\n", total);
    printf("Bayar: %lld\n", bayar);
    return 0;
}
Latihan 4: bilangan prima (loop dan break)

Bilangan prima adalah bilangan bulat lebih dari 1 yang hanya habis dibagi 1 dan dirinya sendiri. Untuk setiap bilangan, tentukan apakah bilangan itu prima.

  • Format input: baris pertama berisi T. T baris berikutnya masing-masing berisi satu bilangan N.
  • Format output: untuk setiap N, cetak "N adalah prima" atau "N bukan prima".
  • Batasan: 1 ≤ T ≤ 100, 1 ≤ N ≤ 1.000.000.
Sample inputSample output
4
7
1
12
97
7 adalah prima
1 bukan prima
12 bukan prima
97 adalah prima
3
2
9
999983
2 adalah prima
9 bukan prima
999983 adalah prima
Petunjuk

Cukup cek pembagi dari 2 sampai akar N dengan kondisi i * i <= n. Kalau N punya pembagi yang lebih besar dari akarnya, pasangannya pasti lebih kecil dari akar, jadi sudah ketemu lebih dulu. Begitu ketemu satu pembagi, break. Angka 1 bukan prima, jadi dicek tersendiri.

Full code 
#include <stdio.h>

int main() {
    int t, k, n, i, prima;

    scanf("%d", &t);
    for (k = 0; k < t; k++) {
        scanf("%d", &n);
        prima = 1;
        if (n < 2) {
            prima = 0;
        }
        for (i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                prima = 0;
                break;
            }
        }
        if (prima) {
            printf("%d adalah prima\n", n);
        } else {
            printf("%d bukan prima\n", n);
        }
    }
    return 0;
}
Latihan 5: segitiga angka (nested loop)

Cetak segitiga angka setinggi N baris. Baris ke-k berisi angka 1 sampai k, dipisah satu spasi, tanpa spasi di akhir baris.

  • Format input: satu bilangan bulat N.
  • Format output: N baris segitiga angka.
  • Batasan: 1 ≤ N ≤ 20.
Sample inputSample output
4

Petunjuk

Loop luar untuk baris, loop dalam berjalan sebanyak nomor baris (materi 03). Cetak spasi sebelum setiap angka kecuali angka pertama, supaya tidak ada spasi di akhir. Sample kedua menguji N = 1.

Full code 
#include <stdio.h>

int main() {
    int n, baris, kolom;

    scanf("%d", &n);

            if (kolom > 1) {
                printf(" ");
            }
            printf("%d", kolom);
        }
        printf("\n");
    }

}
Latihan 6: vokal dan konsonan (string)

Diberikan satu kata yang hanya berisi huruf. Hitung banyaknya huruf vokal (a, i, u, e, o) dan konsonan. Huruf besar juga dihitung.

  • Format input: satu kata tanpa spasi.
  • Format output: dua baris: "Vokal: " dan "Konsonan: ", masing-masing diikuti jumlahnya.
  • Batasan: panjang kata 1–100 huruf.
Sample inputSample output
Informatika
Vokal: 5
Konsonan: 6
BINUS
Vokal: 2
Konsonan: 3
Petunjuk

Array char butuh 101 tempat: 100 huruf ditambah '\0'. Ubah setiap huruf dengan tolower supaya 'I' dan 'i' sama-sama terhitung. Karena kata hanya berisi huruf, konsonan = panjang kata dikurangi vokal.

Full code 
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char kata[101];
    char c;
    int i, panjang, vokal = 0;

    scanf("%s", kata);
    panjang = strlen(kata);
    for (i = 0; i < panjang; i++) {
        c = tolower(kata[i]);
        if (c == 'a' || c == 'i' || c == 'u' || c == 'e' || c == 'o') {
            vokal++;
        }
    }
    printf("Vokal: %d\n", vokal);
    printf("Konsonan: %d\n", panjang - vokal);
    return 0;
}
Latihan 7: penjualan cabang (array 2D)

Sebuah toko punya R cabang, dan penjualan setiap cabang dicatat selama C hari. Cetak total penjualan setiap cabang, total penjualan setiap hari, dan cabang dengan total tertinggi. Kalau ada yang seri, pilih nomor cabang terkecil. Wajib memakai array 2 dimensi.

  • Format input: baris pertama berisi R dan C. R baris berikutnya masing-masing berisi C bilangan bulat: penjualan cabang itu dari hari 1 sampai hari C.
  • Format output: R baris "Cabang k: total", lalu C baris "Hari k: total", lalu satu baris "Terbaik: Cabang k".
  • Batasan: 1 ≤ R ≤ 10, 1 ≤ C ≤ 7, setiap penjualan 0–1000.
Sample inputSample output
3 4
10 20 30 40
5 5 5 5
50 0 25 30
Cabang 1: 100
Cabang 2: 20
Cabang 3: 105
Hari 1: 65
Hari 2: 25
Hari 3: 60
Hari 4: 75
Terbaik: Cabang 3
2 2
3 4
5 2
Cabang 1: 7
Cabang 2: 7
Hari 1: 8
Hari 2: 6
Terbaik: Cabang 1
Petunjuk

Simpan semua angka di jual[10][7] dulu. Total cabang = jumlah satu baris (loop dalam j), total hari = jumlah satu kolom (loop luar j, loop dalam i). Pakai >, bukan >=, saat mencari maksimum, supaya cabang yang seri memilih nomor terkecil seperti di sample kedua.

Full code 
#include <stdio.h>

int main() {
    int jual[10][7];
    int r, c, i, j, total, maks = -1, terbaik = 0;

    scanf("%d %d", &r, &c);
    for (i = 0; i < r; i++) {
        for (j = 0; j < c; j++) {
            scanf("%d", &jual[i][j]);
        }
    }

    for (i = 0; i < r; i++) {
        total = 0;
        for (j = 0; j < c; j++) {
            total += jual[i][j];
        }
        printf("Cabang %d: %d\n", i + 1, total);
        if (total > maks) {
            maks = total;
            terbaik = i + 1;
        }
    }

    for (j = 0; j < c; j++) {
        total = 0;
        for (i = 0; i < r; i++) {
            total += jual[i][j];
        }
        printf("Hari %d: %d\n", j + 1, total);
    }
    printf("Terbaik: Cabang %d\n", terbaik);
    return 0;
}
