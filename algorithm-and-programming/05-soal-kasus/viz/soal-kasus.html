Trace soal kasus

Visualisasi ini menjalankan program jawaban soal kasus baris demi baris dengan sample input, sama seperti langkah 2 resep yang kamu kerjakan di kertas.

Coba: pilih program di menu Program, lalu klik Langkah berikutnya. Isi keyboard bisa diganti lewat Ubah input untuk mencoba edge case.

Perhatikan: kotak memory yang berubah dan trace table yang bertambah satu baris di setiap putaran. Output di layar harus sama persis dengan sample output.
