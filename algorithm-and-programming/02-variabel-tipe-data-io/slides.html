Variabel, tipe data, dan input/output

Algorithm and programming · semua materi ini memakai satu gambar: variabel adalah kotak di memory.

Variabel = kotak di memory

Setiap variabel adalah kotak di memory dengan empat atribut: nama, tipe, alamat, dan nilai (isi kotak).

char ch = 65;

  nama   ch
        ┌──────┐
  nilai │  65  │
        └──────┘
  alamat 0x1000
  tipe   char (1 byte)
  • Deklarasi memesan kotak. Sebelum diisi, isinya garbage value: sisa data lama di memory.
  • = artinya "simpan nilai di kanan ke kotak di kiri", bukan "sama dengan" seperti di matematika.
  • Karena itu x = x + 5 valid: hitung x + 5 dengan nilai lama, lalu simpan hasilnya ke x.

Tipe = ukuran kotak (di Dev-C++)

Tipe menentukan ukuran kotak dan cara isinya dibaca. Format specifier di printf dan scanf harus cocok dengan tipenya.

TipeUkuranprintfscanf
char1 byte (−128 … 127)%c (karakter) / %d (angka)%c
int4 byte%d%d
long4 byte di Windows%ld%ld
float4 byte, sekitar 7 digit%f%f
double8 byte, sekitar 15 digit%f%lf

Perhatikan double: printf memakai %f, tapi scanf wajib %lf. Slide kuliah menulis long double → %lf. Standarnya %Lf, tapi di Dev-C++ keduanya bermasalah, jadi pakai double saja.

Pembagian dan cast: tebak isinya

Hasil operasi ditentukan oleh tipe operand-nya, bukan oleh tipe variabel yang menampung hasilnya.

int a = 7, b = 2;
float r1 = a / b;
float r2 = (float)a / b;
float r3 = (float)(a / b);
int t = (int)3.99;
char c = 130;
  • r1 = 3.0. int / int menghasilkan int, jadi sisanya dibuang sebelum disimpan ke float.
  • r2 = 3.5. Cast dilakukan sebelum membagi, jadi pembagiannya float.
  • r3 = 3.0. Cast dilakukan setelah pembagian int, jadi sudah terlambat.
  • t = 3. Cast ke int memotong desimal (truncate), tidak membulatkan.
  • c = −126. 130 melebihi batas char (127), jadi nilainya overflow dan wrap around.

printf: satu pola, bukan tabel hafalan

Semua format printf mengikuti pola %[flags][width][.precision]type. Pahami arti tiap bagian, maka hasilnya bisa ditebak.

  • flags: - rata kiri, 0 isi sisa dengan nol.
  • width: lebar minimum output.
  • .precision: jumlah digit di belakang koma.
  • type: d int, f float/double, c char, s string.

Kenapa scanf butuh &?

printf hanya perlu tahu nilai yang akan ditampilkan. scanf harus menulis ke dalam kotak, jadi scanf perlu tahu alamat kotak itu.

printf("%d", x);    // baca ISI kotak x
scanf("%d", &x);    // tulis KE kotak x,
                    // jadi butuh alamat x
  • &x artinya "alamat x".
  • Kalau & lupa ditulis, scanf menganggap isi x sebagai alamat dan menulis ke tempat sembarang. Program bisa crash.
  • Array char tidak memakai &, karena nama array sudah berupa alamat.
  • Return value scanf = jumlah variabel yang berhasil diisi.

Format mana yang melewati spasi dan Enter?

Spasi dan Enter juga karakter. Sebagian format scanf melewatinya secara otomatis, sebagian lagi ikut membacanya.

Buffer: kenapa getchar seperti "dilewati"

Semua yang diketik masuk ke buffer keyboard dulu, termasuk Enter (↵). scanf dan getchar mengambil karakter dari buffer ini secara berurutan.

scanf("%[^\n]", name);
scanf("%d", &nim);
gender = getchar();

buffer:
B u d i ↵ 1 2 3 4 5 ↵
                    ↑ tertinggal!
  • %d berhenti tepat setelah angka, jadi Enter terakhir tertinggal di buffer.
  • getchar langsung mengambil Enter itu tanpa menunggu ketikan baru. Akibatnya gender berisi '\n'.
PerbaikanPakai scanf(" %c", &gender);. Spasi sebelum %c membuang semua spasi dan Enter yang tersisa.

Ringkasan

  • Variabel adalah kotak dengan nama, tipe, alamat, dan nilai.
  • int / int = int. Kalau butuh desimal, cast salah satu operand sebelum membagi.
  • printf butuh nilai, scanf butuh alamat.
  • Input lewat buffer. Waspadai Enter yang tertinggal sebelum %c atau getchar.
