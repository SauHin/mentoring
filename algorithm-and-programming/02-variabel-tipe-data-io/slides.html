Variabel, tipe data, dan input/output

Algorithm and programming · materi 02

Target: kamu bisa menebak isi variabel setelah pembagian dan casting, dan tahu kenapa input kadang "dilewati". Semuanya memakai satu gambar: variabel adalah kotak di memory.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Variabel

Setiap variabel adalah kotak dengan nama, tipe, alamat, dan nilai

Variabel adalah kotak di memory untuk menyimpan satu nilai.

Kotak yang baru dideklarasikan berisi garbage value (sisa data lama di memory). Jangan membaca variabel sebelum diisi.

Notes 2️⃣ · Assignment

= artinya simpan nilai di kanan ke kotak di kiri, bukan sama dengan

Assignment adalah perintah menyimpan nilai ke kotak. Sisi kanan dihitung dulu, lalu hasilnya disimpan.

StatementYang terjadiIsi x sesudahnya
int x;Minta kotakgarbage value
x = 10;Simpan 10 ke x10
x = x + 5;Ambil isi x (10), tambah 5, simpan 15 ke x15

Karena itu x = x + 5 valid di C, walaupun di matematika tidak mungkin. Nilai lama x tertimpa.

Notes 3️⃣ · Tipe data

Tipe menentukan ukuran kotak, dan specifier harus cocok dengan tipenya

Tipe data adalah jenis isi variabel. Ukuran di bawah berlaku untuk Dev-C++ di Windows.

TipeUkuranprintfscanf
char1 byte (−128 … 127)%c (karakter) / %d (angka)%c
int4 byte (± 2,1 miliar)%d%d
long4 byte di Windows%ld%ld
float4 byte, sekitar 7 digit%f%f
double8 byte, sekitar 15 digit%f%lf
  • double: printf memakai %f, tapi scanf wajib %lf.
  • Slide kuliah menulis long double → %lf. Di Dev-C++, %lf dan %Lf sama-sama bermasalah, jadi pakai double saja.

Notes 4️⃣ · Overflow

Nilai yang melebihi batas tipenya berputar ke sisi lain, tanpa error

Overflow adalah kondisi saat nilai melebihi batas tipenya, sehingga nilainya wrap around.

char c = 130;    // char: -128 … 127
printf("%d", c); // -126
  1. char punya 256 nilai: −128 sampai 127.
  2. 128 jadi −128, 129 jadi −127, 130 jadi −126.
  3. Cara cepat: 130 − 256 = −126.

Mirip odometer 3 digit yang kembali ke 000 setelah 999, bedanya char kembali ke −128.

Notes 5️⃣ · Pembagian integer

int dibagi int menghasilkan int, jadi sisanya dibuang

Pembagian integer adalah pembagian dua int. Hasil operasi mengikuti tipe terbesar di antara kedua operand.

OperasiHasilKenapa
7 / 23int dan int → int, sisanya dibuang
7 % 21% = sisa bagi: 7 = 2 × 3 + 1
7.0 / 23.5double dan int → double

float r1 = 7 / 2; berisi 3.0, bukan 3.5. Tipe kotak tujuan tidak mengubah cara menghitung.

Notes 6️⃣ · Casting

Cast harus terjadi sebelum pembagian, bukan sesudahnya

Casting adalah mengubah tipe satu nilai dengan (tipe)nilai. Contoh dengan a = 7 dan b = 2:

KodeHasilKenapa
(float)a / b3.5a jadi 7.0 sebelum dibagi
(float)(a / b)3.0Kurung dihitung dulu (3), baru di-cast. Terlambat.
(int)3.993Cast ke int memotong desimal, tidak membulatkan

Notes 7️⃣ · Konstanta

Konstanta mengunci nilai supaya tidak bisa diubah saat program jalan

Konstanta adalah nilai bernama yang tidak bisa diubah. Ada dua cara menulisnya.

#define PI 3.14159          // diganti teks sebelum compile, tanpa tipe
const float PI2 = 3.14159f; // variabel yang dikunci, punya tipe
  • Suffix menentukan tipe angka: 3.14 = double, 3.14f = float, 10L = long.
  • PI2 = 3; ditolak compiler, karena PI2 dikunci dengan const.

Notes 8️⃣ · printf

Semua format printf mengikuti satu pola, jadi hasilnya bisa ditebak

Format specifier (%…) diganti satu nilai, berurutan dari kiri. Polanya %[flags][width][.precision]type.

  • flags: - rata kiri, 0 isi sisa dengan nol.
  • width: lebar minimum output.
  • .precision: jumlah digit di belakang koma.
  • type: d int, f float/double, c char, s string.
Format, nilaiHasil (· = spasi)
%5d, 42···42
%-5d|, 4242···|
%05d, 4200042
%8.2f, 3.14159····3.14

Jangan printf(ss): kalau ss berisi %, outputnya kacau. Tulis printf("%s", ss).

Notes 9️⃣ · scanf

scanf butuh alamat (&x), karena scanf menulis ke kotak

Operator & memberi alamat sebuah variabel. printf cukup melihat isi kotak, scanf harus tahu lokasinya.

printf("%d", x);    // baca ISI kotak x
scanf("%d", &x);    // tulis KE kotak x,
                    // jadi butuh alamat x
  • Kalau & lupa, scanf menulis ke alamat sembarang, dan program bisa crash.
  • Return value scanf = jumlah variabel yang berhasil diisi.
  • Array char tidak memakai &, karena nama array sudah berupa alamat (materi 04).

Notes 10 · Buffer keyboard

%c dan getchar ikut membaca spasi dan Enter

Buffer adalah penampungan ketikan keyboard, termasuk Enter. Format scanf mengambil karakter dari depan buffer.

FormatYang dibacaMelewati spasi/Enter di depan?
%d %f %lfAngkaYa
%sSatu kata, berhenti di spasiYa
%c, getchar()Satu karakter apa pun, termasuk EnterTidak
%[^\n]Satu baris penuh, sampai sebelum EnterTidak

Notes 10 · Buffer keyboard

Enter yang tertinggal setelah %d langsung diambil getchar

Pengguna mengetik nama, Enter, NIM, Enter. Begini isi buffer dan siapa yang mengambil apa.

scanf("%[^\n]", name);
scanf("%d", &nim);
gender = getchar();

buffer:
B u d i ↵ 1 2 3 4 5 ↵
                    ↑ tertinggal!
  • %d berhenti tepat setelah angka, jadi Enter terakhir tertinggal.
  • getchar mengambil Enter itu tanpa menunggu ketikan baru, jadi gender berisi '\n'.

Perbaikan: scanf(" %c", &gender);. Spasi sebelum %c membuang spasi dan Enter yang tersisa.

Ringkasan: semuanya kembali ke gambar kotak di memory

  • Variabel = kotak dengan nama, tipe, alamat, dan nilai. = artinya simpan (1️⃣ 2️⃣).
  • Tipe menentukan ukuran kotak dan specifier-nya. Nilai yang tidak muat akan overflow (3️⃣ 4️⃣).
  • int / int = int. Kalau butuh desimal, cast salah satu operand sebelum membagi (5️⃣ 6️⃣).
  • printf butuh nilai, scanf butuh alamat (8️⃣ 9️⃣).
  • Input lewat buffer. Pakai " %c" kalau membaca karakter setelah angka (10).

Soal latihan: kerjakan dulu, jawabannya di slide berikutnya

  1. Berapa isi float r = 9 / 4; dan float s = (float)9 / 4;?
  2. Berapa nilai char c = 200; kalau dicetak dengan %d?
  3. Apa output printf("[%6.1f]", 3.14159);?
  4. x = scanf("%d %d", &a, &b); dengan input 5 abc. Berapa x?

Soal lain (isi buffer, %s, getchar, program nilai akhir) ada di akhir setiap section notes.

Jawaban soal latihan

  1. r = 2.0 (9 / 4 dihitung sebagai int dulu). s = 2.25 (9 jadi float sebelum dibagi).
  2. 200 − 256 = −56 (overflow).
  3. [···3.1]. Precision 1 → 3.1 (3 karakter), lalu width 6 menambah 3 spasi di kiri.
  4. x = 1. a berhasil diisi 5, tapi "abc" bukan angka, jadi b tidak terisi.
