Variabel, tipe data, dan input/output

Algorithm and programming · satu gambar: variabel adalah kotak

Variabel = kotak di memory

char ch = 65;

  nama   ch
        ┌──────┐
  nilai │  65  │
        └──────┘
  alamat 0x1000
  tipe   char (1 byte)
  • Deklarasi = minta kotak. Isinya sampah sampai diisi.
  • = artinya simpan ke, bukan "sama dengan".
  • x = x + 5: baca kanan dulu, lalu simpan ke kiri.

Tipe = ukuran kotak (Dev-C++)

TipeUkuranprintfscanf

Catatan: di slide kuliah tertulis long double → %lf. Standarnya %Lf, tapi di Dev-C++ keduanya bermasalah. Pakai double.

Tebak isinya

int a = 7, b = 2;
float r1 = a / b;
float r2 = (float)a / b;
float r3 = (float)(a / b);
int t = (int)3.99;
char c = 130;
  • r1 = 3.0: int / int = int, sisa dibuang
  • r2 = 3.5: cast sebelum membagi
  • r3 = 3.0: cast terlambat
  • t = 3: dibuang, bukan dibulatkan
  • c = −126: overflow, berputar

Kenapa scanf butuh &?

printf("%d", x);    // lihat ISI kotak
scanf("%d", &x);    // tulis KE kotak
                    // → butuh ALAMAT
  • &x = alamat x
  • Lupa & = scanf menulis ke alamat sembarang → crash
  • Array char: tanpa &. Nama array sudah alamat.
  • Return scanf = jumlah variabel yang berhasil diisi

Buffer: kenapa getchar "dilewati"

scanf("%[^\n]", name);
scanf("%d", &nim);
gender = getchar();

buffer:
B u d i ↵ 1 2 3 4 5 ↵
                    ↑ tertinggal!
  • Ketikan masuk ke buffer dulu, termasuk Enter (↵).
  • %d berhenti setelah angka → Enter tertinggal.
  • getchar langsung mengambil Enter itu.
Perbaikanscanf(" %c", &gender);. Spasi di depan = buang spasi/Enter dulu.

Ringkasan

  • Variabel = kotak: nama, tipe, alamat, nilai.
  • int / int = int. Cast sebelum membagi.
  • printf butuh nilai, scanf butuh alamat.
  • Input lewat buffer. Waspadai Enter yang tertinggal.
