Memory dan input/output

Visualisasi ini menampilkan variabel sebagai kotak di memory, dan ketikan keyboard sebagai buffer yang dibaca scanf/getchar.

Coba: pilih program di menu Program, lalu klik Langkah berikutnya. Buka Ubah input untuk mengetik input lain.

Perhatikan: kotak yang berubah warna di Memory, dan karakter buffer yang dicoret setelah dibaca.
