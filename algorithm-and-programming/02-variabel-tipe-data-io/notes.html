Variabel, tipe data, dan input/output

Satu gambar yang menjelaskan hampir semuanya: variabel adalah kotak di memory. Kalau gambar ini jelas, aturan scanf, casting, dan nanti pointer jadi masuk akal sendiri.

Slide · Visualisasi memory & buffer · Printf playground

TL;DR
  • Variabel = kotak dengan nama, tipe, alamat, dan nilai. Belum diisi = isinya garbage value.
  • int / int = int: sisa dibuang. Cast salah satunya ke float sebelum membagi.
  • printf butuh nilai, scanf butuh alamat (&x), karena scanf menulis ke kotak.
  • Ketikan keyboard masuk ke buffer dulu. Enter yang tertinggal di buffer adalah penyebab getchar atau %c "dilewati".

1. Variabel = kotak di memory

char ch = 65;

  nama   ch
        ┌──────┐
  nilai │  65  │   ← R-value: isi kotak
        └──────┘
  alamat 0x1000    ← L-value: lokasi kotak di memory
  tipe   char (1 byte, muat -128 … 127)
  • Deklarasi (int x;) = minta kotak. Isinya garbage value: sisa data lama di memory. Jangan dibaca sebelum diisi.
  • Assignment (x = 10;) = simpan nilai ke kotak. = bukan "sama dengan", tapi "simpan ke".
  • x = x + 5; dibaca dari kanan: ambil isi x, tambah 5, simpan kembali ke x.

Variabel bisa dideklarasikan di awal blok { } mana pun, dan hanya dikenal di dalam blok itu.

Lihat sendiri di visualisasi (program "Variabel = kotak").

2. Tipe data: ukuran kotak

Tipe menentukan berapa byte kotaknya dan bagaimana isinya dibaca. Ukuran di bawah ini berlaku untuk Dev-C++ di Windows. Cek sendiri dengan sizeof.

TipeUkuranIsiprintfscanf
char1 byte−128 … 127 (kode ASCII)%c / %d%c
int4 byte± 2,1 miliar%d%d
long4 byte di Windowssama dengan int%ld%ld
long long8 byte± 9,2 × 10¹⁸%lld%lld
float4 bytedesimal, ± 7 digit akurat%f%f
double8 bytedesimal, ± 15 digit akurat%f / %lf%lf

Modifier: unsigned (tanpa nilai negatif, jadi batas atasnya dua kali lipat), short, long. Contoh: unsigned int, long long.

Catatan: long double di Dev-C++Di slide kuliah tertulis long double → %lf. Menurut standar C, yang benar %Lf (L besar). Tapi Dev-C++ memakai runtime Windows yang menganggap long double sama dengan double. Compiler-nya memberi warning untuk %lf dan %Lf, dan angka yang tercetak bisa salah. Untuk desimal, pakai double saja.
Kenapa long dan int sama?Di Windows, long = 4 byte, sama dengan int. Itu sebabnya membaca long pakai %d masih jalan di Dev-C++ (compiler hanya memberi warning). Di Linux atau Mac, long = 8 byte dan hasilnya rusak. Biasakan %ld untuk long.

Overflow

Kalau nilai tidak muat di kotaknya, nilainya wrap around: lewat dari batas atas, lalu mulai lagi dari batas bawah. Tidak ada error.

char c = 130;   // char hanya muat sampai 127
printf("%d", c); // -126

3. Aritmetika, pembagian, dan casting

Tebak dulu isi setiap variabel:

int a = 7, b = 2;
float r1 = a / b;
float r2 = (float)a / b;
float r3 = (float)(a / b);
int t = (int)3.99;
int s = 7 % 3;
Jawaban
VariabelNilaiKenapa
r13.0int / int dihitung sebagai int dulu (3), baru disimpan ke float. Tipe tujuan tidak mengubah cara menghitung.
r23.5a diubah jadi 7.0 sebelum dibagi. float / int = float.
r33.0Kurung dihitung dulu: 7 / 2 = 3, baru di-cast. Terlambat.
t3Cast ke int membuang desimal, bukan membulatkan.
s1% = sisa bagi: 7 = 2 × 3 + 1. Hanya untuk int.

Aturannya: hasil operasi mengikuti tipe "terbesar" di antara kedua operand. int dan int menghasilkan int, sedangkan int dan float menghasilkan float. Casting (tipe)nilai mengubah tipe satu nilai, dan posisinya menentukan kapan perubahan terjadi.

4. Konstanta

#define PI 3.14159        // diganti teks sebelum compile, tanpa tipe
const float PI2 = 3.14159f; // variabel yang dikunci, punya tipe
  • Nilai konstanta tidak bisa diubah saat program jalan.
  • Suffix menentukan tipe angka: 3.14 = double, 3.14f = float, 10L = long, 10U = unsigned.
  • float x = 3.14; menyimpan double ke float. Beberapa compiler (misalnya Visual C++) memberi warning. Pakai 3.14f atau (float)3.14.

sizeof(tipe) atau sizeof(variabel) memberi ukuran dalam byte. Contoh: sizeof(int) = 4 di Dev-C++.

5. Output dengan printf

printf(format, nilai1, nilai2, …): format berisi teks biasa dan specifier (%…) yang diganti nilai, berurutan dari kiri.

Polanya selalu sama: %[flags][width][.precision]type. Coba langsung di printf playground, jadi tidak perlu dihafal.

6. Input dengan scanf

int x;
scanf("%d", &x);

Kenapa harus &? Ingat gambar kotak. printf("%d", x) hanya perlu melihat isi kotak. scanf harus menulis ke kotak, jadi ia butuh alamat kotak itu: &x = "alamat dari x". Lupa & = scanf menulis ke alamat sembarang, dan program bisa crash.

FormatMembacaSpasi/Enter di depan
%d, %f, %lfAngkaDilewati otomatis
%sSatu kata, berhenti di spasiDilewati otomatis
%cSatu karakter apa pun, termasuk spasi dan EnterTidak dilewati
%[^\n]Satu baris penuh termasuk spasi, sampai sebelum EnterTidak dilewati
%4sMaksimal 4 karakterDilewati
  • Array char (string) tanpa &: scanf("%s", nama);. Nama array sudah berupa alamat (dibahas di materi 04).
  • Return value scanf = jumlah variabel yang berhasil diisi. Berguna untuk mengecek input.
  • Untuk double, scanf wajib %lf. printf boleh %f atau %lf.

7. Buffer keyboard: kenapa input "dilewati"

Ketikanmu tidak langsung masuk ke variabel. Semua yang diketik, termasuk tombol Enter (\n), masuk ke buffer dulu. scanf dan getchar lalu mengambil dari depan buffer.

printf("Name: ");          scanf("%[^\n]", name);
printf("NIM: ");           scanf("%d", &nim);
printf("Gender (M/F): ");  gender = getchar();   // "dilewati"!

Isi buffer setelah pengguna mengetik nama, Enter, NIM, dan Enter:

B u d i ␣ S a n t o s o ↵ 1 2 3 4 5 ↵
└──────── name ────────┘   └─ nim ─┘ ↑ tertinggal!

%d berhenti tepat setelah angka, jadi Enter terakhir tertinggal. getchar() mengambil karakter apa pun di depan buffer, yaitu Enter itu. Program tidak menunggu ketikan baru, sehingga kelihatannya "dilewati".

PerbaikanPakai scanf(" %c", &gender);. Spasi sebelum %c artinya "buang semua spasi dan Enter dulu". Atau panggil getchar(); sekali untuk membuang Enter sisa.

Jalankan kasus ini langkah demi langkah di visualisasi (program "Kenapa getchar dilewati?"). Buffer-nya terlihat.

9. Latihan

Untuk setiap soal, gambar isi buffer dulu, baru jawab.

1. x = scanf("%d %d %d", &y, &z, &w); (a) Apa yang terjadi kalau pengguna hanya mengetik 2 bilangan lalu Enter? (b) Berapa x kalau yang diketik 3 huruf?

Jawaban

(a) scanf terus menunggu bilangan ketiga, karena Enter hanya dianggap spasi oleh %d. Setelah bilangan ketiga diketik, x = 3. (b) x = 0: huruf pertama sudah gagal dibaca sebagai %d, jadi tidak ada variabel yang terisi.

2. x = scanf("%s %s", ss1, ss2); dengan input Good morning everyone. Apa isi ss1, ss2, dan x? Bagaimana kalau inputnya Class 1PAT?

Jawaban

ss1 = "Good", ss2 = "morning", x = 2. "everyone" tetap di buffer. Untuk Class 1PAT: ss1 = "Class", ss2 = "1PAT", x = 2 (%s menerima angka juga, selama bukan spasi).

3. scanf("%4s", ss); dengan input Good morning.

Jawaban

ss = "Good": maksimal 4 karakter.

4. ch = getchar(); dengan input Binus. Lalu, kalau ada ch1 = getchar(); ch2 = getchar();, apa isinya?

Jawaban

ch = 'B'. getchar hanya mengambil satu karakter. ch1 = 'B', ch2 = 'i': karakter berikutnya di buffer, tanpa menunggu ketikan baru.

5. Buat program yang membaca nilai assignment, mid exam, dan final exam, lalu mencetak Final Score = 20% assignment + 30% mid + 50% final.

Jawaban 
#include <stdio.h>

int main() {
    float assignment, mid, final_exam, score;
    printf("Assignment: "); scanf("%f", &assignment);
    printf("Mid exam  : "); scanf("%f", &mid);
    printf("Final exam: "); scanf("%f", &final_exam);
    score = 0.2f * assignment + 0.3f * mid + 0.5f * final_exam;
    printf("Final Score = %.2f\n", score);
    return 0;
}

Pakai float supaya desimal tidak hilang. Nama final_exam dipakai karena lebih jelas daripada final.

6. Di program Name/NIM/Gender (bagian 7), kenapa gender = getchar() seolah tidak dijalankan?

Jawaban

Enter setelah NIM tertinggal di buffer. getchar langsung mengambilnya, jadi gender = '\n' tanpa menunggu ketikan. Perbaikan: scanf(" %c", &gender);.

7. Kenapa printf(ss) dan printf("%s", ss) bisa berbeda kalau ss = "10 % 3 = 1\n"?

Jawaban

printf(ss) membaca isi ss sebagai format. % 3 dianggap specifier yang butuh argumen, padahal tidak ada argumen. Hasilnya tidak bisa diandalkan. printf("%s", ss) mencetak isi ss apa adanya.
