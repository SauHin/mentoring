Variabel: kotak di memory yang punya nama, tipe, alamat, dan nilai

deklarasi seperti int x; di anatomi program (materi 01) semua section berikutnya, dan pointer (materi 04)

Loker di stasiun: setiap loker punya nomor (alamat), label nama, ukuran tertentu, dan isi.

loker baru biasanya kosong. Variabel baru tidak kosong: isinya sisa data lama yang tidak bisa ditebak.

Variabel adalah kotak di memory untuk menyimpan satu nilai. Setiap kotak punya empat hal: nama, tipe, alamat, dan nilai (isinya).

Deklarasi (int x;) = minta kotak. Variabel hanya dikenal di dalam blok { } tempat ia dideklarasikan.

Di slide dosen, nilai disebut R-value dan lokasi kotak disebut L-value.

Kotak yang baru dideklarasikan berisi garbage value: sisa data lama di memory. Jangan membaca variabel sebelum diisi.

Buka visualisasi, program "Variabel = kotak". Kotak x berisi ? sampai diisi.

Variabel = kotak dengan nama, tipe, alamat, dan nilai. Belum diisi = isinya garbage value.

Soal latihan: Apa output int x; printf("%d", x);?

Tidak bisa ditebak. x belum diisi, jadi isinya garbage value, dan angka yang tercetak bisa berbeda setiap kali program dijalankan.

Assignment: = artinya simpan, bukan sama dengan

variabel sebagai kotak (1️⃣) akumulator dan update di loop (materi 03)

Mengganti isi loker: keluarkan isi lama, masukkan isi baru. Loker hanya muat satu isi.

isi loker lama bisa kamu bawa pulang. Nilai lama variabel hilang begitu tertimpa.

Assignment adalah perintah menyimpan nilai ke kotak, ditulis dengan =. Arahnya selalu dari kanan ke kiri: hitung sisi kanan dulu, lalu simpan ke kotak di kiri.

StatementYang terjadiIsi x sesudahnya
int x;Minta kotakgarbage value
x = 10;Simpan 10 ke x10
x = x + 5;Ambil isi x (10), tambah 5, simpan 15 ke x15

Karena itu x = x + 5 valid di C, walaupun di matematika tidak mungkin x sama dengan x + 5.

= artinya "simpan nilai di kanan ke kotak di kiri". Nilai lama tertimpa.

Soal latihan: int a = 3, b = 5; a = b; b = a; Berapa a dan b sekarang?

a = 5 dan b = 5. Setelah a = b, nilai lama a (3) sudah tertimpa, jadi b = a menyimpan 5. Untuk menukar dua nilai, simpan dulu salah satunya: t = a; a = b; b = t;.

Tipe data: menentukan ukuran kotak dan cara membaca isinya

variabel (1️⃣) overflow (4️⃣), pembagian (5️⃣), dan format printf/scanf (8️⃣, 9️⃣)

Wadah di dapur: gelas untuk air, mangkuk untuk sup. Ukuran wadah menentukan berapa banyak yang muat.

isi wadah bisa kamu lihat langsung. Isi kotak hanya angka biner, dan tipe yang menentukan angka itu dibaca sebagai bilangan bulat, desimal, atau karakter.

Tipe data adalah jenis isi variabel, yang menentukan berapa byte kotaknya dan bagaimana isinya dibaca. Ukuran di bawah berlaku untuk Dev-C++ di Windows. Cek sendiri dengan sizeof(int), yang memberi ukuran dalam byte.

TipeUkuranIsiprintfscanf
char1 byte−128 … 127 (kode ASCII)%c / %d%c
int4 byte± 2,1 miliar%d%d
long4 byte di Windowssama dengan int%ld%ld
long long8 byte± 9,2 × 10¹⁸%lld%lld
float4 bytedesimal, ± 7 digit akurat%f%f
double8 bytedesimal, ± 15 digit akurat%f / %lf%lf
Modifier, long, dan long double di Dev-C++
  • Modifier: unsigned (tanpa nilai negatif, jadi batas atasnya dua kali lipat), short, long. Contoh: unsigned int, long long.
  • long = int? Di Windows, long = 4 byte. Itu sebabnya membaca long pakai %d masih jalan di Dev-C++ (hanya warning). Di Linux atau Mac, long = 8 byte dan hasilnya rusak. Biasakan %ld.
  • long double: slide kuliah menulis %lf, standar C menulis %Lf. Dev-C++ memakai runtime Windows yang menganggap long double sama dengan double, jadi keduanya memberi warning dan angkanya bisa salah. Untuk desimal, pakai double saja.

double: printf boleh %f, tapi scanf wajib %lf. Dengan %f, scanf hanya mengisi 4 dari 8 byte, dan nilainya jadi aneh.

Tipe menentukan ukuran kotak dan format specifier-nya. Specifier harus cocok dengan tipe.

Soal latihan: Buat program yang membaca nilai assignment, mid exam, dan final exam, lalu mencetak Final Score = 20% assignment + 30% mid + 50% final. 
#include <stdio.h>

int main() {
    float assignment, mid, final_exam, score;
    printf("Assignment: "); scanf("%f", &assignment);
    printf("Mid exam  : "); scanf("%f", &mid);
    printf("Final exam: "); scanf("%f", &final_exam);
    score = 0.2f * assignment + 0.3f * mid + 0.5f * final_exam;
    printf("Final Score = %.2f\n", score);
    return 0;
}

Pakai float supaya desimal tidak hilang. Nama final_exam dipakai karena lebih jelas daripada final.

Overflow: nilai yang tidak muat berputar ke sisi lain rentang

ukuran tipe data (3️⃣) faktorial besar di loop (materi 03)

Odometer motor dengan 3 digit: setelah 999, angkanya kembali ke 000.

odometer kembali ke nol. Tipe bertanda seperti char kembali ke batas negatifnya, yaitu −128.

Overflow adalah kondisi saat nilai melebihi batas tipenya. Nilainya wrap around: lewat dari batas atas, lalu lanjut dari batas bawah. Tidak ada error saat program jalan.

char c = 130;    // char hanya muat -128 … 127
printf("%d", c); // -126

Di program nyata, overflow sering muncul saat mengalikan angka besar, misalnya faktorial: hasilnya tiba-tiba negatif atau mengecil.

Contoh hitungan: kenapa 130 jadi −126
  1. Rentang char: −128 sampai 127, jadi ada 256 nilai.
  2. Lewat batas: 130 lebih besar 3 dari 127.
  3. Wrap around: 128 jadi −128, 129 jadi −127, 130 jadi −126. Cara cepatnya: 130 − 256 = −126.

Nilai yang tidak muat tidak memicu error. Nilainya diam-diam berputar ke sisi lain rentang.

Soal latihan: Berapa isi char c = 200; kalau dicetak dengan %d?

200 − 256 = −56.

Pembagian integer: int dibagi int membuang sisanya

tipe int (3️⃣) dan div/mod di soal detik → jam (materi 01) casting (6️⃣) dan rata-rata di loop (materi 03)

Membagi 7 permen ke 2 anak tanpa memotong permen: masing-masing dapat 3, dan sisa 1.

di dunia nyata sisanya masih ada di tanganmu. Di C, hasil / tidak menyimpan sisa sama sekali, jadi sisanya diambil sendiri dengan %.

Pembagian integer adalah pembagian dua int, yang hasilnya juga int, jadi sisanya dibuang. Aturannya: hasil operasi mengikuti tipe "terbesar" di antara kedua operand.

OperasiHasilKenapa
7 / 23int dan int → int, sisanya dibuang
7 % 21% = sisa bagi: 7 = 2 × 3 + 1. Hanya untuk int.
7.0 / 23.5double dan int → double

float r1 = 7 / 2; berisi 3.0, bukan 3.5. Pembagian int dihitung dulu (3), baru disimpan ke float. Tipe kotak tujuan tidak mengubah cara menghitung.

int / int = int. Yang menentukan adalah tipe operand-nya, bukan tipe variabel penampung.

Soal latihan: Berapa hasil 17 / 5, 17 % 5, dan 17.0 / 5?

17 / 5 = 3 (17 = 5 × 3 + 2, sisanya dibuang). 17 % 5 = 2. 17.0 / 5 = 3.4.

Casting: ubah tipe sebelum menghitung, bukan sesudahnya

pembagian integer (5️⃣) rata-rata (float)total / count di loop (materi 03)

Menukar mata uang sebelum belanja: kalau ditukar dulu, kamu bisa membayar pecahan sen.

menukar uang setelah belanja masih berguna. Casting setelah pembagian int sudah terlambat, karena sisanya sudah hilang.

Casting adalah mengubah tipe satu nilai dengan menulis (tipe)nilai. Posisinya menentukan kapan perubahan terjadi.

Kode (a = 7, b = 2)HasilKenapa
(float)a / b3.5a jadi 7.0 sebelum dibagi, jadi pembagiannya float

(int)3.993Cast ke int membuang desimal, bukan membulatkan

Buka visualisasi, program "Pembagian integer & casting". r1 dan r3 sama-sama 3.0, hanya r2 yang 3.5.

Kalau butuh desimal, cast salah satu operand sebelum membagi: (float)a / b.

int a = 7, b = 2;
float r1 = a / b;
float r2 = (float)a / b;
float r3 = (float)(a / b);
int t = (int)3.99;

Konstanta: nilai yang dikunci dan tidak bisa diubah

variabel (1️⃣) dan #define PI di soal luas lingkaran (materi 01) ukuran array (materi 04)

Tanggal lahir di KTP: dicatat sekali, lalu tidak berubah.

KTP masih bisa diperbaiki di kantor. Konstanta tidak bisa diubah sama sekali selama program jalan.

Konstanta adalah nilai bernama yang tidak bisa diubah saat program jalan. Ada dua cara menulisnya:

#define PI 3.14159          // diganti teks sebelum compile, tanpa tipe
const float PI2 = 3.14159f; // variabel yang dikunci, punya tipe

Suffix di belakang angka menentukan tipenya: 3.14 = double, 3.14f = float, 10L = long, 10U = unsigned.

float x = 3.14; menyimpan double ke float. Beberapa compiler (misalnya Visual C++) memberi warning. Pakai 3.14f atau (float)3.14.

Konstanta = nilai yang dikunci. Pakai #define atau const, supaya angka penting tidak muncul tiba-tiba di tengah rumus.

Soal latihan: Apa yang terjadi kalau program menulis PI2 = 3; setelah const float PI2 = 3.14159f;?

Compiler menolak (error), karena PI2 dikunci dengan const dan tidak boleh diubah.

Output dengan printf: satu pola, bukan tabel hafalan

escape sequence dan header stdio.h (materi 01), tipe data (3️⃣) semua output program

Formulir dengan kolom kosong: teksnya sudah tercetak, dan setiap kolom diisi satu nilai sesuai urutan.

di formulir, kolom yang tidak diisi tetap kosong. Di printf, specifier tanpa nilai membuat output kacau.

printf(format, nilai1, nilai2, …) mencetak teks format, dan setiap format specifier (%…) diganti satu nilai, berurutan dari kiri. Polanya selalu %[flags][width][.precision]type.

Buka printf playground, ketik format sendiri, lalu baca arti tiap bagiannya. Kotak biru adalah spasi tambahan dari width.

Fungsi output lain: putchar, puts, putch
FungsiHeaderGunanya

Jangan menulis printf(ss). Isi ss dianggap format, jadi kalau ada % di dalamnya, printf mencari nilai yang tidak pernah diberikan. Tulis printf("%s", ss).

Specifier = %[flags][width][.precision]type. Satu specifier untuk satu nilai, dan tipenya harus cocok.

Soal latihan: Kenapa printf(ss) dan printf("%s", ss) bisa berbeda kalau ss = "10 % 3 = 1\n"?

printf(ss) membaca isi ss sebagai format. % 3 dianggap specifier yang butuh argumen, padahal tidak ada argumen, jadi hasilnya tidak bisa diandalkan. printf("%s", ss) mencetak isi ss apa adanya.

Soal latihan: Apa output printf("[%6.1f]", 3.14159);?

[···3.1], dengan · = spasi. Precision 1 membulatkan ke 3.1 (3 karakter), lalu width 6 menambah 3 spasi di kiri.

Input dengan scanf: butuh alamat, karena scanf menulis ke kotak

alamat kotak (1️⃣) dan format specifier (8️⃣) buffer keyboard (10) dan pointer (materi 04)

Kurir paket butuh alamat rumahmu untuk mengantar barang. Kalau kamu hanya memberi tahu isi rumahmu, kurir tidak tahu harus ke mana.

kurir yang salah alamat biasanya kembali. scanf yang salah alamat tetap menulis ke tempat sembarang, dan program bisa crash.

printf("%d", x) hanya perlu melihat isi kotak. scanf harus menulis ke kotak, jadi ia butuh alamatnya. Operator & memberi alamat sebuah variabel: &x = "alamat x".

int x;
scanf("%d", &x);   // tulis angka dari keyboard KE kotak x
  • Return value: scanf mengembalikan jumlah variabel yang berhasil diisi. Berguna untuk mengecek input.
  • Pengecualian: array char (string) ditulis tanpa &, misalnya scanf("%s", nama);, karena nama array sudah berupa alamat (materi 04).

Kalau & lupa ditulis, scanf menganggap isi x sebagai alamat dan menulis ke tempat sembarang. Program bisa crash, atau x tidak berubah.

Buka visualisasi, program "scanf & nilai kembaliannya". Ubah input jadi 6 7 abc, lalu lihat isi x.

printf butuh nilai, scanf butuh alamat (&x).

Soal latihan: x = scanf("%d %d %d", &y, &z, &w); (a) Apa yang terjadi kalau pengguna hanya mengetik 2 bilangan lalu Enter? (b) Berapa x kalau yang diketik 3 huruf?

(a) scanf terus menunggu bilangan ketiga, karena Enter hanya dianggap spasi oleh %d. Setelah bilangan ketiga diketik, x = 3.

(b) x = 0: huruf pertama sudah gagal dibaca sebagai %d, jadi tidak ada variabel yang terisi.

Buffer keyboard: kenapa input kadang "dilewati"

scanf (9️⃣) membaca menu, karakter, dan string dari keyboard

Antrean pesanan di dapur: pelayan menaruh semua pesanan di antrean, lalu koki mengambilnya satu per satu dari depan.

koki bisa membuang pesanan yang tidak jelas. scanf dan getchar tidak membuang apa pun yang tidak diminta formatnya, termasuk Enter.

Buffer adalah tempat penampungan ketikan keyboard sebelum dibaca program. Semua yang diketik, termasuk Enter (\n), masuk ke buffer dulu, lalu scanf dan getchar mengambilnya dari depan.

FormatYang dibacaMelewati spasi/Enter di depan?
%d, %f, %lfAngkaYa
%sSatu kata, berhenti di spasiYa
%4sMaksimal 4 karakterYa
%c, getchar()Satu karakter apa pun, termasuk spasi dan EnterTidak
%[^\n]Satu baris penuh, sampai sebelum EnterTidak
Contoh: kenapa getchar setelah %d "dilewati" 
printf("Name: ");          scanf("%[^\n]", name);
printf("NIM: ");           scanf("%d", &nim);
printf("Gender (M/F): ");  gender = getchar();   // "dilewati"!

Isi buffer setelah pengguna mengetik nama, Enter, NIM, dan Enter:

B u d i ␣ S a n t o s o ↵ 1 2 3 4 5 ↵
└──────── name ────────┘   └─ nim ─┘ ↑ tertinggal!
  1. %[^\n] membaca nama sampai sebelum Enter. Enter pertama tetap di buffer.
  2. %d melewati Enter itu, membaca 12345, lalu berhenti. Enter kedua tertinggal.
  3. getchar() mengambil karakter apa pun di depan buffer, yaitu Enter kedua. gender berisi '\n', dan program tidak menunggu ketikan baru.

Perbaikan: tulis scanf(" %c", &gender);. Spasi sebelum %c artinya "buang semua spasi dan Enter dulu". Cara lain: panggil getchar(); sekali untuk membuang Enter sisa.

Buka visualisasi, program "Kenapa getchar dilewati?". Di bagian buffer keyboard, Enter yang tertinggal terlihat jelas. Lalu bandingkan dengan program "Perbaikan".

Bahaya gets: gets tidak tahu ukuran array. Kalau input lebih panjang dari array, kelebihannya menimpa memory lain. Karena itu gets dihapus dari standar C sejak C11, dan compiler lain bisa menolaknya. Alternatif aman: fgets(s, sizeof(s), stdin);. Ingat bahwa fgets ikut menyimpan Enter di akhir string.

Ketikan masuk buffer dulu. Enter yang tertinggal setelah %d akan diambil oleh %c atau getchar, jadi pakai " %c".

Soal latihan: x = scanf("%s %s", ss1, ss2); dengan input Good morning everyone. Apa isi ss1, ss2, dan x? Bagaimana kalau inputnya Class 1PAT?

ss1 = "Good", ss2 = "morning", x = 2. "everyone" tetap di buffer.

Untuk Class 1PAT: ss1 = "Class", ss2 = "1PAT", x = 2. %s menerima angka juga, selama bukan spasi.

Soal latihan: scanf("%4s", ss); dengan input Good morning. Apa isi ss?

ss = "Good": maksimal 4 karakter.

Soal latihan: ch = getchar(); dengan input Binus. Lalu, kalau programnya ch1 = getchar(); ch2 = getchar();, apa isinya?

ch = 'B', karena getchar hanya mengambil satu karakter. ch1 = 'B' dan ch2 = 'i': ch2 mengambil karakter berikutnya di buffer, tanpa menunggu ketikan baru.

Soal latihan: Di program Name/NIM/Gender di atas, kenapa gender = getchar() seolah tidak dijalankan?

Enter setelah NIM tertinggal di buffer. getchar langsung mengambilnya, jadi gender = '\n' tanpa menunggu ketikan. Perbaikan: scanf(" %c", &gender);.

Bug yang sering muncul: kenali dari gejalanya

semua section sebelumnya membaca kodemu sendiri saat output aneh

Dokter yang mengenali penyakit dari gejala: demam dan batuk mengarah ke penyebab tertentu.

dokter bisa salah diagnosis. Di program, kamu bisa memastikan penyebabnya dengan mencoba perbaikannya.

Semua bug di bawah lolos compile (paling banyak hanya warning), jadi harus dikenali dari gejalanya.

BugGejalaPerbaikan
Lupa & di scanfCrash, atau nilai tidak berubahscanf("%d", &x) (9️⃣)
scanf("%f", &d) untuk doubleNilai anehdouble pakai %lf di scanf (3️⃣)
printf("%d", 3.5)Angka anehSpecifier harus cocok dengan tipe: %f
avg = total / n (semua int)Desimal hilang(float)total / n (6️⃣)
getchar() atau %c setelah %dInput "dilewati"" %c" (10)
Membaca variabel sebelum diisiNilai acakSelalu inisialisasi: int total = 0; (1️⃣)

Nilai aneh → cek specifier dan &. Desimal hilang → cek pembagian int. Input dilewati → cek Enter di buffer.

Soal latihan: Program ini selalu mencetak 2.00 untuk input 2 3. Kenapa? int a, b; float avg; scanf("%d %d", &a, &b); avg = (a + b) / 2; printf("%.2f", avg);

(a + b) / 2 = 5 / 2, yaitu pembagian integer, jadi hasilnya 2, baru disimpan ke float sebagai 2.00. Perbaikan: avg = (a + b) / 2.0; atau (float)(a + b) / 2.
