Algoritma: langkah yang jelas, berurutan, dan pasti berhenti

cara kamu menyelesaikan masalah sehari-hari, misalnya mengikuti resep semua materi berikutnya, karena setiap program adalah algoritma yang ditulis dalam C

Resep mie instan: rebus air, masukkan mie, tunggu 3 menit, tiriskan, campur bumbu. Urutannya jelas, dan ada akhirnya.

kamu bisa menebak maksud "garam secukupnya". Komputer tidak bisa menebak, jadi setiap langkah harus pasti.

Algoritma adalah urutan langkah yang jelas untuk menyelesaikan satu masalah, dan pasti berhenti. Satu masalah bisa punya banyak algoritma yang benar, jadi yang dinilai adalah hasilnya, bukan kemiripan dengan contoh.

BerhentiSetelah sejumlah langkah, pasti selesai
EfisienTidak ada langkah yang tidak perlu

Contoh: dua algoritma rata-rata 3 bilangan

Read A
Read B
Read C
average = (A + B + C) / 3
Print average		Read A, B, C sekaligus

Langkahnya berbeda, tapi keduanya benar, karena hasilnya sama untuk semua input.

Algoritma yang baik benar untuk semua input yang valid, tidak ambigu, dan pasti berhenti. Tidak harus mirip contoh.

Soal latihan: Kenapa langkah "tambahkan garam secukupnya" tidak boleh ada di algoritma?

Langkah itu ambigu: setiap orang mengartikan "secukupnya" dengan jumlah yang berbeda. Langkah algoritma harus pasti, misalnya "tambahkan 1 sendok teh garam".

Soal latihan: Baca 3 bilangan, cetak yang terbesar. Pikirkan dua algoritma berbeda.

Cara 1, bandingkan semua: kalau a ≥ b dan a ≥ c, maka a terbesar. Kalau tidak, bandingkan b dan c.

Cara 2, "juara sementara": anggap a terbesar, lalu bandingkan dengan yang lain satu per satu. Cara ini mudah diperluas ke 100 bilangan dengan loop (materi 03).

#include <stdio.h>

int main() {
    int a, b, c, max;
    scanf("%d %d %d", &a, &b, &c);
    max = a;                 // juara sementara
    if (b > max) max = b;
    if (c > max) max = c;
    printf("%d\n", max);
    return 0;
}

Tujuh langkah dari masalah ke program

algoritma (1️⃣) pseudocode dan flowchart (3️⃣, 4️⃣), serta syntax error dan logic error (10, 11)

Membangun rumah: tentukan kebutuhan (berapa kamar), buat denah, baru bangun, lalu cek hasilnya.

rumah yang salah bangun susah dibongkar, sedangkan kode bisa diubah kapan saja. Tapi kesalahan di langkah awal tetap paling mahal, karena semua langkah sesudahnya ikut salah.

Langkah ke-2 butuh satu istilah: model adalah rumus atau aturan yang menghubungkan input dengan output.

LangkahPertanyaan kunci
1. Definisi masalahInput-nya apa? Output-nya apa?
2. ModelRumus atau aturan apa yang dipakai?
3. Desain algoritmaLangkahnya apa, dan urutannya bagaimana? Tulis sebagai pseudocode atau flowchart.
4. Tulis kodeBagaimana menulisnya dalam C?
5. CompileApakah aturan penulisan C sudah benar?
6. Run dan testApakah hasilnya benar?
7. DokumentasiApakah orang lain (atau kamu nanti) paham?
  • Definisi sebelum model: rumus baru bisa dipilih kalau input dan output-nya jelas.
  • Desain sebelum kode: kalau langsung menulis kode, kamu memikirkan logika dan aturan C sekaligus, jadi kesalahannya bercampur.
  • Compile sebelum test: program yang melanggar aturan C tidak bisa dijalankan sama sekali.
Contoh dari kuliah: akar persamaan kuadrat ax² + bx + c = 0
LangkahIsinya
1. DefinisiInput a, b, c. Output x1 dan x2.
2. Modeld = b² − 4ac, lalu x = (−b ± √d) / 2a
3. DesainPseudocode atau flowchart. Kalau d < 0, akarnya imajiner.
4. KodeFile .c di Dev-C++ (programnya ada di 9️⃣)
5. CompilePerbaiki syntax error (10)
6. Testa = 1, b = −3, c = 2 harus menghasilkan 2 dan 1. Kalau tidak, ada logic error (11).
7. DokumentasiKomentar dan nama variabel yang jelas

Jangan langsung menulis kode. Tentukan input, output, dan rumusnya dulu, lalu susun langkahnya.

Soal latihan: Ubah detik menjadi jam, menit, dan detik (contoh: 3725 detik = 1 jam 2 menit 5 detik). Tentukan input, output, model, lalu tulis programnya.

Input: total detik. Output: jam, menit, detik. Model: 1 jam = 3600 detik, 1 menit = 60 detik. Ambil hasil bagi bulat (div) dan sisanya (mod).

Start
Read total
jam = total div 3600
sisa = total mod 3600
menit = sisa div 60
detik = sisa mod 60
Print jam, menit, detik
End
#include <stdio.h>

int main() {
    int total, jam, menit, detik;
    scanf("%d", &total);
    jam = total / 3600;           // int / int: sisa dibuang
    menit = (total % 3600) / 60;  // % = sisa bagi
    detik = total % 60;
    printf("%d jam %d menit %d detik\n", jam, menit, detik);
    return 0;
}

/ antar int = pembagian bulat, dan % = sisanya. Ini dibahas lebih dalam di materi 02.

Pseudocode: algoritma tanpa aturan bahasa

langkah desain algoritma (2️⃣) menulis kode C (6️⃣)

Kerangka esai di kertas coretan: isinya lengkap, tapi kamu belum peduli ejaan dan tanda baca.

kerangka esai boleh lompat-lompat. Pseudocode tetap harus berurutan dan tidak ambigu, sama seperti algoritma.

Pseudocode adalah algoritma yang ditulis mirip kode, tapi bebas dari aturan bahasa pemrograman. Bentuk lain: structured English (kalimat biasa yang terstruktur) dan flowchart (4️⃣).

Setiap keyword pseudocode punya pasangan langsung di C, jadi menerjemahkannya tinggal mencocokkan:

OperasiPseudocodeC
InputRead, Get, Inputscanf("%d", &x);
OutputPrint, Display, Writeprintf("%d", x);
Simpan nilaiSet x to 0, x = 0, Storex = 0;
HitungCompute, Add, +, −, *, /total = total + x;
SelectionIF … THEN … ELSE … ENDIFif (…) { … } else { … }
RepetitionDOWHILE … ENDDO, WHILEwhile (…) { … }

Yang hanya ada di C: deklarasi variabel dan tipenya (int x;), #include, main(), dan ;. Ini aturan bahasa, bukan logika. Detail scanf dan printf ada di materi 02.

Tulis pseudocode dulu. Setelah itu, menerjemahkannya ke C tinggal mencocokkan tabel ini.

Soal latihan: Tulis pseudocode lalu kode C untuk menghitung luas persegi panjang dari panjang dan lebar. 
Start
Read panjang, lebar
luas = panjang * lebar
Print luas
End
#include <stdio.h>

int main() {
    float panjang, lebar, luas;
    scanf("%f %f", &panjang, &lebar);
    luas = panjang * lebar;
    printf("%.2f\n", luas);
    return 0;
}

Strukturnya hanya sequence (5️⃣).

Soal latihan: Tulis program untuk menghitung luas lingkaran dari jari-jari. 
#include <stdio.h>
#define PI 3.14159

int main() {
    float r;
    scanf("%f", &r);
    printf("%.2f\n", PI * r * r);
    return 0;
}

#define PI membuat konstanta bernama, jadi angka 3.14159 tidak muncul "tiba-tiba" di tengah rumus. Konstanta dibahas di materi 02.

Flowchart: algoritma dalam bentuk gambar

pseudocode (3️⃣) tiga struktur (5️⃣) dan visualisasi materi ini

Peta jalur di stasiun: kotak menunjukkan tempat, panah menunjukkan arah jalan.

di peta kamu bebas memilih jalur. Di flowchart, cabang hanya diambil berdasarkan kondisi di simbol decision.

Flowchart adalah gambar algoritma: setiap langkah berupa simbol, dan panah menunjukkan urutannya.

SimbolNamaUntuk
TerminalStart dan End
Input/OutputRead dan Print
ProcessHitung dan simpan nilai
DecisionKondisi ya/tidak (IF, kondisi loop)

Buka visualisasi, program "Selection", lalu klik Langkah berikutnya. Simbol flowchart yang sedang jalan berubah warna, bersamaan dengan baris pseudocode dan C yang sama.

Bentuk simbol menunjukkan jenis langkah. Panah menunjukkan urutannya.

Soal latihan: Simbol apa yang dipakai untuk "Read panjang", "luas = panjang * lebar", dan "n % 2 == 0?"

"Read panjang" = Input/Output (jajar genjang). "luas = panjang * lebar" = Process (persegi panjang). "n % 2 == 0?" = Decision (belah ketupat), karena jawabannya ya atau tidak.

Tiga struktur: semua program hanya tersusun dari ini

pseudocode dan flowchart (3️⃣, 4️⃣) selection dengan if, dan repetition (materi 03)

Perjalanan ke kampus: jalan lurus (sequence), belok kiri atau kanan tergantung macet (selection), naik tangga sampai lantai 5 (repetition).

di jalan kamu bisa berimprovisasi. Program tidak punya bentuk keempat: semuanya hanya gabungan tiga bentuk ini.

Structure theorem menyatakan bahwa semua program bisa disusun hanya dari tiga struktur: sequence, selection, dan repetition.

StrukturArtinyaContoh C
SequenceLangkah dijalankan berurutan dari atas ke bawahscanf(…); avg = sum / 3; printf(…);
SelectionPilih salah satu cabang berdasarkan kondisiif (n % 2 == 0) … else …
RepetitionUlangi selama kondisi masih benarwhile (stars < 5) { … }

Saat bingung menulis program, tanyakan: bagian mana yang berurutan, mana yang memilih, dan mana yang mengulang?

Buka visualisasi "satu algoritma, tiga bentuk". Ketiga struktur dijalankan langkah demi langkah, dengan pseudocode, flowchart, dan C menyala bersamaan.

Sequence = berurutan, selection = memilih satu cabang, repetition = mengulang. Program sebesar apa pun hanya gabungan ketiganya.

Soal latihan: Struktur apa yang dipakai program "baca bilangan, lalu cetak Genap atau Ganjil"?

Selection. Bilangan genap kalau sisa bagi 2 sama dengan 0. Kode lengkapnya ada di visualisasi, program "Selection".

Soal latihan: Sebutkan struktur di setiap bagian: "baca 10 nilai, jumlahkan semuanya, lalu cetak Lulus kalau rata-ratanya ≥ 60".

Membaca dan menjumlahkan 10 nilai = repetition. Menghitung rata-rata setelahnya = sequence. Mencetak Lulus kalau ≥ 60 = selection.

Anatomi program C: setiap baris punya tugas

pseudocode yang diterjemahkan ke C (3️⃣) semua kode di materi berikutnya

Surat resmi: kop surat di atas (#include), isi surat (main), titik di akhir kalimat (;), dan salam penutup (return 0).

surat tetap bisa dibaca walau titiknya lupa. Program C tidak bisa di-compile kalau ; lupa.

Statement adalah satu perintah di C, dan selalu diakhiri ;. C tidak menganggap Enter sebagai akhir perintah.

#include <stdio.h>           // 1. ambil daftar fungsi input/output (printf, scanf)

int main() {                 // 2. program SELALU mulai dari main
    printf("Welcome to BINUS\n");   // 3. statement, diakhiri ;
    return 0;                // 4. beri tahu sistem: program selesai tanpa error
}                            // 5. kurung kurawal menutup blok main
BagianKenapa perlu
#include <stdio.h>Compiler perlu tahu bentuk fungsi printf. Tanpa ini, Dev-C++ memberi warning atau error.
int main()Titik mulai program. Harus ada tepat satu.
{ }Mengelompokkan statement menjadi satu blok.
return 0;Nilai 0 artinya program berakhir normal.

Komentar: teks setelah // (satu baris) atau di antara /* … */ (beberapa baris) diabaikan compiler. Komentar tidak dijalankan dan tidak dicetak.

Kenapa int main(), bukan void main()?

Bentuk void main() atau main() tanpa tipe memang ada di buku lama, tapi di Dev-C++ (gcc) bisa memberi warning. int main() dengan return 0; selalu aman.

C itu case sensitive: huruf besar dan kecil dianggap berbeda. main ≠ Main, sum ≠ Sum, printf ≠ Printf.

Program C mulai dari main, setiap statement diakhiri ;, dan huruf besar-kecil itu berbeda.

Soal latihan: Benar atau salah? (a) Setiap program C mulai dari main. (b) Komentar /* … */ dicetak saat program jalan. (c) Semua variabel harus dideklarasikan sebelum dipakai. (d) Semua variabel harus diberi tipe. (e) C menganggap number dan Number sama.

(a) Benar. (b) Salah: komentar diabaikan compiler, tidak pernah dicetak. (c) Benar. (d) Benar: compiler harus tahu ukuran kotaknya (materi 02). (e) Salah: C case sensitive, jadi keduanya variabel berbeda.

Escape sequence: menulis karakter khusus di dalam string

printf di anatomi program (6️⃣) format output di materi 02

Di aplikasi chat, mengetik :) bisa berubah jadi emoji senyum. Dua karakter berubah jadi satu tanda.

emoji diubah oleh aplikasinya. Escape sequence diubah oleh compiler saat program di-compile.

Escape sequence adalah backslash (\) diikuti satu karakter, untuk menulis karakter yang tidak bisa diketik langsung di dalam string. Contoh: Enter di dalam string ditulis \n.

TulisArtinya
\nPindah baris (newline)
\tTab
\"Tanda kutip ganda di dalam string
\'Tanda kutip tunggal
\\Backslash itu sendiri
\aBunyi beep

Untuk mencetak satu backslash, tulis dua: \\. Satu backslash saja selalu dibaca sebagai awal escape sequence.

Backslash mengubah karakter sesudahnya menjadi karakter khusus: \n pindah baris, \t tab, \\ backslash.

Soal latihan: Tebak output printf("A\tB\nC\\D \"E\""); 
A       B
C\D "E"

\t jadi tab, \n pindah baris, \\ jadi satu backslash, dan \" jadi tanda kutip.

Identifier: nama buatanmu, dengan tiga aturan

deklarasi variabel di anatomi program (6️⃣) semua nama variabel dan fungsi yang kamu buat

Aturan nama akun: tidak boleh pakai spasi, dan tidak boleh memakai nama yang sudah dipakai sistem.

nama akun biasanya tidak membedakan huruf besar dan kecil. Identifier di C membedakannya: Total ≠ total.

Identifier adalah nama yang kamu buat sendiri, misalnya nama variabel dan nama fungsi. Aturannya:

  1. Diawali huruf atau underscore (_), bukan angka.
  2. Isinya hanya huruf, angka, dan underscore. Tidak boleh spasi atau tanda lain.
  3. Tidak boleh sama dengan keyword, yaitu kata yang sudah dipakai C sendiri: int, float, char, if, else, for, while, do, return, void, break, continue, dan seterusnya.

Dev-C++ menebalkan keyword, jadi mudah dikenali.

Identifier diawali huruf atau _, hanya berisi huruf, angka, dan _, dan bukan keyword.

Soal latihan: Mana yang identifier valid? name, x1, _total, 1time, int, total-harga, jumlahData, Total

Valid: name, x1, _total, jumlahData, Total (berbeda dari total).

Tidak valid: 1time (diawali angka), int (keyword), total-harga (tanda - dibaca sebagai operator kurang).

Header file: daftar fungsi siap pakai

#include di anatomi program (6️⃣) printf/scanf (materi 02), fungsi string (materi 04), malloc (data structure)

Katalog toko: kamu tidak perlu menghafal semua barang, cukup tahu katalog mana yang dibuka.

katalog hanya daftar barang. #include juga hanya memberi tahu compiler bentuk fungsinya, sedangkan isi fungsinya sudah disediakan library C.

Header file adalah file berisi daftar fungsi siap pakai. #include artinya "aku akan memakai fungsi dari daftar ini". Kamu tidak perlu menghafal isinya, cukup tahu header mana yang dicari.

HeaderIsinyaContoh fungsi
stdio.hInput/outputprintf, scanf, getchar, puts
math.hMatematikasqrt, pow, fabs, ceil, floor
stdlib.hUtility umummalloc, free, rand, srand, atoi, exit
string.hOlah stringstrlen, strcpy, strcmp, strcat
time.hWaktu dan tanggaltime, clock
Contoh dari kuliah: persamaan kuadrat dengan math.h 
#include <stdio.h>
#include <math.h>

int main() {
    double a, b, c, d;
    scanf("%lf %lf %lf", &a, &b, &c);
    d = b * b - 4 * a * c;
    if (d < 0) {
        printf("Imaginary\n");
    } else {
        double x1 = (-b + sqrt(d)) / (2 * a);   // kurung (2 * a) wajib!
        double x2 = (-b - sqrt(d)) / (2 * a);
        printf("x1 = %.2f, x2 = %.2f\n", x1, x2);
    }
    return 0;
}

Algoritma di flowchart (sequence lalu selection) diterjemahkan baris demi baris. Input 1 -3 2 harus menghasilkan 2.00 dan 1.00.

Lupa #include <math.h> saat memakai sqrt: compiler hanya memberi warning, tapi hasilnya bisa aneh, karena compiler tidak tahu bentuk fungsinya.

Pakai fungsi siap pakai → include header-nya dulu. Cukup tahu header mana untuk keperluan apa.

Soal latihan: Program kamu memakai printf, sqrt, dan strlen. Header apa saja yang harus di-include?

stdio.h (untuk printf), math.h (untuk sqrt), dan string.h (untuk strlen).

Syntax error: melanggar aturan bahasa, ditolak compiler

langkah compile (2️⃣) dan anatomi program (6️⃣) membaca pesan error di Dev-C++

Petugas tata bahasa yang menolak surat karena salah ketik, dan menunjuk baris yang salah.

petugas manusia bisa menebak maksudmu. Compiler menolak sampai tulisannya benar-benar sesuai aturan.

Syntax error adalah kesalahan penulisan yang melanggar aturan bahasa C, sehingga compiler menolak program. Kabar baiknya, compiler memberi tahu nomor barisnya.

KodeKenapa salah
printf("Hi") tanpa ;Statement belum ditutup
Printf("Hi");Case sensitive: fungsinya printf
printf('Hi');String pakai kutip ganda "…". Kutip tunggal hanya untuk satu karakter.

Kalau ; lupa, pesan error sering menunjuk baris berikutnya, karena compiler baru sadar ada yang salah saat membaca baris itu. Cek juga baris sebelumnya.

Syntax error ditemukan compiler. Baca nomor barisnya, lalu cek baris itu dan baris sebelumnya.

Soal latihan: Ada 3 syntax error di program ini. Temukan semuanya. 
#include <stdio.h>

int Main() {
    int x = 5
    printf("%d\n", X);
    return 0;
}

(1) Main harus main: tanpa main, program tidak punya titik mulai. (2) int x = 5 belum diakhiri ;. (3) X belum dideklarasikan, karena yang ada x huruf kecil.

Logic error: program jalan, tapi hasilnya salah

langkah run dan test (2️⃣) mencari bug dengan trace table (materi 03)

Resep yang tertulis rapi, tapi takaran gulanya salah: kuenya tetap jadi, tapi rasanya aneh.

kue yang salah langsung terasa. Logic error bisa tidak kelihatan sama sekali kalau kamu tidak mengecek hasilnya.

Logic error adalah kesalahan di algoritma: program jalan tanpa protes, tapi hasilnya salah. Compiler tidak bisa menemukannya, jadi kamu harus menguji dengan input yang jawabannya sudah kamu tahu.

KodeKenapa salahPerbaikan
x / 2 * aDihitung (x / 2) * ax / (2 * a)
avg = a + b + c / 3Hanya c yang dibagi 3, karena / dikerjakan sebelum +(a + b + c) / 3
Syntax errorLogic error
Yang menemukanCompilerKamu sendiri, lewat testing
Program bisa jalan?TidakBisa, tapi hasilnya salah

Program yang jalan belum tentu benar. Selalu test dengan input yang jawabannya sudah kamu tahu.

Soal latihan: avg = a + b + c / 3 dengan a = 3, b = 6, c = 9. Berapa hasilnya, dan berapa seharusnya?

Hasilnya 3 + 6 + 9 / 3 = 3 + 6 + 3 = 12. Seharusnya (3 + 6 + 9) / 3 = 18 / 3 = 6.
