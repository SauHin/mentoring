Algorithm and programming · 01

Algoritma dan struktur program C

Dari masalah → langkah-langkah → kode C. Tujuannya: kamu bisa menyusun langkah sendiri, bukan menghafal contoh program.

Slide · Visualisasi: satu algoritma, tiga bentuk

TL;DR
  • Algoritma = langkah yang jelas, berurutan, dan pasti berhenti untuk menyelesaikan masalah.
  • Semua program dibangun dari 3 struktur: sequence, selection, repetition.
  • Pseudocode dan flowchart = algoritma tanpa aturan bahasa. Kode C = algoritma + aturan bahasa (tipe data, ;, { }).
  • Bedakan syntax error (ditolak compiler) dan logic error (program jalan, tapi hasilnya salah).

1. Apa itu algoritma?

Algoritma adalah resep: daftar langkah yang urutannya jelas untuk menyelesaikan satu masalah. Komputer tidak bisa menebak maksudmu, jadi setiap langkah harus pasti.

Satu masalah bisa punya banyak algoritma yang benar. Contoh: rata-rata 3 bilangan.

Algoritma 1Algoritma 2
Read A
Read B
Read C
average = (A + B + C) / 3
Print average		Read A, B, C sekaligus
sum = A + B + C
average = sum / 3
Print average

Keduanya benar, karena hasilnya sama. Yang dinilai bukan "mirip contoh atau tidak", tapi hasilnya benar dan langkahnya jelas.

Ciri algoritma yang baikArtinya
Logikanya benarMenghasilkan output yang benar untuk semua input yang sah
Tidak ambiguSetiap langkah hanya bisa diartikan satu cara
BerhentiSetelah sejumlah langkah, pasti selesai (tidak berputar selamanya)
EfisienTidak membuang langkah yang tidak perlu
Mudah diterjemahkanBisa langsung ditulis ke bahasa pemrograman

2. Dari masalah ke program

Contoh masalah dari kuliah: mencari akar persamaan kuadrat ax² + bx + c = 0.

LangkahPertanyaan kunciContoh
1. Definisi masalahInput apa? Output apa?Input a, b, c. Output x1 dan x2.
2. ModelRumus atau aturan apa yang dipakai?d = b² − 4ac, x = (−b ± √d) / 2a
3. Desain algoritmaLangkahnya apa saja, urutannya bagaimana?Pseudocode atau flowchart. Kalau d < 0, akarnya imajiner.
4. Tulis kodeBagaimana menulisnya dalam C?File .c di Dev-C++
5. CompileApakah aturan bahasanya sudah benar?Perbaiki syntax error
6. Run & tesApakah hasilnya benar?Coba a=1, b=−3, c=2 → harus 2 dan 1. Perbaiki logic error.
7. DokumentasiApakah orang lain (atau kamu nanti) paham?Komentar dan nama variabel yang jelas
Dua jenis errorSyntax error: melanggar aturan bahasa (lupa ;, salah ketik Printf). Compiler menolak, dan memberi tahu nomor barisnya. Logic error: program jalan, tapi hasilnya salah (misalnya menulis / 2 * a padahal maksudnya / (2 * a)). Compiler tidak bisa mendeteksinya, jadi kamu harus menguji dengan input yang jawabannya sudah kamu tahu.

3. Tiga cara menulis algoritma

  • Structured English: kalimat biasa yang terstruktur.
  • Pseudocode: mirip kode, tapi bebas aturan bahasa. Fokus ke logika.
  • Flowchart: gambar dengan simbol dan panah.

4. Structure theorem: hanya 3 struktur

Program serumit apa pun hanya tersusun dari tiga struktur ini. Saat bingung menulis program, tanyakan: bagian mana yang berurutan, mana yang memilih, mana yang mengulang?

StrukturArtinyaContoh C
SequenceLangkah dijalankan berurutan dari atas ke bawahscanf(…); avg = sum / 3; printf(…);
SelectionPilih salah satu cabang berdasarkan kondisiif (n % 2 == 0) … else …
RepetitionUlangi selama kondisi masih benarwhile (stars < 5) { … }

Buka visualisasi "satu algoritma, tiga bentuk": ketiga struktur dijalankan langkah demi langkah, dengan pseudocode, flowchart, dan C menyala bersamaan.

5. Anatomi program C

#include <stdio.h>           // 1. ambil "katalog" fungsi input/output (printf, scanf)

int main() {                 // 2. program SELALU mulai dari main
    printf("Welcome to BINUS\n");   // 3. statement, diakhiri ;
    return 0;                // 4. beri tahu sistem: program selesai tanpa error
}                            // 5. kurung kurawal menutup blok main
BagianKenapa perlu
#include <stdio.h>Compiler perlu tahu bentuk fungsi printf. Tanpa ini, Dev-C++ memberi warning atau error.
int main()Titik mulai program. Harus ada tepat satu.
{ }Mengelompokkan statement menjadi satu blok.
;Menandai akhir satu statement. C tidak melihat Enter sebagai akhir baris.
return 0;Nilai 0 artinya program berakhir normal.
main di Dev-C++Tulis int main() dengan return 0;. Bentuk void main() atau main() tanpa tipe memang ada di buku lama, tapi di Dev-C++ (gcc) bisa memberi warning. int main() selalu aman.

C itu case sensitive: main ≠ Main, sum ≠ Sum, printf ≠ Printf.

Komentar

// komentar satu baris
/* komentar
   beberapa baris */

Komentar diabaikan compiler: tidak dijalankan dan tidak dicetak. Gunanya untuk manusia yang membaca kode.

6. Karakter dan escape sequence

Beberapa karakter tidak bisa diketik langsung di dalam string (misalnya Enter), atau punya arti khusus (tanda kutip). Untuk itu dipakai escape sequence: backslash + satu huruf.

TulisArtinya
\nPindah baris (newline)
\tTab
\"Tanda kutip ganda di dalam string
\'Tanda kutip tunggal
\\Backslash itu sendiri
\aBunyi beep

Tebak output-nya dulu, baru buka jawabannya:

printf("A\tB\nC\\D \"E\"");
Jawaban 
A       B
C\D "E"

\t jadi tab, \n pindah baris, \\ jadi satu backslash, dan \" jadi tanda kutip.

7. Identifier dan keyword

Identifier = nama yang kamu buat sendiri (nama variabel, fungsi). Aturannya:

  • Diawali huruf atau underscore (_), bukan angka.
  • Isinya hanya huruf, angka, dan underscore. Tidak boleh spasi atau tanda lain.
  • Case sensitive, dan tidak boleh sama dengan keyword.

Keyword = kata yang sudah dipakai C sendiri: int, float, char, if, else, for, while, do, return, void, break, continue, dan seterusnya. Dev-C++ mewarnai keyword dengan tebal, jadi mudah dikenali.

Cek sendiri: mana yang identifier sah?

name   x1   _total   1time   int   total-harga   jumlahData   Total
Jawaban

Sah: name, x1, _total, jumlahData, Total (berbeda dari total). Tidak sah: 1time (diawali angka), int (keyword), total-harga (tanda - dibaca sebagai operator kurang).

8. Standard library: katalog fungsi siap pakai

Header file adalah katalog. #include berarti "saya akan memakai fungsi dari katalog ini". Kamu tidak perlu menghafal isinya: cukup tahu katalog mana yang dicari.

HeaderIsinyaContoh fungsi
stdio.hInput/outputprintf, scanf, getchar, puts
math.hMatematikasqrt, pow, fabs, ceil, floor
stdlib.hUtilitas umummalloc, free, rand, srand, atoi, exit
string.hOlah stringstrlen, strcpy, strcmp, strcat
time.hWaktu dan tanggaltime, clock

Contoh: persamaan kuadrat dari kuliah, memakai math.h.

#include <stdio.h>
#include <math.h>

int main() {
    double a, b, c, d;
    scanf("%lf %lf %lf", &a, &b, &c);
    d = b * b - 4 * a * c;
    if (d < 0) {
        printf("Imaginary\n");
    } else {
        double x1 = (-b + sqrt(d)) / (2 * a);   // kurung (2 * a) wajib!
        double x2 = (-b - sqrt(d)) / (2 * a);
        printf("x1 = %.2f, x2 = %.2f\n", x1, x2);
    }
    return 0;
}

Perhatikan: algoritma di flowchart (sequence → selection) diterjemahkan baris demi baris. Coba input 1 -3 2: hasilnya harus 2.00 dan 1.00.

10. Latihan

Untuk setiap soal: tulis pseudocode dulu, lalu terjemahkan ke C pakai tabel di bagian 3.

1. Hitung luas persegi panjang dari panjang dan lebar.

Jawaban 
Start
Read panjang, lebar
luas = panjang * lebar
Print luas
End
#include <stdio.h>

int main() {
    float panjang, lebar, luas;
    scanf("%f %f", &panjang, &lebar);
    luas = panjang * lebar;
    printf("%.2f\n", luas);
    return 0;
}

Strukturnya hanya sequence.

2. Ubah detik menjadi jam, menit, dan detik. Contoh: 3725 detik = 1 jam 2 menit 5 detik.

Jawaban 
Start
Read total
jam = total div 3600
sisa = total mod 3600
menit = sisa div 60
detik = sisa mod 60
Print jam, menit, detik
End
#include <stdio.h>

int main() {
    int total, jam, menit, detik;
    scanf("%d", &total);
    jam = total / 3600;           // int / int: sisa dibuang
    menit = (total % 3600) / 60;  // % = sisa bagi
    detik = total % 60;
    printf("%d jam %d menit %d detik\n", jam, menit, detik);
    return 0;
}

Kuncinya: / antar int = pembagian bulat, dan % = sisanya. Ini dibahas lebih dalam di materi 02.

4. Hitung luas lingkaran dari jari-jari.

Jawaban 
#include <stdio.h>
#define PI 3.14159

int main() {
    float r;
    scanf("%f", &r);
    printf("%.2f\n", PI * r * r);
    return 0;
}

#define PI membuat konstanta bernama, jadi angka 3.14159 tidak muncul "tiba-tiba" di tengah rumus.

5. Baca 3 bilangan, cetak yang terbesar. Coba pikirkan dua algoritma berbeda.

Jawaban

Cara 1, bandingkan semua: kalau a ≥ b dan a ≥ c, maka a terbesar. Kalau tidak, bandingkan b dan c.

Cara 2, "juara sementara": anggap a terbesar, lalu bandingkan dengan yang lain satu per satu. Cara ini mudah diperluas ke 100 bilangan (dengan loop, materi 03).

#include <stdio.h>

int main() {
    int a, b, c, max;
    scanf("%d %d %d", &a, &b, &c);
    max = a;                 // juara sementara
    if (b > max) max = b;
    if (c > max) max = c;
    printf("%d\n", max);
    return 0;
}

6. Benar atau salah? Kalau salah, jelaskan.

  1. Setiap program C mulai dijalankan dari fungsi main.
  2. Komentar /* … */ dicetak ke layar saat program jalan.
  3. Semua variabel harus dideklarasikan sebelum dipakai.
  4. Semua variabel harus diberi tipe saat dideklarasikan.
  5. C menganggap number dan Number sama.
Jawaban

a. Benar. b. Salah: komentar diabaikan compiler, tidak pernah dicetak. c. Benar. d. Benar: compiler harus tahu ukuran kotaknya. e. Salah: C case sensitive, jadi keduanya variabel berbeda.
