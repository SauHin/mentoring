Dari masalah ke program

LangkahPertanyaan kunci
1. Definisi masalahInput apa? Output apa?
2. ModelRumus atau aturan apa?
3. Desain algoritmaLangkahnya apa, urutannya bagaimana? (pseudocode / flowchart)
4–5. Tulis kode & compileAturan bahasanya benar? → syntax error
6. Run & tesHasilnya benar? → logic error
7. DokumentasiOrang lain bisa paham?

Dua jenis error

Syntax errorMelanggar aturan bahasa: lupa ;, Printf, kutip salah.

Compiler menolak dan menunjuk barisnya.
Logic errorProgram jalan, hasilnya salah: a + b + c / 3.

Compiler diam saja. Uji dengan input yang jawabannya sudah kamu tahu.

Yang hanya ada di C: deklarasi tipe (int x;), #include, main(), dan ;.

Hanya 3 struktur

SequenceBerurutan dari atas ke bawah
SelectionPilih satu cabang: if … else
RepetitionUlangi selama kondisi benar: while

Bingung menulis program? Tanya: bagian mana yang berurutan, yang memilih, dan yang mengulang?

Coba sendiri: satu algoritma, tiga bentuk

Anatomi program C

#include <stdio.h>

int main() {
    printf("Welcome\n");
    return 0;
}
  • #include: ambil katalog fungsi (printf)
  • main: program selalu mulai di sini
  • ;: akhir statement (Enter tidak dihitung)
  • return 0: selesai tanpa error
  • Case sensitive: main ≠ Main

Ringkasan

  • Algoritma = langkah jelas, berurutan, berhenti. Banyak versi bisa benar.
  • Semua program = sequence + selection + repetition.
  • Tulis pseudocode dulu, lalu terjemahkan ke C.
  • Syntax error ditangkap compiler. Logic error harus kamu uji sendiri.
