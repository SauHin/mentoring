Notes 1️⃣ · Algoritma

Algoritma yang baik benar, tidak ambigu, dan pasti berhenti

Algoritma adalah urutan langkah yang jelas untuk menyelesaikan satu masalah. Contoh: rata-rata tiga angka.

Algoritma 1Algoritma 2
Read A
Read B
Read C
avg = (A+B+C) / 3
Print avg		Read A, B, C
sum = A + B + C
avg = sum / 3
Print avg
  • Kedua algoritma berbeda, tapi sama-sama benar. Satu masalah bisa punya banyak algoritma.
  • Yang dinilai adalah hasilnya benar untuk semua input, bukan kemiripan dengan contoh.
  • "Garam secukupnya" bukan langkah algoritma, karena ambigu.

Notes 2️⃣ · Tujuh langkah

Tentukan input, output, dan rumusnya dulu, baru menulis kode

Model adalah rumus atau aturan yang menghubungkan input dengan output.

LangkahPertanyaan kunci
1. Definisi masalahInput-nya apa? Output-nya apa?
2. ModelRumus atau aturan apa yang dipakai?
3. Desain algoritmaLangkahnya apa dan bagaimana urutannya? Tulis sebagai pseudocode atau flowchart.
4–5. Tulis kode, compileApakah aturan penulisan C sudah benar?
6. Run dan testApakah hasilnya benar?
7. DokumentasiApakah orang lain bisa memahami program ini?

Kesalahan di langkah awal paling mahal, karena semua langkah sesudahnya ikut salah.

Notes 3️⃣ · Pseudocode

Setiap baris pseudocode punya pasangan langsung di C

Pseudocode adalah algoritma yang ditulis mirip kode, tapi bebas dari aturan bahasa pemrograman.

PseudocodeC
Read xscanf("%d", &x);
Print xprintf("%d", x);
Set x to 0x = 0;
IF … THEN … ELSE … ENDIFif (…) { … } else { … }
DOWHILE … ENDDOwhile (…) { … }

Yang hanya ada di C: deklarasi tipe (int x;), #include, main(), dan ;. Itu aturan bahasa, bukan logika. Detail scanf dan printf ada di materi 02.

Notes 5️⃣ · Tiga struktur

Semua program hanya disusun dari tiga struktur

Structure theorem menyatakan bahwa program sebesar apa pun bisa dibangun dari sequence, selection, dan repetition.

SequenceLangkah dijalankan berurutan dari atas ke bawah.
SelectionProgram memilih satu cabang sesuai kondisi: if … else.
RepetitionLangkah diulang selama kondisi benar: while, for.

Bingung harus mulai dari mana? Tanyakan: bagian mana yang berurutan, bagian mana yang memilih, dan bagian mana yang mengulang?

Notes 6️⃣ · Anatomi program C

Program C selalu mulai dari main, dan setiap statement diakhiri ;

Statement adalah satu perintah di C. Ini program C terkecil yang bisa jalan.

#include <stdio.h>

int main() {
    printf("Welcome\n");
    return 0;
}
  • #include <stdio.h> memasukkan daftar fungsi input/output, termasuk printf.
  • return 0 memberi tahu sistem bahwa program selesai tanpa error.
  • C itu case sensitive: main dan Main dianggap berbeda. Komentar (//, /* */) diabaikan compiler.

Backslash mengubah karakter sesudahnya menjadi karakter khusus

Escape sequence adalah \ diikuti satu karakter, untuk menulis karakter yang tidak bisa diketik langsung di dalam string.

Notes 8️⃣ · Identifier

Identifier diawali huruf atau _, dan tidak boleh berupa keyword

Identifier adalah nama yang kamu buat sendiri, misalnya nama variabel dan nama fungsi.

  1. Diawali huruf atau _.
  2. Hanya berisi huruf, angka, dan _.
  3. Bukan keyword, yaitu kata yang sudah dipakai C (int, for, if, …).
NamaHasil

Notes 9️⃣ · Header file

Cukup tahu header mana yang dipakai, isinya tidak perlu dihafal

Header file berisi daftar fungsi siap pakai, dan #include artinya "aku memakai fungsi dari daftar ini".

HeaderIsinyaContoh fungsi
stdio.hInput/outputprintf, scanf
math.hMatematikasqrt, pow
stdlib.hUtility umumrand, malloc, atoi
string.hStringstrlen, strcpy
time.hWaktutime

Lupa #include <math.h> saat memakai sqrt hanya memberi warning, tapi hasilnya bisa aneh.

Notes 10 · Syntax error

Syntax error ditolak compiler, dan pesannya bisa menunjuk baris sesudahnya

Syntax error adalah kesalahan penulisan yang melanggar aturan bahasa C.

KodeKenapa salah
printf("Hi") tanpa ;Statement belum ditutup
Printf("Hi");Case sensitive: fungsinya printf
printf('Hi');String pakai kutip ganda. Kutip tunggal hanya untuk satu karakter.

Kalau ; lupa, compiler baru sadar saat membaca baris berikutnya. Cek juga baris sebelum nomor yang ditunjuk.

Notes 11 · Logic error

Logic error lolos compile, jadi hanya testing yang bisa menemukannya

Logic error adalah kesalahan di algoritma: program jalan tanpa protes, tapi hasilnya salah.

Syntax errorLogic error
Yang menemukanCompilerKamu, lewat testing
Program jalan?TidakYa, tapi salah

a = 3, b = 6, c = 9

a + b + c / 3     // = 3 + 6 + 3 = 12
(a + b + c) / 3   // = 18 / 3 = 6

/ dikerjakan sebelum +, jadi hanya c yang dibagi 3. Test selalu dengan input yang jawabannya sudah kamu tahu.

Ringkasan: dari masalah, ke algoritma, ke program C

  • Algoritma = langkah yang jelas, berurutan, dan pasti berhenti. Banyak versi bisa sama-sama benar (1️⃣).
  • Tentukan input, output, dan model dulu. Tulis pseudocode atau flowchart, lalu terjemahkan ke C (2️⃣ 3️⃣ 4️⃣).
  • Semua program disusun dari sequence, selection, dan repetition (5️⃣).
  • Program C mulai dari main, statement diakhiri ;, dan C case sensitive (6️⃣ sampai 9️⃣).
  • Syntax error ditemukan compiler. Logic error harus kamu temukan sendiri dengan testing (10 11).
