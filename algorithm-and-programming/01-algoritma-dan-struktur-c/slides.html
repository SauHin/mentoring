Algoritma dan struktur program C

Algorithm and programming · cara mengubah masalah menjadi langkah-langkah (algoritma), lalu menjadi program C.

Algoritma = resep

Algoritma adalah urutan langkah untuk menyelesaikan masalah. Contoh masalah: hitung rata-rata tiga angka.

Algoritma 1Algoritma 2
Read A
Read B
Read C
avg = (A+B+C) / 3
Print avg		Read A, B, C
sum = A + B + C
avg = sum / 3
Print avg
  • Setiap langkah harus jelas, berurutan, dan algoritmanya pasti berhenti.
  • Kedua algoritma di samping berbeda, tapi sama-sama benar. Satu masalah bisa punya banyak algoritma.
  • Yang dinilai adalah hasilnya benar untuk semua input, bukan kemiripan dengan contoh.

Dari masalah ke program: 7 langkah

Jangan langsung menulis kode. Jawab dulu pertanyaan di setiap langkah, karena kesalahan di awal paling mahal untuk diperbaiki.

LangkahPertanyaan kunci
1. Definisi masalahInput-nya apa? Output-nya apa?
2. ModelRumus atau aturan apa yang menghubungkan input dan output?
3. Desain algoritmaLangkahnya apa dan bagaimana urutannya? Tulis sebagai pseudocode atau flowchart.
4–5. Tulis kode, compileApakah aturan penulisan C sudah benar? Kalau belum, muncul syntax error.
6. Run dan testApakah hasilnya benar? Kalau salah, ada logic error.
7. DokumentasiApakah orang lain bisa memahami program ini?

Dua jenis error

Bedanya ada pada siapa yang bisa menemukan error itu: compiler, atau kamu sendiri.

Syntax errorKode melanggar aturan penulisan C, misalnya lupa ;, menulis Printf, atau tanda kutip tidak ditutup.

Compiler menolak program dan menunjukkan baris yang salah.
Logic errorProgram jalan, tapi hasilnya salah. Contoh: a + b + c / 3 hanya membagi c, karena / dikerjakan sebelum +.

Compiler tidak memberi tahu. Test dengan input yang jawabannya sudah kamu tahu.

Pseudocode → C: tinggal mencocokkan

Pseudocode adalah algoritma yang ditulis dengan bahasa sehari-hari. Setiap baris pseudocode punya padanan langsung di C.

PseudocodeC
Read xscanf("%d", &x);
Print xprintf("%d", x);
Set x to 0x = 0;
IF … THEN … ELSE … ENDIFif (…) { … } else { … }
DOWHILE … ENDDOwhile (…) { … }

Bagian yang hanya ada di C: deklarasi tipe (int x;), #include, main(), dan ; di akhir statement.

Hanya ada 3 struktur

Semua program, sebesar apa pun, hanya disusun dari tiga struktur ini.

SequenceLangkah dijalankan berurutan dari atas ke bawah.
SelectionProgram memilih satu cabang sesuai kondisi: if … else.
RepetitionLangkah diulang selama kondisi benar: while, for.

Bingung harus mulai dari mana? Tanyakan: bagian mana yang berurutan, bagian mana yang memilih, dan bagian mana yang mengulang?

Coba sendiri: satu algoritma, tiga bentuk

Anatomi program C

Ini program C terkecil yang bisa jalan. Setiap baris punya tugas sendiri.

#include <stdio.h>

int main() {
    printf("Welcome\n");
    return 0;
}
  • #include <stdio.h> memasukkan daftar fungsi input/output, termasuk printf.
  • Program selalu mulai dari main.
  • ; menandai akhir statement. Enter tidak dihitung sebagai akhir statement.
  • return 0 memberi tahu sistem bahwa program selesai tanpa error.
  • C bersifat case sensitive: main dan Main dianggap berbeda.

Escape sequence: tebak output-nya

Beberapa karakter tidak bisa diketik langsung di dalam string. Karakter itu ditulis dengan backslash (\) diikuti satu huruf.

printf("A\tB\nC\\D \"E\"");
\nnewline\ttab
\\backslash\"double quote

Output:

A       B
C\D "E"

Identifier: valid atau tidak?

Identifier adalah nama yang kamu buat sendiri, misalnya nama variabel dan nama fungsi. Ada tiga aturan.

  • Diawali huruf atau _.
  • Hanya berisi huruf, angka, dan _.
  • Bukan keyword C (int, for, if, …).

Ringkasan

  • Algoritma adalah langkah yang jelas, berurutan, dan pasti berhenti. Banyak versi bisa sama-sama benar.
  • Semua program disusun dari sequence, selection, dan repetition.
  • Tulis pseudocode dulu, lalu terjemahkan baris demi baris ke C.
  • Syntax error ditemukan oleh compiler. Logic error harus kamu temukan sendiri dengan testing.
