Repetition (loop)

for, while, dan do-while bukan tiga hal yang harus dihafal terpisah. Ketiganya adalah satu konsep dengan empat bagian, hanya ditulis di tempat yang berbeda.

Slide · Loop tracer (trace table)

TL;DR
  • Setiap loop punya 4 bagian: inisialisasi, kondisi, body, update. Hilang satu = bug.
  • for: exp1 jalan sekali → (cek exp2 → body → exp3) diulang sampai exp2 false.
  • while cek dulu (bisa 0 kali). do-while jalan dulu (minimal 1 kali).
  • Alat utama memahami loop: trace table, yaitu nilai variabel di setiap putaran.

1. Kenapa perlu loop?

Mencetak angka 1 sampai 100 tanpa loop butuh 100 baris printf. Dengan loop, cukup tulis pola-nya sekali, lalu komputer mengulanginya:

for (int i = 1; i <= 100; i++)
    printf("%d\n", i);

Kunci menulis loop: temukan apa yang sama di setiap ulangan (body) dan apa yang berubah (variabel yang di-update).

3. Urutan eksekusi for

for (exp1; exp2; exp3) body;

exp1 → exp2? → body → exp3 → exp2? → body → exp3 → … → exp2 false → keluar
 └ sekali    └──────────── diulang ────────────┘
  • exp1 jalan sekali, sebelum apa pun.
  • exp2 dicek sebelum setiap putaran. Kalau sejak awal false, body tidak pernah jalan.
  • exp3 jalan setelah body, lalu kembali ke exp2.
  • Setelah loop selesai, variabel loop berisi nilai yang membuat kondisi false. Contoh: setelah for (i = 1; i <= 5; i++), i = 6.
  • exp1 dan exp3 boleh berisi beberapa ekspresi dipisah koma: for (i = 0, j = n - 1; i < j; i++, j--). Ketiganya juga boleh kosong: for (;;) = loop tanpa henti.

Lihat urutannya menyala di flowchart loop tracer (program "for").

Berapa kali loop jalan? Hitung, jangan hafal

Untuk for (i = a; i < b; i++), i bernilai a, a+1, …, b−1. Banyaknya b − a kali (kalau a < b), dan 0 kali kalau a ≥ b. Dengan <=, nilainya sampai b, jadi b − a + 1 kali. Kalau ragu, trace dengan angka kecil: a = 1, b = 3, lalu tulis nilai i satu per satu.

4. Trace table: cara membaca loop apa pun

Buat tabel: satu kolom per variabel yang berubah, satu baris per putaran. Contoh dari kuliah: faktorial.

long number = 4, x = 1;
while (number >= 1)
    x *= number--;     // x = x * number, LALU number dikurangi 1
Putarannumber (sebelum)x setelah x *= numbernumber (sesudah)
141 × 4 = 43
234 × 3 = 122
3212 × 2 = 241
4124 × 1 = 240 → kondisi false, berhenti

Hasil: x = 24 = 4!. number-- (post-decrement) memakai nilai lama dulu, baru dikurangi.

Latihan terbaikBuka loop tracer, nyalakan mode tebak, lalu isi trace table di kertas sebelum setiap langkah ditampilkan.

5. while vs do-while

while (kondisi) { … }do { … } while (kondisi);
Cek kondisiSebelum bodySesudah body
Minimal jalan0 kali1 kali
Cocok untukJumlah ulangan belum tentu adaMenu, validasi input: body harus jalan dulu

Contoh do-while: minta input sampai valid.

#include <stdio.h>

int main() {
    int nilai;
    do {
        printf("Nilai (0-100): ");
        scanf("%d", &nilai);
    } while (nilai < 0 || nilai > 100);   // ulangi selama TIDAK valid
    printf("Nilai = %d\n", nilai);
    return 0;
}

Perhatikan ; setelah while (…) pada do-while. Ini wajib, berbeda dengan while biasa.

6. Pola loop yang sering dipakai

Hampir semua soal loop adalah salah satu pola ini, atau gabungannya. Kenali polanya, lalu tulis kodenya sendiri.

Akumulasi (jumlah, rata-rata)total = 0; sebelum loop, total += x; di body
Hitung yang memenuhi syaratcount = 0; lalu if (syarat) count++;
Cari max/minmax = data pertama; lalu if (x > max) max = x;
Sentinel (sampai nilai khusus)Baca → while (x != 0) { proses; baca lagi; }

Nested (baris × kolom)Loop luar = baris, loop dalam = isi tiap baris
Nested loopLoop dalam selesai seluruhnya untuk setiap satu putaran loop luar. Kalau luar jalan 3 kali dan dalam 4 kali, body dalam jalan 3 × 4 = 12 kali. Lihat program "Nested loop" di loop tracer.

7. break dan continue

EfekContoh output untuk i = 1..10, berhenti/lewati di 5
breakKeluar dari loop sekarang juga1 2 3 4
continueLewati sisa body putaran ini saja, lanjut ke putaran berikutnya1 2 3 4 6 7 8 9 10

Pada for, continue tetap menjalankan exp3 (i++). Pada while, hati-hati: kalau i++ ada setelah continue, update ikut terlewat dan loop bisa tidak berhenti.

break juga dipakai untuk keluar dari switch, dan dari loop for (;;) yang sengaja dibuat tanpa kondisi.

9. Latihan

Untuk soal "berapa kali" dan "apa output-nya", buat trace table dulu.

1. for (i = k; i < n; i++) printf("Binus\n"); Berapa kali printf jalan kalau k < n, k = n, dan k > n?

Jawaban

k < n: n − k kali (i = k, k+1, …, n−1). k = n dan k > n: 0 kali, karena kondisi sudah false sejak awal.

2. for (i = k; i >= n; i--) printf("Binus\n"); Sama, untuk k < n, k = n, k > n.

Jawaban

k < n: 0 kali. k = n: 1 kali. k > n: k − n + 1 kali (i = k, k−1, …, n).

3. Kalau p = statement dan e = ekspresi, tulis ulang dengan while: (a) for (; e ;) p; (b) for (; ; e) p;

Jawaban

(a) while (e) p;: tanpa exp1 dan exp3, for sama dengan while. (b) while (1) { p; e; }: kondisi kosong = selalu benar (infinite loop), dan e jalan sebagai update setelah p.

4. Bandingkan output kedua baris ini:

for (i = 0, j = 1; i < 8; i++, j++) printf("%d + %d = %d\n", i, j, i + j);
for (i = 0, j = 1; i < 8; ++i, ++j); printf("%d + %d = %d\n", i, j, i + j);
Jawaban

Baris 1 mencetak 8 baris: 0 + 1 = 1, 1 + 2 = 3, …, 7 + 8 = 15. Baris 2 punya ; setelah for, jadi loopnya kosong. Loop berjalan sampai i = 8, j = 9, lalu printf jalan sekali: 8 + 9 = 17. i++ vs ++i di exp3 tidak berpengaruh, karena nilainya tidak dipakai.

5. Jelaskan output-nya:

int score = 0, total = 0;
while (score < 10) {
    total += score;
    printf("Score =%d, Total =%d\n", score++, total);
}
Jawaban

10 baris. score++ mencetak nilai lama, baru menambah 1. Baris pertama Score =0, Total =0, lalu 1/1, 2/3, 3/6, 4/10, 5/15, 6/21, 7/28, 8/36, dan terakhir Score =9, Total =45. Total adalah jumlah 0 + 1 + … + score.

6. Faktorial dari kuliah: while (number >= 1) x *= number--; dengan input 5. Berapa hasilnya?

Jawaban

5 × 4 × 3 × 2 × 1 = 120, dicetak 5! = 120. Lihat trace table di bagian 4. Di slide, long number dibaca dengan %d. Di Dev-C++ ini jalan karena long = 4 byte, tapi lebih tepat %ld. Hati-hati juga: 13! sudah melebihi batas long di Windows (overflow).

7. Cetak bilangan ganjil dari 11 sampai 188 dengan for, while, dan do-while.

Jawaban

Mulai dari 11, naik 2. Batasnya 188, tapi ganjil terakhir 187, dan kondisi <= 188 otomatis berhenti di sana.

#include <stdio.h>

int main() {
    int i;
    for (i = 11; i <= 188; i += 2) printf("%d ", i);
    printf("\n");

    i = 11;
    while (i <= 188) { printf("%d ", i); i += 2; }
    printf("\n");

    i = 11;
    do { printf("%d ", i); i += 2; } while (i <= 188);
    printf("\n");
    return 0;
}

Ketiga loop mencetak hal yang sama. Hanya letak empat bagiannya yang berbeda.

8. Setiap angka = tanggal di bulan Januari 2024. Tanggal 1 jatuh pada hari Senin. Baris pertama input berisi jumlah data, lalu angka-angkanya. Contoh input 3 lalu 8 12 7 → output Monday, Friday, Sunday.

Jawaban

Hari berulang setiap 7. Tanggal 1, 8, 15, … semuanya Senin. Jadi hari = (tanggal − 1) % 7, dengan 0 = Monday. Cek: 8 → 7 % 7 = 0 (Monday), 12 → 11 % 7 = 4 (Friday), 7 → 6 (Sunday).

#include <stdio.h>

int main() {
    const char *hari[] = {"Monday", "Tuesday", "Wednesday", "Thursday",
                          "Friday", "Saturday", "Sunday"};
    int t, d;
    scanf("%d", &t);
    for (int k = 0; k < t; k++) {      // pola: ulangi N kali
        scanf("%d", &d);
        printf("%s\n", hari[(d - 1) % 7]);
    }
    return 0;
}

hari adalah array berisi string (dibahas di materi 04). Tanpa array, bisa juga memakai deretan if.
