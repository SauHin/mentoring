for dan while: loop yang sama

for (i = 1; i <= n; i++) {
    total += i;
}
i = 1;               // inisialisasi
while (i <= n) {     // kondisi
    total += i;      // body
    i++;             // update
}

Bagiannya sama, hanya tempatnya yang berbeda.

Urutan eksekusi for

for (exp1; exp2; exp3) body;

exp1 → exp2? → body → exp3 → exp2? → body → exp3 → … → exp2 false → keluar
 └ sekali    └──────────── diulang ────────────┘
  • exp2 dicek sebelum setiap putaran: bisa jalan 0 kali.
  • Setelah for (i = 1; i <= 5; i++), i = 6.
  • Berapa kali? i < b dari a: b − a. Ragu? Trace dengan angka kecil.

break vs continue

for (i = 1; i <= 10; i++) {
    if (i == 5) break;      // atau continue
    printf("%d ", i);
}
  • break: keluar dari loop sekarang → 1 2 3 4
  • continue: lewati sisa body putaran ini → 1 2 3 4 6 7 8 9 10

Ringkasan

  • Loop = inisialisasi + kondisi + body + update.
  • for, while, do-while = loop yang sama, beda tempat penulisan.
  • Ragu berapa kali jalan atau apa output-nya? Buat trace table.
  • Kenali polanya (akumulasi, max, sentinel, nested), lalu tulis sendiri.
