Notes 1️⃣ · Loop

Loop menulis pola sekali, lalu komputer yang mengulangnya

Loop adalah bagian program yang dijalankan berulang selama suatu kondisi masih terpenuhi.

Tanpa loop: 100 baris

printf("1\n");
printf("2\n");
…
printf("100\n");

Dengan loop: 2 baris (baris for dijelaskan di slide for)

for (int i = 1; i <= 100; i++)
    printf("%d\n", i);
  • Cari apa yang sama di setiap ulangan (jadi isi loop) dan apa yang berubah (jadi variabel yang diubah).
  • Contoh 5 10 15 20 25: yang sama printf, yang berubah angkanya, naik 5.

Notes 2️⃣ · Empat bagian loop

Setiap loop butuh empat bagian, dan kalau satu salah, loop rusak

Body adalah perintah yang diulang. Tiga bagian lain mengatur kapan loop mulai, lanjut, dan berhenti.

BagianPertanyaanKalau salah atau lupa
InisialisasiMulai dari nilai berapa?Variabel berisi garbage value (sisa data lama di memory), jadi hasilnya acak
KondisiKapan masih lanjut?Loop jalan kurang atau lebih satu kali
BodyApa yang diulang?Tidak ada yang dikerjakan
UpdateApa yang berubah tiap putaran?Kondisi tidak pernah berubah → loop tidak pernah berhenti

Notes 3️⃣ · while

while mengecek kondisi sebelum setiap putaran

while menjalankan body selama kondisi true, misalnya untuk menjumlahkan 1 sampai n ke total.

i = 1;                // inisialisasi
while (i <= n) {      // kondisi
    total += i;       // body
    i++;              // update
}
  1. Cek kondisi.
  2. True: jalankan body, lalu kembali ke langkah 1.
  3. False: keluar dari loop.

i++ artinya i = i + 1. total += i artinya total = total + i.

Kalau kondisi sudah false sejak awal, body jalan 0 kali.

Notes 4️⃣ · for

for menaruh inisialisasi, kondisi, dan update dalam satu baris

Dua loop di bawah sama persis. Bedanya hanya tempat menulis keempat bagian.

for

for (i = 1; i <= n; i++) {
    total += i;
}

while

i = 1;
while (i <= n) {
    total += i;
    i++;
}
  • Bentuk umum for (exp1; exp2; exp3): exp1 = inisialisasi, exp2 = kondisi, exp3 = update.
  • Pakai for kalau jumlah putaran diketahui, while kalau loop berhenti karena suatu kejadian.
  • for (;;) tidak pernah berhenti, karena exp2 yang kosong dianggap true.

Notes 5️⃣ · Urutan eksekusi for

exp1 jalan sekali, lalu exp2, body, dan exp3 berulang sampai exp2 false

Diagram ini membaca for (i = 1; i <= n; i++) { total += i; } langkah demi langkah.

  • exp2 dicek sebelum body, jadi body bisa jalan 0 kali.
  • exp3 jalan setelah body, jadi putaran pertama memakai i = 1, bukan 2.

Notes 6️⃣ · Berapa kali loop jalan

Kondisi i < b berhenti sebelum b, sedangkan i <= b ikut menjalankan b

Off-by-one adalah bug saat loop jalan satu kali lebih banyak atau lebih sedikit, biasanya karena < dan <= tertukar.

Bentuk loop: for (i = a; kondisi; i++), jadi a = nilai awal i dan b = batas di kondisi.

KondisiNilai i yang dijalankanBanyak putaranContoh: a = 1, b = 3
i < ba, a + 1, …, b − 1 (b tidak ikut)(b − a) kalii = 1, 2 → 2 kali
i <= ba, a + 1, …, b (b ikut)(b − a + 1) kalii = 1, 2, 3 → 3 kali
  • Hasil 0 atau negatif berarti loop jalan 0 kali. Ragu? Trace dengan angka kecil.
  • Template jawaban: "Loop ini jalan ___ kali, karena i bernilai ___ sampai ___."

Notes 7️⃣ · Trace table

Trace table menjawab "apa output-nya" tanpa menebak

Trace table mencatat nilai setiap variabel yang berubah, satu baris per putaran. Contoh dari kuliah: faktorial.

long number = 4, x = 1;
while (number >= 1)
    x *= number--;
Putarannumber sebelumxnumber sesudah
141 × 4 = 43
234 × 3 = 122
3212 × 2 = 241
4124 × 1 = 240
  • number-- memakai nilai lama dulu, baru dikurangi 1. Jadi x dikali 4 lebih dulu.
  • Saat number = 0, 0 >= 1 false. Loop berhenti dengan x = 24 = 4! (4 × 3 × 2 × 1).

Notes 8️⃣ · do-while

do-while menjalankan body dulu, jadi body pasti jalan minimal sekali

do-while mengecek kondisi sesudah body. Contoh: minta nilai sampai valid, karena nilai harus dibaca dulu sebelum bisa dicek.

while / fordo-while
Kondisi dicekSebelum bodySesudah body
Body minimal0 kali1 kali
Cocok untukHitungan, kejadianMenu, validasi input
do {
    printf("Nilai (0-100): ");
    scanf("%d", &nilai);
} while (nilai < 0 || nilai > 100);  // || = atau

do-while wajib diakhiri ; setelah while (…). while biasa tidak.

Notes 9️⃣ · Akumulator

Akumulator harus diisi sebelum loop: jumlah mulai dari 0, perkalian dari 1

Akumulator adalah variabel yang mengumpulkan hasil dari setiap putaran.

PolaSebelum loopDi body
Ulangi N kalifor (i = 0; i < n; i++) { … }
Jumlahtotal = 0;total += x;
Hasil kalihasil = 1;hasil *= x;
Hitung yang memenuhi syaratcount = 0;if (syarat) count++;

  • Tanpa = 0, total mulai dari garbage value. Hasilnya acak, dan compiler diam saja.
  • max diisi data pertama, bukan 0, supaya tetap benar kalau semua data negatif.

Notes 10 · Sentinel

Sentinel menghentikan loop tanpa perlu tahu jumlah data

Sentinel adalah nilai khusus (di sini 0) yang menandakan input selesai. Input contoh: 8 6 10 0.

int x, total = 0, count = 0;
scanf("%d", &x);        // baca pertama
while (x != 0) {
    total += x;
    count++;
    scanf("%d", &x);    // baca lagi
}
x dicekx != 0totalcount

6true142
10true243
0false243
  • Baca sebelum loop, karena kondisi butuh nilai x.
  • Baca lagi di akhir body, supaya 0 dicek dulu dan tidak ikut diproses. Rata-ratanya 24 / 3 = 8.

Notes 11 · Nested loop

Loop dalam selesai penuh untuk setiap satu putaran loop luar

Nested loop adalah loop di dalam body loop lain. Di sini loop luar = baris, loop dalam = isi baris (n = 4).

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        printf("*");
    }
    printf("\n");
}

Output, dengan catatan j di kanan

*       ← i = 1: j = 1
**      ← i = 2: j = 1, 2
***     ← i = 3: j = 1..3
****    ← i = 4: j = 1..4
  • Total bintang 1 + 2 + 3 + 4 = 10. Kalau luar 3 kali dan dalam 4 kali, body dalam jalan 3 × 4 = 12 kali.
  • Pakai nama berbeda (i dan j). Kalau sama, loop dalam mengubah i milik loop luar.

Notes 12 · break

break keluar dari loop saat itu juga, walaupun kondisi masih true

break adalah perintah untuk berhenti total dari loop.

int i;
for (i = 1; i <= 10; i++) {
    if (i == 5) break;
    printf("%d ", i);
}

Output

1 2 3 4

Setelah loop: i = 5

  • Sisa body dan i++ terakhir tidak jalan, jadi i tetap 5.
  • Dipakai untuk keluar dari for (;;) yang sengaja tanpa kondisi (juga di switch, di luar materi ini).

Notes 13 · continue

continue hanya melewati sisa putaran ini, dan loop tetap lanjut

continue adalah perintah untuk lompat ke putaran berikutnya. Di for, exp3 tetap jalan.

Di body loop i = 1..10EfekOutput
if (i == 5) break;Keluar dari loop sekarang juga1 2 3 4
if (i == 5) continue;Lewati sisa body putaran ini saja1 2 3 4 6 7 8 9 10

Di while, i++ yang ditulis di bawah continue ikut terlewat. Loop mencetak 1 2 3 4, lalu macet di i = 5.

Ringkasan: satu konsep, empat bagian, tiga cara menulis

  • Setiap loop = inisialisasi + kondisi + body + update (2️⃣).
  • while dan for cek dulu (bisa 0 kali). do-while jalan dulu (minimal 1 kali) (3️⃣ 4️⃣ 8️⃣).
  • for: exp1 sekali, lalu exp2, body, exp3 berulang. Setelah loop, i = nilai yang membuat exp2 false (5️⃣).
  • Dengan < loop jalan (b − a) kali, dengan <= jalan (b − a + 1) kali. Ragu? Buat trace table (6️⃣ 7️⃣).
  • Pola: akumulator, sentinel, nested. break berhenti total, continue melewati satu putaran (9️⃣ sampai 13).

Jawaban soal latihan

  1. 6 kali. Kondisinya <, jadi (b − a) = 8 − 2 = 6. Nilai i: 2, 3, 4, 5, 6, 7.
  2. 10 7 4 1. x berubah 10 → 7 → 4 → 1 → −2, dan −2 > 0 false.
  3. 1 3 5. Angka genap dilewati continue, tapi loop tetap lanjut sampai i = 6.
  4. ; setelah for (…) menjadi body kosong. Loop berputar tanpa mencetak sampai i = 3, lalu printf jalan sekali.
