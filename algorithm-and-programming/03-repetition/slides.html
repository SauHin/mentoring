Empat bagian setiap loop

Semua loop, apa pun bentuknya, terdiri dari empat bagian ini. Saat menulis loop, isi keempatnya satu per satu.

for dan while: loop yang sama

for dan while punya empat bagian yang sama. Bedanya hanya di mana bagian-bagian itu ditulis.

for (i = 1; i <= n; i++) {
    total += i;
}
i = 1;               // inisialisasi
while (i <= n) {     // kondisi
    total += i;      // body
    i++;             // update
}

for mengumpulkan inisialisasi, kondisi, dan update dalam satu baris. Pakai for kalau jumlah putaran sudah diketahui, dan while kalau loop berhenti karena suatu kejadian.

Urutan eksekusi for

exp1 hanya jalan sekali di awal. Setelah itu, kondisi, body, dan update diulang sampai kondisi bernilai false.

for (exp1; exp2; exp3) body;

exp1 → exp2? → body → exp3 → exp2? → body → exp3 → … → exp2 false → keluar
 └ sekali    └──────────── diulang ────────────┘
  • exp2 dicek sebelum setiap putaran, jadi body bisa jalan 0 kali kalau kondisinya sudah false sejak awal.
  • Setelah for (i = 1; i <= 5; i++) selesai, i bernilai 6, yaitu nilai pertama yang membuat kondisi false.
  • Loop i < b yang dimulai dari a jalan b − a kali. Kalau ragu, buat trace table dengan angka kecil.

Trace table: cara membaca loop apa pun

Trace table mencatat nilai setiap variabel di akhir setiap putaran. Ini cara paling pasti untuk menebak output loop.

long number = 4, x = 1;
while (number >= 1)
    x *= number--;

while vs do-while

Bedanya hanya pada kapan kondisi dicek: sebelum body, atau sesudah body.

whiledo-while
Kondisi dicekSebelum bodySesudah body
Body jalan minimal0 kali1 kali
do {
    scanf("%d", &nilai);
} while (nilai < 0 || nilai > 100);

do-while cocok untuk menu dan validasi input: input harus dibaca dulu sebelum bisa dicek. Jangan lupa ; setelah while (…).

break vs continue

Keduanya mengubah alur loop dari dalam body, tapi efeknya berbeda.

for (i = 1; i <= 10; i++) {
    if (i == 5) break;      // atau continue
    printf("%d ", i);
}
  • break keluar dari loop saat itu juga. Output: 1 2 3 4
  • continue melewati sisa body untuk putaran ini saja, lalu lanjut ke putaran berikutnya. Output: 1 2 3 4 6 7 8 9 10

Ringkasan

  • Setiap loop = inisialisasi + kondisi + body + update.
  • for, while, dan do-while adalah loop yang sama dengan tempat penulisan yang berbeda. do-while selalu jalan minimal sekali.
  • Ragu berapa kali loop jalan atau apa output-nya? Buat trace table.
  • Kenali polanya (akumulasi, max, sentinel, nested), lalu tulis sendiri.
