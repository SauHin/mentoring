Inference dengan quantifier dan teknik pembuktian

Discrete mathematics · dari rules of inference ke bukti matematika.

Truth table tidak cukup

Argumen dengan quantifier tidak bisa dicek dengan truth table. Ketiga kalimat di bawah hanya akan menjadi p, q, r yang tidak saling berhubungan.

"Setiap mahasiswa SCE mengambil discrete math. Jackson mahasiswa SCE. ∴ Jackson mengambil discrete math."

1. ∀x, SCE(x) → DM(x)          premise
2. SCE(Jackson)                premise
3. SCE(Jackson) → DM(Jackson)  dari 1
4. DM(Jackson)                 dari 2, 3

Caranya: turunkan ∀ ke satu elemen (Jackson) dulu di langkah 3. Setelah itu, modus ponens dari materi 02 bisa dipakai di langkah 4.

Empat aturan quantifier

Instantiation turun dari quantifier ke satu elemen. Generalization naik dari satu elemen ke quantifier.

AturanBentukArtinya
Universal instantiation∀x P(x) ∴ P(c)Berlaku untuk semua, jadi berlaku untuk c
Universal generalizationP(c) untuk c sembarang ∴ ∀x P(x)Valid hanya kalau c tidak dipilih secara khusus (arbitrary)
Existential instantiation∃x P(x) ∴ P(c)Beri nama baru c pada elemen yang ada itu
Existential generalizationP(c) ∴ ∃x P(x)Satu witness cukup untuk ∃

Membuktikan P(2) lalu menyimpulkan ∀x P(x) itu salah. 2 adalah nilai khusus, bukan sembarang.

Contoh: Sam dapat A

Contoh ini memakai existential instantiation, universal instantiation, dan modus ponens dalam satu argumen.

"Siapa pun yang nilainya > 80 dapat A. Ada mahasiswa yang nilainya > 80, dan Sam salah satunya. ∴ Sam dapat A."

1. ∀x, M(x) → A(x)    premise
2. ∃x, M(x)           premise
3. M(Sam)             existential inst. dari 2
4. M(Sam) → A(Sam)    universal inst. dari 1
5. A(Sam)             modus ponens 3, 4

M(x) = "nilai x lebih dari 80", A(x) = "x dapat A".

Universal modus ponens dan tollens

Langkah "universal instantiation lalu modus ponens" sangat sering muncul, jadi keduanya digabung menjadi satu aturan.

NamaBentukStatus
Universal modus ponens∀x, P(x) → Q(x); P(a) ∴ Q(a)Valid
Universal modus tollens∀x, P(x) → Q(x); ~Q(a) ∴ ~P(a)Valid
Converse error∀x, P(x) → Q(x); Q(a) ∴ P(a)Tidak valid
Inverse error∀x, P(x) → Q(x); ~P(a) ∴ ~Q(a)Tidak valid

Contoh converse error: "Semua kucing berbulu. Rex berbulu. ∴ Rex kucing." Kesimpulannya tidak dijamin, karena Rex bisa saja anjing.

Pola semua bukti: ∀x, P(x) → Q(x)

Hampir semua teorema berbentuk universal conditional. Polanya selalu sama: ambil x sembarang yang memenuhi P(x), lalu tunjukkan Q(x). Bedanya ada pada cara menunjukkan Q(x).

TeknikAsumsikanLalu tunjukkan
Direct proofP(x)Q(x)
Proof by contrapositive~Q(x)~P(x)
Proof by contradictionP(x) dan ~Q(x)Sebuah contradiction C ∧ ~C

"Ambil x sembarang" adalah universal generalization: hasilnya berlaku untuk semua x.

Direct proof: trik Euler

Direct proof berangkat dari yang diketahui, lalu menurunkan kesimpulan langkah demi langkah. Contoh: buktikan 0 + 1 + … + n = n(n + 1)/2.

  S =   0   +   1   + … + (n−1) +   n
  S =   n   + (n−1) + … +   1   +   0
 2S =   n   +   n   + … +   n   +   n     (n + 1 suku)

 2S = n(n + 1)   →   S = n(n + 1)/2

Tulis jumlahnya dua kali, maju dan mundur. Setiap kolom berjumlah n, dan ada n + 1 kolom.

"Jika n² genap, maka n genap"

Kalimat ini sulit dibuktikan secara langsung, karena "n² genap" tidak memberi rumus untuk n. Dua teknik berikut memakai "n ganjil", yang langsung memberi n = 2k + 1.

Contrapositive: buktikan "jika n ganjil, maka n² ganjil".

n = 2k + 1
n² = 4k² + 4k + 1
   = 2(2k² + 2k) + 1   ganjil ∎

Contradiction: misalkan n² genap dan n ganjil.

Hitungan yang sama menunjukkan n² ganjil. Ini bertentangan dengan "n² genap", jadi asumsi "n ganjil" pasti salah. ∎

Mathematical induction

Induction membuktikan statement ∀n ≥ 1, P(n) dengan dua langkah.

  1. Basis step: tunjukkan P(1) benar.
  2. Inductive step: asumsikan P(k) benar (inductive hypothesis), lalu tunjukkan P(k + 1) juga benar.

Seperti domino: domino pertama jatuh (basis step), dan setiap domino menjatuhkan domino berikutnya (inductive step). Jadi semua domino jatuh.

P(1) benar, P(1) → P(2)  ∴ P(2)     modus ponens
P(2) benar, P(2) → P(3)  ∴ P(3)     modus ponens  …

Contoh induction: 1 + 2 + … + n = n(n + 1)/2

Rumus yang sama dengan trik Euler, sekarang dibuktikan dengan induction.

Basis:     n = 1  →  1 = 1·2/2  ✓
Hipotesis: 1 + … + k = k(k + 1)/2
Langkah:   1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1)
                               = (k + 1)(k + 2)/2     ✓ ini bentuk P(k + 1)
Trik menulis inductive stepTulis dulu P(k + 1) yang ingin dicapai. Pecah sisi kirinya menjadi "bagian P(k)" + "suku baru", lalu ganti bagian P(k) dengan inductive hypothesis.

Kapan memakai teknik yang mana

Pilih teknik dari bentuk statement-nya. Kalau satu teknik buntu, coba teknik lain.

TeknikCocok jika
Direct proofP bisa langsung diolah (ada rumus atau definisi)
Contrapositive~Q lebih mudah diolah daripada P
ContradictionKesimpulannya berbentuk "tidak ada …" atau "… irrational"
InductionStatement berlaku untuk n = 1, 2, 3, … (deret, habis dibagi)
CounterexampleIngin menunjukkan bahwa statement ∀ bernilai F

Program yang mengecek n = 1 sampai 1000 bisa menemukan counterexample, tapi tidak membuktikan ∀n.

Ringkasan

  • Instantiation turun ke satu elemen. Generalization naik kembali ke quantifier.
  • Universal modus ponens dan tollens valid. Converse error dan inverse error tidak valid.
  • Bukti statement ∀: ambil x sembarang, lalu pakai direct proof, contrapositive, atau contradiction.
  • Induction = basis step + inductive step. Contoh sebanyak apa pun tidak membuktikan statement ∀.

Latihan (irrational, jumlah bilangan ganjil = n², n³ − n habis dibagi 3) ada di notes.
