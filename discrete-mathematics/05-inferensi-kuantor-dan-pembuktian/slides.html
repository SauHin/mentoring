Inferensi kuantor dan teknik pembuktian

Discrete mathematics · dari aturan inferensi ke bukti matematika

Truth table tidak cukup

"Setiap mahasiswa SCE mengambil discrete math. Jackson mahasiswa SCE. ∴ Jackson mengambil discrete math."

1. ∀x, SCE(x) → DM(x)
2. SCE(Jackson)
3. SCE(Jackson) → DM(Jackson)
   ← universal instantiation
4. DM(Jackson)
   ← modus ponens 2, 3

Turunkan ∀ ke satu elemen dulu, baru aturan dari materi 02 bisa dipakai.

Contoh: Sam dapat A

Siapa pun yang nilainya > 80 dapat A. Ada mahasiswa yang nilainya > 80, dan Sam salah satunya.

1. ∀x, M(x) → A(x)    premise
2. ∃x, M(x)           premise
3. M(Sam)             existential inst.
4. M(Sam) → A(Sam)    universal inst. 1
5. A(Sam)             modus ponens 3, 4

NamaBentukStatus

"Semua kucing berbulu. Rex berbulu. ∴ Rex kucing." Converse error: Rex bisa saja anjing.

Pola semua bukti ∀x, P(x) → Q(x)

  1. Ambil x sembarang yang memenuhi P(x).
  2. Tunjukkan Q(x), dengan salah satu teknik:
TeknikAsumsikanTunjukkan
DirectP(x)Q(x)
Contrapositive~Q(x)~P(x)
ContradictionP(x) dan ~Q(x)Kontradiksi C ∧ ~C

Langkah 1 adalah universal generalization.

Direct proof: trik Euler

  S =   0   +   1   + … + (n−1) +   n
  S =   n   + (n−1) + … +   1   +   0
 2S =   n   +   n   + … +   n   +   n     (n + 1 suku)

 2S = n(n + 1)   →   S = n(n + 1)/2

Tulis jumlahnya dua kali, maju dan mundur. Setiap kolom berjumlah n.

"Jika n² genap, maka n genap"

Contrapositive: jika n ganjil, maka n² ganjil.

n = 2k + 1
n² = 4k² + 4k + 1
   = 2(2k² + 2k) + 1   ganjil ∎

Contradiction: misalkan n² genap dan n ganjil.

Hitungan yang sama memberi n² ganjil. Ini bertentangan dengan "n² genap", jadi asumsinya salah. ∎

"n² genap" sulit diolah, sedangkan "n ganjil" langsung memberi n = 2k + 1.

Mathematical induction

  1. Basis step: P(1) benar.
  2. Inductive step: asumsikan P(k), lalu tunjukkan P(k + 1).

Seperti domino: P(1) jatuh, dan setiap domino menjatuhkan berikutnya. Jadi semuanya jatuh.

P(1) benar, P(1) → P(2)  ∴ P(2)     modus ponens
P(2) benar, P(2) → P(3)  ∴ P(3)     modus ponens  …

Contoh induksi: 1 + 2 + … + n = n(n + 1)/2

Basis:     n = 1  →  1 = 1·2/2  ✓
Hipotesis: 1 + … + k = k(k + 1)/2
Langkah:   1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1)
                               = (k + 1)(k + 2)/2     ✓ bentuk P(k + 1)

Trik: tulis dulu P(k + 1) yang ingin dicapai. Pecah sisi kirinya menjadi "bagian P(k)" + "suku baru", lalu ganti bagian P(k) dengan hipotesis.

Kapan memakai teknik yang mana

TeknikCocok jika
DirectP bisa langsung diolah (rumus, definisi)
Contrapositive~Q lebih mudah diolah daripada P
ContradictionKesimpulan berbentuk "tidak ada …" atau "irrational"
InductionBerlaku untuk n = 1, 2, 3, … (deret, habis dibagi)
CounterexampleIngin menunjukkan pernyataan ∀ salah

Program yang mengecek n = 1..1000 bisa menemukan counterexample, tapi tidak membuktikan ∀n.

Ringkasan

  • Instantiation = turun ke satu elemen. Generalization = naik ke kuantor.
  • Universal modus ponens/tollens valid. Converse dan inverse error tidak.
  • Bukti ∀: ambil x sembarang, lalu direct, contrapositive, atau contradiction.
  • Induksi: basis + inductive step. Contoh tidak pernah membuktikan ∀.

Latihan (irrational, ganjil = n², n³ − n habis dibagi 3) ada di notes.
