Inference dengan quantifier dan teknik pembuktian

Discrete mathematics · materi 05 · prasyarat: argumen (materi 02) dan quantifier (materi 04)

Target: kamu bisa menulis langkah inference dengan quantifier, lalu memilih dan menulis direct proof, contrapositive, contradiction, atau induction.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Kenapa butuh aturan baru

Truth table tidak bisa melihat hubungan antara "semua" dan satu elemen

Solusinya universal instantiation: turunkan ∀ ke satu elemen dulu, baru pakai modus ponens.

"Setiap mahasiswa SCE mengambil discrete math. Jackson mahasiswa SCE. ∴ Jackson mengambil discrete math."

1. ∀x, SCE(x) → DM(x)          premise
2. SCE(Jackson)                premise
3. SCE(Jackson) → DM(Jackson)  univ. instantiation 1
4. DM(Jackson)                 modus ponens 2, 3

Dengan truth table, ketiga kalimat hanya menjadi p, q, r yang tidak berhubungan, jadi argumennya terlihat tidak valid.

Notes 2️⃣ · Empat aturan

Instantiation turun ke satu elemen, generalization naik kembali ke quantifier

Generalization ke ∀ hanya boleh dari elemen sembarang, bukan elemen yang dipilih khusus.

AturanBentukArtinya
Universal instantiation∀x P(x) ∴ P(c)Berlaku untuk semua, jadi berlaku untuk c
Universal generalizationP(c), c sembarang ∴ ∀x P(x)Valid hanya kalau c tidak dipilih khusus
Existential instantiation∃x P(x) ∴ P(c)Beri nama baru c pada elemen yang ada itu
Existential generalizationP(c) ∴ ∃x P(x)Satu witness cukup untuk ∃

Membuktikan P(2) lalu menyimpulkan ∀x P(x) itu salah, karena 2 adalah nilai khusus.

Notes 2️⃣ · Empat aturan

Sam dapat A: existential instantiation, universal instantiation, lalu modus ponens

M(x) = "nilai x lebih dari 80", A(x) = "x dapat A".

"Siapa pun yang nilainya > 80 dapat A. Ada mahasiswa yang nilainya > 80, dan Sam salah satunya. ∴ Sam dapat A."

1. ∀x, M(x) → A(x)    premise
2. ∃x, M(x)           premise
3. M(Sam)             existential inst. 2
4. M(Sam) → A(Sam)    universal inst. 1
5. A(Sam)             modus ponens 3, 4

Notes 3️⃣ · Universal modus ponens

Universal modus ponens dan tollens valid, converse error dan inverse error tetap tidak

Universal modus ponens menggabungkan universal instantiation dan modus ponens dalam satu langkah.

NamaBentukStatus
Universal modus ponens∀x, P(x) → Q(x); P(a) ∴ Q(a)Valid
Universal modus tollens∀x, P(x) → Q(x); ~Q(a) ∴ ~P(a)Valid
Converse error∀x, P(x) → Q(x); Q(a) ∴ P(a)Tidak valid
Inverse error∀x, P(x) → Q(x); ~P(a) ∴ ~Q(a)Tidak valid

"Semua kucing berbulu. Rex berbulu. ∴ Rex kucing" adalah converse error, karena Rex bisa saja anjing.

Notes 4️⃣ · Pola bukti

Semua bukti ∀ dimulai dengan "ambil x sembarang yang memenuhi P(x)"

Teorema biasanya berbentuk ∀x, P(x) → Q(x). Elemen sembarang membuat hasilnya berlaku untuk semua x.

TeknikAsumsikanLalu tunjukkan
Direct proofP(x)Q(x)
Proof by contrapositive~Q(x)~P(x)
Proof by contradictionP(x) dan ~Q(x)Sebuah contradiction C ∧ ~C

Notes 5️⃣ · Direct proof

Trik Euler: tulis jumlahnya dua kali, maju dan mundur

Direct proof berangkat dari yang diketahui sampai kesimpulan. Contoh: buktikan 0 + 1 + … + n = n(n + 1)/2.

  S =   0   +   1   + … + (n−1) +   n
  S =   n   + (n−1) + … +   1   +   0
 2S =   n   +   n   + … +   n   +   n     (n + 1 suku)

 2S = n(n + 1), jadi S = n(n + 1)/2

Setiap kolom berjumlah n, dan ada (n + 1) kolom.

Notes 6️⃣ · Contrapositive

"Jika n² genap, maka n genap" lebih mudah dibuktikan lewat contrapositive-nya

Proof by contrapositive membuktikan ~Q → ~P, yang ekuivalen dengan P → Q.

Buktikan: jika n ganjil, maka n² ganjil.
n = 2k + 1
n² = 4k² + 4k + 1
   = 2(2k² + 2k) + 1, jadi ganjil  ∎
  • "n² genap" tidak memberi rumus untuk n.
  • "n ganjil" langsung memberi n = 2k + 1, yang bisa diolah.

Notes 7️⃣ · Contradiction

Proof by contradiction: anggap pernyataannya salah, lalu tunjukkan itu mustahil

Proof by contradiction mengasumsikan P dan ~Q, karena ~(P → Q) ≡ P ∧ ~Q.

  1. Asumsikan: n² genap dan n ganjil.
  2. Turunkan: n = 2k + 1, jadi n² = 2(2k² + 2k) + 1 ganjil.
  3. Bertentangan: n² genap dan ganjil sekaligus. Asumsi "n ganjil" pasti salah. ∎

Valid karena (~S → (C ∧ ~C)) ≡ S, yang bisa dicek dengan truth table.

Notes 8️⃣ · Induction

Induction: basis step menjatuhkan domino pertama, inductive step menjamin sisanya

Mathematical induction membuktikan ∀n ≥ 1, P(n) dengan dua langkah.

  1. Basis step: tunjukkan P(1) benar.
  2. Inductive step: asumsikan P(k) benar (inductive hypothesis), lalu tunjukkan P(k + 1) benar.
P(1) benar, P(1) → P(2)  ∴ P(2)   modus ponens
P(2) benar, P(2) → P(3)  ∴ P(3)   modus ponens
…

Notes 9️⃣ · Inductive step

Inductive step: pecah P(k + 1) menjadi bagian P(k) ditambah suku baru

Contoh: rumus yang sama dengan trik Euler, sekarang dengan induction.

Basis:     n = 1: 1 = 1·2/2  ✓
Hipotesis: 1 + … + k = k(k + 1)/2
Langkah:   1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1)
                               = (k + 1)(k + 2)/2     ✓ ini bentuk P(k + 1)
  • Trik: tulis dulu P(k + 1) yang ingin dicapai, lalu ganti bagian P(k) dengan hipotesis.
  • Program yang mengecek n = 1 sampai 1000 bisa menemukan counterexample, tapi tidak membuktikan ∀n.

Notes 10 · Memilih teknik

Pilih teknik dari bentuk statement, dan ganti teknik kalau buntu

Lihat bentuk P dan Q sebelum mulai menulis bukti.

TeknikCocok jika
Direct proofP bisa langsung diolah (ada rumus atau definisi)
Contrapositive~Q lebih mudah diolah daripada P
ContradictionKesimpulannya berbentuk "tidak ada …" atau "… irrational"
InductionStatement berlaku untuk n = 1, 2, 3, … (deret, habis dibagi)
CounterexampleIngin menunjukkan statement ∀ bernilai F

Notes 11 · Kesalahan umum

Kesalahan paling sering: membuktikan dengan contoh dan salah mengasumsikan

Setiap baris menyebut cara memperbaikinya.

KesalahanPerbaikan
"Benar untuk n = 1, 2, 3, jadi benar untuk semua"Pakai x sembarang atau induksi.
Induksi tanpa basis stepDomino yang tidak didorong tidak jatuh. Tulis basis.
Mengasumsikan P(k + 1)Yang diasumsikan hanya P(k). P(k + 1) diturunkan.
Memulai dari Q sampai ke PItu converse. Mulai dari P atau dari ~Q.
Contradiction hanya mengasumsikan ~QAsumsikan P dan ~Q.

Ringkasan

Bukti adalah argumen valid: setiap langkah memakai satu aturan yang bisa kamu sebut.

  • Quantifier: instantiation turun ke satu elemen, generalization naik kembali.
  • Universal modus ponens dan tollens valid. Converse error dan inverse error tidak.
  • Bukti ∀: ambil x sembarang, lalu direct, contrapositive, atau contradiction.
  • Induction: basis step + inductive step. Contoh sebanyak apa pun tidak membuktikan ∀.

Soal

Kerjakan dulu, lalu cek jawabannya di slide berikutnya.

  1. "Semua programmer suka kopi. Budi suka kopi. Jadi Budi programmer." Valid?
  2. q real positif. Buktikan: kalau q irrational, maka √q irrational.
  3. Buktikan dengan induksi: 1 + 3 + … + (2n − 1) = n².
  4. Buktikan dengan induksi: n³ − n habis dibagi 3.

Jawaban

Pembahasan lengkap ada di notes (nomor section di kurung).

  1. Tidak valid: converse error (3️⃣).
  2. Contrapositive: kalau √q = a/b rational, maka q = a²/b² rational (6️⃣).
  3. Basis 1 = 1². Langkah: k² + (2k + 1) = (k + 1)² (9️⃣).
  4. Basis 0 habis dibagi 3. Langkah: (k + 1)³ − (k + 1) = (k³ − k) + 3(k² + k) (9️⃣).
