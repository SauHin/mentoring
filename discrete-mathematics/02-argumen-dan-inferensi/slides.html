Argumen dan aturan inferensi

Discrete mathematics · valid atau tidak, cukup lihat critical row

Argumen = premise + conclusion

p → q        premise
p            premise
∴ q          conclusion
  • Valid: kalau semua premise T, conclusion pasti T.
  • Validitas soal bentuk, bukan isi kalimat.
  • Ganti p, q dengan kalimat apa pun, validitasnya tetap.

Cara mengecek: critical row

  1. Buat truth table untuk semua premise dan conclusion.
  2. Tandai critical row: baris yang semua premise-nya T.
  3. Semua critical row punya conclusion T → valid.
  4. Ada satu critical row dengan conclusion F → tidak valid.

Baris dengan premise F tidak relevan: di sana tidak ada yang dijanjikan.

Contoh tidak valid

p → q ∨ ~r
q → p ∧ r
∴ p → r
pqrprem 1prem 2concl
TTTTTT
TFFTTF

Baris p = T, q = F, r = F: kedua premise T tapi conclusion F. Satu baris ini cukup untuk membuktikan tidak valid.

Valid ≠ benar

Jika bulan terbuat dari keju, maka aku presiden.
Bulan terbuat dari keju.
∴ Aku presiden.
  • Bentuknya modus ponens, jadi valid.
  • Tapi premise-nya salah, jadi conclusion tidak dijamin benar.
  • Sound = valid dan semua premise benar.

Aturan inferensi

NamaBentukKenapa valid
Modus ponensp → q; p ∴ qJanji, dan syaratnya terjadi
Modus tollensp → q; ~q ∴ ~pHasilnya tidak ada, jadi syaratnya tidak terjadi
Eliminationp ∨ q; ~q ∴ pMinimal satu T, dan bukan q
Transitivityp → q; q → r ∴ p → rRantai janji
Division into casesp ∨ q; p → r; q → r ∴ rKasus mana pun, hasilnya r
Generalization / specializationp ∴ p ∨ q / p ∧ q ∴ pLangsung dari definisi ∨ dan ∧

Dua jebakan klasik

NamaBentuk (TIDAK valid)Contoh
Converse errorp → q; q ∴ pJika hujan, jalan basah. Jalan basah. ∴ Hujan.
Inverse errorp → q; ~p ∴ ~qJika hujan, jalan basah. Tidak hujan. ∴ Jalan kering.

Keduanya runtuh di baris p = F, q = T: jalan basah karena disiram.

Ringkasan

  • Valid = setiap critical row punya conclusion T.
  • Satu critical row dengan conclusion F → tidak valid.
  • Valid soal bentuk. Sound = valid + premise benar.
  • Modus ponens dan tollens valid. Converse dan inverse error tidak.
