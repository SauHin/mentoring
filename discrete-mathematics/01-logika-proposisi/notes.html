Discrete mathematics · 01

Logika proposisi

Di logika proposisi, truth table adalah hakim. Hukum apa pun bisa dicek dengan truth table, jadi kamu tidak perlu menghafal: cukup paham kapan setiap operator bernilai T.

Slide · Visualisasi: truth table & cek equivalence

TL;DR
  • Statement = kalimat yang pasti bernilai T atau F, tidak keduanya.
  • Pahami satu kalimat untuk setiap operator, misalnya "∧ hanya T kalau keduanya T". Tabelnya akan mengikuti sendiri.
  • Dua bentuk ekuivalen (≡) kalau nilainya sama di setiap baris. Satu baris beda = bukti tidak ekuivalen.
  • p → q hanya F saat p T dan q F. Dari sini: ~(p → q) ≡ p ∧ ~q dan p → q ≡ ~q → ~p.

1. Statement

Statement (proposisi) adalah kalimat yang pasti benar (T) atau pasti salah (F), tidak keduanya.

KalimatStatement?Kenapa
"Jakarta adalah ibu kota Jepang."Ya (F)Salah, tapi tetap punya nilai pasti
"2 + 2 = 4"Ya (T)Pasti benar
"Tutup pintunya!"BukanPerintah, tidak bernilai T/F
"x + 1 = 3"Bukan (belum)Nilainya bergantung pada x. Ini predicate (materi 04)

Statement digabung dengan connective menjadi compound statement, misalnya "hujan dan dingin". Kita menulisnya dengan variabel: p = "hujan", q = "dingin", lalu p ∧ q.

2. Enam connective: cukup pahami kapan T

"Atau" sehari-hari vs ∨"Mau teh atau kopi?" biasanya berarti pilih satu (⊕). Di logika, ∨ selalu inclusive: dua-duanya T juga T.

3. Membuat truth table

  1. Hitung baris: n variabel → 2n baris (2 variabel = 4, 3 variabel = 8). Setiap kombinasi T/F muncul tepat sekali.
  2. Isi kolom variabel dengan pola: variabel pertama TTTTFFFF, kedua TTFFTTFF, ketiga TFTFTFTF.
  3. Satu kolom per sub-ekspresi, dari dalam ke luar. Setiap kolom hanya memakai kolom yang sudah ada.

Contoh ~(p ∧ q):

pqp ∧ q~(p ∧ q)
TTTF
TFFT
FTFT
FFFT

Urutan operasi: ~ dikerjakan dulu, lalu ∧ ∨, terakhir → ↔. ∧ dan ∨ setingkat, jadi p ∧ q ∨ r ambigu dan wajib diberi kurung. Jadi ~p ∧ q = (~p) ∧ q, dan p ∧ q → r = (p ∧ q) → r.

Coba sendiri di visualisasi truth table. Ekspresi yang ambigu akan ditolak beserta alasannya.

4. Logical equivalence

P ≡ Q artinya P dan Q bernilai sama di setiap baris. Contoh paling penting, De Morgan:

pq~(p ∧ q)~p ∨ ~q~p ∧ ~q
TTFFF
TFTTF
FTTTF
FFTTT
  • ~(p ∧ q) ≡ ~p ∨ ~q: kolomnya sama di keempat baris.
  • ~(p ∧ q) tidak ekuivalen dengan ~p ∧ ~q: baris p = T, q = F saja sudah cukup sebagai bukti.
  • Cara ingat De Morgan tanpa menghafal: "tidak (hujan dan dingin)" berarti minimal salah satunya tidak terjadi, yaitu "tidak hujan atau tidak dingin". Negasi membalik ∧ menjadi ∨ dan sebaliknya.
Di kode Cif (!(umur >= 17 && punyaKTP)) sama dengan if (umur < 17 || !punyaKTP). De Morgan dipakai setiap kali kamu membalik kondisi if.

Tautology = selalu T (contoh p ∨ ~p). Contradiction = selalu F (contoh p ∧ ~p). Di hukum logika, Epp menulisnya t dan c.

5. Hukum logika: kenali bentuknya, cek dengan tabel

Semua hukum di bawah bisa dibuktikan dengan truth table. Kamu tidak perlu hafal namanya untuk paham, tapi kenali bentuknya supaya bisa menyederhanakan ekspresi.

HukumBentuk
Commutativep ∧ q ≡ q ∧ p, p ∨ q ≡ q ∨ p
Associative(p ∧ q) ∧ r ≡ p ∧ (q ∧ r), sama untuk ∨
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r), p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
Identityp ∧ t ≡ p, p ∨ c ≡ p
Negationp ∨ ~p ≡ t, p ∧ ~p ≡ c
Double negation~(~p) ≡ p
Idempotentp ∧ p ≡ p, p ∨ p ≡ p
Universal boundp ∨ t ≡ t, p ∧ c ≡ c
De Morgan~(p ∧ q) ≡ ~p ∨ ~q, ~(p ∨ q) ≡ ~p ∧ ~q
Absorptionp ∨ (p ∧ q) ≡ p, p ∧ (p ∨ q) ≡ p
Negation of t and c~t ≡ c, ~c ≡ t

Contoh menyederhanakan (dari slide)

~(~p ∧ q) ∧ (p ∨ q)
≡ (~~p ∨ ~q) ∧ (p ∨ q)     De Morgan
≡ (p ∨ ~q) ∧ (p ∨ q)       double negation
≡ p ∨ (~q ∧ q)             distributive (p "dikeluarkan")
≡ p ∨ c                    negation: ~q ∧ q selalu F
≡ p                        identity

Strategi umumnya: dorong ~ ke dalam dengan De Morgan, lalu cari pola x ∧ ~x atau x ∨ ~x.

6. Conditional: p → q

Bayangkan p → q sebagai janji: "Kalau kamu datang Senin pagi (p), kamu dapat pekerjaannya (q)."

pqp → qJanjinya …
TTTditepati
TFFdilanggar: satu-satunya baris F
FTTtidak diuji, jadi tidak dilanggar
FFTtidak diuji, jadi tidak dilanggar

Dua baris terakhir disebut vacuously true (benar secara default): kalau kamu tidak datang Senin, janjinya tidak bisa dibilang dilanggar.

Karena hanya ada satu baris F, dua hal berikut bisa diturunkan sendiri:

  • p → q ≡ ~p ∨ q: "p salah, atau q benar". Ini persis kondisi agar baris F tidak terjadi.
  • Negasi: ~(p → q) ≡ p ∧ ~q, yaitu baris F itu sendiri.
Negasi conditional BUKAN conditionalNegasi "Jika mobilku di bengkel, maka aku tidak bisa ke kampus" adalah "Mobilku di bengkel dan aku bisa ke kampus". Bukan "jika … maka aku bisa ke kampus".

7. Contrapositive, converse, inverse

NamaBentuk (dari p → q)Ekuivalen dengan p → q?
Contrapositive~q → ~pYa: selalu sama
Converseq → pTidak
Inverse~p → ~qTidak (tapi ekuivalen dengan converse)

Contoh: "Jika hari ini Paskah, maka besok Senin."

  • Contrapositive: Jika besok bukan Senin, maka hari ini bukan Paskah. (Pasti benar juga.)
  • Converse: Jika besok Senin, maka hari ini Paskah. (Salah: setiap Minggu, besoknya Senin.)
  • Inverse: Jika hari ini bukan Paskah, maka besok bukan Senin. (Salah, alasannya sama.)
Cara ingatContrapositive = tukar dan negasikan. Inverse adalah contrapositive dari converse, jadi keduanya selalu ekuivalen. Cek di visualisasi (preset "Contrapositive" dan "Converse").

8. Biconditional dan "only if"

p ↔ q ("p if and only if q") ≡ (p → q) ∧ (q → p): benar ke dua arah.

Contoh slide: "Program ini benar jika dan hanya jika menghasilkan jawaban benar untuk semua input" sama dengan dua janji: "jika program benar, maka jawabannya benar untuk semua input" dan "jika jawabannya benar untuk semua input, maka programnya benar".

"p only if q" = p → q"Kamu lulus hanya jika mengerjakan tugas" artinya: kalau lulus, pasti mengerjakan tugas (p → q). Bukan sebaliknya: mengerjakan tugas tidak menjamin lulus.

9. Syarat cukup dan syarat perlu

KalimatBentukIntuisi
r adalah syarat cukup (sufficient) untuk sr → sr saja sudah menjamin s
r adalah syarat perlu (necessary) untuk ss → r ≡ ~r → ~stanpa r, s tidak mungkin terjadi
r syarat perlu dan cukup untuk sr ↔ skeduanya
  • "Lahir di AS adalah syarat cukup untuk menjadi warga AS" → Jika Pia lahir di AS, maka ia warga AS.
  • "Berumur 35 adalah syarat perlu untuk menjadi presiden AS" → Jika George belum 35, maka ia tidak bisa jadi presiden. Atau: jika George bisa jadi presiden, maka ia sudah 35.

11. Latihan

Cek setiap jawabanmu di visualisasi.

1. Buat truth table (p ∨ q) ∧ ~(p ∧ q). Operator apa yang hasilnya sama persis?

Jawaban

Kolom akhirnya F, T, T, F. Hasilnya T kalau tepat satu dari p dan q yang T, jadi sama dengan p ⊕ q (exclusive or). Bentuk ini muncul lagi di logic circuit (materi 03).

2. Apakah p → (q → r) ekuivalen dengan (p → q) → r?

Jawaban

Tidak. Bukti: p = F, q = T, r = F. Kiri: p F, jadi vacuously true (T). Kanan: p → q = T, lalu T → F = F. Ini alasan p → q → r tanpa kurung dianggap ambigu.

3. Tulis negasi dari "Jika hujan, maka jalan basah".

Jawaban

"Hujan dan jalan tidak basah." Polanya p ∧ ~q: satu-satunya keadaan yang membuat janji dilanggar.

4. Untuk "Jika n habis dibagi 4, maka n genap" (n bilangan bulat), tulis contrapositive, converse, dan inverse. Mana yang benar?

Jawaban
  • Asli: benar.
  • Contrapositive: "Jika n tidak genap, maka n tidak habis dibagi 4". Benar, karena ekuivalen dengan aslinya.
  • Converse: "Jika n genap, maka n habis dibagi 4". Salah: n = 2.
  • Inverse: "Jika n tidak habis dibagi 4, maka n tidak genap". Salah: n = 2 juga.

5. "Lulus ujian akhir adalah syarat perlu untuk lulus mata kuliah." Tulis dalam bentuk if-then.

Jawaban

Syarat perlu → arahnya dari hasil ke syarat: "Jika kamu lulus mata kuliah, maka kamu lulus ujian akhir". Versi contrapositive: "Jika kamu tidak lulus ujian akhir, maka kamu tidak lulus mata kuliah".

6. Sederhanakan ~(p ∨ ~q) ∨ (~p ∧ ~q).

Jawaban 
~(p ∨ ~q) ∨ (~p ∧ ~q)
≡ (~p ∧ q) ∨ (~p ∧ ~q)     De Morgan + double negation
≡ ~p ∧ (q ∨ ~q)            distributive
≡ ~p ∧ t                   negation
≡ ~p                       identity

7. Apakah (p ∧ (p → q)) → q tautology?

Jawaban

Ya. Satu-satunya cara membuatnya F adalah bagian kiri T dan q F. Tapi kalau p T dan p → q T, maka q pasti T. Bentuk ini adalah modus ponens, rule of inference pertama di materi 02.
