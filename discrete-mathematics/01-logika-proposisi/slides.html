Membuat truth table

  1. n variabel → 2ⁿ baris.
  2. Kolom variabel: pola T/F berselang 4-2-1.
  3. Satu kolom untuk setiap sub-ekspresi, dari dalam ke luar.
  4. Kolom terakhir = jawaban.

Logical equivalence dan De Morgan

P ≡ Q jika kolom terakhirnya sama di setiap baris.

~(p ∧ q) ≡ ~p ∨ ~q
~(p ∨ q) ≡ ~p ∧ ~q

Negasi masuk ke dalam kurung, ∧ dan ∨ bertukar.

Di C:

!(x > 0 && x < 10)
≡ x <= 0 || x >= 10

"Tidak di antara 0 dan 10" = "≤ 0 atau ≥ 10".

Hukum penting untuk menyederhanakan

HukumBentuk
Commutative / associativep ∧ q ≡ q ∧ p, (p ∨ q) ∨ r ≡ p ∨ (q ∨ r)
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
Negation / double negationp ∨ ~p ≡ t, p ∧ ~p ≡ c, ~(~p) ≡ p
Identity / universal boundp ∧ t ≡ p, p ∨ t ≡ t
Absorptionp ∨ (p ∧ q) ≡ p
Conditionalp → q ≡ ~p ∨ q, ~(p → q) ≡ p ∧ ~q

t = tautology, c = contradiction. Contoh penyederhanaan dari slide ada di notes.

Coba sendiri: truth table dan cek ekuivalensi

Ringkasan

  • Statement bernilai T atau F. Connective menggabungkannya, dan semuanya punya padanan di C.
  • Truth table: 2ⁿ baris, satu kolom per sub-ekspresi.
  • Ekuivalen = kolom terakhir sama. Dua yang paling sering dipakai: De Morgan dan p → q ≡ ~p ∨ q.
  • p → q hanya F saat p T dan q F. Contrapositive ekuivalen, converse dan inverse tidak.
