Logika proposisi

Discrete mathematics · materi 01 · prasyarat: kondisi if di C

Target: kamu bisa membuat truth table, membuktikan dua ekspresi ekuivalen atau tidak, dan menulis negasi serta contrapositive sebuah conditional.

Label di atas setiap judul (misalnya "Notes 3️⃣") menunjuk section notes yang membahas hal yang sama secara lengkap.

Notes 1️⃣ · Statement

Statement adalah kalimat yang pasti benar atau pasti salah

Logika proposisi hanya bekerja dengan statement, yang diberi nama p, q, r.

Notes 3️⃣ · Truth table

Truth table mencoba semua kombinasi, dari sub-ekspresi terdalam ke luar

Truth table berisi nilai ekspresi untuk semua kombinasi nilai variabelnya.

  1. Baris: n variabel menghasilkan 2ⁿ baris.
  2. Kolom variabel: pola TTFF untuk p, TFTF untuk q. Variabel berikutnya berganti dua kali lebih sering.
  3. Satu kolom per sub-ekspresi, supaya setiap langkah bisa dicek.
pq~qp ∧ ~q

Notes 4️⃣ · Urutan operasi

Tanpa kurung, ~ dikerjakan dulu dan → ↔ paling akhir

Seperti × sebelum + di aritmetika, urutan ini disebut precedence.

UrutanOperatorContoh
1~~p ∧ q artinya (~p) ∧ q, bukan ~(p ∧ q)
2∧ ∨ ⊕ (setingkat)p ∧ q ∨ r ambigu, jadi wajib diberi kurung
3→ ↔ (setingkat)p ∨ q → r artinya (p ∨ q) → r

Kalau ragu, pakai kurung. Kurung tambahan tidak pernah membuat ekspresi salah.

Notes 5️⃣ · Logical equivalence

De Morgan: negasi masuk ke kurung, lalu ∧ dan ∨ bertukar

Dua ekspresi ekuivalen (P ≡ Q) kalau nilainya sama di setiap baris truth table.

pq~(p ∧ q)~p ∨ ~q~p ∧ ~q
TTFFF
TFTTF
FTTTF
FFTTT
  • ~(p ∧ q) ≡ ~p ∨ ~q dan ~(p ∨ q) ≡ ~p ∧ ~q.
  • ~p ∧ ~q beda di baris 2, dan satu baris beda sudah cukup sebagai bukti tidak ekuivalen.
  • Di C: !(x > 0 && x < 10) sama dengan x <= 0 || x >= 10.

Notes 6️⃣ · Tautology

Lihat kolom terakhir: semua T, semua F, atau campuran

Jenis ekspresi ditentukan oleh kolom terakhir truth table-nya.

Notes 8️⃣ · Conditional

p → q hanya salah kalau janjinya dilanggar

Anggap conditional sebagai janji: "Kalau kamu lulus (p), aku traktir (q)."

pqp → q
TTT
TFF
FTT
FFT
  • Baris F: lulus tapi tidak ditraktir, satu-satunya cara melanggar janji.
  • p F: janji tidak diuji, jadi T. Ini disebut vacuously true.
  • Negasi: ~(p → q) ≡ p ∧ ~q, karena negasi conditional bukan conditional.

Notes 9️⃣ · Contrapositive

Hanya contrapositive yang selalu ekuivalen dengan p → q

Contrapositive menukar dan menegasikan keduanya: ~q → ~p.

NamaBentukEkuivalen dengan p → q?
Contrapositive~q → ~pYa
Converseq → pTidak
Inverse~p → ~qTidak (tapi ekuivalen dengan converse)

"Jika hujan, jalan basah" ekuivalen dengan "Jika jalan tidak basah, maka tidak hujan". Tapi jalan basah tidak berarti hujan, karena jalan bisa basah karena disiram.

Notes 10 · Biconditional

"p only if q" artinya p → q, bukan sebaliknya

Biconditional p ↔ q sama dengan (p → q) ∧ (q → p): benar ke dua arah.

KalimatSimbol
p if qq → p
p only if qp → q
p if and only if qp ↔ q

"Kamu lulus hanya jika mengerjakan tugas": kalau lulus, pasti mengerjakan tugas. Mengerjakan tugas tidak menjamin lulus.

Notes 11 · Syarat cukup dan perlu

Syarat cukup menjamin hasil, syarat perlu wajib ada

Syarat cukup menjamin hasilnya. Syarat perlu tidak menjamin, tapi tanpanya hasil tidak mungkin terjadi.

KalimatBentuk
r adalah sufficient condition untuk sr → s
r adalah necessary condition untuk ss → r ≡ ~r → ~s
r necessary and sufficient untuk sr ↔ s

"Lulus only if kehadiran 75%": kehadiran 75% adalah syarat perlu. Wajib ada, tapi tidak menjamin lulus.

Ringkasan

Semua hukum di materi ini bisa dicek dengan truth table, jadi pahami cara mengeceknya.

  • Statement bernilai T atau F. Connective punya padanan di C.
  • Truth table: 2ⁿ baris, satu kolom per sub-ekspresi.
  • Ekuivalen = sama di semua baris. De Morgan membalik ∧ dan ∨.
  • p → q hanya F saat p T dan q F. Negasinya p ∧ ~q. Contrapositive ekuivalen, converse dan inverse tidak.
  • Only if dan syarat perlu: panahnya menunjuk ke syarat.

Soal

Kerjakan dulu, lalu cek jawabannya di slide berikutnya.

  1. Tulis negasi "Jika hujan, maka jalan basah".
  2. Apakah p → (q → r) ekuivalen dengan (p → q) → r?
  3. "Jika n habis dibagi 4, maka n genap." Mana yang benar: contrapositive, converse, inverse?
  4. "Lulus ujian akhir adalah syarat perlu untuk lulus mata kuliah." Tulis sebagai if-then.
  5. Sederhanakan ~(p ∨ ~q) ∨ (~p ∧ ~q).

Jawaban

Pembahasan lengkap ada di notes (nomor section di kurung).

  1. "Hujan dan jalan tidak basah" (8️⃣).
  2. Tidak. Bukti: p = F, q = T, r = F membuat kiri T dan kanan F (8️⃣).
  3. Hanya contrapositive. Converse dan inverse salah karena n = 2 (9️⃣).
  4. "Jika lulus mata kuliah, maka lulus ujian akhir" (11).
  5. ~p, lewat De Morgan, distributive, negation, identity (7️⃣).
