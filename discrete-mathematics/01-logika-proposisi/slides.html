Logika proposisi

Discrete mathematics · statement, connective, truth table, dan logical equivalence.

Statement: benar atau salah, tidak keduanya

Logika proposisi hanya bekerja dengan statement: kalimat yang nilainya pasti benar (T) atau pasti salah (F).

KalimatStatement?
2 + 2 = 4Ya, nilainya T
Jakarta ibu kota JepangYa, nilainya F
x + 1 = 5Bukan: nilainya bergantung pada x
Tutup pintunya!Bukan: perintah tidak bisa benar atau salah
  • Statement diberi nama dengan huruf: p, q, r.
  • Beberapa statement bisa digabung dengan connective (∧, ∨, →, …) menjadi compound statement.
  • Nilai compound statement hanya bergantung pada nilai p, q, dan r.

Enam connective dan padanannya di C

Connective menggabungkan statement. Hampir semuanya sudah kamu pakai di kondisi if.

Membuat truth table

Truth table menghitung nilai sebuah ekspresi untuk semua kombinasi nilai variabelnya. Kerjakan dari dalam ke luar.

  1. n variabel menghasilkan 2ⁿ baris.
  2. Isi kolom variabel dengan pola T/F. Kolom pertama berganti di tengah tabel, kolom berikutnya berganti dua kali lebih sering, dan kolom terakhir berganti setiap baris.
  3. Buat satu kolom untuk setiap sub-ekspresi, dari yang paling dalam.
  4. Kolom terakhir adalah nilai ekspresi.
pq~qp ∧ ~q
TTFF
TFTT
FTFF
FFTF

Kolom terakhir semuanya T: tautology. Semuanya F: contradiction. Campuran: contingency.

Urutan operasi

Seperti × sebelum + di aritmetika, connective juga punya urutan. Tanpa kurung, operator di baris atas dikerjakan lebih dulu.

UrutanOperatorContoh
1~~p ∧ q artinya (~p) ∧ q, bukan ~(p ∧ q)
2∧ ∨ ⊕ (setingkat)p ∧ q ∨ r ambigu, jadi wajib diberi kurung
3→ ↔ (setingkat)p ∨ q → r artinya (p ∨ q) → r

Kalau ragu, pakai kurung. Kurung tambahan tidak pernah membuat ekspresi salah.

Logical equivalence dan De Morgan

Dua ekspresi ekuivalen (P ≡ Q) jika kolom terakhir truth table-nya sama di setiap baris. Artinya, keduanya bisa saling menggantikan.

~(p ∧ q) ≡ ~p ∨ ~q
~(p ∨ q) ≡ ~p ∧ ~q

De Morgan's law: saat negasi masuk ke dalam kurung, setiap variabel dinegasikan, dan ∧ dan ∨ bertukar.

Contoh di C:

!(x > 0 && x < 10)
≡ x <= 0 || x >= 10

"Tidak di antara 0 dan 10" sama dengan "≤ 0 atau ≥ 10".

Hukum untuk menyederhanakan ekspresi

Setiap hukum di bawah adalah logical equivalence yang sudah terbukti. Pakai untuk menyederhanakan ekspresi tanpa membuat truth table.

HukumBentuk
Commutative, associativep ∧ q ≡ q ∧ p, (p ∨ q) ∨ r ≡ p ∨ (q ∨ r)
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
Negation, double negationp ∨ ~p ≡ t, p ∧ ~p ≡ c, ~(~p) ≡ p
Identity, universal boundp ∧ t ≡ p, p ∨ t ≡ t
Absorptionp ∨ (p ∧ q) ≡ p
Conditionalp → q ≡ ~p ∨ q, ~(p → q) ≡ p ∧ ~q

t = tautology (selalu T), c = contradiction (selalu F). Contoh penyederhanaan langkah demi langkah ada di notes.

Conditional: anggap sebagai janji

p → q sering terasa aneh di baris p = F. Cara termudah memahaminya: anggap p → q sebagai janji.

pqp → q
TTT
TFF
FTT
FFT

Janji: "Kalau kamu lulus (p), aku traktir (q)."

  • Janji hanya dilanggar kalau kamu lulus tapi tidak ditraktir. Itu satu-satunya baris F.
  • Kalau kamu tidak lulus, janjinya tidak diuji. Janji tidak dilanggar, jadi nilainya T. Ini disebut vacuously true.

Contrapositive, converse, inverse

Dari satu conditional p → q bisa dibuat tiga variasi. Hanya contrapositive yang nilainya selalu sama dengan aslinya.

NamaBentukEkuivalen dengan p → q?
Contrapositive~q → ~pYa
Converseq → pTidak
Inverse~p → ~qTidak (tapi inverse ekuivalen dengan converse)

Contoh: "Jika hujan, jalan basah" ekuivalen dengan "Jika jalan tidak basah, maka tidak hujan". Tapi jalan basah tidak berarti hujan, karena jalan bisa basah karena disiram.

Biconditional, "only if", necessary dan sufficient

Kalimat sehari-hari punya banyak cara menulis conditional. Arah panahnya sering tertukar, jadi pakai tabel ini.

KalimatSimbol
p if qq → p
p only if qp → q
p if and only if qp ↔ q, sama dengan (p → q) ∧ (q → p)
p adalah sufficient condition untuk qp → q
p adalah necessary condition untuk qq → p

Contoh: "Lulus only if kehadiran 75%". Kehadiran 75% adalah syarat wajib (necessary), tapi tidak menjamin lulus.

Ringkasan

  • Statement bernilai T atau F. Connective menggabungkan statement, dan semuanya punya padanan di C.
  • Truth table berisi 2ⁿ baris, dengan satu kolom untuk setiap sub-ekspresi.
  • Dua ekspresi ekuivalen jika kolom terakhirnya sama. Yang paling sering dipakai: De Morgan dan p → q ≡ ~p ∨ q.
  • p → q hanya F saat p T dan q F. Contrapositive ekuivalen dengan aslinya, converse dan inverse tidak.
