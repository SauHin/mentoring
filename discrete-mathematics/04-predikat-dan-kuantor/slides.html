Predikat dan kuantor

Discrete mathematics · ∀ adalah AND besar, ∃ adalah OR besar

Predicate: kalimat dengan variabel

P(x) = "x² > x", domain ℝ

xP(x)
24 > 2 → T
1/21/4 > 1/2 → F
  • P(x) baru menjadi statement kalau x diisi atau diberi kuantor.
  • Truth set = semua x yang membuat P(x) T.
  • Truth set bergantung pada domain.

∀x ∈ ℝ, x² ≥ x salah (x = 1/2). ∃m ∈ ℤ, m² = m benar (witness m = 1).

∀ = AND besar, ∃ = OR besar = loop

// ∀: cari satu yang gagal
int semua = 1;
for (i = 0; i < n; i++)
    if (!P(D[i])) { semua = 0; break; }
// ∃: cari satu yang berhasil
int ada = 0;
for (i = 0; i < n; i++)
    if (P(D[i])) { ada = 1; break; }

∀x P(x) ≡ P(x₁) ∧ P(x₂) ∧ … dan ∃x P(x) ≡ P(x₁) ∨ P(x₂) ∨ …

Negasi: balik kuantor, negasikan predikat

~(∀x, P(x))        ≡  ∃x, ~P(x)
~(∃x, P(x))        ≡  ∀x, ~P(x)
~(∀x, P(x) → Q(x)) ≡  ∃x, P(x) ∧ ~Q(x)

Kafetaria

Uta: green salad, spaghetti, pie, milk · Tim: fruit salad, fish, pie, cake, milk, coffee · Yuen: spaghetti, fish, pie, soda

Ringkasan

  • ∀ = AND besar (satu counterexample cukup untuk menyangkal). ∃ = OR besar (satu witness cukup).
  • ∀ berpasangan dengan →, ∃ berpasangan dengan ∧.
  • Negasi: balik setiap kuantor, lalu negasikan predikatnya.
  • Urutan dua kuantor penting: ∀x ∃y ≠ ∃y ∀x.
